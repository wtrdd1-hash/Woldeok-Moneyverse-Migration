## 한국어 문서 이동 규칙

1. 일반 프로젝트 문서는 한국어 대응 문서가 있으면 반드시 `*.ko.md`로 이동합니다.
2. `Planning`은 **기획서**, `Architecture`는 **아키텍처**, `Features`는 **기능**, `Operations`는 **운영**, `Release / Worklog`는 **릴리스 / 작업 기록**으로 표시합니다.
3. 영어 문서는 명시적으로 `English` 또는 `영문 원문`을 선택한 경우에만 이동합니다.
4. 한국어 탐색 중 일반 문서 링크가 영문 `.md`로 연결되지 않도록 유지합니다.
