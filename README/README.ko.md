## 한국어 문서 이동 규칙

1. 한국어 페이지의 프로젝트 문서 링크는 가능한 경우 반드시 `*.ko.md`로 연결합니다.
2. `Planning`은 한국어 페이지에서 **기획서**로 표시합니다.
3. `Architecture`, `Features`, `Operations`, `Release / Worklog`는 각각 **아키텍처**, **기능**, **운영**, **릴리스 / 작업 기록**으로 표시합니다.
4. 영어 원문은 별도로 유지하지만 한국어 문서 탐색 중 자동으로 영문 문서로 이동시키지 않습니다.
5. 전체 한국어 문서 목록은 [한국어 문서 색인](../docs/INDEX.ko.md)을 기준으로 합니다.

문서 이동 정비 버전: **v2026.09.13.15**
