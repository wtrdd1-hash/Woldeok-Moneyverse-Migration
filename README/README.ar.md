# Woldeok Moneyverse — الدليل العربي

[← README الرئيسي](../README.md) · [سجل التغييرات](../docs/changelog/CHANGELOG.ar.md) · [فهرس الوثائق](../docs/INDEX.md)

Woldeok Moneyverse منصة اقتصاد افتراضي للمجتمع مبنية باستخدام **Next.js وNestJS وPostgreSQL**. ‏WLD والأسهم الافتراضية وألعاب الكازينو والمكافآت كلها بيانات داخل الخدمة وليست أموالاً أو استثمارات أو مقامرة حقيقية.

## الوظائف الرئيسية
- المهن والمهام المتكررة ونقاط الخبرة؛
- المهام اليومية والتقدم؛
- محفظة WLD وسجل المعاملات؛
- المتجر والمخزون؛
- الأسهم والشركات الافتراضية؛
- الإيداع والفائدة والائتمان والسندات الافتراضية؛
- ألعاب كازينو افتراضية بنتيجة يحددها الخادم؛
- أدوات الإدارة والتشغيل.

تتم عمليات الاقتصاد الحساسة عبر دوال PostgreSQL `SECURITY DEFINER` التي تتحقق من المستخدم والسياسات والمفاتيح المتكررة وسلامة السجل.

تُنقل مبالغ WLD كسلاسل أعداد صحيحة دقيقة لتجنب فقدان الدقة في JavaScript.

الحد الأساسي للكازينو: RTP بنسبة 95%، من 10 إلى 200 WLD لكل لعبة، 2,000 WLD إجمالي رهان يومي و1,000 WLD خسارة يومية فعلية. يمكن للمستخدم فرض حدود أشد.
