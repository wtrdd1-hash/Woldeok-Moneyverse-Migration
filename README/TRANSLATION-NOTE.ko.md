# 한국어 README 번역 정책

`README/README.auto.ko.md`는 루트 `README.md`를 기준으로 만든 한국어 번역본입니다.

## 이미지 번역 범위

README에 삽입된 스크린샷의 **섹션 제목, 표 제목, 이미지 대체텍스트(alt), 주변 설명**을 한국어로 제공합니다.

이미지 파일 자체(`docs/images/showcase/*.png`)는 실제 운영 화면을 기록한 원본 증거 자료이므로 번역 과정에서 수정하지 않습니다. 이렇게 하면 번역 때문에 실제 서비스 화면이 변조되거나 원본과 번역본의 스크린샷 버전이 달라지는 문제를 피할 수 있습니다.

## 현재 연결된 이미지

- `home-desktop.png` — 실제 운영 홈 화면
- `guide-desktop.png` — 서비스 가이드 화면
- `casino-desktop.png` — 가상 카지노 화면
- `status-desktop.png` — 서비스 상태 화면
- `home-mobile.png` — 모바일 홈 화면
- `home-tablet.png` — 태블릿 홈 화면
- `casino-mobile.png` — 모바일 카지노 화면
