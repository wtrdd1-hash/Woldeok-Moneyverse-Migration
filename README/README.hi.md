# Woldeok Moneyverse — हिन्दी गाइड

[← मुख्य README](../README.md) · [परिवर्तन लॉग](../docs/changelog/CHANGELOG.hi.md) · [दस्तावेज़ सूची](../docs/INDEX.md)

Woldeok Moneyverse एक समुदाय आधारित वर्चुअल इकॉनमी प्लेटफ़ॉर्म है जो **Next.js, NestJS और PostgreSQL** पर बना है। WLD, वर्चुअल स्टॉक, कैसीनो खेल और पुरस्कार केवल सेवा के अंदर के वर्चुअल डेटा हैं; वे वास्तविक पैसा या निवेश/जुआ उत्पाद नहीं हैं।

## प्रमुख सुविधाएँ
- करियर, दोहराए जाने वाले कार्य और EXP;
- क्वेस्ट और प्रोग्रेशन;
- WLD वॉलेट और लेजर;
- शॉप और इन्वेंटरी;
- वर्चुअल स्टॉक और बिज़नेस;
- बैंक, ब्याज, क्रेडिट और वर्चुअल बॉन्ड;
- सर्वर द्वारा तय किए गए कैसीनो मिनीगेम;
- एडमिन संचालन उपकरण।

महत्वपूर्ण आर्थिक लिखावट PostgreSQL `SECURITY DEFINER` फ़ंक्शनों से होती है, जहाँ उपयोगकर्ता, नीति, idempotency और ledger consistency जाँची जाती है।

WLD राशि API में सटीक integer string के रूप में रहती है ताकि JavaScript precision loss न हो।

वर्तमान कैसीनो आधार: 95% RTP, प्रति खेल 10–200 WLD, दैनिक कुल stake 2,000 WLD और दैनिक realized loss 1,000 WLD। सदस्य इससे कड़े self-limits लगा सकते हैं।
