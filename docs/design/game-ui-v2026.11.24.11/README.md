## 🎮 Core Design Standards Applied

1. **Elimination of Artificial Purple Gradients (`anti-ai-frontend-craftsmanship`)**:
   - Neutral graphite & deep navy (`#0d1117`, `#161b22`) surface elevations.
   - Warm gold (`#f59e0b`) and emerald (`#10b981`) high-contrast accents.
2. **100% SVG Vector Graphics (`interactive-minigame-web-engine`)**:
   - Lucide SVG vector icons exclusively at 1.75px stroke width, eliminating emoji rendering glitches across OS platforms.
3. **Fully Open Guest Browsing Mode**:
   - Non-authenticated visitors can view all 180 game, quest, shop, and exchange pages with full UI rendering.
   - Login prompts trigger only upon stateful actions (betting, claiming, trading).
4. **High-Contrast Monospace Numbers (`font-mono tabular-nums`)**:
   - Fixed alignment and zero layout shift for balances, multipliers, orderbook depths, and timestamps.
