1. 모든 UI 수정 전 [통합 기획 마스터](../planning/INTEGRATED_PLANNING_MASTER.md), [UI/UX 단일 참조 문서](../UI_UX_SINGLE_REFERENCE.md) 및 본 권위 문서를 필독하십시오.
2. [공식 180개 갤러리](game-ui-v2026.11.24.11/README.ko.md) 및 [매니페스트](CURRENT_UI_DESIGN_MANIFEST.json)에서 대상 페이지를 확인하십시오. **오직 신규 v11 PNG만을 유일한 활성 비주얼 참조로 사용**해야 합니다.
3. Stake, Roobet, Linear 수준의 다크 게이밍 & 네오 핀테크 크래프트맨십을 준용하며, 보라색 인위적 그라데이션을 배제하고 흑연/딥 네이비 표면과 웜 골드/에메랄드 악센트를 적용합니다.
4. 비로그인 방문자도 180개 전 화면을 에러나 튕김 없이 탐색할 수 있는 **완전 개방 게스트 모드**를 준수해야 합니다.
5. 모든 금융/원장/게임 수치는 `font-mono tabular-nums` 고대비 타이포그래피와 100% Lucide SVG 벡터 아이콘으로 렌더링해야 합니다.
