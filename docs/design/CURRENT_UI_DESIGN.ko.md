# 현행 UI 디자인 권위 — G2 길드 원장 단말기

**권위: v2026.11.27.PLAN-AUDIT.2.** [English](CURRENT_UI_DESIGN.md). 2026-11-27 사용자 확인: 비관리자 관리자 접근 차단. G2는 기존 기록상 최신 승인 디자인(2026-11-24). 문서·검증 도구 정합성 정리이며 런타임 인증 아님.

## 현행 구현 규칙

1. 작업 시작·중간에 [문서 권위](../DOCUMENT_AUTHORITY.ko.md), [통합 기획](../planning/INTEGRATED_PLANNING_MASTER.ko.md), [UI/UX 통합 기준](../UI_UX_SINGLE_REFERENCE.ko.md), [매니페스트](CURRENT_UI_DESIGN_MANIFEST.json)를 읽는다.
2. [G2 시각 규칙](game-ui-v2026.11.24.G2/README.ko.md)과 [180경로 시안](game-ui-v2026.11.24.G2/routes/README.md)만 현행 시각 기준으로 사용한다. 유형 기반 예시로 경로별 고유 기능 구현 또는 개별 미술 승인 증거가 아니다. 각 경로 업무 요구와 대조한다. 핵심 13개 시안의 원장 띠(실제 API만), 6px 헤어라인 패널, 바이올렛 행동색, 회원 본인 잔액만 금색/Orbitron, 고정폭 숫자, 그룹 메뉴, GM은 관리자만. 실제 파비콘만 사용.
3. 신규 웹 화면은 Next.js/React/TypeScript/Tailwind 및 동일 출처 서버 전용 BFF. Spring Boot가 인증·권한·세션·업무 API, PostgreSQL 제한 함수가 원장을 담당한다. 기존 Spring MVC/Thymeleaf/정적 화면은 검증된 교체까지 유지한다. 정상 기능, 실데이터, EN 기본·KO 두 번째(JA/ZH/VI 지원), 모바일/PC 접근성 및 보안 규정 유지.
4. **관리자 접근 기본 차단.** 비로그인·일반 회원에게 관리자 메뉴, 대시보드, 보호 HTML·데이터·API·행위·캐시/RSC 응답·소켓 구독·검색 바로가기를 제공하지 않는다. BFF·Spring API·해당 소켓/엣지 경로 서버 권한 검사 필수이며 CSS 숨김으로 대체 금지. 미인증 보호 요청은 적절한 로그인/401, 일반 회원은 403(정책상 존재 비공개 404 가능); 보호 페이로드 반환 금지. 게스트는 승인된 공개 안전 콘텐츠만 탐색한다. 180개 시안이 180개 공개 경로를 뜻하지 않는다. 로그인만으로 관리자 권한 부여 금지.
5. 경로×역할×언어×뷰포트 QA, 직접 접근/부정 테스트, 실제 데이터 및 정확 후보 Test 후 별도 승인 무중단 운영 승격. 합성 잔액·시간·성공 금지. 이미지는 기능 인증 아님.

## 이전 시안 보관

G1, v2026.11.24.11(v11), v2026.11.23.10(v10), v2026.11.23.8(v8), v2026.11.18.12(11월18일)은 이력 전용이며 구현 대체 자료로 사용 금지. 원본 파일·날짜별 기록 보존. 과거 Spring 단독 프론트엔드 및 전 경로 게스트 개방 지시(자동 작업 지시 포함)는 폐기된 지시다. 변경되지 않은 업무·보안 조건 유지.
