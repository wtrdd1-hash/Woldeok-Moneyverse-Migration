# 현행 UI 디자인 단일 기준 — 작업 AI용

**기준 정리 버전:** v2026.11.24.1 (2026-11-24 KST)

**이미지 기준 버전:** v2026.11.23.10 (11월 23일 수정본 180개)

**범위:** PC·모바일 반응형 웹 전체(비회원·회원·관리자)

**상태:** 참조 이미지 선택 기준 확정. 이미지 파일 QA 통과, 180개 개별 시각 승인과 실제 서버 기능 수용시험은 미완료.

## GPT·Gemini 등 모든 코딩 AI의 필수 절차

1. 작업 전 [통합 기획서](../planning/INTEGRATED_PLANNING_MASTER.ko.md), [UI/UX 단일 기준](../UI_UX_SINGLE_REFERENCE.ko.md), 이 문서를 읽는다.
2. [현행 v10 갤러리](game-ui-v2026.11.23.10/README.ko.md) 또는 [기계 판독용 180경로 목록](CURRENT_UI_DESIGN_MANIFEST.json)에서 해당 화면 이미지를 선택한다. **v10만 레이아웃·색상·배치·정보구조의 현행 시각 기준**이다.
3. v10 파일이 없거나 깨졌거나 기획과 충돌하면 QA 이슈를 기록한다. **v8·11월 18일 시안으로 임의 대체하거나 이전 공통 카드를 복제하지 않는다.**
4. 기능·보안·접근성·다국어·Spring 웹 아키텍처·실제 API는 통합 기획서와 검증된 코드가 우선이다. 시안에 있는 수치로 잔액·금리·게임 시간·거래 결과를 만들지 않는다.
5. 현재 실제 파비콘(spring-backend/src/main/resources/static/assets/mv39/favicon.ico)을 로고로 사용한다. 관리자 메뉴는 서버 권한 검증을 거친 관리자에게만 출력한다. 영문 정본·한국어 번역을 함께 유지한다.
6. 사용자가 새 시안을 명시적으로 지시한 경우에만 디자인 기준 버전을 변경한다. 그때 이 문서·매니페스트·영/한 갤러리·통합 기준서·작업 기록을 동시에 갱신하고 전체 180경로를 검증한다.

## 완료 여부 및 운영 안전

- v10 이미지 180개 파일 QA와 경로 매핑 통과. 파일별 SHA-256 매니페스트 고정. 이전 이미지 검사에서 실제 파비콘 픽셀 표본 검사 시행.
- 화면별 최종 디자인 승인, 실제 180개 페이지 구현, 모바일·5언어 시각 QA, 은행/원장·인증·관리자 권한 E2E, Test와 운영 승격은 **별도 미완료**.
- 이전 이미지 360개는 이력과 링크 보존을 위해 삭제하지 않는다. 보관이란 **코딩 AI의 현행 디자인 입력 후보에서 제외**한다는 뜻이다.
- 2026-11-24 확인 당시 v10은 아직 origin/main에 없음. 이 작업도 별도 브랜치에서 심사 후 통합하며 운영 배포를 의미하지 않는다.
