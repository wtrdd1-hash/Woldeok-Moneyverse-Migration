## 기존 화면에서 개선한 점

거대한 소개 영역을 반복하는 대신 금융·관리자 화면의 주요 작업을 먼저 배치합니다. 클럽 생성에는 클럽 정보, 사진 등록에는 이미지·대체 텍스트, 주식에는 캔들·거래량·주문 검토, 거래 상세에는 금액·수수료·참조 번호를 배치합니다. 모바일에서는 입력·결과를 세로로 배치하고 표를 카드 목록으로 바꿉니다.

## 후속 구현 조건

버튼별 실제 API·역할·오류 계약을 확인하고 서버 데이터와 연결해야 합니다. 권한 거부·세션 만료·중복 요청·오류·빈 결과를 구현하고, 독립 Test에서 실제 기능을 검증한 뒤 별도 운영 승인을 받아야 합니다. 현재 PR은 디자인 산출물과 생성·검사 도구만 포함합니다.
