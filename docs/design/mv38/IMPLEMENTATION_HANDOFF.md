- Shared static CSS: `spring-backend/src/main/resources/static/assets/mv38/site.css`.
- Shared locale dictionary & manual preference: `.../assets/mv38/i18n.js`.
- Shared auth, fetch & page views: `.../assets/mv38/app.js`.

## Data & access
- Read-only public API: `/api/v1/stocks` (market), `/api/v1/shop/public-catalog` (catalog), `/api/v1/board` (posts).
- Member API only after `GET /api/v1/auth/session` returns signedIn/authenticated + user: `/api/v1/wallet/summary`, `/api/v1/stocks/portfolio`. Never set `X-User-Id` on the client. On session change/visibility restoration wipe previous member state before refetching; localStorage only contains language preference, never money.
- Backend `/api/v1/wallet/overview`, progression quest, support thread routes require actor/session ownership hardening, thus **not used as member-owned data**. Quest, private support and detailed wallet history remain honest unavailable states, not fabricated API successes. Write actions and money mutations deliberately not implemented.
- Hide raw server versions, API/DB internals, Treasury 100T, fake return percentages/online counts. Admin link is added only on verified signed-in administrator role; backend must independently enforce RBAC.

## Locale
- Existing project locales `en`, `ko`, `ja`, `zh`, `vi`, Auto option (browser `navigator.languages`). `wdmv_locale` cookie retains manual selection; localStorage preference tracks Auto/reset. Set `html.lang` and translate all shared UI/navigation, errors and aria labels. Currency WLD values are NEVER converted as side-effect of locale.
