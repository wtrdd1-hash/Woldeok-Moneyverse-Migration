# 회원 관리자 문의 한국시간 날짜 검색

로그인·동의 확인을 마친 회원은 **본인 최근 문의 100건**에서 마지막 메시지 날짜를 한국시간 시작일·종료일(양끝 포함, 최대 366일)로 검색할 수 있습니다. 결과는 최대 50건이며 제목·처리 상태·오래된 순서와 함께 사용할 수 있습니다. **전체 기간 문의 검색이 아닙니다.**

`GET /api/v1/support/threads?from=YYYY-MM-DD&to=YYYY-MM-DD`는 두 날짜를 모두 요구하며 잘못된 날짜·중복·역순을 거부합니다. 기존 소유자 범위 SQL 함수 결과만 필터링하고 신규 DB 마이그레이션이나 WLD 원장 변경은 없습니다. 웹은 접근 가능한 GET 양식을, Android app-api는 검증되지 않은 성공 응답 차단을 제공합니다. 개인정보 캐시·색인 금지 정책을 유지합니다.

**릴리스:** 후보 단계. 전체 CI·정확 SHA 격리 Test 인증 E2E·운영 실행 파일 출처·독립 롤백 확인 전에는 병합과 배포를 금지합니다.
