# 가상 주식

[English](stocks.md) | **한국어** | [문서 색인](../INDEX.ko.md)

주식 시장은 PostgreSQL 기반 가격 이력, 회원 포트폴리오, 제한된 시장 변동 로직으로 구동되는 서비스 내부 가상 시장입니다.

## 주요 개념
- 가상 주식 카탈로그
- 현재 가격과 과거 캔들
- 회원 매수/매도 흐름
- 포트폴리오 가치
- 시장 이벤트/변동 로직
- 원장 기반 WLD 정산

## 가격 변동
시장 변동은 의도적으로 범위가 제한됩니다. 기본 변동성이나 장중 이동 한도 같은 매개변수는 제한 없는 랜덤 워크가 우발적인 무한 가치 생성기가 되는 것을 방지합니다. 실시간 시장 튜닝은 단순한 프론트엔드 상수가 아니라 경제 정책으로 취급해야 합니다.

## 정확한 값
주식 수량은 일반 정수일 수 있지만 WLD 가격/비용/수익은 정확한 정수 표현을 유지해야 합니다. UI 차트 비율은 제한된 숫자 계산을 사용할 수 있지만 실제 금액 값은 그렇게 처리하면 안 됩니다.

## 쓰기 경계
매수/매도 작업은 데이터베이스가 최종 권한을 가져야 하며 보유량, 사용 가능한 WLD, 원장 정산을 하나의 원자적 작업으로 검증해야 합니다.
