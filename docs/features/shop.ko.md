# 상점 및 인벤토리

[English](shop.md) | **한국어** | [문서 색인](../INDEX.ko.md)

카탈로그 상점은 WLD를 서비스 내부 가상 아이템과 수집 진행도로 전환합니다.

## 가격 권한
표시되는 실효 가격과 실제 구매 가격은 같은 서버/데이터베이스 규칙에서 나와야 합니다. 클라이언트가 제출한 가격은 최종 기준이 아닙니다.

마켓 세일 퀘스트 효과는 이 원칙의 예시입니다. 이벤트가 활성화된 날 대상 초보 아이템은 동일한 10% 할인 실효 가격을 표시하고 그 가격으로 결제됩니다.

## 재고 무결성
카탈로그 정책에는 기준/실효 가격, 활성/비활성 상태, 현재 재고, 한정 아이템의 최대 재고, 회원 소유/인벤토리 상태가 포함될 수 있습니다.

관리자 변경은 `moneyverse_app` 테이블을 직접 수정하는 대신 행위자 검증 데이터베이스 함수를 통해 처리합니다.

## 검증
데이터베이스 제약조건은 음수 재고나 설정된 최대치를 초과한 한정 재고처럼 잘못된 가격 또는 불가능한 재고 상태를 거부합니다.

## 관련 화면
- `/shop/catalog`
- 회원 인벤토리/컬렉션
- 퀘스트 및 성장

## 회원 카탈로그 가격순 정렬 (A2125 코드 후보, 운영 미적용)

로그인 회원은 `/shop/catalog`에서 기본순·낮은 가격순·높은 가격순을 선택할 수 있습니다.
`GET /api/v1/shop/catalog?sort=price_asc|price_desc`는 기존 회원별 PostgreSQL 조회
결과의 정수 문자열 가격을 서버에서 `BigInt`로 비교합니다. 동일 가격은 코드/ID로
안정 정렬하며, 정렬 값이 없으면 기존 순서를 유지하고 잘못된 값은 조회 전 400입니다.
Android `/app-api/v1/shop/catalog`에서도 같은 쿼리를 전달하며 오류 응답까지
`private, no-store`와 `noindex`를 적용합니다. 실제 결제 가격·재고는 구매 트랜잭션에서
다시 확인합니다. 신규 마이그레이션·가격 예약·WLD 변동은 없습니다. PR #1745는 운영 보류입니다.
