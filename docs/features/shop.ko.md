# 상점 및 인벤토리

[English](shop.md) | **한국어** | [문서 색인](../INDEX.ko.md)

카탈로그 상점은 WLD를 서비스 내부 가상 아이템과 수집 진행도로 전환합니다.

## 가격 권한
표시되는 실효 가격과 실제 구매 가격은 같은 서버/데이터베이스 규칙에서 나와야 합니다. 클라이언트가 제출한 가격은 최종 기준이 아닙니다.

마켓 세일 퀘스트 효과는 이 원칙의 예시입니다. 이벤트가 활성화된 날 대상 초보 아이템은 동일한 10% 할인 실효 가격을 표시하고 그 가격으로 결제됩니다.

## 재고 무결성
카탈로그 정책에는 기준/실효 가격, 활성/비활성 상태, 현재 재고, 한정 아이템의 최대 재고, 회원 소유/인벤토리 상태가 포함될 수 있습니다.

관리자 변경은 `moneyverse_app` 테이블을 직접 수정하는 대신 행위자 검증 데이터베이스 함수를 통해 처리합니다.

## 검증
데이터베이스 제약조건은 음수 재고나 설정된 최대치를 초과한 한정 재고처럼 잘못된 가격 또는 불가능한 재고 상태를 거부합니다.

## 관련 화면
- `/shop/catalog`
- 회원 인벤토리/컬렉션
- 퀘스트 및 성장

## 회원 보유 여부 필터 (A0425 후보·미배포)

로그인한 회원은 `/shop/catalog`에서 **전체 상품**, **보유 중**, **미보유**를 선택하고 검색어와 함께 사용할 수 있습니다. 회원 API `GET /api/v1/shop/catalog?ownership=all|owned|unowned`는 생략 시 전체를 반환하며, 잘못된 값은 비공개 DB 조회 전에 HTTP 400으로 거부합니다. PostgreSQL `shop_catalog_list_v2(actor)`가 인증된 회원의 `user_owned_quantity`를 직접 반환하므로 사용자 ID나 보유 수량을 클라이언트에서 지정하지 않습니다. 공개 카탈로그는 영향을 받지 않습니다. Android `/app-api/v1/shop/catalog?ownership=...`는 검색 조건을 전달하면서 응답을 비공개·캐시 금지·검색 제외로 처리합니다. 신규 마이그레이션·금융 원장 변경은 없으며, 운영 배포는 승인 게이트 충족 전까지 보류합니다.
