# 가상 카지노

[English](casino.md) | **한국어** | [문서 색인](../INDEX.ko.md)

카지노는 **서비스 내부 WLD만 사용하는 가상 엔터테인먼트 기능**입니다. 실물 화폐 도박 서비스가 아니며 현금화 기능이 없습니다.

## 권한 모델
브라우저는 게임 선택과 가상 베팅액만 제출합니다. 결과 결정, 정책/제한 적용, 원장 기록, 영수증 생성은 서버/데이터베이스가 담당합니다. 브라우저가 승리를 만들어 내거나 애니메이션으로 정산 결과를 추론해서는 안 됩니다.

## 공개된 핵심 게임 수학
| 게임 | 승리 확률 | 지급 배수 | 기준 RTP |
| --- | ---: | ---: | ---: |
| 동전 | 50% | 1.9× | 95% |
| 주사위 홀짝 | 50% | 1.9× | 95% |
| 주사위 숫자 | 1/6 | 5.7× | 95% |

작은 실제 플레이 표본과 별개로 분포 시험을 사용해 RNG/분포 계약을 검증합니다.

## 노출 정책
- 최소 베팅: **10 WLD**
- 1회 최대 베팅: **200 WLD**
- 일일 총 베팅: **2,000 WLD**
- 일일 실현 손실: **1,000 WLD**

회원의 자체 제한은 플랫폼 제한보다 더 엄격할 수 있습니다.

## 자체 제한 / 자기 배제
자체 제한값 0은 해당 제한이 설정되지 않았음을 뜻합니다. 시간 잠금은 사실상 자기 배제이며, 잠금 동안 플레이와 제한 변경이 만료 시점까지 차단됩니다. UI는 이를 단순한 설정 잠금처럼 표현하지 않고 명확히 설명해야 합니다.

## 테마 게임
슬롯, 하이/로우, 휠, 보물, 보석 화면은 서버가 결정한 게임 결과를 보여 주는 테마 UI입니다. 최종 화면은 실제 영수증 결과에서 정해집니다. 과거에는 서버가 패배를 반환했는데 `777`이 표시될 수 있었고, 최종 애니메이션이 저장 결과와 모순되지 않도록 수정되었습니다.

## 금액 타입 안전성
카지노 영수증의 WLD는 기준 정수 문자열입니다. 프론트엔드는 정확한 정수 표현만 받아야 하며, 예상치 못한 숫자에 문자열 메서드를 호출하거나 안전하지 않은 JavaScript 실수로 조용히 반올림해서는 안 됩니다.

## 회원 기록
카지노 기록은 작은 일반 지갑 피드를 필터링하는 대신 행위자 범위 전용 읽기 모델을 사용합니다. 다른 지갑 거래가 많아도 최근 게임 기록을 볼 수 있습니다.

## UX 상태
UI는 승리, 패배, 무승부/중립, 요청/시스템 오류를 구분합니다. 처리된 요청이 자동으로 승리를 의미하지 않습니다.
