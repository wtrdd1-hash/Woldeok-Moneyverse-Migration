# 은행, 신용 및 가상 채권

[English](banking.md) | **한국어** | [문서 색인](../INDEX.ko.md)

은행 하위 시스템은 가상 예금, 예금 이자, 신용등급 기반 대출, 가상 채권을 관리합니다. 모든 값은 서비스 내부 WLD 기준입니다.

## 예금 이자
표시되는 이자와 실제 정산 이자는 같은 서버 측 금리 계약에서 나와야 합니다.

### 무결성 규칙
- 입금/출금으로 잔액이 변경되면 이자 누적 시계를 재설정합니다.
- 1 WLD 미만 이자는 무료 최소 지급으로 올림하지 않고 누적합니다.
- 하나의 수동 이자 청구에는 하나의 멱등성 키를 사용합니다.
- 같은 키를 재생하면 다시 지급하지 않고 이전 정산 결과를 반환합니다.
- 애플리케이션 코드는 내부 예금 이자 추적 테이블을 직접 변경할 수 없습니다.

이 규칙은 새로 예치한 금액에 과거 경과 시간을 소급 적용하는 문제와, 최소 1 WLD를 반복 청구하는 문제를 막습니다.

## 대출
새 대출은 우회 경로가 아니라 기존 신용등급 정책을 사용합니다. 등급별로 대출 한도, 총 이율, 만기 기간, 상환 규칙을 정의할 수 있습니다. 기존 대출은 발급 당시 계약을 유지하며 소프트웨어 릴리스가 과거 채무 조건을 조용히 다시 쓰지 않습니다.

## 가상 채권
채권 구매/만기는 가상 경제 계약입니다. 표시되는 예상 정산값은 정확한 정수 연산을 사용하고 데이터베이스 계약과 일치해야 합니다. 기존 채권도 이후 정책 릴리스로 소급 변경하지 않습니다.

## 금액 표현
잔액, 대출, 채권, 이자는 API 전체에서 기준 정수 문자열을 유지합니다. 정확한 연산이 필요한 코드에서만 `BigInt`를 사용합니다.
