# 관리자 제어 센터

[English](admin-control-center.md) | **한국어** | [문서 색인](../INDEX.ko.md)

관리자 화면은 운영/경제 읽기 모델과 범위가 엄격히 제한된 제어 함수를 제공합니다. 회원에게 적용되는 데이터베이스 보안 규칙을 우회하는 통로가 아닙니다.

## 원칙
1. HTTP/관리자 UI 권한 검사는 필요하지만 그것만으로 충분하지 않습니다.
2. 민감한 작업에서는 데이터베이스 함수도 실제 관리자/운영자를 검증합니다.
3. 경제 금액은 API와 UI 전체에서 문자열/BigInt 안전성을 유지합니다.
4. 호출자가 관리자라는 이유만으로 애플리케이션 역할에 보호 경제 테이블 직접 쓰기 권한을 부여하지 않습니다.

## 상점 관리
카탈로그 읽기/수정은 관리자 범위 함수를 사용합니다. 가격, 재고, 활성 상태 변경에는 운영자/최고관리자 경계와 데이터베이스 검증이 적용됩니다.

## 경제/회원 조회
읽기 모델은 실제 데이터베이스 계약을 반환합니다. 프론트엔드 필드명이 반환 필드와 일치해야 하며, 오래된 UI 스키마는 실제 데이터가 정상이어도 0/undefined를 표시할 수 있습니다.

## 자산 정정
권한이 필요한 정정 경로는 지원 자산 유형과 변경 방향을 명확히 해야 합니다. 데이터베이스가 안전하게 지원하지 않는 대출 변경을 UI 옵션으로 제공해서는 안 됩니다.

## 거시 제어
인증되지 않거나 행위자가 없는 애플리케이션 호출 가능 함수보다 행위자 범위의 거시 제어 함수를 우선합니다. 최종 권한 결정을 쿼리/제어 로직 가까이에 둡니다.
