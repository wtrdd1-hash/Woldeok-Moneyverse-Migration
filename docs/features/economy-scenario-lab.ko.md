# 경제 시나리오 실험실

> 후보 버전: `v2026.09.12.14`
> 범위: P3 읽기 전용 시뮬레이션 1차 구현

## 목적

경제 시나리오 실험실은 P3 장기 확장의 첫 구현입니다. 인증된 관리자가 실제 잔액, 원장 전표, 정책 노브, DB 행, 운영 설정을 변경하지 않고 통화량 시나리오를 계산할 수 있습니다.

기준값은 관리자 경제 대시보드의 현재 M2, 최근 24시간 발행량, 최근 24시간 소각량입니다. 관리자는 발행/소각 흐름 변화율을 bp 단위로 입력하고 1~365일 기간을 선택합니다.

## 안전 경계

- 기존 관리자 세션/권한 Guard를 그대로 사용합니다.
- DB 쓰기와 신규 migration이 없습니다.
- WLD는 integer string을 유지하고 `BigInt`로 계산합니다. 권위 있는 금액을 JavaScript 부동소수점으로 변환하지 않습니다.
- 결과는 자동 추천이나 정책 제안이 아닌 단순 시뮬레이션입니다.
- 정책 적용, 원장, 잔액, 상점 가격, 이율, 보상, 한도를 변경하는 경로를 호출하지 않습니다.
- 단순 상수 흐름 계산이 0 아래로 내려가면 M2는 0에서 바닥 처리하고 모델 한계 플래그를 반환합니다.
- 90일 초과 장기 계산에는 모델 위험 경고를 표시합니다.

## API

`GET /api/v1/admin/economy/scenario-lab/preview`

입력 범위는 `days` 1~~365, `issuanceChangeBps`와 `sinkChangeBps` 각각 -10000~~50000이며 기본값은 30일/0bp/0bp입니다.

## UI

`/admin/economy/scenario-lab`에서 읽기 전용 GET 폼과 결과를 제공합니다. 기존 `/admin/economy`에서 진입할 수 있으며 관리자 콘솔 인증 경계와 `noindex` 정책을 유지합니다.

## 이후 단계

추천 또는 자동 정책 실행으로 확장하려면 제품 문구, 안전성, 데이터 품질, 운영 비용, 법적 검토, 권한, 감사, 롤백, 테스트 서버 검증을 별도로 통과해야 합니다. 시뮬레이션 결과만으로 경제 쓰기 작업을 실행해서는 안 됩니다.
