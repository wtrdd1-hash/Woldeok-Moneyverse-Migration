# 공개 게시판 — 사진 없는 글 찾기 (2026-11-02 A 18:25)

[English canonical](public-board-text-only.md) | **한국어 안내**

`/board`에서 **모든 글** 또는 **사진 없는 글만** 선택할 수 있습니다. `media=text`는 기존 제목 검색 `q`, 종목 `stock`과 함께 사용하며, **최근 공개 글 50건**에만 적용됩니다. 전체 과거 글을 검색하지 않습니다.

Nest 공개 API는 `media=text`만 허용하고 중복·알 수 없는 조건을 거절합니다. 기존 공개 조회 함수의 반환 결과에서 이미지 저장 키가 없는 글만 선택하며, 검증된 빈 결과에도 `filterApplied:'text'`를 반환합니다. 이미지가 섞이면 검증을 거부합니다. 신규 테이블 권한, 마이그레이션, 금융 데이터 변경은 없습니다.

웹은 검증된 빈 목록과 조회 실패를 구별하고 필터 검색을 색인하지 않습니다. Android App API는 필터 적용 표시, 최대 50건, UUID 중복 및 이미지 유무를 검증하며 근거 없는 HTTP 200을 503으로 거부합니다. 필터된 HEAD는 본문 검증이 불가능하므로 405를 반환합니다. 캐시 저장·검색 색인·Referrer 노출을 제한합니다.

**운영 보류:** 정확한 SHA의 전체 테스트, 실제 DB 최소 권한, 격리 Test 인증 E2E, 독립 복원, 운영 실행 출처와 릴리스 승인 전에는 병합·배포하지 않습니다. `media`를 제거하면 기존 전체 글 조회로 복귀할 수 있습니다.
