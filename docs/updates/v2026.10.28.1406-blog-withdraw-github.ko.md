# GitHub 업데이트 — v2026.10.28.1406 운영 블로그 공개 철회

사용자가 기존 블로그 글을 즉시 삭제하도록 지시했다. 운영 저장소 199건(기존 활성·미철회 198건, 기철회 1건)을 확인했고, 원본 접근 제한 백업 후 198건에 철회 상태·시각·사유를 기록했다. 공개 `/api/blog`는 HTTP 200 / 0건이며, 삭제한 기사 주소는 404, 4개 언어의 목록 페이지는 200/빈 목록이다. 블로그 사이트맵에는 개별 기사 주소가 없다. 앱 배포·금융 DB·원장 변경이나 릴리스 게이트 예외는 없다. 원본은 감사 및 안전한 복구를 위해 보관했고 영구 물리 삭제한 것은 아니다. 자동 발행은 임의 중지하지 않았으므로 향후 새 글이 나올 수 있다.
