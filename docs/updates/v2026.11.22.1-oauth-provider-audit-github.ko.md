## 변경 내역
- Google 로그인을 제거하라는 지시 없이 화면에서 사라졌고 Discord 로그인이 처리되지 않는다는 사용자 신고를 기록.
- 최초 Spring 인증 UI `ac12a17328`(11월 20일 14:32, Git 작성자 `wtrdd1-hash`), 통합 `2ac581b24f`, 후속 전면 수정 `88b70b90d7`(Git 작성자 `Hong Jong-hwan`) 구분. Git 작성자와 실제 작업 도구 실행자를 혼동하지 않음.
- Google OAuth 인가·콜백은 미완성인데 공급자 API는 사용 가능으로 표시하며, Spring UI에는 이용 불가 안내가 있고 기존 Next UI에는 Google·Discord 링크가 있다는 모순 확인.
- Git Nginx OAuth 전달 대상 `prod_node`와 현재 설치된 `prod_spring` 차이 및 MCP 변경 명령 시각 검증. 실제 사람 또는 AI의 인증된 신원, Discord 콜백 실패 단계는 미확정.
- 보안상 민감한 원본 증거는 비공개 미니PC 운영 기록에만 보존. GitHub에 비밀값·로그 본문·계정 데이터 없음.

## 테스트 / 운영
소스·기획서·Git 이력·로컬 HTML/API·감사 로그 메타데이터만 점검. HTTP 302는 실제 로그인 성공이 아니다. 공급자 실인증 E2E, CI 통과, 운영 배포 또는 DB 변경 없음. 타 작업자의 스테이징 파일 무변경. MCP 대용량 감사 백업/조회는 `Invalid string length`로 실패.
