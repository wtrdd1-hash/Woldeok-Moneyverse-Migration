# v2026.10.29.1501 — Treasury SWF fail-closed and truthful central-bank console

## Problem
A Production SWF liquidation raised SQLSTATE 42P08, but casting the conflicting text/numeric placeholder alone would permit an unbalanced treasury cash credit. The central-bank console also claimed fictitious supply, mint approvals and browser-local policy changes.

## Changes
- Block legacy manual liquidation before any SQL/Discord operation at both application layers; HTTP 503 with an explicit release-gate code and CSRF protection.
- Read the legacy central-bank backend state through an authenticated no-store BFF; label it non-persistent and non-authoritative instead of claiming actual WLD ledger settlement.
- Clearly show SWF rebalance and liquidation as unavailable pending atomic ledger settlement certification, including mobile-sized controls.
- Add RED/GREEN regression tests, bilingual internal and public change records.

## Release status
Source branch candidate; Production remains on v2026.10.29.1213 until the new exact source is tested and verified. This change does not enable Mint issuance or SWF liquidation. Actual financial writes require a future, durable, audited settlement implementation.
