# 개발 C v1261 — 주식 호가·체결 정보 출처 검증

- 기존 화면은 현재 가격으로 매수·매도 호가 잔량과 체결 수량을 임의 생성했고, 무작위 체결 알림도 표시했습니다. 실제 호가 원천이 없어 실거래 증빙으로 사용할 수 없습니다.
- NestJS는 검증된 호가 원천이 마련되기 전까지 503을 반환하며, Next.js는 200으로 오인하지 않고 private/no-store/noindex 정책으로 차단합니다.
- 웹은 최근 제공 가격만 구분 표시하고, 검증되지 않은 잔량·스프레드·체결 내역 및 가짜 체결 알림을 제거했습니다. 접근성·모바일 반응형을 유지합니다.
- 금융 원장·DB 스키마·운영 환경 변경 없음. 모든 필수 검증 완료 전 PR 병합·배포 금지.
