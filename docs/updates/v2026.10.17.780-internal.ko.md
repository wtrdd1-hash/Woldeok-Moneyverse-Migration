### 추가 수정
기존 주소에 /ja 접두사나 ?lang= 쿼리가 남으면 사용자 수동 선택/자동 감지로 변경해도 router.refresh가 기존 언어를 강제했음. 수동 선택 시 언어 주소 자체를 교체하고 자동 감지 선택 시 언어 접두사/쿼리를 제거하도록 수정. 관련 없는 검색어 보존 및 다국어 전용 복리 계산기 자동 초기화 시 실제 기본 계산기로 이동. React 라우터 상태 테스트 추가.

### 서버 화면 실측으로 발견한 추가 오류
