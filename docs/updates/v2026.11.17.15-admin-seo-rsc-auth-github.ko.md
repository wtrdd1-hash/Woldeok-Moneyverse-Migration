# v2026.11.17.15 — GitHub 업데이트: 관리자 SEO RSC 인증 호환
**수정:** 실제 페이지 전환은 유지하면서 내부 인증 JSON 요청에만 RSC 관련 헤더 제거.
**원인:** 인증 상태 API의 307 리다이렉트를 Nginx auth_request가 잘못된 응답으로 간주해 503 발생.
**보안:** 관리자 인증 우회 없음, 쿠키·Spring·DB·WLD 변경 없음, 롤백 경로 보장.
**테스트:** 분리 환경에서 RSC 500 재현 후 두 관리자 SEO 화면의 일반·RSC·사전 요청 모두 익명 401, 백엔드 200, 실제 UI 렌더 200 확인.
**상태:** 운영 반영 전; 이슈 #3238 및 한·영 작업 로그 참조.
