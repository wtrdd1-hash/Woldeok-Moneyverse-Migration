# 내부 변경 기록 — v2026.10.29.1501

## 장애 원인
- 운영 v1213 국부펀드 자금 회수 500 오류는 PostgreSQL 42P08 매개변수 text/numeric 충돌로 확인(13:51, 13:53 KST).
- 기존 회수 SQL은 검증된 복식부기 출금 기록 없이 국고 잔액만 직접 올릴 수 있다. 형변환만 고쳐 집행하면 원장 불일치 위험이 커진다.
- 중앙은행 화면은 고정 통화량·가상 조폐 배치를 표시하고 브라우저 상태만 수정한다. 기존 백엔드의 정책/조폐 메모리는 재시작 시 사라진다.

## 소스 변경
- 국부펀드 즉시 회수는 DB 연결 전에 명시적 503(SWF_LEDGER_SETTLEMENT_UNAVAILABLE) 반환. Next 게이트웨이에서도 차단하고 백엔드에 CSRF 가드를 추가한다.
- 중앙은행은 인증이 전달되는 읽기 전용 실제 백엔드 임시 API로 화면을 채운다. 원장 비영속 데이터를 공식 공시/승인으로 표현하지 않는다.
- 국부펀드 자동 구동/현금 환원 성공 오인 문구와 실행 버튼을 수정한다.

## 확인 상태
- 변경 전 실패 테스트(RED)를 확인하고 집중 SWF 테스트 9/9 통과. 프런트 테스트 및 빌드 진행 중.
- DB 마이그레이션·금융 쓰기·운영 변경은 아직 없음. 실제 승인·자동 복리 성장은 정식 영속 원장과 무결성 테스트를 갖춘 별도 작업이 필요하다.
