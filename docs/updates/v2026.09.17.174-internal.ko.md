# 내부 업데이트 v2026.09.17.174 — Debian 자동 백업 시스템

## 범위
- 폐기된 과거 Docker 호스트 절차 대신 현재 Debian/systemd 운영에 맞는 백업 경로를 추가했다.
- DB + 운영 사진 암호화 백업, 검증, 보존정책, 6시간 timer를 추가했다.
- 동일 filesystem 저장을 fail-closed하고 off-host DR은 명시적 P0로 유지했다.

## 증거
- DB 데이터/사진: `/dev/sdb1`; 백업 목적지: `/dev/sda1`.
- 동일 장치 negative test: PASS(백업 차단).
- 별도 장치 positive test: PASS; 약 9.4 MiB 암호화 archive가 SHA-256, 복호화, 내부 checksum, `pg_restore -l`, 사진 zstd integrity, format marker를 통과했다.

## 승격
브랜치 테스트/CI 후 root-only key, script, systemd unit을 설치한다. 즉시 1회 백업·검증 후 timer를 활성화하고 service/timer 증거를 기록한다. off-host immutable replication은 후속 P0다.
