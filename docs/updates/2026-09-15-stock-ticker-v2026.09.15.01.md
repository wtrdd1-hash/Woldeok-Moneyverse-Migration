# Stock Market Ticker Recovery — v2026.09.15.01

## Summary
Production stock prices stopped moving because `MARKET_TICKER_ENABLED` was absent from the backend process environment. The ticker factory therefore returned `null` and no automatic market ticks were scheduled.

## Production Recovery
- Added `MARKET_TICKER_ENABLED=true` to the production backend environment.
- Restarted the backend through its existing `Restart=always` systemd policy.
- Confirmed the backend logged `market ticker running`.
- Confirmed a live price changed from `9994` to `9999` within 3.5 seconds through `stock_live_prices()`.

## Code Hardening
- Production now enables the ticker by default when the flag is absent.
- `MARKET_TICKER_ENABLED=false` remains the explicit operator kill switch.
- Test and development environments remain opt-in.

## Verification
- `market-ticker.config.test.ts`: 3/3 passed.
- Backend TypeScript typecheck: passed.
- Backend build: passed.
