# v2026.09.28.478 — Superpowers 프로젝트 명령 강제

[English canonical](v2026.09.28.478.md) | **한국어**

- 모든 사용자 지시 Moneyverse 작업과 모든 예약/자동화 실행에 Superpowers 프레임워크를 명시적 작업 진입 규칙으로 적용했다.
- `skills/using-superpowers`를 먼저 실행하고, 이후 적용 가능한 Superpowers skill을 해당 행동 전에 실행한다.
- `AGENTS.md`, 프로젝트 실행 메모, 문서 거버넌스, 통합 기획 원장에 같은 규칙을 동기화했다.
- 현재 활성 Moneyverse 예약 작업 프롬프트에도 동일 요구사항을 직접 반영한다.
- 거버넌스 전용이며 애플리케이션 runtime/Test/Production 배포 및 제품 기획 버전 상승은 없다.
