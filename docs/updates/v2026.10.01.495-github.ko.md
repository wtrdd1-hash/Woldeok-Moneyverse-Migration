# v2026.10.01.495 — 단일 국고 및 사회 세금 재순환 설계

이번 변경은 기획 전용 초안이며, 실제 WLD 중앙국고 계좌 하나와 논리적 예산 버킷 구조를 제안한다.

핵심 설계:
- 징수된 세금은 100% 중앙국고로 들어가며 세금을 소각하지 않는다.
- 통화 소각이 필요하면 세금과 분리된 명시적 비과세 싱크 정책으로 운영한다.
- 국고 세수는 복지, 공공일자리, 커뮤니티 사업, 시민참여 배당, 시장안정/아이템 역매수, 이벤트 예산으로 사회에 재순환한다.
- 공공지출은 새 WLD를 발행하지 않고 기존 국고 WLD를 이전한다.
- 비축금, 대사, 악용방지, 멱등성, 이중분개 조건을 유지한다.
- 현재 다중 금고/세금소각 방향은 추후 권위 기획 통합 시 정리할 충돌로 기록한다.

런타임·DB·Test·Production 변경은 포함하지 않는다.
