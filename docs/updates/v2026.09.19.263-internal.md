# Internal update — v2026.09.19.263

## Incident findings
- `moneyverse-v259-test-backend.service` failed because a release-local environment file supplied `PORT=3100`, overriding the intended transient `PORT=3120`; the process collided with `test-main-backend.service` and exited with `EADDRINUSE`.
- The persistent Test backend and frontend were assembled from different historical release directories and an old shared release identity, so the public Test origin returned an obsolete SHA.
- The primary workspace also carried unrelated untracked Economy AI work and was behind its remote branch; this recovery therefore uses a clean worktree from current `origin/main`.

## Remediation
- Do not load release-local `.env`/`.env.local` in persistent Test units.
- Keep stable secret-bearing settings under `/etc/moneyverse/test-backend.env` and `/etc/moneyverse/test-frontend.env`.
- Generate release identity files from one exact SHA and load them last.
- Point both Test services at one `/srv/moneyverse-data/releases/test-current` release root.
- Preserve old release/unit configuration as rollback evidence until Production smoke is complete.
