# v2026.11.14.2208 — 관리자 화면 API 호환성 장애 복구

관리자 화면 참조 코드 `237831372`의 직접 원인은 기존 인증·관리자 API가 일부 빠진 Spring Boot로 운영 프론트엔드가 연결되어 발생한 404였다.

- 표준 Next.js `:4501`의 내부 API 연결을 기존 NestJS `:4500`으로 복구. Spring Boot `:4550`은 이미 별도 이관된 API용으로 유지.
- 기존 빌드로 `:4511` 대체 인스턴스 구성 → 검증 → Nginx 무중단 전환 → 표준 인스턴스 설정 수정·검증 → Nginx 복귀. 백업과 대체 서비스 유지.
- 공개 `/admin` 200 및 원래 오류 코드 미발생, 비로그인 은행·채팅은 307 로그인 이동, 주식·로그인·헬스·버전 200.
- 내부 토큰 보호 URL 검증과 API 경로 검사 추가, 회귀 테스트 4건 통과.
- DB·원장·잔액 변경 및 신규 운영 코드 릴리스 없음. 인증된 실제 관리자 전체 QA와 동일 SHA 공식 Test 전체 검증은 미완료.
