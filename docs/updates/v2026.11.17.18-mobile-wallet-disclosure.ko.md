# v2026.11.17.18 — 모바일 지갑·가상 주식 공시 수정 내역

상태: **소스 수정 완료 / 격리 테스트 검증 / 운영승격 보류**. `main` 병합·공식 Test 배포·운영 승격은 아직 수행하지 않음.

## 변경 사항
- Next ↔ Spring 간 누락된 **읽기 전용** 지갑 `GET /api/v1/wallet` 추가. 검증된 서버 세션 소유자만 정규 WLD 현금/은행 계정과 최근 원장 전표를 조회. 자료 불일치 또는 장애 시 임의 잔액·0원 성공 반환하지 않으며 비공개 캐시.
- 기존 PostgreSQL 함수 기반의 본인 전용 조회 `GET /api/v1/bank/loans` 및 `GET /api/v1/rewards/availability` 복구. 대출/보상 실행 요청은 이번 수정에 포함하지 않음.
- 비로그인 `GET /api/v1/auth/session`의 임의 CSRF 성공 응답 제거(401). 주식 개인 조회·주문은 로그인 세션 소유자를 확인하고 `X-User-Id` 위조 입력을 신원으로 사용하지 않음.
- 기본 사용자/가상 잔액/직접 잔액 수정 위험이 있던 기존 `/api/wallet/*` 경로 3개를 503으로 격리. 정규 복식부기 금융 기능 검증 전까지 실행 금지.
- 지갑 오류 화면에 재시도/고객 지원, 주식 공시 팝업에 화면 높이 제한·내부 스크롤·모바일 터치/안전영역 대응. 오래된 가상 공시를 자동 LIVE 알림처럼 표시하지 않도록 변경.
