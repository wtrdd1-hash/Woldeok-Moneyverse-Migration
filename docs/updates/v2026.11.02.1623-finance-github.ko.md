# v2026.11.02.1623 — KDIC/신규 연금 API 인증-원장 오류 분리

- KDIC 관리자 개요·원장 및 신규 연금의 조회·납입·환급 BFF에서 인증 401·권한 403을 원장 미검증 503으로 조작하던 오류 수정. 재원이 없거나 원장 검증이 불가하면 기존 503 차단 유지.
- 신규 연금 화면에 로그인 필요·권한 없음·정식 원장 미확인 분리 메시지 제공. 이 코드 변경은 잔액이나 원장 내역을 바꾸지 않음.
- 실제 운영 DB의 PG17.11 격리 복제본에서 1000 WLD 적립, 동일 키 재시도, 950/50 조기 환급, 총 WLD 공급 변화 0, 2+3 복식분개 및 불변 영수증, 타인 키/출금 초과 거부 확인. 운영 금전 집행은 하지 않음.
- 구 국고 552건 및 배당 744건 중 738건은 원장 연결 ID가 없으므로 임의 인증 불가. 공식 Test·운영 승격은 별도 검증으로 기록.
