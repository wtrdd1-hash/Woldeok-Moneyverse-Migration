- classify intentional Search Console exclusions separately from real indexability defects;
- require canonical/sitemap/hreflang/status/internal-link consistency;
- prohibit thin/duplicate pages created only for index count or ad inventory;
- track each URL as INDEX_EXPECTED, NOINDEX_EXPECTED, REDIRECT_EXPECTED or REMOVE_EXPECTED;
- use 7/28/90-day measurement cohorts;
- recover qualified organic traffic before increasing advertising load.

The supplied Search Console/AdSense values are recorded as planning observations. No production, Test, Search Console or AdSense configuration changes are claimed in v512.
