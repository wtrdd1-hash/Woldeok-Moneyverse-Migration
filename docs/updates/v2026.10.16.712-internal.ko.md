# v2026.10.16.712 — 내부 업데이트: 자동 언어·전송 성능

**[English canonical](v2026.10.16.712-internal.md) | 한국어**

상태: 후보. 코드/테스트 통과만으로 운영 반영 완료를 주장하지 않는다.

- 첫 SSR 국가별 언어(`KR→ko`, `JP→ja`, `CN→zh`, `US→en`), 사용자 선택 쿠키와 명시 URL 우선순위를 유지한다.
- 자동 감지 때마다 `wdmv_detected_locale` 쿠키를 다시 생성하지 않도록 수정했다. 수동/명시 언어 설정만 `wdmv_locale`에 지속 기록한다. 과거 자동 감지 쿠키가 현 국가의 판단에 우선하지 않는다.
- `Nanum_Myeongjo` 및 `Noto_Sans_KR`의 다수 CJK 폰트 샤드 강제 preload를 차단한다. 자체 호스팅과 필요 시 로딩, `font-display: swap`은 유지한다.
- DB/금액/회원 세션/백그라운드 작업은 수정하지 않았다.
- 운영 v697(3213/3214) 내부 홈 응답 약 20~31ms, 내부 health 약 1~3ms; 외부 Cloudflare 경유 홈페이지 1.2~5.3초. 외부 지연이 개선됐다는 결론은 별도 검증 필요하다.
- 품질: 회귀 테스트 RED 8개→GREEN 14개, 프론트 전체 1,224개 통과, 타입·프론트/백엔드 빌드 통과, lint 오류 0개·기존 경고 1,088개.

정확 SHA Test/CI/세션 연속성/롤백 증거 확인 후 운영 승격 여부를 결정한다. [작업 기록](../worklog/2026-10-16-locale-response-v712.ko.md).
