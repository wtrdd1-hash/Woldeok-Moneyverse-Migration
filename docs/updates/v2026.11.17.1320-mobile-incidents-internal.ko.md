# v2026.11.17.1320 — 내부용 모바일 장애 업데이트 내역

**상태:** P0 대시보드·지갑·채권, P1 전직 오류·고정 UI 겹침. **미해결 / GitHub #3243**. 최신 확인 main `e96e8f81f4d6b99b221392a2b6fe46356361b145`. 통합 기획 정본 및 Gemini 등 타 작업자의 로컬 변경 보존.

**사용자 증거:** 대시보드 WLD `—`·관심/보유 종목 `0`, 지갑 조회 실패 문구, 채권 정보 미검증·청약 중지, 직업 카드 전직 영역 `대상을 찾을 수 없어요.`, 언어 메뉴/CTA와 하단 플로팅 UI 겹침 위험. 캡처만으로 실제 HTTP 상태, 원장 잔액, 직업 변경 결과, 클릭 완전 불가 단정 금지.

**코드 근거:** 대시보드는 API 실패를 `[]`로 대체해 `0` 표시할 수 있음. 지갑은 `!wallet`이면 실패 화면. 채권은 서버 원천 검증 실패 시 청약 보류(의도된 금융 안전장치). 직업은 POST 요청 후 본인 프로필 GET 검증을 수행하므로 **전직 적용 후 후속 조회 실패** 가능성 포함. Spring 및 다른 릴리스 서비스가 따로 활성인 만큼 구 백엔드 inactive만으로 장애 원인 확정 불가.

**다음 조치:** 인증된 격리 환경에서 API 응답·Nginx 선택 라우트·실행 SHA·세션·CSRF·DB 읽기 권한·계약 검사·실제 프로필 재조회, 320~430px/200% 확대·국문/영문/일문/중문 UI 테스트. 원장 위조·허위 0/금리·청약 허위 성공 차단. 개발/공식 Test/무중단 승격 승인 게이트 충족 전 운영 변경 금지.
