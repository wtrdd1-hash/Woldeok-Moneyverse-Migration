# v2026.09.25.438 — 릴리스 저장공간 보존

이번 문서/운영 업데이트는 호스트 릴리스 보존 수를 제한하고 오래된 불변 릴리스 사본을 안전하게 정리한 증거를 기록한다.

- Production/Test 활성 릴리스는 symlink target과 실행 프로세스 CWD 근거로 모두 보호한다.
- 보존 정책은 환경별 활성 + 롤백 가능 릴리스 최소 10개다.
- 용량 정책은 70% 경고, 80% artifact 증가 중단, 90% 사고 임계치를 둔다.
- 관측 data disk 사용률은 오래된 릴리스 정리 후 72%에서 22%로 감소했다.
- DB 데이터, upload, backup, 보호 QA data, swap은 제거하지 않았다.
- 애플리케이션 런타임은 정상 유지됐으며 이번 업데이트는 새 application release가 아니다.
