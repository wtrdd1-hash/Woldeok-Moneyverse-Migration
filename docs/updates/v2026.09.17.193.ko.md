# v2026.09.17.193 — API 기반 화면 캐시 권한 강화

- 쓰기 가능한 Next.js 서버 캐시 준비를 위한 보호된 host-runtime helper를 추가했습니다.
- helper는 소유권 변경 범위를 `frontend/.next/cache`로 제한하고 release root 밖의 경로를 거부합니다.
- frontend service 사용자로 실제 파일 쓰기가 가능한지 확인하는 runtime readiness 검사를 추가했습니다.
- 장애 범위는 frontend 서버 캐시 최신성에 한정하며 NestJS, PostgreSQL, session, 경제 데이터, migration 204는 변경하지 않습니다.
- 같은 수정의 Production 적용 전 Test에서 backend health, BFF JSON, frontend cache 검사를 통과해야 합니다.
- Production 수정은 backend 재시작 없이 무중단으로 적용하도록 설계했습니다.
