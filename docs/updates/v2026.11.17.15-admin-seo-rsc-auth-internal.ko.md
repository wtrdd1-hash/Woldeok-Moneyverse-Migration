# v2026.11.17.15 — 내부 SEO 관리자 RSC 인증 장애 기록
상태: **분리 테스트 통과, 운영 미반영.** 이슈 #3238.

## 원인
v14 복구 후에도 Next.js RSC 페이지 전환 헤더가 Nginx 내부 인증 서브요청에 전달되어, 인증 상태 API가 익명 401 JSON 대신 307 리다이렉트를 반환. Nginx auth_request가 이를 허용하지 않아 브라우저 탐색에 503이 발생함.

## 최소 변경
실제 페이지 RSC 요청, 쿠키, 관리자 권한 검사, Spring/API는 그대로 유지. **내부 인증 서브요청에만** RSC / Next-Router-Prefetch / Next-Router-State-Tree 헤더가 전달되지 않도록 설정.

## 테스트
- RED: 분리 Nginx에서 기본 익명 401, RSC 500; Next 인증 API의 RSC 307 확인.
- GREEN: 분리 Nginx에서 관리자 SEO 두 경로 기본·RSC·사전 가져오기 모두 익명 401, Spring 헬스 200, 후보 UI 렌더 200. Nginx 문법 검사 및 사전검사 통과.
- 운영 적용 전; 백업·실패 시 롤백 계획 존재. DB, WLD, 로그인 세션 데이터 미변경.
- 로그인 관리자 긍정 E2E는 아직 별도 증거 없음.

## 운영 검증 후속 기록 — 2026-11-17 13:15 KST
