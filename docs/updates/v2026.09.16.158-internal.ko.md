# 내부 업데이트 v2026.09.16.158 — 관리자 내비게이션 기능 목록 정합성 복구

## 원인

관리자 기능 자체는 구현되어 있었지만 두 개의 진입 목록이 서로 달라졌습니다. `AdminSubNav`에는 보안, 사업·시즌, 작업·직업, Discord가 빠져 있었고 `ADMIN_AREAS`에는 문의 채팅과 상점 관리가 빠져 있었습니다. 운영도 `main`과 같은 불완전한 상단 메뉴를 제공하고 있었으므로 백엔드 미배포가 아니라 프론트 관리자 내비게이션 목록 불일치가 원인이었습니다.

## 변경

- 관리자 상단 메뉴에 `/admin/security`, `/admin/catalog`, `/admin/work`, `/admin/discord`를 추가했습니다.
- 관리자 대시보드 관리영역에 `/admin/support`, `/admin/shop`을 추가했습니다.
- 탭 목록을 테스트 가능하게 공개하고, 모든 최상위 관리자 영역이 상단 메뉴에서 접근 가능해야 한다는 회귀 테스트를 추가했습니다.
- 활동/전달/무결성 로그, AI 뉴스, 경제 시나리오 같은 하위 화면은 기존 상위 관리영역 아래에 유지하여 상단 메뉴 중복을 피했습니다.

- 로컬 workspace: typecheck PASS, build PASS, lint 0 error PASS(기존 이미지 최적화 warning 11건), contract 선빌드 후 workspace test PASS.

- 백엔드 로컬 비DB 실행: 871 PASS / DB 테스트 351개는 worktree에 CI DB 환경변수가 없어 skip되었습니다. 승격 판단은 GitHub DB 포함 candidate CI를 기준으로 합니다.
