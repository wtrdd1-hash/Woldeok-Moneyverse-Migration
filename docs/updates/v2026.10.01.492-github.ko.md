# v2026.10.01.492 — 국고 재순환·세금 확장·유저 활동 강화

이번 기획은 세금이 국고에 쌓이기만 하지 않고 실제 플레이 거리로 돌아오게 만든다.

### 변경
- 장터 판매세, listing/broker fee, 상향 reprice fee 분리
- 선택형 사업 초과이익, luxury/property, license, 시즌 세금/fee 확장
- P2P 기본 0%, starter/core 보상·환불 보호
- reserve state + fail-closed Treasury Recycling Engine
- 도시/커뮤니티 matching, 공공계약, 시즌 공공사업, fee-relief, 신규·복귀 지원, 제한형 안정화, item salvage
- 유저 Treasury Today/공공 프로젝트 루프
- 참여도 KPI와 wash/다계정 방지

### 유저 경험 원칙
세금은 돈만 빼는 기능이 아니라 새 할 거리를 만드는 재원이어야 한다. 국고재원 보상은 납세액이 아니라 검증된 참여를 기준으로 한다.

### 안전
납세액 P2W, 최고납세자 ranking, 세금복권/베팅, 휴면잔액세, 징벌적 부유세, 자동 reserve 침해를 금지한다.

기획/문서 전용이며 런타임/Test/Production 완료를 주장하지 않는다.
