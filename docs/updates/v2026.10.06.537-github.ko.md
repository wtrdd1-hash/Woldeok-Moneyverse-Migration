# v2026.10.06.537 — 관리자 모바일 UI 수정

최신 제공 스크린샷과 v530 긴급 UI 점검에서 재현된 관리자 모바일 레이아웃 결함을 수정하는 업데이트다.

## 변경 사항
- SEO 액션이 긴 라벨을 서로 압축하지 않고 안전하게 세로/격자로 재배치된다.
- 분석 카테고리 탭은 축소되지 않는 버튼과 제한된 가로 터치 스크롤 영역을 사용한다.
- 코호트 텔레메트리 제목/상태 배지가 모바일에서 재배치된다.
- 사용자용 온보딩/고객지원 플로팅 런처를 전체 관리자 라우트에서 제외해 운영 콘텐츠 가림을 제거한다.
- 세 가지 실제 재현 실패 유형을 회귀 가드로 고정했다.

## 검증
첫 exact-SHA Test에서 레이아웃 수정은 확인했지만 `/admin/seo`의 40px touch target과 React hydration mismatch가 추가로 발견됐다. 이를 44px default 액션 크기와 서버 제공 결정적 기준 시각으로 수정하고, 실제 제출 전 표시되던 가짜 Indexing API 성공 이력도 제거했다. 현재 관리자/SEO/분석 타깃은 3개 파일 / 20개 테스트 통과, typecheck 통과, 타깃 lint 오류 0개다. 갱신된 candidate는 Production 완료 주장 전에 exact-SHA Test를 다시 통과해야 한다.
