# v2026.09.25.438 — Release-storage retention

This documentation/operations update formalizes bounded host release retention and records a safe cleanup of stale immutable release copies.

- Active Production/Test releases are protected by both symlink target and running-process CWD evidence.
- Retention is active + at least 10 rollback-capable releases per environment.
- Capacity policy adds 70% warning, 80% artifact-growth stop, and 90% incident thresholds.
- The observed data disk moved from 72% used to 22% used after stale release cleanup.
- Database data, uploads, backups, protected QA data and swap were not removed.
- Application runtime remained healthy; this update does not represent a new application release.
