# 관리자 입력 상태 자동 새로고침 방지 — 내부 업데이트

업데이트 버전: **2026.09.12-04**  
상태: **후보 / 테스트 서버 검증 필요**  
브랜치: `fix/admin-disable-auto-refresh`

## 문제

관리자 편집 화면에서 운영자가 입력 중이어도 서버 데이터 갱신 때문에 화면이 다시 렌더링될 수 있었습니다. 시장 관리 페이지는 15초마다, AI 뉴스 실행 화면은 실행 중 4초마다 갱신했고, 상점 편집 화면은 저장 성공 1초 뒤 `router.refresh()`를 강제로 호출했습니다.

이 동작은 입력 중인 폼 값, 검색어, 편집 상태를 서버 상태로 덮어써서 입력 내용이 사라지는 원인이 될 수 있습니다.

## 수정 내용

- `/admin/market`의 `LiveRefresh` 제거
- AI 뉴스 관리자 화면의 4초 자동 폴링 제거
- AI 뉴스 실행 안내 문구를 자동 새로고침 비활성 기준에 맞게 수정
- 관리자 상점 저장 성공 후 지연 `router.refresh()` 제거
- 상점 저장 결과는 로컬 React 상태에 즉시 반영하여 페이지를 다시 불러오지 않아도 저장값이 화면에 보이도록 변경
- 영향받는 관리자 편집 파일에 `LiveRefresh`, `router.refresh(`, `setInterval(`이 다시 들어오지 못하도록 회귀 테스트 추가

## 검증

- 프론트엔드 TypeScript 타입검사 통과
- 프론트엔드 Vitest 전체 테스트 통과
- 영향 파일에서 자동 라우트 새로고침 트리거가 제거된 것을 소스 검사로 확인

## 배포 기준

먼저 테스트 환경에 배포하고 백엔드 정상 동작을 확인한 뒤, 관리자 폼에 값을 입력해 둔 상태에서 서버 정보가 바뀌어도 입력값이 유지되는지 확인합니다. 테스트 서버 검증 완료 후에만 운영으로 승격합니다.
