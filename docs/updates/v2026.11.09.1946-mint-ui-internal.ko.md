# 내부 업데이트 — v2026.11.09.1946 조폐국 UI·정책값 일치화
**상태: 후보 코드 검증; 공식 테스트·운영 승격 검증 대기.** [영어 정본](v2026.11.09.1946-mint-ui-internal.md)

- 실제 운영 사진 2건 확인: 승인 WORK_REWARD 항목은 드롭다운에 보이지만 비동기 로딩 후 내부 선택값은 빈 문자열. 정책 발의는 화면 기본 TREASURY 대상이 DB 244번 체크 제약조건에 없는 값이라 500 오류.
- 검증: 네트워크 차단 PostgreSQL17 복제본에서 `MINT/WORK_REWARD` 삽입 후 ROLLBACK 성공, `MINT/TREASURY`는 실제 제약조건 위반 확인. 영구 DB 데이터 변경 없음.
- 수정: 화면 드롭다운 선택 표시·실제 요청 ID 일치, 유효한 정책 값만 노출, Next BFF와 백엔드에서 잘못된 유형을 DB 이전에 422/400으로 차단, 사용자에게 이해 가능한 오류 안내.
- 모바일 폼 세로 배치, 금액 버튼 자동 줄바꿈, 긴 명령서 명칭 축약, 입력값 변경 시 오래된 오류 초기화.
- **금융 정본 제약:** 기존 주조 백엔드는 승인 한도와 발행 증명서만 기록하고 국고 정본 전표·금고 증가가 없음. 따라서 화면의 VAULT_MAIN 자동 입금 문구를 삭제. 직접 국고 MINT는 신규 정본 결제/원천 증빙과 공개 검증 게이트가 구축될 때까지 미지원. 신규 344 마이그레이션은 관리자 역할을 확인하는 DB 함수(정책 발의/승인/인증서 기록)와 앱 읽기 권한만 부여. 앱에 인증서 직접 쓰기 권한은 부여하지 않고 금액도 변경하지 않음.
- 프론트 17·백엔드 12·DB 마이그레이션 6·보안 2 테스트, 양쪽 타입 검사, 린트 오류 0건 통과. 공식 CI·테스트 서버·운영 검증은 별도.
