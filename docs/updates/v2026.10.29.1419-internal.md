# Internal release v2026.10.29.1419 — automatic verified blog publisher

## Owner intent
Every two hours rotate KR/US/JP/CN (Korean, English, Japanese, Simplified Chinese) and economy/coding/computers. Fetch first-party sources, create source-grounded local-AI educational articles, independently verify quality, and publish immediately without mandatory human review. Never auto-withdraw a published article on a timer; administrators may manually revise, withdraw or delete. No Google-served ad placement on unreviewed automatically generated content.

## Root cause
Production v1213 runs the general Nest scheduler disabled to avoid duplicate financial jobs. Another legacy backend process still runs a general hourly scheduler but the separate verified blog flag was disabled. The verified publisher database was empty on 2026-10-29; a frontend admin UI alone did not mean that publishing happened.

## Implementation
Dedicated Nest-independent one-shot Node backend worker, PostgreSQL advisory lock held across source fetch/model/writer, same exact period receipt for idempotency, and Seoul-local current 2-hour window catch-up. Systemd one-shot + timer with publishing at even hour +05, bounded retries at even +45 and following odd +25/+55, all retries skip immediately once an immutable receipt exists. Worker executes no economy jobs; user-approved finance DML unchanged. Existing original source discovery/local model, independent quality gate and secure SQL blog_publish_verified function used unmodified; no legacy JSON write or fabricated generated evidence.

Backend publisher-status API recognizes separately configured dedicated timer only when model receipt verification is independently completed. Config values cannot claim success without actual run/receipt proof.
