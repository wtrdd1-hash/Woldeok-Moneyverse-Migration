# 업데이트 v2026.09.12.8 — 경제/이벤트 캘린더

## 요약

Living Project Plan의 P1 경제/이벤트 캘린더 첫 회원용 화면을 구현했습니다.

## 추가 내용

- 로그인 회원용 `/calendar` 페이지 추가.
- 진행 중 시즌 이벤트의 종료 시각을 한 화면에서 확인.
- 오늘의 결정론적 초반 사건 상태와 한국 시간 기준 갱신 안내 표시.
- 서버가 계산한 주간 목표 주기를 이용해 주간 갱신 시점 표시.
- 실제 참여/보상 작업은 기존 퀘스트 화면으로 연결하여 별도의 변경 경로를 만들지 않음.

## 데이터 및 안전 원칙

- 신규 데이터베이스 테이블이나 마이그레이션은 추가하지 않았습니다.
- 이벤트 상태, 보상, 가격, 진행도는 기존 서버 API를 계속 기준으로 사용합니다.
- WLD 값은 문자열 정밀도 규칙을 유지하며 JavaScript `Number`로 변환하지 않습니다.
- 조회 실패 시 값을 추측하지 않고 불러올 수 없음 상태로 표시합니다.

## 남은 범위

기획서에는 가상 주식 이벤트와 상점 이벤트도 같은 캘린더에 통합하도록 되어 있습니다. 현재 이 두 영역에는 안정적인 일정 조회 계약이 없으므로 이번 버전에서는 임의의 날짜를 만들지 않았습니다. 서버 측 권위 있는 일정 API가 준비되면 같은 화면에 추가합니다.
