# v2026.11.18.1 — 관리자 UI 긴급 엣지 복구 (GitHub 공개 업데이트)

- **상태:** 관리자 진입 경로 운영 복구 및 읽기 전용 검증 완료. **로그인한 운영자 E2E·OAuth 로그인·전 사이트 기능 정상화 미인증.**
- **원인:** 운영 Nginx `prod_frontend`가 Spring Boot :4550을 가리켜 대화형 화면이 아닌 475바이트 로딩 문구를 HTTP 200으로 반환. Next.js 실행 서비스 부재.
- **변경:** 기존 검증 자산 `prod-v2026.11.14.1217-43ab5a5110`의 standalone Next.js 번들 모듈 참조를 복원하고 별도 로컬 :4524 서비스 구동. Nginx에서 `/admin`, `/admin/*`, `/login`, `/api/viewer`만 전환. 관리자 UI는 반드시 Spring `/api/v1/admin/me` 인증 서브요청으로 선차단. Spring 전체 API 경로 유지. 빌드 해시 CSS·JS 보완, 비공개 `no-store/noindex` 응답 헤더 정규화.
- **검증:** 분리 Nginx 8/8 PASS; 공개 HTTPS 관리자 익명 302 로그인 이동, 로그인 UI 200, viewer 200, 관리자 API 익명 401, Spring health 200, CSS/JS 200 및 MIME 정상. Nginx 구문 검사 후 무중단 reload. 금융·원장·DB 쓰기 및 기존 백엔드 재시작 없음.
- **미해결:** Discord/Google OAuth 시작 주소는 아직 Spring 임시 화면을 반환하고, 실제 배포된 Spring이 요구 OAuth JSON 계약을 제공하지 않음. 공식 Test 웹 `/`는 502; 실제 관리자 로그인·전 메뉴 E2E 미실시. 일반 홈 `/`, `/wallet` 등도 아직 임시 화면. **전 사이트 복구라고 표시하지 않음.**
- **승격/기록:** v2026.11.18.1 운영 긴급 우회 및 원본 백업 적용. 작업 PR은 공식 Test 게이트 미충족으로 심사 대기.
