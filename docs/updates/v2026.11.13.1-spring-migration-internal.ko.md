# 내부 업데이트 v2026.11.13.1 — Spring Boot 전 시스템 전환 기획 시작

**분류:** 아키텍처 기획이며 실제 런타임 구현 아님. **상태:** 초안, 사용자 검토 필요.

- **지시:** TypeScript/NestJS 백엔드 전체를 Java/Spring Boot로 단계적으로 이관. 전체 API·인증/관리자·경제/금융·게임·커뮤니티·실시간·Discord/Telegram/Minecraft·작업·알림·봇/워커와 최종 NestJS 종료 포함. Next.js UI·Android 앱·PostgreSQL 원장 함수는 초기 유지.
- **기준과 격리:** 미니PC MCP; `wtrdd1-hash/Woldeok-Moneyverse-Migration` origin/main `90965f1dd84e272e757041eb9afd8a477699eb7c` 시작/중간 확인. 별도 `planning/spring-platform-migration-v2026.11.13.1` 브랜치 사용. 타 개발자·제미나이 작업 공간 미수정.
- **관찰:** Nest controller 파일 89, service 52, 백엔드 TypeScript 900, DB migration 추적 파일 345. Kubernetes/Flux와 Debian systemd/Nginx 문서가 충돌하여 실제 인그레스/SHA 재검증 필요. 사용 가능 RAM 약 0.8 GiB, Swap 사용 약 6.5 GiB이므로 운영 JVM 상주 추가 미승인.
- **설계:** G0 기준선·백업/복원·ACL·실행 SHA, G1 Java 기반, G2 읽기 API, G3 인증·커뮤니티 쓰기, G4 게임·스케줄·연동, G5 금융 도메인별, G6 기존 서버 종료. 금융 쓰기·스케줄 활성 주체는 각각 한 시점에 하나, 원장 함수 경계 재사용.
- **향후 필수 시험:** 정확한 SHA의 공식 Test·실제 PostgreSQL, 금융/권한/멱등/OTP/CSRF/연동/Android 계약, 성능·용량, 무중단 전환, 독립 복원과 롤백. 과거 QA 실패를 최신 판정으로 취급하지 않음.
- **현재 변경:** 문서만. DB SQL·회원 돈·코드 빌드·JVM 배포·Test/Production 서비스 재시작·트래픽 전환·main 병합 없음. 구현 승인 대기.
