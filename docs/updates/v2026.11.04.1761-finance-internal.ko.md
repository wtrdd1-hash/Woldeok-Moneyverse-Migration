# v2026.11.04.1761 — 구형 W 계좌의 정식 WLD 통화 코드 정합화 (내부용)

운영 실측: 활성 사용자 현금 계좌 2개가 구형 W 코드로 잔존하고 잔액은 1,066,011 + 1,076,011 = 2,142,022. 해당 사용자는 별도의 WLD 현금 계좌가 없고 각 계좌에 2개의 실제 정식 분개가 있다. 기존 전체 원장은 영합계이나 WLD 코드만 집계하면 회원 잔액이 2,699,488로 축소 표시되며, 구형 W 계좌 회원의 새 WLD 연금/국고 정산이 거부될 수 있다. W와 WLD 전체 회원 자금 4,841,510은 기존 실제 돈이다.

순방향 SQL336: 정식 분개·잔액·계좌 소유관계 검증을 통과한 W USER_CASH 계좌만 원장 ID·잔액은 그대로 둔 채 WLD로 코드 변경. 계좌별 SHA256 불변 감사 영수증을 별도 저장, 향후 W 코드 신규 생성 방지 CHECK, 앱 직접쓰기권 제거. 전체 원장/계좌 금액 영합계·기존 분개 수 보존에 실패하면 전체 롤백한다. 새 통화 발권·수익 생성·기존 자금 삭제 없음.
