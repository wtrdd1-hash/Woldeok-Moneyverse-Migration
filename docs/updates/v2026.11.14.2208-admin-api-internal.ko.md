# v2026.11.14.2208 — 내부 업데이트: 관리자 API 연결 장애 복구

**작업 전:** 2026-11-14 18:05:52 운영 Next.js 로그에서 `/admin` 참조 코드 `237831372`와 API 404를 정확히 대조했다. 프론트엔드 `:4501`이 아직 기존 관리자·인증 API가 모두 이관되지 않은 Spring Boot `:4550`을 호출했으며, 기존 NestJS `:4500`에는 필요한 경로가 존재했다. 미니PC 우선 접근, 공식 통합문서·기획서·릴리스 규정·main 확인 후 다른 개발자의 Spring 작업공간을 보존했다.

**진행 중:** 서버 간 API 경로 4개 호환성 검사 구현. Spring 실패, 운영·공식 테스트 Nest 통과. URL 검증 보안 단위 테스트 1건 실패를 먼저 재현한 뒤 수정해 4/4 PASS. 기존 불변 빌드로 `:4511` 대체 프론트엔드를 기동·검증하고 Nginx를 무중단 전환했다. 표준 `:4501`에 Nest API 원점 설정을 추가하고 대체 인스턴스가 요청을 처리하는 동안 재시작·검증한 다음 Nginx를 표준 포트로 복귀시켰다.

**작업 종료:** 공개 `/admin` 200 및 기존 오류 코드 미발생, `/bank`·`/chat` 비로그인 307 로그인 이동, `/stocks`·`/login` 200, Nest/Spring 헬스·버전 200. 데이터베이스·원장·회원 잔액·세션·관리자 정책·운영 릴리스 소스 불변. 복구용 프론트엔드 `:4511`과 Nginx 원본 백업 보관.
