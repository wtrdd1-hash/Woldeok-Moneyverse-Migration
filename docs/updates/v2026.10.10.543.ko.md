# v2026.10.10.543 — 긴급 경제 격리

> 릴리스 상태: 소스 구현 완료 / TEST 대기 / PRODUCTION 대기
> 브랜치: `fix/v543-emergency-containment-20261010`

## 변경 내용

- `MONEYVERSE_SWF_EXECUTION_ENABLED=true`를 명시하지 않으면 자율 SWF 경제변동을 fail-closed 하도록 변경.
- 시간주기 스케줄러도 별도 `MONEYVERSE_SWF_SCHEDULER_ENABLED=true`를 요구.
- 백엔드 시작 30초 후 SWF 경제 사이클이 실행되던 동작 제거.
- 명시적으로 활성화한 사이클에도 PostgreSQL transaction advisory lock과 영속 최소 실행간격 적용.
- 기본 비활성, 재시작 안전, lock 충돌, 조기 재실행 차단 회귀 테스트 추가.
- exact-SHA 불변 Debian host release staging 도구 추가. dirty/mismatched source와 기존 destination을 거부하고 Git metadata 제거 후 `.moneyverse-release.json` 기록.
- 현재 기획 권위, 통합 원장, 배포 절차, 내부 업데이트 로그를 영문/한국어로 동기화.

## 변경 이유

기존 자율 경로는 백엔드 재시작만으로 경제를 변경할 수 있었고, 권위 Economy Core의 자금보존 모델과 충돌하는 정산 동작을 포함했다. v543은 구조수정 전에 자동 변동을 먼저 격리한다.

## 남은 차단 / 다음 단계

v544에서 SWF·FX·연금·국채·Repo의 위험 정산을 canonical Economy Core / SECURITY DEFINER 흐름과 forward privilege repair로 교체해야 한다. v530 전체 UI 수용 차단도 계속 유효하다.
