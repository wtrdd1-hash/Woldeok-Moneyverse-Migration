# v2026.11.10.2028 — 내부 P0 카지노 복지세 보안·원장 보류

**상태:** 긴급 보안 수정 개발 브랜치. 관련 PR #3015, #3018, CI run 42757727717.

## 원인
마이그레이션 346의 `trigger_casino_pigouvian_welfare_tax()` 함수가 SECURITY DEFINER인 채로 PUBLIC 실행 권한을 유지하여 DB 보안 테스트 실패. 또한 고액 주사위 베팅 시 복지금고(`VAULT_WELFARE`)를 늘리는 동안 공식 지급 재원 차감 및 정식 복식원장 대응 전표가 없어 복지 자산 허위 증가 가능성이 확인됨.

## 구현
이미 적용된 346은 불변으로 유지. **전방 마이그레이션 347**에서 문제의 자동 과세 트리거만 제거하고 PUBLIC·앱 직접 EXECUTE 권한 회수. 사용자 베팅 삭제·금액 자동 교정·과거 원장 수정 없음. 정적 RED/GREEN 및 실제 PostgreSQL 판정용 테스트 추가.

## 필수 보류 조건
신규 PostgreSQL 전체 마이그레이션, DB 보안/금융 대사, 정확 SHA Test, 실제 디스코드·텔레그램 OTP 인증, 세션 유지, 백업·복원, 무중단 운영 승격까지 증빙 필요. 과거 허위 세금 전표는 별도 정합성 조사 전 운영 금융 완료 판단 금지.
