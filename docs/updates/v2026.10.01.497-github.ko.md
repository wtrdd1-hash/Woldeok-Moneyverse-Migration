# v2026.10.01.497 — App/Site/Economy Core 보안 아키텍처

이번 변경은 문서 전용 초안이며 승인된 multi-core 방향을 보안 관점에서 재설계한다.

핵심:
- native App Core와 browser Site Core BFF 계약 분리;
- 권위 Economy Core와 금융 ledger/DB 권위는 하나;
- workload identity와 user/admin/automation actor context 독립검증;
- shared static internal bearer token의 최종구조 교체방향;
- BFF/AI model runtime의 protected economy table write 금지;
- request digest, policy version, replay/idempotency를 가진 typed Economy Command Envelope;
- generated method/path/scope API inventory를 보안권위로 사용;
- 설정된 모바일 고가치 action에 Play Integrity request binding;
- adaptive economy tuning은 Economy Policy Registry 하나 + policy executor 하나;
- 초기 AI numeric change/cooldown/drift 한도 명시;
- tax, policy rate, macro credit buffer, WLD issuance/retirement는 human approval 유지;
- prompt injection/excessive agency 격리와 controlled model egress;
- App API v1 compatibility를 유지하는 무중단 단계 migration.

조사근거는 12개 분야 신규 Crossref unique 118,490건, 기존 Moneyverse 경제/AI 코퍼스와 병합한 최종 discovery 후보 149,691 unique를 기록한다. 이 숫자를 모든 전문을 읽었다는 의미로 표현하지 않는다.

런타임·마이그레이션·Test·Production 변경은 없다. implementation/integration plan 전에 written-spec 승인이 필요하다.
