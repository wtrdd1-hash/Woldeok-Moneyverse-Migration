## Change
- Reject automatic publication of a previously published normalized title within seven days, or another market-moving event for that company within 24 hours. Prefer companies least featured in recent history. Fail closed when market history cannot be read.
- Generate at most five distinct deterministic fallback candidates instead of the same two stocks every cycle. Persist the actual model name on fallback.
- Pass a deterministic content-and-stock-derived idempotency UUID to the existing PostgreSQL stock market event publisher, preserving database advisory-lock/unique-key defense against concurrent identical publications.
- Send "published" admin alerts only for actual publication.
- Preserve existing news/events as auditable history, no price/financial ledger changes, no schema migration or public API changes.
