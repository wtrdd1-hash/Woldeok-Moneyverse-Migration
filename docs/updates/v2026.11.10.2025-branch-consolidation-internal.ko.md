## 단계별 버전과 검증
1. **v2025.1 작업 전** — 통합 기획 및 배포 지침을 우선 확인하고 $pc로 Debian 13 접속. 변경 전 작업 기록. 웹 원격 참조 598개(HEAD 포함), 미병합 548개, 최초 로컬 425개 및 연결 worktree 50개 확인. 기존 로컬 main은 원격보다 7커밋 앞/2커밋 뒤이며 OTP 테스트 미커밋 수정 존재.
2. **v2025.2 진행 중** — 원격 main 기반 독립 통합 브랜치를 만든 뒤 로컬 7개 커밋 병합(원본 변경 없음). 웹 원격 main 제외 597개 분류: 기존 포함 51개, 기획/문서 중심 미병합 226개, 코드/활성 worktree 미병합 320개. Android 기존 포함 1개, 미병합 기능 5개.
3. **v2025.3 안전 정리** — SHA 및 Git 포함 관계 확인 후 웹 42개, Android 1개 원격 브랜치 삭제. 작업 중 또는 독자 변경이 있는 브랜치 보존. 이미 다른 작업에서 사라진 브랜치 1개는 이 작업의 삭제 수에 포함하지 않음. [웹 42개 삭제 SHA 증빙](../worklog/2026-11-10-contained-remote-deletions-v2025.tsv).
4. **v2025.4 선별 통합** — 회원 소유 아이템 캐시 차단(B934) 통합 및 테스트 2/2 통과. 기존 OTP 테스트에서 텔레그램 실제 `sendAlert` API 반영 후 3/3 통과. 원래 미커밋 변경은 보존.
5. **v2025.5 QA** — 타입 검사, 앱 전체 빌드 통과, 린트 오류 0/경고 1,062. 백엔드 테스트 3,034 통과/0 실패/518 건너뜀. 첫 프론트 전체 테스트는 220초 시간 초과였으나, 독립 재실행 3,055/3,055 통과. 최종 동일 HEAD `cc7ed57bf28f2c43a1f2dc700bebdec7b4bc034e`에서 `pnpm test`도 종료 코드 0 통과: 백엔드 3,034 통과/0 실패/518 건너뜀, 프론트 3,055 통과/0 실패. 필수 DB/보안 테스트의 건너뜀으로 운영 합격은 아님. 운영 DB 읽기 전용 금융 준비 점검은 검사 범위 내 정상이나 국고 재원·DB 필수 테스트·복구·세션 확인은 별도 필수.

## 영향 범위 및 복구
통합 후보에만 OTP, 연금, 관리자 국고/조폐국, 블로그, UI, 개인정보 응답 캐시 차단, SQL346이 존재함. 이번 작업에서는 DB 마이그레이션, 회원 데이터 변경, 서비스 재시작, Nginx 교체, 공식 배포를 실행하지 않음. 기존 운영과 복구 세대 유지.

## 완료 기준
남은 미병합 브랜치의 충돌 및 작업 소유권 확인, 정확한 SHA 기준 전체 필수 테스트, 공식 Test 백엔드/프론트/API/실 DB/로그인 QA, 국고 및 독립 백업 복구 확인, 메인 변경 재반영, 무중단 운영 교체 후 검증. 그 전 나머지 브랜치 삭제 금지.
