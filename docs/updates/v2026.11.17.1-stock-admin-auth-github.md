# v2026.11.17.1 — Fail-closed stock admin console authorization

Spring's success-on-anonymous session endpoint and internally authorized, hardcoded open-console response were incompatible with protected Nest admin APIs. This isolated Nginx snippet routes the exact admin console/identity endpoints through existing Nest authentication and authorization, aligning the market page's gate with the already protected stock APIs. No stock/financial writes, public API redesign or Spring deployment is included.
