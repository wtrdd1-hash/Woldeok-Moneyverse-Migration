# GitHub 업데이트 — v2026.11.09.1946 조폐국 UI 선택값·정책 DB 제약 일치
[영어 정본](v2026.11.09.1946-mint-ui-github.md)

- **문제1:** 승인 WORK_REWARD가 화면에 보여도 처음 비어 있던 React 선택값 때문에 제출 시 ‘선택해 주세요’ 오류.
- **문제2:** 정책 MINT/TREASURY는 현재 DB 244번 스키마 미지원인데 UI가 허용해 PostgreSQL 제약조건 위반을 500으로 표출.
- **수정:** 보이는 승인 명령과 실제 API ID 일치화, 정상 조합만 제공하며 BFF/백엔드 422/400 검증, 모바일 화면 보강. 실제 전표 없는 VAULT_MAIN 자동 입금 안내 삭제. 신규 344번 보안 함수로 관리자 발의·승인·인증서 기록 권한 범위를 처리.
- **검증:** 격리 PG17에서 정상/오류 정책 INSERT 후 rollback. 관련 프론트 17·백엔드 12·DB 6·보안 2, 타입 검사·린트 통과. 신규 344번 제한형 DB 함수로 앱 인증서 INSERT 거부 문제 해결. 정식 Test/Production 별도 게이트.
- **남은 기능:** 직접 국고 발행에는 새로운 복식부기 원장 결제·출처 증빙·공개금융 검증이 필요하며 본 수정은 가짜 국고 입금을 만들지 않음.
