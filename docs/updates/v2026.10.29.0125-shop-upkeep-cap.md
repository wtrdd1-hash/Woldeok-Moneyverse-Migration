# Shop: Weekly Upkeep Ceiling — Candidate Only

The `/shop` catalogue now offers an optional **Maximum weekly upkeep (WLD)** field alongside product search. Enter `0` to show products with no weekly maintenance cost; enter a positive whole WLD amount to include products at or below that ceiling. Clear the field to restore the full catalogue. The member and guest catalogue endpoints accept `maxUpkeep`, and the Android app gateway forwards the same query.

The backend validates canonical nonnegative decimal strings up to 30 digits and compares database-sourced `maintenance_cost` using `BigInt`. Invalid queries return HTTP 400 before a catalogue read; invalid database values fail closed. Authenticated catalogue reads still derive the owner from the session, and Android shop responses are private and not cached. The shop page preserves existing search terms and membership status when a filter hides the membership product. No migration, financial ledger mutation, new grants or background task is introduced.

**Release status:** Unmerged engineering candidate. Full CI, isolated exact-SHA Test with authenticated web/Android flows, finance reconciliation, backup restore and GitOps release approval are required before Production.
