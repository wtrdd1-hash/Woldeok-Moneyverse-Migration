# v2026.11.22.2013 — Java4Shell runtime audit (GitHub update, EN)

**Status:** READ-ONLY ASSESSED / REMEDIATION OPEN / DOCUMENTATION ONLY.
Owner-shared 2026-11-22 Instagram reel concerns the real Oracle/OpenJDK vulnerability CVE-2026-114938. KISA and Oracle confirm patched Java 21.0.13.1. On the authorized AMD Ryzen 7 7735HS mini-PC, default JDK and main Spring backend have been updated; 28 of 32 running Java PIDs were independently identified as old JDK 21.0.12.1, one uses 21.0.13.1, and three could not be verified. AVX-512 VBMI was not exposed; this reduces the specific Java4Shell exploit precondition on this host but is not assurance against other November 2026 Java CVEs. No JVM restarts, releases, DB changes or vulnerability exploit tests were performed. A staged, QA-gated runtime rotation is still needed.
