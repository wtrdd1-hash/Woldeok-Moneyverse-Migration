# Release note — v2026.10.16.742 — Discord administrator alerts

## Highlights

Send existing curated operational Discord messages to the administrator's direct messages as well as the designated channel. Important financial, audit, administrator, SEO and policy alerts no longer require an explicit critical flag to reach the DM. Preserve urgent DM-only alerts.

## Safety and observability

- No credentials, member exports, or raw application logs are forwarded.
- Recipient-specific channel cache, mention suppression, credential/email masking.
- Failure of a channel post no longer hides a successful administrator DM.
- Operators can choose critical-only mode or disable DMs using environment flags.
