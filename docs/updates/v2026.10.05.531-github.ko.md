# v2026.10.05.531 — 긴급 UI 수정 후보

v530 긴급 UI 점검에 대한 구현 응답이다. 재현된 관리자 모바일 잘림과 UI 수용을 막던 여러 공용 원인을 수정했다.

## 주요 내용

- 모바일 `/admin/seo` 액션이 viewport 밖으로 뻗지 않고 stack/wrap.
- 관리자 주요 인터랙션에 mobile/coarse-pointer 44×44 최소 target 적용.
- 온보딩/고객지원 소비자 floating widget이 관리자 본문을 덮지 않음.
- 전역 헤더 주요 제어를 모바일 44px 바닥값으로 상향.
- 홈에 실제 보이는 localized H1 추가.
- account linked-identity read가 기존 `local_email` provider를 허용해 local-email 계정에서 identities 500을 만들던 provider contract 불일치 수정.
- 재현 responsive 조건과 provider contract 회귀 테스트 추가.

## 현재 gate

소스 구현과 로컬 검증은 Test 후보를 만들 수 있는 상태지만 아직 **Production 승인 상태가 아니다**. exact-SHA Test 배포, backend health, 인증 관리자/전체 route 5회 UI 증거가 계속 필요하다.
