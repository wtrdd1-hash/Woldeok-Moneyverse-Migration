# v2026.11.19.32 — 디자인 비교 페이지 운영 홈 노출 기록

**변경 범위:** 문서 전용 장애 분석 및 릴리스 수용 기준. **실행 코드·운영 배포 변경 없음.**

### 발견
공개 홈페이지 HTML과 사용자 첨부 모바일 화면 모두 '홈 화면 3안' 비교 화면을 표시한다. `/design-preview` 원본은 탐색용 비교 시안임을 밝힌다. 미니PC의 로컬 QA 기록에는 해당 HTML을 Spring 메인 `index.html`로 복사했다고 되어 있으나, 이 QA 기록은 조사 당시 원격 `origin/main`에 없었다.

### 변경 문서
확인 증거·디자인 불일치·원인 범위·시각 및 실제 기능 QA·승격 차단 규칙을 영문/국문으로 정리. 작업 전·중·후 이력 포함. 제작자 확정·이미지 승인·전체 API 검증 성공·운영 수정 완료라고 주장하지 않는다.

**해결:** 승인 원본 비교 및 별도 구현 PR 필요. **운영:** 본 PR로 변경하지 않음.
