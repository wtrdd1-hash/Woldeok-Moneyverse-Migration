- 자동발행 전용 `/srv/moneyverse-data/shared/blog-unverified-posts.json`은 기존 JSON과 분리. 단일 DB advisory lock, 0600 원자 저장, 회차별 멱등 처리. Test 파일은 고정된 별도 경로. 관리자 수동 비공개·삭제 유지.
- 국가별 블로그/상세/API/사이트맵 공개 및 광고 배치 코드. **중요 위험:** Google Publisher Policies는 사람의 검수·큐레이션 없는 자동생성 콘텐츠에 Google 광고 제공을 금지함. 사용자 승인과 광고 네트워크의 정책은 별개이며 실제 광고 노출·수익을 보장하지 않음.
- 금융 원장·전역 금융 스케줄러·기존 레거시 파일 발행 API 503·검증 영수증 유지. 실제 Test, CI, 운영 카나리·승격 증거 전에는 운영 완료로 보고하지 않음.
