# v2026.11.17.1 — 주식 관리자 콘솔 인증 경계 일치
실제 운영 `/admin/market`은 익명 요청에도 HTTP 200을 반환했지만, Nest 주식 관리자 API는 정상적으로 401을 반환했습니다. 원인은 Spring의 익명 세션 성공 응답과 내부 전송 토큰만으로 관리자 콘솔을 열림 처리하는 응답에 있었습니다. Nginx 내부 게이트웨이의 관리자 보안 콘솔·관리자 본인 검증 경로만 기존 Nest 인증 체계로 연결하여 권한 경계를 일치시킵니다. 금융/주식 쓰기와 Spring·Next 배포 변경은 없습니다.

TDD 3건 통과, 독립 Test 백엔드 재가동 후 헬스·버전 200, 격리 Nginx 구문 검사와 비인증 관리자·주식 API 401 확인. 실제 로그인한 관리자 E2E 및 공식 전체 릴리스 검증은 미완료입니다.
