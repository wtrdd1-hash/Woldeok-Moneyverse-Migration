# v2026.09.15.125

Release candidate for persistent support chat and administrator security simplification.

## User-facing changes
- Adds persistent one-to-one support conversations between a member and administrators.
- Adds `/support` for members and `/admin/support` for the administrator inbox, replies, and case status.
- Keeps lobby chat separate and ephemeral; support messages are durable records.
- Mobile API contract expands from 139 to 147 endpoints and includes the complete support surface.

## Administrator changes
- Retires administrator TOTP/2FA enrollment, verification, trusted-device and recovery-code flows.
- Keeps rotated short-lived administrator sessions, role checks, CSRF, IP allowlists, database actor checks and append-only audit events.
- Administrator replies and support-status changes are audited server-side.
