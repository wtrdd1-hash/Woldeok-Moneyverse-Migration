# GitHub 공개 업데이트 — v2026.11.22.2151.1 11월18일 웹 UI 불일치 감사

[영문 정본](v2026.11.22.2151.1-ui-runtime-audit-github.md)

**문서만 변경. 사이트·앱 운영 배포 없음.** 최신 GitHub 병합 코드, FE/QA 작업기록, 미니PC Nginx/Java, 로컬 익명 HTTP를 대조해 11월18일 디자인 불일치를 추적했다.

현행 정적HTML 59개 중 새 공통 셸 CSS는 19개만 참조하고, 50개에는 기존 Next 자산이 남는다. Nginx 뒤 서로 다른 Java 원천 세 개가 운영되며 로컬 버전 API 503, 실제 홈 응답과 최신 소스 불일치가 확인됐다. #3355·#3359·#3362의 코드 병합만으로 전체 180경로의 실제 로그인·시각·기능 수용 또는 운영 승격 성공을 주장할 수 없다.

현재 상태는 **미해결(OPEN)**. 후속 순서는 URL→실행물·SHA 경로 원장, 공통 Spring 레이아웃 및 실데이터 기능 보존, PC/모바일·5언어·관리자/회원 QA, 독립 Test 정확 SHA와 롤백 검증 후 운영 승격이다.
