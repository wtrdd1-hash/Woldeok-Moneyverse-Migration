# v2026.10.03.509 — 글로벌 SEO / 해외 서비스 기획 통합

v508 최신 main 위에서 승인된 v507 글로벌 성장 설계를 현재 기획 권위로 채택한 문서 전용 업데이트다.

주요 내용:
- 제품/공개 기본 fallback 언어는 한국어를 유지한다.
- GeoIP는 언어 추천을 보조하며 명시 locale URL과 저장된 사용자 선택이 우선한다.
- 해외 서비스 기획에 현지화 utility, 지식/검색, 온보딩, 번역, 시간대/이벤트, 해외 탐색·리텐션 기능을 포함한다.
- 국제 SEO의 다국어 URL/hreflang/canonical/sitemap/내부링크 품질 계약을 현재 권위로 채택했다.
- 얇은 자동번역/대량 pSEO와 가짜 검색지표를 금지한다.
- 현금수익은 현재 광고 전용 권위를 유지하고 해외 확장은 실제 광고 단위경제로 평가한다.
- 이번 업데이트에는 런타임, DB, Test, Production 배포가 없다.
