# v2026.10.06.537 — Administrator Mobile UI Repair

This update addresses the administrator mobile layout defects reproduced from the latest screenshots and the v530 emergency UI audit.

## Changes
- SEO actions now stack/reflow safely instead of compressing long labels into each other.
- Analytics category tabs now use a contained horizontal touch scroller with non-shrinking tab controls.
- The cohort telemetry heading/status badge reflows on mobile.
- Consumer onboarding and support floating launchers are suppressed throughout administrator routes, so they no longer cover operational content.
- Regression guards cover all three reproduced failure classes.
