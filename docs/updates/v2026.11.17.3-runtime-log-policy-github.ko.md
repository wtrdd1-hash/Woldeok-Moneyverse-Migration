# GitHub 업데이트 — 서버 로그 보관 정책·관리자 콘솔 v2026.11.17.3

**기획 초안 / 문서만 수정 / 운영 보류** · [English canonical](v2026.11.17.3-runtime-log-policy-github.md)

Nginx·Spring Boot·Next.js 프론트엔드 서버·전환 중 기존 NestJS에 적용할 사용자 지시 로그 관리 기획이다.

- **일반 7일 / 중요 30일**, UTC 이벤트 발생 시각 기준. 관리자 명령·인증/보안 사고·중대 장애 기록은 중요로 분류.
- 일/파일 크기 기준 순환, 닫힌 로그 zstd 압축(gzip 대체), 체크섬·시간 인덱스·보존 기한에 따른 안전한 자동 정리.
- 저장 공간 경보, 수집/압축 장애 명시, Test/운영 분리, 중요 로그 조기삭제 금지.
- 관리자 `/admin/logs/system`: 기간·심각도·출처별 이력 검색, 커서 페이지 조회, 실시간 SSE 또는 5초 폴링 대체. 중요/보안 로그 및 추출에는 고권한 관리자와 최근 OTP 필요.
- 저장 전/조회 전 자격증명·쿠키·토큰·OTP·개인정보를 마스킹하고 관리자 열람/추출 감사를 남김.
- **제외:** DB 백업 정책 수정, 금융 감사/원장 테이블 삭제, 실제 서버 로테이션·배포.

[상세 한국어 기획](../planning/RUNTIME_LOG_RETENTION_ADMIN_CONSOLE_v2026.11.17.3.ko.md) / [영문 정본](../planning/RUNTIME_LOG_RETENTION_ADMIN_CONSOLE_v2026.11.17.3.md) · [작업 기록](../worklog/2026-11-17-log-retention-admin-console-v2026.11.17.3.md).
