# v2026.11.13.1 — 전체 Spring Boot 백엔드 전환 기획

**상태: 초안 / 문서 전용 / 미배포**

Spring Boot 전환 아키텍처를 국고 한 기능이 아닌 **전체 NestJS 백엔드**를 대상으로 설계했다. 목표는 Java/Spring Boot 모듈형 백엔드로 모든 API·관리자·금융/게임·스케줄·실시간·외부 연동을 단계적으로 옮기고 최종적으로 NestJS를 종료하는 것이다. 공개 Next.js 화면 계약, Android 앱 호환성, PostgreSQL의 감사 가능한 복식원장은 유지한다.

G0~G6은 기존 소스/경로·실제 배포 환경 조사, 격리 시험과 독립 복구 증명부터 시작한다. 다음으로 읽기 API, 커뮤니티/인증, 게임/연동, 마지막으로 보호된 금융 명령을 이전한다. 금융 동시 쓰기 두 주체·원장 테이블 직접 수정·잔액 초기화·추가 인증 파괴·증거 없는 운영 승격을 금지한다.

**변경:** 영/한 상세 설계, 기존 Living/통합 기획서 참조, 작업기록, CHANGELOG, 기획 버전 문서. **미변경:** 애플리케이션 코드, DB, 배포 매니페스트, 테스트 서버, 운영 서비스, 회원 돈, main 브랜치.

아키텍처는 사용자 검토 대기이며, 실제 상세 구현계획·PR·공식 Test QA·운영 릴리스는 각각 별도 버전을 사용한다.
