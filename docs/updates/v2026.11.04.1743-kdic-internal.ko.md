# v2026.11.04.1743 — KDIC 예금보험공사 조회 정상화 (내부용)

실제 공식 Test의 KDIC 공개 API HTTP500을 재현. 기금 1건, 부보 금융기관 2곳이 존재하지만 Test 웹 앱 역할에는 기금/기관/보험료/지급/회원 프로필 직접 SELECT 권한이 없어 실패했다. 운영은 기존 조회 권한으로 HTTP200 응답 중.

SQL335에 DB 소유자 SECURITY DEFINER 전용 조회함수 4개를 추가했다. 기금/기관은 안전한 공개 조회, 최근 보험료/지급은 관리자 역할·최대 10건 검사. 백엔드는 원본 테이블 조회 대신 전용 함수를 사용하고 공개 포털에서 관리자 민감 내역 자체를 조회하지 않는다. 앱 원본 금융 테이블 조회권을 확대하지 않는다.

신규 테스트 RED 후 총 8/8 통과, 백엔드 타입 검사 통과. 실제 Test DB 전체 백업(20,878,252바이트, SHA256 68cf1f8a78c1342676c42d7a0a4905528fde35320119fd70da715274b7a029fd)을 격리 PG17.11에 복원 후 SQL334→335 적용 성공. 웹 역할로 기금 1/기관 2 조회, 관리자 권한 없는 사용자 조회 거부, 직접 테이블 읽기 계속 차단 확인. 실제 Test/운영 적용은 SQL334 선행 PR #2683 CI 실패 상태로 **미완료**.

예보료 징수·대위변제·긴급자금 지급은 여전히 검증된 재원/원장/승인/멱등 영수증이 없어 정지 상태(#2366). 이번 변경은 지급 기능 해제가 아님.
