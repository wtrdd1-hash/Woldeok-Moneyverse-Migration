# v2026.11.17.2 — SEO 실제 데이터 출처 복구 및 관리자 보호

- 잘못된 Spring SEO 라우팅을 기존 NestJS SEO API로 우선 전환해 고정 통계/허위 접수 응답을 운영 SEO 게이트웨이에서 차단.
- 관리자 SEO 감사 API·화면에 공개 경계 권한 검증 추가. 로그인 없는 조회 차단, IndexNow 인증키 일치 유지.
- 읽기전용 운영 QA·독립 Nginx 테스트 스크립트, 무중단 설정 재적용 절차 및 원복 백업 보유.
- 프론트엔드 소스 수정(운영 미배포): Spring 내부 토큰만으로 관리자 권한 승인 금지, 근거 없는 GSC 순위·CTR·IndexNow 651건 표기 제거.
- 검증: 프론트 관련 **50/50 PASS**, 운영 독립 읽기전용 **13/13 PASS**, 테스트 서버 권한 거부·장애 대응 PASS.
- **미검증/보류:** 실제 GSC 색인 확인, 검색엔진 제출 실요청, 로그인 관리자 브라우저 E2E, Spring SEO 완전 전환, 프론트 배포 및 전체 CI. GitHub 검토용 브랜치이며 Nginx 운영 완화 조치와 구별.
