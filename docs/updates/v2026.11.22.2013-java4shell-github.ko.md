# v2026.11.22.2013 — Java4Shell 실행 JVM 조사 (GitHub 업데이트, KO)

**상태:** 읽기 전용 점검 완료 / 보완 필요 / 문서만 작성.
2026-11-22 사용자 제공 인스타그램 릴스의 Java4Shell(CVE-2026-114938)은 실제 취약점으로 KISA·Oracle이 패치 안내함. AMD Ryzen 7 7735HS 미니PC의 기본 JDK 및 주 Spring 백엔드는 21.0.13.1. 하지만 32개 Java PID 중 28개는 실제 구버전 21.0.12.1이며 1개는 21.0.13.1, 3개는 검증 불가. 이 호스트는 AVX-512 VBMI 명령을 노출하지 않으므로 Java4Shell 자체의 필수 CPU 조건 미충족. 다만 동시 공지된 다른 Java 보안 문제의 안전까지 의미하지 않음. JVM 재시작, 코드·DB·Nginx 변경, 배포, 침투 시험 없음. 향후 QA와 롤백 조건을 충족한 순차 재기동이 필요함.
