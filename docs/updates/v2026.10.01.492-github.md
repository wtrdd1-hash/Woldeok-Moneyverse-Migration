# v2026.10.01.492 — Treasury recycling, expanded taxes, more player activity

This planning update makes the virtual treasury useful instead of letting tax revenue sit idle.

### What changed
- separated marketplace sale tax, listing/broker fee and upward-reprice fee;
- added optional business-surplus, luxury/property, license and seasonal tax/fee classes;
- preserved 0% default P2P tax and protected starter/core rewards/refunds;
- added reserve states plus a fail-closed Treasury Recycling Engine;
- added city/community matching, public contracts, seasonal public works, fee-relief events, new/return support, bounded stabilization and item salvage drives;
- added a member-facing Treasury Today/public-project loop;
- added participation KPIs and anti-wash/alt-account controls.

### Player-experience rule
Tax should create more visible things to do, not simply remove money. Treasury-funded rewards are based on verified participation, never on how much tax a member paid.

### Safety
No P2W tax benefits, richest-taxpayer ranking, tax-funded lottery/wagering, idle-balance tax, confiscatory wealth tax or automatic reserve breach.

Planning/docs only; no runtime/Test/Production completion claim.
