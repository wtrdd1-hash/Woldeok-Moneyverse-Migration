# 상점: 주간 유지비 상한 필터 — 배포 전 후보

`/shop`에서 상품 검색과 함께 **주간 유지비 상한(WLD)**을 설정할 수 있습니다. `0`을 입력하면 주간 유지비가 없는 상품만 표시하고, 양의 정수를 입력하면 해당 금액 이하의 상품만 표시합니다. 입력을 지우면 전체 상품으로 돌아갑니다. 회원·비회원 상점 API와 Android 앱 게이트웨이에서도 `maxUpkeep` 검색 조건을 동일하게 전달합니다.

서버는 최대 30자리의 올바른 음이 아닌 정수 문자열만 허용하며, 데이터베이스에서 반환된 `maintenance_cost`를 `BigInt`로 비교합니다. 잘못된 입력은 데이터베이스 조회 전에 HTTP 400으로 거부합니다. 회원별 조회 권한은 기존 세션과 PostgreSQL 함수를 유지하고, Android 상점 응답은 `private, no-store`를 적용합니다. 검색 조건 때문에 VIP 상품이 숨겨져도 실제 회원 등급을 별도로 확인합니다. 신규 마이그레이션·금융 원장 변경·권한 확대는 없습니다.

**배포 상태:** 미병합 개발 후보입니다. 정확한 SHA의 전체 CI, 격리 Test 인증·앱 흐름, 금융 무결성, 백업 복원 및 GitOps 승인이 완료되기 전에는 운영에 적용하지 않습니다. 기존 데이터베이스 권한·마이그레이션·원장 잔액 문제가 계속 차단 요인입니다.
