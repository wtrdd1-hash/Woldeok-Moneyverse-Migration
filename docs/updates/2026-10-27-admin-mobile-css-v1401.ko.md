# v2026.10.27.1401 — 관리자 모바일 화면 스타일 복구

**공개용 GitHub 업데이트 내역.**

관리자 모바일 화면에서 로고 과대 표시, 기본 글머리 목록, 상단 메뉴 중첩 현상이 보고됐다. 활성 프론트엔드가 이전 빌드의 CSS를 HTML에 적고 있었지만 해당 CSS는 실제 빌드 디렉터리에 없었다. 현재 디스크의 정상 Tailwind CSS가 HTML과 불일치하는 것을 확인했다.

DB·잔고·인증·권한은 변경하지 않는다. GitHub 코드 반영과 Test/운영 승격은 별개이며 실제 결과는 작업 로그에 기록한다.

**실제 상태 갱신:** PR #1593은 병합됐지만 Test CSS 5/5 HTTP 500 및 삭제된 런타임 경로가 확인됐다. Test 설정 변경은 실행 안전 검사에 차단돼 운영 전환은 하지 않았다.
