# v2026.11.17.1414 — 앱을 게임처럼 구현하기 위한 공통 기획

## 요약
월덕 머니버스의 앱 성격과 실제 경제/계정 안전성은 유지하면서 전체 화면·동작을 게임형 사용자 경험으로 설계하는 기획 문서 추가.

## 변경
- 영어 기준 명세와 한국어 상세 번역.
- 게임 로비 홈, 아바타, 퀘스트, 지갑/시장, 상점/보관함, 직업, 커뮤니티, 업적, 관리자 화면 배치와 디자인 원칙.
- 서버 검증 후 보상 연출, 정확한 WLD 원장, 미확인/로딩/장애 상태, 접근성·반응형·Android 패리티.
- GX-01~GX-08 단계별 코딩/QA 인수인계 및 통합 기획서·문서 인덱스 연결.
