# GitHub 업데이트 — Spring 개발 전문 공용 스킬

**버전:** v2026.11.13.2218 · **범위:** 에이전트 지침·문서 한정.

Codex/GPT 및 Gemini CLI가 공통으로 인식할 수 있는 `.agents/skills`에 Spring 전문 스킬 8종을 추가합니다. NestJS의 점진적 전환, Next/Android API 호환성, Spring Security, 금융 JDBC 안전성, 실제 PostgreSQL 검증, Gradle 빌드, 단일 스케줄러 소유권, 운영 관측성 등을 포함합니다.

**검토:** YAML 이름/폴더와 중복 여부, 한영 문서, 운영 코드·DB 변경 없음 확인. Spring 전환 기획 초안 승인이나 배포를 의미하지 않습니다. 미니PC에 Gemini CLI 실행 파일이 없으므로 Gemini 실제 활성화는 별도 확인이 필요합니다. 상세 검증은 작업 로그 참조.
