# v2026.10.05.531 — Emergency UI Remediation Candidate

This implementation responds to the v530 emergency UI audit. It repairs the reproduced administrator mobile clipping and several shared causes that made the UI acceptance gate remain blocked.

## Highlights

- Mobile `/admin/seo` actions now stack/wrap instead of extending beyond the viewport.
- Administrator primary interactive controls receive a 44×44 mobile/coarse-pointer minimum target.
- Onboarding/support consumer floating widgets no longer cover administrator content.
- Primary global header controls meet the 44px mobile target floor.
- The home page now has a visible localized H1.
- Account linked-identity reads accept the existing `local_email` provider, fixing the provider-contract mismatch that produced an identities 500 for local-email accounts.
- New regressions cover the reproduced responsive condition and provider contract.

## Current gate

Source implementation and local verification are complete enough to form a Test candidate, but the change is **not Production-approved yet**. Exact-SHA Test deployment, backend health and five-pass authenticated administrator/full-route UI evidence are still required.
