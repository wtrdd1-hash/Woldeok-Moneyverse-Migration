# v2026.11.10.2010 — 국채 쓰기 API의 CSRF 토큰 전달 수정

국채 청약·담보대출 신청·상환·자동 롤오버 등 네 개의 변경 API가 서버 측 CSRF 인증 경로를 사용하도록 수정했습니다. 유효한 요청 출처만 처리하며 응답 캐시를 금지합니다.

검증: 변경 전 실패 20건을 재현하고 수정 후 20건 통과, 확대 회귀 43건 통과, 타입 검사·Next 전체 빌드 통과, 격리 실행에서 악성 출처 요청 네 건 모두 HTTP 403.

**소스 수정 후보이며 공식 Test/운영 미승격.** 실제 회원 결제 원장·중복 방지·이자/만기 정산은 아직 인증되지 않았습니다. Repo 신청·상환은 백엔드에서 의도적으로 보류 중이며 별도 QA PR #3008 이슈를 계속 추적합니다. DB·자금·원장 데이터는 변경하지 않았습니다.
