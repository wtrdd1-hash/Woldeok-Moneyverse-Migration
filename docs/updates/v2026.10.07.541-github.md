# v2026.10.07.541 — Real Google Search Console Sitemap Submission

The administrator SEO console now uses the registered Google Search Console service account for a real Google API write operation instead of presenting ordinary finance/calculator pages as eligible for Google’s restricted Indexing API.

## Changes
- Added one-click Search Console sitemap submission for the Production `/sitemap.xml` through the official Sitemaps API.
- Kept Search Analytics on the read-only OAuth scope; the write scope is requested only for sitemap submission.
- Added administrator-session + CSRF protection to sitemap and IndexNow mutation endpoints.
- Added real sitemap status feedback: submission/download timestamps, processing state, warning/error counts and submitted URL count.
- Blocked sitemap submission when SEO indexing is disabled, so isolated Test cannot publish its hostname to Search Console.
- Removed the misleading Indexing API batch card from the active SEO console and relabeled the remaining generic notification action as IndexNow.
- Removed the BFF path that returned fabricated SEO-submission success during backend failures.
