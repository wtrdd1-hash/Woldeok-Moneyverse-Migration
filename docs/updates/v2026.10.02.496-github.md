# v2026.10.02.496 — Site Translation Audit

A documentation-only audit compared the live site translation behavior and current main against the authoritative localization plan.

Key gaps:
- current main defaults to Korean instead of the required English primary language;
- current implementation supports ko/en/ja/zh, while the authoritative P0/P1 target is en/ko/ja/de/fr/es/pt-BR;
- locale detection is coupled to GeoIP despite the plan requiring locale and jurisdiction to remain separate;
- mixed Korean text remains on English/Japanese/Chinese localized production pages;
- French, German, Spanish, and Brazilian Portuguese localized paths return 404;
- translation infrastructure is fragmented between binary EN/KO rendering and mostly unused dictionaries.

Verification: four targeted test files passed 13/13, but those tests currently encode the existing four-locale/Korean-default behavior.

No runtime, database, Test, or Production deployment change was made.
