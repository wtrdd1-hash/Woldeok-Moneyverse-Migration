# 내부 업데이트 — v2026.10.02.507

범위: 글로벌 제품 성장, 해외 SEO, 광고수익 기획.

주요 위험:
- main 소스 기본 locale은 아직 영어;
- 다국어 소스 coverage가 불완전하고 혼합언어 위험이 큼;
- GSC 운영 코드에 synthetic/fixed 지표가 있어 검색량 판단 불가;
- main/Test/Production runtime lineage 불일치;
- 과거 고정 pSEO 페이지수 문구는 scaled-content 품질위험.

채택 설계:
- 한국어 제품 fallback;
- 공개 색인면은 GeoIP 추천/selector 기본값, 비색인 onboarding만 자동 기본값;
- 사용자 선택과 명시 locale URL 최우선;
- 실제 검색성과와 시장 검색량 provenance 분리;
- EN/JA 해외 품질 wave 우선;
- 실제 가치 기반 public utility/knowledge cluster;
- 일반검색/Image/video/Discover 획득;
- 광고 전용 시장 기여이익 모델.

구현 상태: 시작하지 않음. 구현계획 전에 written design 검토가 필요하다.
