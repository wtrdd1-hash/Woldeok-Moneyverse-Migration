- 최신 19대 계산기를 기준으로 하며 검색어별 복제 계산기를 만들지 않는다.

- 내부 AI는 검증된 source-grounded brief로 구조화 초안을 만들며 금융/YMYL 글을 자동 공개하지 않는다.
- canonical/noindex/카니벌라이제이션 게이트로 얇은 대량 콘텐츠를 차단한다.
- Search Console 실제 성과를 다음 개선/신규 계산기 의사결정에 다시 사용한다.
- 첫 구현은 신규 대량생성이 아니라 기존 계산기 3개에서 전체 루프를 검증한다.

v922에서는 앱 코드·DB·WLD·Test·Production 배포를 변경하지 않는다.
