# v2026.10.29.1501 — 국부펀드 위험 회수 차단 및 중앙은행 화면 정정

## 문제
운영 국부펀드 회수 기능에서 PostgreSQL 42P08 오류를 확인했다. 단순 형변환 수정은 복식부기 원장에 없는 자금을 국고에 생성할 수 있다. 중앙은행 화면에도 고정 샘플값과 브라우저 내부에서만 변경되는 결재 동작이 존재했다.

## 변경
- 국부펀드 구형 즉시 회수 기능을 백엔드와 프런트 API에서 503으로 차단하고 CSRF 보호를 추가했다.
- 중앙은행 임시 백엔드 데이터만 조회하고, 실제 원장에 기록된 공식 통화량이나 정책이 아니라는 점을 표시한다.
- 모바일에서도 국부펀드 자동 복리 및 회수 중단 상태를 정확히 표시하고 실패한 금전 작업을 성공이라 보고하지 않는다.
- 회귀 테스트와 내부/깃허브용 영문·국문 변경 기록을 작성했다.

## 배포 상태
현재 별도 브랜치 후보이며 운영 v2026.10.29.1213은 별도 검증 전까지 유지한다. 실제 화폐 인수와 국부펀드 집행은 영속 원장 정산 및 정합성 검증 완료 후 별도 구현이 필요하다.
