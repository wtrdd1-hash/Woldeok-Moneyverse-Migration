# 내부 v1617 — 국고 공개 회계기 검증 표시 복구
**상태: 소스·대상 프론트 검증 성공, 공식 Test/운영 승격 미완료.**
- 원인: 프론트 국고 API/SSR이 DB 원장 대사를 읽지 않고 무조건 HTTP503/UNVERIFIED를 표시. 실행 신원 게이트도 과거 사고 때문에 공개 국고가 무조건 503이어야 한다고 가정하고 있어 실제 정상 0원 회계기 표시를 차단.
- 새 서버 전용 조회는 회원 쿠키 전달 없이 내부 API에서 매번 독립 검증 후 최신 회계기를 읽고, 금고별 합산/정확한 WLD 정수/가용·비축 금액/시간/유통량 0의 정의되지 않은 비율 등을 검증. 위조·누락·미검증이면 기존 503 유지.
- 현재 국고 0 WLD만 검증될 경우 표시. 과거 국고 552·배당 744·연금 지급 238 및 조폐·중앙은행 발권은 증빙 미비로 미검증 유지, 임의 지급·자금 초기화 없음. 화면 30% 정책 목표를 실제 준수 실적으로 표시하지 않음.
- 대상 테스트 18, 프론트 TypeScript/ESLint 통과. 최종 CI 및 공식 Test/운영 서비스 전환은 별도.
