# v2026.09.19.263 — Test runtime release identity repair

## GitHub update

The Test host release contract now separates stable secrets from release-scoped identity and routing. Persistent Test backend/frontend units must use the same release root and exact 40-character Git SHA. Release-local `.env` files are not valid persistent unit inputs because they can silently override candidate ports or BUILD_ID values.
