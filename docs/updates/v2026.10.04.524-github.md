# GitHub Update — v2026.10.04.524

## Google Search Console credential persistence and real Search Analytics repair

This release fixes the admin SEO flow that previously acknowledged a service-account key without forwarding it to the backend, kept backend credentials only in process memory, and rendered deterministic demo Search Analytics values.

### Changes
- Forward `/api/seo/gsc` credential writes/deletes to the backend BFF instead of returning local fake success.
- Validate Google service-account JSON, perform RS256 OAuth JWT exchange, discover the accessible Search Console property, and query the official Search Analytics API.
- Persist the service-account JSON encrypted at rest through migration `247-gsc-service-account-credentials.sql`; the application role has no direct table read privilege.
- Protect GSC analytics with the administrator session guard chain and protect credential mutations with CSRF.
- Remove all fabricated GSC fallback metrics. Unconfigured state now returns zero/empty values; API failures are surfaced explicitly.
- Never write service-account private-key material to repository files or logs.
