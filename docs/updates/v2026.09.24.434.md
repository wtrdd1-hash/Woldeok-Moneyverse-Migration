# Update v2026.09.24.434 — Responsive QA five-pass gate

Development policy now requires at least five responsive QA passes for every new or changed frontend surface. Completion evidence must cover clipping/overflow, breakpoint placement, interactive states, accessibility/content stress and a final exact-SHA regression pass. Responsive defects block release; if layout is changed after testing, affected screens restart the five-pass sequence.

Scope: planning/documentation only. No runtime deployment.
