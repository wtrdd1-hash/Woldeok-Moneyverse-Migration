# v1652 — KDIC 과잉 경고 해결 및 조폐국 실제 DB 증빙 표시 (GitHub용)

KDIC 기금·원장을 독립적으로 갱신하여 어느 한 요청이 실패해도 다른 검증된 값까지 사라지지 않도록 수정. 조폐국 고정 경고 대신 인증된 DB의 정책 승인·발행 증명서·폐기 증명서 기록 건수 조회, 0건과 실제 오류 분리. 중앙은행 정상 부분 조회는 중립 정보로, 실제 동결/오류만 경고. 국고 코어 앱 실행 ACL 및 원장 수치 대조, 거래 891/전표 1829, 국고 미연결·잔액 불일치 0 확인. 연금 신규 적립 코어와 달리 기존 금융 테이블 DML 권한은 별도 개선 필요. 외환 10월7일 가격은 신선도 부족으로 실시간 표시 금지. 백엔드 23·프런트 32개 관련 테스트 통과. 발권·실제 지급 기능 해제나 WLD 이동 없음. 배포 전.
