- canonical/sitemap/hreflang/status/내부링크 정합성 요구;
- 색인 수·광고 inventory만을 위한 얇은/중복 페이지 금지;
- 모든 URL을 INDEX_EXPECTED, NOINDEX_EXPECTED, REDIRECT_EXPECTED, REMOVE_EXPECTED로 관리;
- 7/28/90일 측정 코호트 적용;
- 광고 load 확대 전에 자격 자연검색 회복을 선행.
