# 개발 B v695 — 외환 환율 근거 누락 시 안전 차단 (Draft / 배포 보류)

외환보유액 원본 행이 없을 때 `getLatestRate`가 1350 WLD를 실시간 환율처럼 대체 반환하던 동작을 제거했습니다. 원본 누락·비숫자·NaN/Infinity·0·음수 환율은 HTTP 503으로 차단합니다. 외환보유액 원본 행 누락도 일반 500 대신 503으로 처리합니다. 정상적인 양의 유한 환율은 변경 없이 반환합니다.

대상은 Backend 읽기 계약이며 API 경로, DB 스키마, 금융 원장, 환전 집행, WLD 잔액은 변경하지 않았습니다. 1350 WLD 정책 기준값 자체는 그대로 두되 관측된 실시간 환율을 대체하는 용도로 사용하지 않습니다. 단위 테스트와 Nest 실제 HTTP 503 회귀 테스트를 추가했습니다.

**배포 보류:** 공식 Test 외환 API HTTP 500, DB 마이그레이션/권한 불일치 #2111은 별도 P0 문제로 남습니다. `moneyverse_app`의 외환 테이블 직접 SELECT를 임의로 허용하지 않습니다. 공식 Test 후보 SHA, 인증 E2E, CI, 독립 복구 검증 전에는 병합·운영 배포를 하지 않습니다.
