# v2026.10.07.541 — 실제 Google Search Console 사이트맵 제출

관리자 SEO 관제실이 등록된 Google Search Console 서비스 계정을 사용해 실제 Google API 쓰기 작업을 수행하도록 변경했다. 일반 금융/계산기 페이지를 제한된 Google Indexing API 대상처럼 표시하지 않는다.

## 변경 사항
- 공식 Search Console Sitemaps API로 Production `/sitemap.xml`을 1클릭 제출/갱신.
- Search Analytics는 readonly OAuth scope 유지, 사이트맵 제출에서만 write scope 요청.
- 사이트맵/IndexNow mutation에 관리자 세션 + CSRF 보호 적용.
- 제출/다운로드 시각, 처리 상태, 경고/오류 수, 제출 URL 수를 실제 API 응답으로 표시.
- SEO 색인이 비활성화된 격리 Test에서는 사이트맵 제출 차단.
- 활성 SEO 화면에서 오해 가능한 Indexing API 배치 카드를 제거하고 범용 알림 기능은 IndexNow로 명확히 표시.
- backend 장애 시 SEO 제출 성공을 만들어 내던 BFF fallback 제거.
