# v2026.10.16.710 — 4개 국가별 블로그 콘텐츠 및 SEO 표준 URL 개선

**[English canonical](v2026.10.16.710-blog-country-seo.md) | 내부 변경 기록**

## 문제 확인
- Google Search Console 이메일에는 중복 페이지 경고 유형만 보이며 영향을 받은 개별 URL과 Google 선택 표준 URL이 없어 이번 코드 변경으로 실제 경고가 해소됐다고 확인할 수 없다.
- 기존 블로그는 화면 버튼으로 번역을 전환했으나 최초 서버 HTML과 표준 URL은 한국어 기준이었다. 자동 글 생성은 5개 반복 템플릿, 오래되거나 미검증된 시황 수치 및 근거 불분명한 수익률 주장을 포함한다.
- 중복 복리 글 두 주소, 임의 URL의 다른 포스트 대체 제공, Google에 오해를 줄 수 있는 사이트맵 최종수정 날짜, 부정확한 이미지 인증 표기 및 관련 없는 복리 인포그래픽 자동 노출을 확인했다.

## 구현 변경
- 한국·미국·일본·중국 각각에 맞는 복리/저축, 세금, ETF, 대출, 물가, 연금 **6개 주제 × 4개 국가 = 24개 독립 국가별 본문** 작성. 해당 국가의 정부 기관과 공적 참고자료를 연결하고 가상 수익 보장 표현을 피함.
- `/blog`, `/en/blog`, `/ja/blog`, `/zh/blog` 국가별 목록·상세 SSR, 제목/본문/표준 URL/OG 메타를 일치시킴. 완전한 국가별 본문이 있는 글에만 상호 `hreflang` 제공. 영어 기본 국가 페이지, 한국어 2차 지원은 서비스 기존 언어 정책 유지.
- 로케일 경로를 한국어 경로로 강제 변경하던 프록시 분기 해결. 기존 중복 복리 글은 단일 대표 글로 308 이동, 임의 부분일치 글 대체 제공 중단.
- 블로그 사이트맵에 국가별 URL 및 언어 대체 선언 반영하고 사이트맵 인덱스에 연결. `lastmod`를 응답시간이 아닌 실제 문서 수정시간 기준으로 계산.
- 이미지 파일 존재·경로 검증, SVG 설명 접근성, 거짓 ‘100% Verified Telemetry’ 표시 제거, 관계없는 금융 인포그래픽 자동 노출 제거. 별도 승인된 고유 이미지 자산이 없는 글에는 이미지를 강제 생성하지 않음.
- 목록 컴포넌트에 문서 전체 대신 글 요약만 전달해 초기 HTML 크기 및 클라이언트 중복 데이터 감소. 게시 테스트 전용 임시 저장소 적용해 운영 공유 파일 불변.

## 검증 및 미완료 조건
- 테스트 14개 통과. 별도 미리보기 서버 HTTP 200/404/308, 국가별 HTML 언어/캐노니컬/hreflang 응답 확인. 전체 빌드 및 검사 최종 SHA 재검증 필요.
- 실 테스트 서버의 백엔드와 프론트 서비스는 읽기 전용 확인으로 접근 가능하나 **이번 수정본이 해당 테스트 릴리스에 설치된 것은 아님**. 테스트 환경 전체 검증 및 운영 무중단 승격 미실행.
- **P0 미완료:** 기존 일일 자동발행은 검증되지 않은 시세·수치·중복 콘텐츠와 편집 승인 절차 부재가 있어 그대로 SEO 안전하다고 볼 수 없음. 출처 최신성, 국가별 사실 확인, 검수 대기열, 중복 발행 차단을 갖춘 별도 정비가 필요.
- **P0 미완료:** 실제 GSC 영향 URL, Google 선택 대표 URL 자료가 필요. 검토 후 재색인 요청·노출 추적.
- **P1:** 국가별 상세 글 확장, 법·제도 적용일 점검, 주제별 적법한 대표 이미지 확충, 성능 지표 및 운영 모바일 QA.
