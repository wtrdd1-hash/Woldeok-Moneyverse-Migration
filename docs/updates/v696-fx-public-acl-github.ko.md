# 개발 B v696 — 외환 공개 조회 최소권한 경계 (Draft / HOLD)

QA v1420에서 공식 Test 외환 포털의 HTTP 500 원인은 앱 계정에 외환 원천 테이블 직접 SELECT 권한이 없는데도 Backend가 직접 조회하는 것이었다. 테이블 조회 권한을 넓히지 않고, 전방 마이그레이션 314에 읽기 전용 SECURITY DEFINER 함수 4개를 추가해 공개 집계 DTO만 반환하도록 했다. 함수는 고정 search_path, 제한된 이력 건수, 앱 계정 EXECUTE만 허용하며 원본 테이블 권한은 회수한다.

Backend의 외환보유액·환율 이력·SDR·통화스왑 공개 조회를 해당 함수로 전환했다. 환율 원본 누락이나 잘못된 값은 임의의 1350 환율로 대체하지 않고 503으로 처리한다. API 경로, 회원 금융 원장, WLD 잔액, 인증 정책은 변경하지 않았다.

**출시 차단 유지:** 기존 데이터는 실제 시장 출처가 검증되지 않은 시드 값이다. 이번 ACL 수정만으로 실시간 환율 서비스가 완성되는 것은 아니다. 별도 Draft #2114의 공개 출처 검증 차단과 #2193의 중복 코드 통합, 후보 SHA의 공식 Test·CI·복구 검증이 완료되기 전에는 병합하거나 Production에 배포하지 않는다.
