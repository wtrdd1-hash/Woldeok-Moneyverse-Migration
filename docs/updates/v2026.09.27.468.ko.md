# v2026.09.27.468 — API 전수 관측성 기획 강화

[English canonical](v2026.09.27.468.md) | **한국어**

Primary project plan에서 API 관측성을 P0 release gate로 강화했다.

- 모든 API/realtime/BFF surface는 14-domain hard-code가 아니라 exact-SHA generated inventory에서 파생한다.
- Production의 hard-coded/random latency, success, health 값을 금지한다.
- stale/no-data/partial/unknown을 숨기거나 false green으로 바꾸지 않는다.
- endpoint inventory, telemetry registry, QA evidence를 1:1 대사한다.
- source-present/disabled/deprecated/decommissioned lifecycle을 명확히 분리한다.
- passive traffic, 안전 probe, dependency, SLO/error budget, alert, release 비교를 필수화한다.
- 운영 telemetry는 관리자 control-plane이며 authorization negative test를 요구한다.
- runtime 승격 전 exact-SHA Test failure injection과 기존 전 경로/반응형 gate를 수행한다.

이번 업데이트는 기획/문서 전용이다. 현재 관측된 hard-coded runtime이 이미 수정·Test·Production 검증됐다고 주장하지 않는다.
