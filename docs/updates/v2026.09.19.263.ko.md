# v2026.09.19.263 — Test 런타임 릴리스 identity 복구

## GitHub 업데이트

Test 호스트 릴리스 계약에서 stable secret과 릴리스별 identity/routing을 분리했습니다. 영구 Test backend/frontend unit은 동일 release root와 동일한 40자 Git SHA를 사용해야 합니다. release-local `.env`는 후보 port 또는 BUILD_ID를 조용히 덮어쓸 수 있으므로 영구 unit 입력으로 사용하지 않습니다.

### 변경
- stable Test service용 backend/frontend systemd drop-in 예시를 추가했습니다.
- 비밀값 없이 exact-SHA Test identity 파일을 생성하는 `write-test-release-env.sh`와 회귀시험을 추가했습니다.
- 영문/한국어 Living Plan 버전을 v2026.09.19.263으로 동기화했습니다.
- Test-first exact-SHA 및 무중단 Production 승격 gate를 문서화했습니다.

### 검증 gate
helper 회귀시험과 repository 검사를 수행하고 동일 exact SHA를 Test backend/frontend에 배포한 뒤 공개 version, backend health, catalog, noindex, 대표 페이지를 검증합니다. 이 SHA가 모두 통과한 경우에만 Production 승격이 허용됩니다.
