# v2026.11.17.15.1 — 내부 관리자 SEO 운영 검증 보완

## 작업 전
v15 SEO RSC 인증 헤더 수정 PR #3239 병합. 무중단 Nginx reload 직후 구 작업자 응답 503을 성급하게 검사하여 안전 롤백. 권한 우회는 발생하지 않음.

## 작업 중
검토된 내부 인증 헤더 수정만 백업 보존 상태에서 다시 적용. 신규 Nginx 작업자가 응답한 후 운영 RSC 요청 3회 연속 익명 401 및 실제 Next SEO 화면 HTML 정상 확인.

## 작업 완료
운영 스크립트에 2초 작업자 교체 대기를 추가. 이미 설치된 설정에서는 --check가 실제 접근제어와 헬스를 확인하고 --apply는 재수정·재시작 없이 검증만 수행. 운영 서버에서 bash 문법 검사와 두 명령 모두 통과. Spring 헬스 200, SEO RSC 익명 401, Next 프런트엔드 200, CSS 200, Nginx 문법 통과. DB·세션·원장·WLD·타 작업자 브랜치 변경 없음.

미검증: 로그인한 관리자 화면 긍정 E2E·세션 연속성. 다른 관리자 404는 별도 현안. 사이트 전체 전환·출시 인증 완료라는 의미가 아님.
