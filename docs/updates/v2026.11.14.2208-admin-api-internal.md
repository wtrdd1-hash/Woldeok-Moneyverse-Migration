# v2026.11.14.2208 — Internal: administrator API-origin outage recovery

**Before (2026-11-14 18:06 KST).** The reported `/admin` error reference `237831372` exactly matched Production Next.js `ApiError: API responded 404` at 18:05:52. The deployed frontend on port 4501 was configured with `API_ORIGIN=http://127.0.0.1:4550`, but that Spring Boot server did not implement the existing Next.js `/api/v1/auth/session`, `/api/v1/admin/security`, policy and stock paths. The existing NestJS on port 4500 still implemented the required routes. Inspected AGENTS, the master documentation index, living/integrated plans, release procedures, exact service environments and current `origin/main` (`6a37d5688b5d`). Protected the other agent's active Spring worktree.

**During.** Added a strictly loopback-scoped backend compatibility guard with four route probes. It fails for Spring 4550 and passes with the appropriate runtime tokens for Production Nest 4500 and official Test Nest 3100. A security-focused TDD test first exposed a malicious-host URL-validation issue (3 PASS, 1 FAIL), which was corrected (4 PASS, 0 FAIL). Started a separate frontend canary on 4511 from the existing immutable Production build using Nest 4500, verified anonymous admin/bank/chat/stock/login responses, and backed up Nginx. Hot-reloaded the frontend upstream to the canary without stopping 4501. Applied a final environment override to the canonical 4501 service, restarted it while canary handled traffic, checked it, then returned the Nginx upstream to canonical 4501. Spring 4550 was left running for separately routed migrated paths.

**Finished (18:18 KST).** Public cURL `/admin` 200 without the old digest, `/bank` and `/chat` 307 to login, `/stocks` and `/login` 200, `/health`, `/health/spring`, `/api/version` 200. Canonical runtime `API_ORIGIN` is Nest 4500; no matching new 404 appeared in its sampled journal after the correction. The spare 4511 frontend and `/etc/nginx/backups/moneyverse.before-admin-api-origin-20261114-1818-v2208` remain for rollback. No database, ledger, member balance, session, administrator policy, or immutable artifact was modified.

**Limitations.** This is a Production *configuration restoration*, not a new source release. Official Test backend contract was checked but its source SHA differs from Production/main. Authenticated administrator browser flows, OTP and money-affecting commands were not exercised. No full exact-SHA release or complete admin functionality certification is claimed. One Python-client public probe returned transient HTTP 403; direct Nginx and subsequent public cURL succeeded, so its cause remains unconfirmed.
