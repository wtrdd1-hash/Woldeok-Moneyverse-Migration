- Spring 전환 대상을 백엔드뿐 아니라 웹 프론트엔드까지 확대. 실제 이식 전에는 기존 Next.js·게임·인증 상호작용을 보존.
- Spring MVC·Thymeleaf로 영문 우선/한국어 두 번째 비회원 홈/안내 화면 2개 구현. 반응형 로컬 CSS와 접근성 시맨틱, 거짓 잔액·기술 스택 홍보 배너 배제.
- 검토 주소 `/spring-ui/home`, `/spring-ui/guide`에 `noindex,nofollow`와 `no-store` 적용. `MONEYVERSE_SPRING_HOME_ENABLED`, `MONEYVERSE_SPRING_GUIDE_ENABLED` 기본 **OFF**. 기존 `/`, `/guide`로 운영 전환하지 않음.
- Next 페이지 178개(관리자 39, 동적 33) 전수 목록과 읽기 전용 프론트 진입점 검증 스크립트 추가. 미전환 176개 경로는 Next 소유.
- 통합기획서 2종 영/한과 웹 전환 상세 계획 갱신.
