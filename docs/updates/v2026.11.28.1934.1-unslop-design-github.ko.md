- 동일 격리 서비스에서 원본 파일 16개 해시, 읽기 전용, 필수 참조 및 보조 frontend-design/emil-design-eng 확인. 원본 스크립트 3개 Node 문법 검사 통과, 실제 실행하지 않음. 브라우저 스크립트 안전성 전체 또는 모델 실제 스킬 사용을 증명한 것은 아님.
- root 관리 워커가 P7-W/QA04/P8-AR 시각 작업에서 고정 버전 스킬·감사 체크리스트 읽도록 지시. 간격→색상→아이콘→문구→타이포→배치→디테일→시각 자료→모션 9단계 의무 검토. 변경 범위·실제 문제·테스트·가능한 경우 브라우저 전후 스크린샷 기록. 목록이나 테스트 건수만으로 시각 PASS 선언 금지. 소스 기반 검토 가능, 실제 모델 준수 및 브라우저 검증은 미확인.
- 승인된 G2 Guild Ledger Terminal, 실제 favicon, 보라색 주요 액션, 본인 잔액 골드/Orbitron, 헤어라인 패널, 실제 데이터, 의미 있는 금융 색상, 화면별 구조, 역할 권한, 다섯 언어 유지. 일반 Unslop 지침이 승인 디자인을 덮어쓰지 않음. G1/v10/매니페스트 문서 불일치는 별도 정합성 검토 사항. 보라색 일괄 제거, 가짜 수치, 기능 삭제, 임의 전면 재설계 금지.
- 실서비스 스냅샷, 운영 접근, 이미지 서비스 연동, 영상 제작, 격리 완화 없음. 별도 격리 런타임에서 Chromium/Playwright 실제 검증 전까지 브라우저 QA HOLD. 전체 180개 화면 시각·기능 검증은 미완료. P6/P7/P8, 독립 검토, G7/G8/G9 및 네이티브 앱 중단 유지.
