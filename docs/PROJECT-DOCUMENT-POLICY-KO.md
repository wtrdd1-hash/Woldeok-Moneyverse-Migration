# 프로젝트 문서 운영 정책

- 정책 버전: **v1.0.0**
- 적용일: **2026-09-12**
- 저장소: `wtrdd1-hash/Woldeok-Moneyverse-Migration`
- 적용 범위: 프로젝트 문서 작성·수정·번역·업데이트

## 1. 문서 반영 원칙

문서 파일만 변경하는 작업은 별도 개발 브랜치나 Pull Request를 만들지 않고 **`main` 브랜치에 직접 반영한다.**

이 예외는 문서 전용 변경에만 적용한다. 소스 코드, 데이터베이스 마이그레이션, 배포 설정, CI/CD, 서버 설정 등 실행 결과에 영향을 주는 변경은 기존 개발·검증·배포 절차를 따른다.

## 2. 언어 원칙

프로젝트 문서는 사용자가 확인하기 쉽도록 **한국어 문서를 반드시 제공한다.**

영문 문서가 필요한 경우에도 한국어 문서를 함께 유지하며, 문서의 의미·버전·업데이트 내역이 서로 어긋나지 않도록 관리한다.

## 3. 문서 버전 관리

문서 정책 또는 주요 문서 구조가 바뀌는 경우 작업 순서에 따라 버전을 부여하고 문서 안의 업데이트 내역에 기록한다.

버전 표기 예시:

- `v1.0.0`: 최초 정책 확정
- `v1.0.1`: 오탈자·표현 수정
- `v1.1.0`: 문서 운영 규칙 추가 또는 변경

## 4. 업데이트 내역

### v1.0.0 — 2026-09-12

- 문서 전용 변경은 `main` 브랜치에 바로 반영하도록 확정.
- 코드·DB·배포 관련 변경은 문서 전용 예외 대상에서 제외.
- 한국어 문서를 반드시 제공하도록 명시.
- 문서 변경에도 버전과 내부 업데이트 내역을 기록하도록 명시.

## 5. 프로젝트 작업 시 적용

이 저장소에서 이후 문서 작업을 수행할 때 다음 순서를 기본으로 한다.

1. 현재 `main`의 최신 문서를 확인한다.
2. 기존 GitHub 문서 구조와 표준을 유지한다.
3. 문서를 작성 또는 수정한다.
4. 문서 자체에 버전 및 업데이트 내역을 반영한다.
5. 문서 전용 변경이면 `main`에 직접 커밋한다.
6. 코드가 함께 바뀌면 문서 전용 예외를 적용하지 않고 기존 코드 개발 절차를 따른다.
