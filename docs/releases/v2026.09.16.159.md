# v2026.09.16.159 — Work Day/Week Reset Convergence

## User-facing changes

- The Work page now shows server-authoritative daily and weekly WLD usage, remaining quota, and the exact next reset time.
- Career-task actions are disabled with an explicit reason when the member-wide daily/weekly reward cap or that task's daily completion limit has been reached.
- Reward previews now reflect the same task/day/week quota that settlement enforces instead of advertising an amount the server would refuse or clamp.

## Root cause and correction

Work settlement and task-board counters already used the accelerated Moneyverse clock (`600` real seconds per game day, `7` game days / `70` real minutes per game week). The legacy `work_my_dashboard` read model still keyed its rows by the civil `Asia/Seoul` day/week. Production audit reproduced this mismatch for 4 active members: current game-window receipt totals and dashboard values disagreed.

Forward migration `203-work-reset-convergence.sql` adds `work_my_dashboard_v2`, keeps the legacy five-column function as a compatibility wrapper, and makes reward previews quota-aware. No applied migration is edited or renumbered.
