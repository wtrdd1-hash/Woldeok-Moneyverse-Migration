# v2026.10.18.855 — 실제 기능 검증 및 허위 QA 완료 방지

**상태:** 독립 브랜치 검증 후보. **공개 운영 승격 승인 아님.**

## 수정

- 같은 브라우저의 다른 계정에 7·30·90일 모의 저축 기록이 노출되던 구조를 계정별로 분리했습니다. 회원 ID는 로그인 상태의 서버 지갑 API에서 얻으며 실패하면 모의 기록을 표시하지 않습니다. 실제 WLD 입출금이나 스키마는 변경하지 않았습니다.
- HTTP URL 조회·HTML 너비 문자열만으로 모바일 화면, 관리자 권한, 100조 WLD 거래를 전부 확인했다고 표시하던 QA 판정을 차단했습니다. 내부 API 토큰 없는 공지·사진 백엔드 조회의 401도 정상 예상 상태로 교정했습니다.

## 검증 및 제한

- 프론트엔드 1,276개, 완전 독립 최신 276개 SQL DB 기준 백엔드 1,836개 통과(34개 스킵), 256개 HTTP 스모크 확인; 전체 타입·Next 빌드·API 계약 통과.
- **운영 금융 원장 P0 지속:** 19개 잔액 불일치(+4,779,188 WLD 차이), 금융 3개 테이블 앱 직접 쓰기 권한. 실제 로그인 사용자 전체 E2E 및 모바일 렌더링은 아직 검증하지 못했습니다.
- 승인된 금융·Test·세션·CI·백업·무중단 절차가 모두 통과되기 전에는 운영으로 올리지 않습니다.
