# v2026.09.17.172 — 기획서 소스코드 동기화

Moneyverse 권위 기획서가 최근 변경된 카지노, 직업 초기화, 경제 AI 운영, 관리자 내비게이션의 현재 구현 파일 경로를 직접 참조하도록 갱신했다.

## 갱신된 근거

- 카지노 server-action 경계 복구와 client-safe runtime 상태.
- 카지노 정수 stake 계약과 서버 결과 기반 주사위 표현.
- 직업 가속 일/주 초기화 API, DB migration, frontend 필드, mobile API 계약.
- 경제 AI Debian/systemd runtime 운영 profile.
- 관리자 내비게이션 inventory 수렴과 회귀 검증.

## 릴리스 상태

문서 전용 변경이다. `main`의 소스 존재는 Production 검증이 아니다. v171 release-control 결함은 계속 OPEN이며, runtime 승격을 주장하려면 exact-SHA Test와 실제 runtime QA 증거가 필요하다.
