# v2026.09.07 — 게임플레이, UX 및 경제 안정성

[English](v2026.09.07.md) | **한국어** | [문서 색인](../INDEX.ko.md)

이 릴리스는 9월 7일 게임플레이/UX 감사 결과를 기준 배포에 통합합니다.

## 주요 변경

### 작업 UX
- 직업 과제 완료 모달에서 무기한 스피너에 갇히는 문제를 제거했습니다.
- 하나의 모달 시도는 하나의 멱등성 키를 유지하므로 타임아웃/재시도 때 이중 지급 대신 같은 영수증을 재생합니다.
- 느린 요청은 모달을 닫았다 다시 열지 않아도 복구 상태를 표시합니다.

### 반응형 탐색
- 브랜드/아이콘/텍스트 표시가 CSS breakpoint와 display 유틸리티를 따릅니다.
- 좁은 화면에서는 보조 브랜드/탐색 콘텐츠를 숨기되 DOM에는 유지하고, 화면을 넓히면 자연스럽게 다시 표시됩니다.

### 카지노
- 서버가 패배를 반환했는데 슬롯 릴이 `777`을 보여줄 수 있었던 문제 등 UI/서버 결과 불일치를 수정했습니다.
- 테마 게임의 최종 시각 결과는 서버 영수증에서 결정됩니다.
- 브라우저에 하드코딩된 지급 배수를 제거하고 DB에 공개된 조건을 UI가 사용합니다.
- 회원 전용 카지노 기록 읽기 모델을 추가했습니다.
- 숫자/문자열 충돌을 피하도록 프론트엔드 금액 처리를 표준화했습니다.
- 기준 노출을 1회 10–200 WLD, 일일 베팅 2,000 WLD, 일일 실현 손실 1,000 WLD로 재조정하며 기준 RTP 95%를 유지했습니다.
- 개인 베팅/손실 제한과 자기 배제는 더 엄격한 회원 제어로 유지합니다.

### 은행
- 강제 최소 1 WLD 이자 지급을 제거했습니다.
- 예금 잔액 변경 시 이자 누적 시계를 재설정합니다.
- 수동 이자 청구와 표시 금리가 같은 서버 계약을 사용합니다.
- 이자 청구에 멱등성을 적용했습니다.
- 새 대출은 우회 smart-loan 경로가 아니라 기존 신용등급 정책을 사용합니다.
- 애플리케이션 역할의 예금 이자 추적기 직접 접근을 차단했습니다.

### 퀘스트 정확성
실제 게임플레이 구현이 없던 임시 이벤트 효과를 제거했습니다. 실제 WLD/EXP/아이템 보상은 변경하지 않았습니다.

### 문서
오래된 마이그레이션 호스트 README를 현재 Production/Test 주소로 교체하고 한국어, 영어, 중국어 간체/번체, 일본어, 스페인어 현지화 문서를 추가했습니다.
