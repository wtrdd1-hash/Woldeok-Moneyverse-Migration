# v2026.10.29.1511 — 텔레그램 주식 뉴스·주가 급변·중요 오류 알림

**범위**: 기존 v1510 개인 대화 봇을 재사용하는 독립 Python/systemd 읽기 전용 서비스. 금융 거래/DB 쓰기/주가 조작/뉴스 생성/기존 웹서비스 재시작 없음.

## 알림 항목
- AI 뉴스 시나리오가 생성되면 **초안 생성(미발행)**으로 구분하여 통지.
- 시장에 발행된 실제 이벤트는 종목·제목·출처·방향·강도를 **발행됨/시장 반영**으로 통지.
- 종목별 2분 관측 사이 ±5% 급변(20분 간격 제한), 당일 시가 ±10%(하루 한 번), 거래정지/해제, 한국시간 오전 9시 시황 요약. 모든 가격은 가상경제 WLD.
- 중요 systemd 오류는 서비스별 건수만 전송하며 로그 원문·회원 정보·비밀정보 미전송.
- 첫 실행은 과거 자료 기준값만 기록. 전송 영수증 기준으로 성공을 기록하고 실패 시 재시도. 다량 이벤트는 초과 건수 요약.

- 가상 주식의 필요한 컬럼만 읽기 전용 SQL 트랜잭션으로 조회. 현재 debian 호스트 계정의 Docker 그룹은 DB SELECT 전용 계정보다 권한이 넓으므로 추후 최소권한 DB 조회 방식 보완 권장.
- 인증 토큰과 수신자 정보는 미니PC 보안 디렉터리에만 저장, GitHub 비공개.
