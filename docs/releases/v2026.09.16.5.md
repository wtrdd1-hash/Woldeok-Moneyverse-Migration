# v2026.09.16.5 — Trade-history sorting

## User-facing change

The member-only `/stocks/history` workspace now supports sorting personal virtual-stock trades by newest, oldest, largest gross trade value, or largest quantity. Search, buy/sell filtering, and sorting compose in one URL-driven form so members can narrow and order their history at the same time.

## Integrity and privacy

This is a read-only presentation enhancement over the existing actor-scoped stock-history endpoint. WLD and share quantities remain integer-string safe: value and quantity sorting use `BigInt` rather than JavaScript floating-point conversion. No database schema, migration, ledger posting, trade mutation, authorization, idempotency, or Production data path changes.

## Release gate

Do not treat source integration as runtime proof. Promotion still requires the repository CI gates and isolated exact-SHA Test evidence for authenticated ownership, combined search/filter/sort behavior, responsive/accessibility behavior, private noindex policy, and candidate image/SHA parity.
