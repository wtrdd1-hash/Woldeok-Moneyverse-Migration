# v2026.09.08 — Public Board & Search Discoverability

This candidate release keeps restricted features permission-driven while making the community board readable without membership.

- Public visitors may read board lists, threads, comments and images attached to visible posts.
- Posting, editing, deletion, commenting and uploads remain authenticated, policy-consented and CSRF-protected.
- New PostgreSQL public read models preserve the no-direct-table-grant boundary.
- Board threads now expose indexable canonical metadata derived from their public content.
- Production frontend builds accept the public `SEARCH_CONSOLE_VERIFICATION` value; test builds do not.
- Robots/sitemap behavior is covered by a regression test.

This release is not eligible for Production until its stacked deployment changes and this migration are verified on the isolated test stack first.
