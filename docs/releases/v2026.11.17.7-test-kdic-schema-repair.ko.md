## 사후 백업 보호
테스트 DB 덤프 원본은 최종 AES-256-CBC + PBKDF2 암호화 파일 actual-test-baseline.dump.enc (21,932,144바이트, root 0600)로 보존. 암호화 파일 SHA256 e9036164e02d4ec301da5bb655a846fdd839c0a3a4286cfe55ca5193eab6c751, 원문 SHA b140de45a7c16e5c8aa425fc54fbce2b78fa3dc2c5ac81ec68732851f19bd419을 복호화 스트림으로 교차 검증했다. 비공식 CI 덤프도 별도 암호화해 보존하고 원문 덤프 파일은 최선의 삭제(shred) 실행. SSD의 물리적 완전 삭제 보장은 하지 않는다. 임시 QA 복제 DB 2개는 연결 0건 확인 후 삭제, 실제 공식 Test DB는 유지.
