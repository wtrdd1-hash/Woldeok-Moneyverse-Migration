# v2026.10.16.739 — 테스트 서버의 의도치 않은 검색엔진 제출 방지

**상태: 수정 후보, 신규 운영승격 검증 대기.** [English](v2026.10.16.739.md)

## 확인된 문제
v738 금융 검증용 별도 테스트 카나리에서 기존 `SeoCronPingService`가 테스트 모드·색인 활성 조건 확인 없이 30초 후 자동 제출을 실행. 로그상 IndexNow/Google에 URL 39건 제출 기록. 카나리 즉시 중지 및 설치된 유닛 제거, 공식 Test·운영 서비스는 변경 없음.

## 수정
- `NODE_ENV=test`이면 SEO 색인 설정이 true여도 자동 실행 예약을 차단.
- 테스트 외 서버에서도 `SEO_INDEXING_ENABLED=true`를 명시한 경우에만 예약하며, 기본값은 차단.
- 시작 30초 타이머와 6시간 반복 타이머를 서비스 종료 시 해제.
- 금융 DB·회원 금액·로그인 세션·운영 릴리스·블로그 글 내용 변경 없음.
- 회귀 테스트 4/4 통과. CI 및 최종 빌드 결과는 GitHub PR 확인.

## 별도 남은 조건
39건 로그는 **제출 기록**이지 실제 Google 색인 성공 증거가 아님. 실제 운영 v717과 Test v735.2는 유지. 금융 DB 직접 쓰기 권한, 19개 잔액 근거 미확인, 전체 인증 UI 166개 경로 × 5회 검증 조건 계속 미충족.
