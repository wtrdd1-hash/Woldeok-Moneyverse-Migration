## P0 발견 및 수정
기존 마이그레이션 232의 marketplace_bid_auction 함수는 이중기입 원장 거래 없이 account_balances를 직접 변경합니다. Backend는 입찰 전 경매 마감 시간을 변경하고 프록시 입찰을 메모리에만 보관했습니다. 경매 화면은 실제 DB에 확인되지 않은 매물 3개를 표시하고 HTTP 실패 시에도 에스크로 입찰 성공을 알렸습니다.

PostgreSQL 숫자형의 .0000도 정수 문자열로 정밀하게 처리합니다. 회원 전용 /marketplace는 noindex/nofollow입니다. Android app-api의 쿠키·CSRF 전달, 503·no-store 전파를 테스트했습니다. DB 마이그레이션·원장 쓰기·신규 권한 부여는 없습니다.
