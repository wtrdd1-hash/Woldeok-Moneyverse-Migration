# v2026.09.19.291 — Durable member login persistence

## Summary
Ordinary member login now persists for 180 days and survives backend/frontend process or host restarts because session authority remains in PostgreSQL.

## Changes
- Member auth cookie lifetime: 30 days → 180 days.
- Member DB session sliding expiry: 30 days → 180 days.
- Migration 215 extends currently active ordinary member sessions and protects all future member-session INSERT paths.
- /auth/session continues to refresh the same opaque browser cookie, so active users receive the longer lifetime without a new login.
- Pre-login sessions remain 30 days.
- Privileged administrator-console lifetime/idle controls are unchanged.
