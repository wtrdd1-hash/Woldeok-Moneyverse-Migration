# 지갑 거래내역 커서 페이지네이션 — 개발 A / 2026-10-24 03:25 KST

**배포 판정: HOLD / 미배포.** 기존 최근 50건 제한 때문에 확인할 수 없던 과거 WLD 거래를 읽기 전용으로 페이지별 조회하는 기능을 구현했습니다. 백엔드 조회 API, 서비스·PostgreSQL 조회, 지갑 거래내역 화면, Android app-api 개인정보 보호를 연결했습니다. 원장·마이그레이션·운영 서비스는 변경하지 않았습니다.

## 기능과 안전성
`GET /api/v1/wallet/history?before=<거래 UUID>`는 `{transactions, nextCursor}`를 반환합니다. 한 페이지는 20건이며 21번째 레코드로 다음 페이지 유무를 판단합니다. PostgreSQL 내부에서 거래 UUID의 원래 시각을 조회해 마이크로초 정밀도를 보존하고 `(created_at, id)` 순서로 탐색합니다. 타인 거래나 존재하지 않는 커서는 빈 결과를 반환합니다. 사용자 ID는 인증 세션에서만 결정하며 금액은 정수 문자열로 유지합니다. Android 프록시는 인증 쿠키·커서를 전달하되 `private, no-store`를 강제하고 ETag/Last-Modified를 제거합니다.
