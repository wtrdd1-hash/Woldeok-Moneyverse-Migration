# v2026.09.16.3 — 관심 종목 탐색 기능

## 사용자 기능
- 회원 전용 관심 종목 화면에서 종목 코드 또는 이름으로 저장 종목을 검색할 수 있습니다.
- 최근 저장순, 당일 등락률순, 현재 WLD 가격순, 이름순으로 정렬할 수 있습니다.
- 검색어와 정렬 조건은 `q`, `sort` URL 파라미터로 유지되어 새로고침하거나 북마크해도 같은 탐색 상태를 복원합니다.
- 검색 결과가 없는 상태를 빈 관심 목록과 구분하고 필터 초기화 경로를 제공합니다.

## 무결성
- 필터링은 기존 인증된 actor-scoped 관심 종목 조회 결과에만 적용되는 읽기 전용 기능입니다.
- 가격과 등락률 정렬은 `BigInt`를 사용하며 integer-string 가격을 부동소수점으로 변환하지 않습니다.
- DB 스키마, migration, ledger, 거래 mutation, idempotency, authorization, Production 데이터 경로는 변경하지 않았습니다.

## 검증/승격
- staging 전에 GitHub CI와 exact-SHA 후보 검증이 필요합니다.
- 병합/Production 승격 전 staging에서 인증된 검색·정렬 조합, URL 상태 유지, 검색 결과 없음/초기화, 반응형·접근성, private noindex 정책, exact candidate SHA/image parity를 검증해야 합니다.
