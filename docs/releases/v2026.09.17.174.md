# v2026.09.17.174 — Automated backup safety

Moneyverse adds a Debian-native encrypted backup workflow for the authoritative database and production photos. Backups run on a separate local disk, verify checksums and archive structure, retain 14 days, and refuse to run when the destination shares the source filesystem.

This release improves local recovery but does not claim complete disaster recovery: off-host immutable replication and isolated restore/RPO/RTO proof remain required.
