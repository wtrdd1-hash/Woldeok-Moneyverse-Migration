# v2026.09.18.232 — Admin user access visibility

The administrator member directory now exposes recent account access as a first-class field instead of burying it inside the identity cell.

- Shows recent activity, last login, and administrator-console access timestamps.
- Displays the full Korea-time date and time, including year and seconds.
- Adds a “recent access” sort so operators can bring the most recently active members to the top.
- Preserves the existing search, restriction filter, asset view, and detail/audit navigation.
- Reuses the existing server-side access summary and activity logging path; no schema or ledger mutation is introduced.

Validation: component regression tests, frontend typecheck, production build, exact-SHA Test canary, Test backend version probe, and unauthenticated admin API guard.
