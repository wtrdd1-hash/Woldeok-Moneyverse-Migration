# v2026.09.15.121 — Virtual Stock Discovery Search

## Summary

Adds a user-facing search flow to the authenticated virtual-stock market so members can quickly narrow the market by symbol, name, or description without changing trading or ledger behavior.

## Highlights

- Adds a keyboard-accessible GET search form to `/stocks` with shareable `?q=` state.
- Matches symbol, display name, and description case-insensitively and limits accepted UI query state to 80 characters.
- Shows localized result counts, clear action, and a search-specific empty state.
- Keeps all holdings, trading, watchlist, pricing, ledger, and authorization paths unchanged.
