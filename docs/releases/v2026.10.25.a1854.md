# Release Candidate v2026.10.25.a1854 — Owner-Verified Recent Wallet Receipt

**Status: DRAFT / PARTIAL / BLOCKED — NOT RELEASED.** English canonical release note; [Korean translation](v2026.10.25.a1854.ko.md).

## Change
One P1 end-to-end member feature: a read-only, owner-scoped receipt for a transaction within the last 50 wallet entries. A member selects a transaction in `/wallet/activity` and opens `/wallet/activity/[id]`. The server resolves the signed cash, bank and total movements from the existing PostgreSQL ledger projection; an absent, foreign, older-than-50 or malformed transaction never produces a confirmed receipt. Amounts remain canonical WLD integer strings. The Android `/app-api/v1/wallet/transactions/{id}/receipt` contract is documented and the gateway is tested. No database migration, ledger mutation or new table privilege.
