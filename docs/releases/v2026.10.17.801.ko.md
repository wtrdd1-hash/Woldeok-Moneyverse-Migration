# v2026.10.17.801 — 암시장 경매 무원장 정산 긴급 차단

**상태:** [GitHub PR #928](https://github.com/wtrdd1-hash/Woldeok-Moneyverse-Migration/pull/928) CI·Test 후보 이미지 빌드 통과 및 main `bd6cf172` 병합 완료. 공식 Test/운영 앱 승격 미실시.

## 수정 내용
- 기존 암시장 경매는 보유 WLD를 확보하지 않고 입찰을 수락하고, `settleExpiredAuctions`가 복식부기 원장 없이 회원 USER_CASH를 직접 차감한 뒤 SINK에 입금·아이템을 지급할 수 있었다. 단일 SQL 트랜잭션만으로 불변 원장 정산이 성립하는 것은 아니다.
- `placeBid()`는 어떤 기능 환경 변수에도 관계없이 **첫 SQL 실행 전** HTTP 503 `BLACK_MARKET_LEDGER_SETTLEMENT_UNCERTIFIED`로 차단. 자동 정산은 DB 조회·수정 없이 종료. 기존 입찰과 경매 상태는 복구 검토를 위해 보존한다.
- 기존 경매 목록/입찰 로그 읽기는 유지. 웹에서 새 입찰 금액과 성공 안내 버튼을 없애고, 검증 중이라는 설명을 노출한다. 기존 최고가가 실제 지급·소각·아이템 수령 완료라는 의미가 아니라고 명시한다.
- 기존 금융 원자성 회귀검사를 ‘검증된 단일 정산 트랜잭션 **또는** 원장 미인증 시 거래 실행 차단’ 계약과 맞게 보강했다.
