# v2026.09.16.2 — 관심 종목 전용 화면

## 사용자 기능
- 저장한 가상 주식만 모아 보는 회원 전용 `/stocks/watchlist` 화면을 추가했습니다.
- 주식 도구 내비게이션에서 관심 종목 화면으로 바로 이동할 수 있습니다.
- 각 관심 종목에서 종목 코드, 현재 WLD 가격, 정수 기반 당일 등락률, 관심 종목 해제, 종목 허브 이동을 제공합니다.
- 관심 종목이 없는 상태와 API 오류 상태를 구분하고 거래소로 돌아가는 경로를 제공합니다.
- 실제 증권·투자 상품이 아닌 게임 전용 데이터라는 안내를 한국어·영어에서 동일하게 제공합니다.

## SEO/개인정보 수정
- 인증이 필요한 `/stocks` 전체 경로가 주식 레이아웃의 `noindex,nofollow` 메타데이터를 상속하도록 변경했습니다. SEO-132-01의 단기 private-UI 정책을 적용해 회원 전용 주식 도구가 공개 검색 대상이라고 광고하지 않도록 합니다.

## 무결성
- DB 스키마, migration, ledger, 거래 mutation, 가격 권위, actor authorization, idempotency, Production 데이터 경로는 변경하지 않았습니다.
- 등락률 표시는 부동소수점 변환 대신 `BigInt` basis-point 연산을 사용합니다.

## 검증/승격
- staging 전에 GitHub CI와 exact-SHA 후보 검증이 필요합니다.
- 병합/Production 승격 전 staging에서 인증된 관심 종목 로딩·해제, empty/error 상태, 종목 허브 이동, noindex 메타데이터, 반응형 화면, exact candidate SHA/image parity를 검증해야 합니다.
