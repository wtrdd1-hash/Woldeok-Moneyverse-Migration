# v2026.09.19.262 — 로컬 비밀번호 보안 재인증

## 한국어

- `local_email` 자격 증명을 사용하는 회원이 이메일·비밀번호로 최근 본인 확인을 갱신할 수 있게 했습니다.
- 보안 센터는 로컬 로그인 수단이 연결된 계정에만 접근 가능한 이메일·비밀번호 재인증 폼을 표시하고, 기존 OAuth 재인증도 그대로 유지합니다.
- `POST /api/v1/auth/local/reauthentication`은 로그인 세션과 CSRF를 요구하고, 제출된 자격 증명이 현재 사용자 소유인지 확인한 뒤 Argon2id 비밀번호 검증에 성공한 경우에만 해당 활성 세션의 `reauthenticated_at`을 갱신합니다.
- 다른 계정의 자격 증명은 fail-closed 처리되어 현재 세션을 최근 재인증 상태로 만들 수 없습니다. 알 수 없거나 틀린 자격 증명도 동일한 일반 오류 경로를 사용합니다.
- DB 스키마 migration이나 경제 상태 변경은 없습니다. 민감한 계정 작업의 허용 시간은 기존 recent-reauthentication guard가 계속 권위 있게 판정합니다.
