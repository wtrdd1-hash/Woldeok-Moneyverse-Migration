2. **New issuance to Treasury:** Mint UI separately allows `TREASURY_ISSUANCE` policy proposal; approved, unexpired, bounded MINT orders (1–10,000,000 WLD per execute) may issue actual WLD in **one** canonical MINT→TREASURY double-entry transaction and same atomic VAULT_MAIN/epoch/journal/mint certificate/settlement receipt transaction. The user's actual role, freeze status, amount ceiling and UUID replay are checked at PostgreSQL scope, with no direct financial-table writes by `moneyverse_app`.

Former snapshot-only `executed:true` response now returns `executed:false` and `SWF_SETTLEMENT_SOURCE_UNVERIFIED`; historic simulated AUM and PnL are labelled unspendable. Unsupported modeled AUM return/rebalance buttons are disabled. **A real custody/trade-fill/settlement-based auto-investment engine was not created by this release and is not claimed to be operating.** Existing scheduled execution remains disabled/fail-closed.
