# v2026.09.16.156 — 카지노 플레이 계약 및 주사위 UX 수정

## 사용자 변경 사항

- 동전/주사위 베팅 금액을 카지노 API DTO 계약에 맞는 JSON 숫자로 전송하도록 수정하여, 정상 금액이 숫자 문자열로 전달되어 HTTP 400으로 거절되던 문제를 해결했습니다.
- 주사위 홀짝/숫자 맞히기 게임에 동전 뒤집기와 같은 수준의 전용 비주얼 플레이 영역, 서버 결과 표시, 처리 중 굴림 효과를 추가했습니다.
- 애니메이션은 화면 표현만 담당하며 실제 결과와 정산은 계속 서버 영수증만을 기준으로 합니다.

## 원인

`AmountInput`은 읽기 쉬운 표시를 위해 텍스트 값을 전송합니다. 기존 서버 액션은 `wholeAmount()`로 금액을 정규화한 뒤 문자열 상태로 `stake`에 넣었습니다. 반면 백엔드 카지노 DTO는 암시적 숫자 변환을 비활성화하고 숫자 문자열을 의도적으로 거부합니다. 따라서 화면에서 입력한 정상 값 `10`도 `/api/v1/casino/dice/plays`에는 `"10"`으로 전달되어 HTTP 400이 발생했고, 공통 오류 문구인 “입력한 내용을 다시 확인해 주세요.”가 표시됐습니다.

## 계약 수정

카지노 플레이 서버 액션은 이제 제한된 베팅 금액에 `wholeNumber()`를 사용합니다. 표시용 쉼표를 제거하고 양의 안전 정수만 허용한 뒤 JSON 숫자로 전송합니다. 최소/최대 베팅, 일일 한도, 결과 생성, 멱등성, 정산 권한은 기존과 동일하게 백엔드/DB가 유지합니다. 확률·배당·원장·DB 마이그레이션은 변경하지 않았습니다.
