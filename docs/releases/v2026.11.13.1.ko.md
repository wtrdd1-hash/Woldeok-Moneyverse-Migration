## 요약·주요 변경
- NestJS/TypeScript에서 Java/Spring Boot로 **전체 백엔드**를 바꾸는 기획 시작. 일반 API·관리자·금융·실시간·스케줄·봇·외부 연동 전부 포함. 기존 Next.js UI와 Android 클라이언트, PostgreSQL 정식 원장을 초기 구조에서 유지한다.
- **Spring 모듈형 백엔드와 경로별 점진 이관**을 권장안으로 제안. 구현 승인이 완료되었다는 뜻은 아니다.
- G0(실사/복원)~G6(NestJS 종료) 단계, 단계별 설계/승인·격리 Test 정확 SHA·보안·DB 대사·클라이언트 계약·메모리 여력·무중단 승격·롤백 조건 제시.
- 금융 쓰기 이중 실행, 원장 직접 수정, 데이터 초기화, 강제 로그아웃, 스케줄 이중 리더, 독립 복원/배포 신원 없는 승격 금지.
- Kubernetes/Flux와 systemd/Nginx 배포 설명의 불일치 기록, 운영 실제 경로 실사 필요.

## 변경 파일·영향 대상
- 상세 설계: `docs/superpowers/specs/2026-11-13-spring-platform-migration-design.md` 및 `.ko.md`.
- 영/한 작업기록·버전 릴리스 메모·CHANGELOG, 영/한 `PROJECT_PLAN`·`INTEGRATED_PLANNING_MASTER` 참조.
- `backend/`, `frontend/`, `bot/`, Android 앱, SQL migration, 인프라, 런타임 소스 변경 없음.

## 검증·시험
- 이번 변경은 문서 구조, 링크, 영/한 상태 동등성, diff 점검만 대상으로 하며 실제 검증 결과는 작업기록에 기재한다.
- Java 빌드·단위·통합 시험: **미실행**(Java 코드 없음).
- DB migration·원장 대사·인증된 웹 및 Android E2E·Test·Production 검증: 이번 초안에서는 **미실행**.

## 데이터베이스 migration
없음. 기존 원장·회원 데이터 변경 없음.

## 운영 안전
- 인증 정보·비밀·회원 데이터를 기획서에 기록하지 않음.
- 기존 기능 스위치와 금전 처리 그대로 유지.
- Test·운영 전환, 서비스 재시작, Nginx 수정, DB 초기화, GitHub Release/태그, main 병합 없음.
- 롤백은 **향후 의무 조건**이며 이번 단계에서 실제 롤백 시험을 수행한 것이 아님.
