# v2026.10.17.796 — 마켓 감정서 원장 우선 처리 수정 후보

**[English](v2026.10.17.796.md)** | 한국어

**상태:** 격리 브랜치 구현 및 폐기 가능한 테스트 DB 복제본 검증 완료. 공식 Test와 운영은 이 후보를 아직 배포하지 않았습니다.

## 변경
- PostgreSQL DO 블록의 잘못된 파라미터와 원장 없는 직접 잔액 변경을 원장·감정서 단일 DB 트랜잭션으로 대체합니다.
- 같은 회원·아이템·희귀도 재요청은 기존 감정서를 반환하고 중복 결제하지 않습니다. 잔액 부족 시 지급·발급을 차단합니다.
- 앱에는 전용 SECURITY DEFINER 함수 실행 권한만 부여하며 재무 테이블 직접 쓰기 권한은 주지 않습니다. 원작자 출처는 검증 전으로 표시합니다.

## 증거 및 운영 보류
- 수정 전 실패 1건, 수정 후 관련 7개 테스트 통과. 공식 Test DB의 폐기 가능한 복제본에 마이그레이션 276 적용: 감정서 1건, 거래 1건, 균형 분개 2건, 사용자 −250/SINK +250 WLD, 중복 청구 없음, 잔액 부족 거부, 앱 직접 재무 UPDATE 0. 복제본은 삭제했습니다.
- 전체 CI/PR/정확한 SHA 테스트 승격은 별도 필수 관문입니다. 운영은 19개 계정 원장 차이 4,779,188 WLD, 핵심 테이블 5개 직접 쓰기 권한 및 v530 인증 전체 UI 5회 검증 미완료로 보류 상태입니다. 4,410 WLD 추가분과 연금 지급 98×45 WLD 로그가 일치하나 지급 적법성과 재원은 추가 검증 대상입니다.
- 허구의 보정 원장 또는 잔액 덮어쓰기를 금지합니다.

- 전체 테스트에서 새 MARKETPLACE_APPRAISAL 원장 유형의 한국어 지갑 표시명 누락을 발견하여 '마켓 감정서 발급 수수료'로 지정하고 회귀 검증을 추가했습니다.
