# v2026.10.16.738 — 통화 발행·소각 및 자동 통화 조정 안전 차단

**상태: 구현 후보. 전체 금융·UI 운영승격 조건 미달로 운영 반영은 차단.** [English](v2026.10.16.738.md)

## 변경 내용
- 금융 초안 PR #892의 통화 안전 코드만 별도 최신-main 브랜치로 분리. 다른 작업자의 원본 PR/브랜치, 미승인 migration 272, 실제 금융 데이터는 변경하지 않음.
- 조폐국 발행·소각 인증, 중앙은행 명령서 발의·승인, AI 통화정책 명령을 정식 원장 검증 전 HTTP 503으로 차단하며 SQL 변경 전에 반환.
- 기존 초안과 달리 **오래된 MONEYVERSE_MINT_* 두 환경값을 모두 켜도 발행·소각을 다시 열 수 없음**. 향후 정식 원장 분개·DB 권한·독립 Test 검증 및 코드 리뷰 후 별도 구현 필요.
- 자동 통화 조정의 신규 활성화도 설정으로 열지 못함. 관리자는 비활성화할 수 있고 비상 발행 동결은 계속 사용 가능.
- 통화 관리 API는 관리자 콘솔 세션·CSRF 검사를 강화하고 승인·발행·동결 해제·수동 자동조정에 재인증 추가.

## 검증
- 초기 통화 관련 21/21 통과, 이후 설정값 양쪽 강제 활성화 및 자동 조정 거부 테스트 통과. 전체 백엔드 **1,227 통과/DB 의존 396 생략**(최종 설정 보호 추가 전); 후속 최종 CI·타입 검사·빌드·독립 Test 확인 필요.
- DB 스키마/권한·보유 금액·회원 로그인 세션·운영 프로세스 변경 없음. 생략한 DB 검증을 성공 처리하지 않음.
- 현 운영 v717 `176ca04e`, Test v735.2 `9618a249`; 새 후보는 기존 서버를 자동 대체하지 않음.
