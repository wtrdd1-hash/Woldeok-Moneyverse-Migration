**Status: isolated GitHub candidate; public Test/Production NOT deployed.**

## Root causes and patch
- Mines/Plinko have no trusted backend wager or payout route; client-side Math.random and React state previously described fake WLD wins/losses as completed. Both now visibly disclose that they are **browser-only demos** with no real balance debits, payouts, or transaction receipts; simulated amounts and results say so.
- Plinko's unsupported “RNG normal-distribution verification complete” badge is removed in favor of “browser random simulation — not certified.”
- Shared input parser rejects unsafe, fractional, negative, nonnumeric, unbounded and remaining-quota-exceeding simulated stakes; no fallback silently fabricates a stake.
- Mines auto-win when the last safe gem is opened now computes payout from the *current gem count*, rather than the previous React render's multiplier. Browser-only math, not evidence of a settled game payout.
- Added pure-math tests and UI regression tests covering visible truth, invalid stakes and the last-gem payout.
