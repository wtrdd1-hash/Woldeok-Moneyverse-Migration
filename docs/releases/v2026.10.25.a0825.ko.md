## P0 허위 지급 차단과 실제 구현
- **수정 전:** 포춘쿠키 POST는 원장 거래 없이 임의의 500~1,000 WLD 지급 성공을 반환했고, 브라우저도 API 실패 여부와 무관하게 별도의 임의 금액을 '즉시 지급'으로 표시했습니다. 기존 Android app-api에서는 해당 경로가 차단되어 있었습니다.
- **수정 후:** 기존 보상 POST는 HTTP 503으로 실패 처리. 인증·동의 검증을 통과한 GET `/api/v1/engagement/dopamine/pet-fortune/preview`가 `{kind:'preview',quote,rewardPosted:false}`만 반환합니다. `private, no-store` 적용, 거래 ID·지급액·허위 수령 영수증 없음.
- Android app-api는 **읽기 전용 미리보기 경로 하나만** 허용하고 다른 engagement 지급 경로는 열지 않았습니다. 웹은 서버에서 실제 응답을 확인한 경우에만 운세 문구를 보여주고, 실패하면 재시도 오류를 표시합니다. 지갑 갱신 이벤트나 허위 보상 안내 없음. 쓰다듬기 친밀도는 화면 내 값으로 명시, 기본 HTML 버튼으로 키보드·포커스 접근성 개선.
- 신규 마이그레이션·DB 쓰기·원장 변경·운영 배포 없음. 실제 일일 WLD 보상은 아직 미구현이며 #1244에서 별도 관리.
