# v2026.09.16.5 — 거래 내역 정렬

## 사용자 변경 사항

회원 전용 `/stocks/history` 화면에서 개인 가상 주식 거래를 최신순, 오래된순, 거래금액 큰순, 수량 많은순으로 정렬할 수 있습니다. 종목 검색, 매수/매도 필터, 정렬을 하나의 URL 기반 폼에서 함께 적용할 수 있어 원하는 거래를 더 빠르게 찾을 수 있습니다.

## 무결성 및 개인정보

기존 actor-scoped 주식 거래내역 API를 사용하는 읽기 전용 화면 확장입니다. WLD와 주식 수량은 integer-string 안전성을 유지하며 거래금액·수량 정렬은 JavaScript 부동소수점 변환 대신 `BigInt`를 사용합니다. DB 스키마, migration, ledger posting, 거래 mutation, authorization, idempotency, Production 데이터 경로는 변경하지 않습니다.

## 릴리스 게이트

소스 통합만으로 런타임 검증 완료로 간주하지 않습니다. 승격 전 저장소 CI와 격리된 exact-SHA Test에서 인증 사용자 소유권, 검색/필터/정렬 조합, 반응형·접근성, private noindex 정책, 후보 image/SHA parity를 확인해야 합니다.
