# v2026.09.19.262 — local-password security reauthentication

## English (canonical)

- Adds first-party email/password reauthentication for members who use `local_email` credentials.
- The security center now exposes an accessible email/password step-up form only when the account has a local identity, while preserving OAuth reauthentication for linked providers.
- `POST /api/v1/auth/local/reauthentication` requires the authenticated session plus CSRF, verifies that the submitted credential belongs to the current user, verifies the Argon2id password, and only then refreshes `reauthenticated_at` for that exact active session.
- Cross-account credentials fail closed and cannot mark the current session as recently reauthenticated. Unknown/wrong credentials use the same generic error path.
- No schema migration or economic state change is required. Existing recent-reauthentication guards continue to own the authorization window for sensitive account actions.
