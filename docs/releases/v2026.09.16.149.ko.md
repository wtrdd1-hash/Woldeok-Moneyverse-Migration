# v2026.09.16.149 — 직업 대시보드 초기화 기준 통합

## 요약

- 직업 정산은 가속 Moneyverse 서버 시간을 사용하지만 직업 대시보드 조회는 실제 Asia/Seoul 달력을 사용하던 불일치를 수정했습니다.
- 일간 직업 사용량 조회를 정산과 동일한 `server_game_day_key()` 기준으로 통일했습니다.
- 주간 직업 사용량 조회를 정산과 동일한 `server_game_week_key()` 기준으로 통일했습니다.
- 현재 서버 일/주 보상 윈도우를 대시보드가 정확히 읽는지 실제 DB 회귀 테스트를 추가했습니다.

## 사용자 영향

직업 대시보드의 주간 사용량이 현실 월요일까지 남아 있는 현상을 제거합니다. 현재 정책은 현실 10분 = 서버 1일, 현실 70분 = 서버 1주입니다.

## 안전성

기존 마이그레이션을 수정하지 않는 forward-only 조회 모델 수정입니다. 기존 보상 영수증, 직업 숙련도, 멱등성, 관리자 한도 및 정산 원장은 다시 쓰지 않습니다.
