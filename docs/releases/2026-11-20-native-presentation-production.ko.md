# 2026-11-20 공개 프론트엔드 운영 전환 기록

**현재 상태: 공개 화면 5개 운영 전환 완료. 전체 사이트·관리자·금융 기능 완료를 뜻하지 않습니다.**

2026-11-20 21:53:58 KST에 새 프론트엔드를 운영 기본 경로로 연결했습니다. 사용자가 백엔드 문제를 후속 작업으로 분리하도록 지시했으므로, 이번 전환은 DB 연결이 없는 공개 화면 전용 실행 모드입니다. 기존 API·로그인·송금·매매·관리자 작업 경로는 이 작업에서 변경하지 않았습니다.

## 적용 경로와 실제 연결

| 경로 | 적용 내용 |
|---|---|
| `/` | 새 홈·반응형 공통 메뉴·기존 운영 API를 호출하는 위젯 |
| `/tools` | 도구 검색·카테고리·검증 도구 필터 |
| `/calculators` | 계산기 목록·검색·필터 |
| `/tools/compound-calculator` | 실제 서버 계산과 결과 표시 |
| `/tools/stock-calculator` | 실제 평균단가·목표 매도가 계산 |

`/index.html` 및 위 도구의 기존 끝 슬래시 주소도 호환 처리했습니다. 새로운 화면이 호출하는 기존 주식 API는 종목 10개, 게시판 API는 `ok:true`와 게시글 2개를 반환했습니다. 운영 브라우저의 새 홈에는 표시 제한에 따라 실제 종목 8개와 게시글 2개가 렌더링됐습니다. 새로고침과 기존 투자 화면으로 이동도 직접 확인했습니다. 비로그인 세션은 회원 정보와 잔액을 노출하지 않았습니다. 현재 브라우저는 비로그인 상태여서 로그인 회원의 실제 잔액·거래·관리자 작업을 재인증한 것은 아닙니다.

## 검증 결과

- 새 소스의 clean 검증: Spring 542건/92 suites, Node 276건. 실패·오류·건너뜀 0, JAR 빌드 성공.
- 화면 전용 실제 컨텍스트는 잘못된 DB URL을 주어도 DB 없이 시작하고, API·회원·관리자·변경 요청을 거부합니다.
- 차단된 HTML 요청이 JSESSIONID를 만들던 문제를 먼저 재현하고 수정했습니다. 실제 Tomcat HTTP 회귀 검사도 통과했습니다.
- 한국어·영어·일본어·중국어·베트남어 × 모바일/PC × 5페이지, 총 50개 브라우저 레이아웃 검사 통과. 이 사전 매트릭스의 화면·자산·언어 파일 45개는 CI 산출물과 바이트 단위로 동일합니다. 최종 main의 Test 소스 식별과 화면을 재확인했고, 운영에서도 10개 화면을 다시 검사했습니다.
- 운영 10개 화면에서 가로 넘침과 44px 미만 유효 클릭 영역이 없었습니다. 20px 체크박스는 실제 클릭 가능한 44px 연결 라벨을 측정하고 직접 눌러 확인했습니다.
- 검색어 `복리`는 결과 1개, 검증 도구 필터는 2개를 표시했습니다. 복리 예제는 1,100,000, 주식 예제는 평균단가 75·목표가 82.5·예상 이익 150으로 계산됐습니다. 실제 매매가 아닌 입력 시뮬레이션입니다.
- 공용 파일 3개는 새 콘텐츠 해시의 요청만 새 프론트엔드로 보냅니다. 구버전·알 수 없는 버전은 기존 파일을 계속 받으며, 실제 응답 해시로 확인했습니다.
- 전체 버전 응답을 바꾸면 기존 Next 페이지가 자동 새로고침되는 결함을 전환 전에 발견했습니다. 명시적 `scope=public-presentation`만 새 소스를 응답하도록 고쳤고 실제 격리 Nginx 8개 사례로 검증했습니다.
