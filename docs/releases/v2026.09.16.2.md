# v2026.09.16.2 — Focused stock watchlist

## User-facing change
- Added `/stocks/watchlist`, a dedicated member-only workspace for saved virtual stocks.
- The stock tools navigation now links directly to the watchlist.
- Each saved stock shows its symbol, current WLD price, exact integer-derived day change, a remove-watch control, and a direct link to its stock hub.
- Empty and unavailable states are distinct and provide a route back to market discovery.
- Korean and English copy are provided with the same game-only/non-investment disclosure.

## SEO/privacy correction
- The authenticated `/stocks` route family now inherits `noindex,nofollow` metadata from the stock layout. This resolves SEO-132-01's near-term private-UI policy and prevents authenticated stock tools from advertising themselves as public crawl targets.

## Integrity
- No database schema, migration, ledger, trade mutation, price authority, actor authorization, idempotency, or production data path changed.
- Day-change display uses `BigInt` basis-point arithmetic rather than floating-point conversion.

## Validation/promotion

- Staging must verify authenticated watchlist loading/removal, empty/error states, stock-hub navigation, noindex metadata, responsive layout, and exact candidate SHA/image parity before merge or Production promotion.
