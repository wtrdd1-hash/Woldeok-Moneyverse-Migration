# v2026.10.19.913 — 카지노 미니게임 모의 지급 표시 시정

**상태: GitHub 별도 브랜치 코드 후보. 테스트/운영 서버 미배포.**

## 확인 및 수정
- Mines와 Plinko는 브라우저 난수·화면 상태만 사용합니다. 실제 WLD 베팅 차감·상금 지급 원장과 연결되지 않았는데도 지급 성공처럼 보이던 화면을 **모의 체험 전용**으로 명시하고, 실제 잔액 차감·지급·영수증이 없음을 안내합니다.
- Plinko의 근거 없는 ‘RNG 정규분포 검증 완료’ 표시를 제거하고 공정성 인증을 받은 기능이 아님을 알립니다.
- 입력 금액의 범위·잔여 한도·안전 정수 검사를 추가하고, 유효하지 않은 입력을 기본 1,000 WLD로 조용히 바꾸지 못하도록 시정합니다.
- Mines의 마지막 보석 자동 종료가 과거 React 렌더링 배율을 사용하던 계산 오류를 수정하고 테스트를 추가했습니다.

## 제한 및 운영 승인 조건
기존 WLD 계좌·원장·DB·세션·운영 포인터는 변경하지 않습니다. 실거래 게임 구현 완료가 아니며, 운영 금융 권한 3개 및 19개 계좌 원장 증빙 차이 P0는 별개입니다. GitHub CI·독립 Test 정확 SHA·로그인/모바일 UI·복구·금융 무결성 검증이 끝나기 전에는 운영 승격하지 않습니다.
