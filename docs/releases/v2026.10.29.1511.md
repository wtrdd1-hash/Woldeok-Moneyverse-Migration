# v2026.10.29.1511 — Telegram market/news and priority-log notifications

**Scope**: an independent, read-only Python/systemd worker reusing the authenticated v1510 Telegram private chat. No new migrations, API/backend/frontend changes, financial writes, price manipulation, news fabrication, or application restarts.

## Features
- A new AI-news scenario batch is announced as **generated draft** (not published).
- A new virtual-stock market event is announced as **published/market-impacting**, with symbol, headline, source, direction and strength.
- Per-stock >=5% change since prior two-minute sample with a 20-minute cooldown; >=10% versus day-open once per day; halt/recovery; 09:00 KST market digest. All prices use virtual WLD.
- Priority systemd errors are reported as per-unit counts, never raw log text or private information.
- Initial observation baselines old data. Telegram send receipts checkpoint each event for retries and deduplication. Overflow receives a count summary instead of silent loss.

## Security and rollback
- Read-only SQL transaction selects specific virtual market fields. Existing debian service has Docker and systemd-journal access, which is a broader host permission than a dedicated SELECT role; moving to least-privilege DB access is recommended in follow-up.
- Telegram bot token and recipient remain only on the miniPC private state directory; GitHub contains no credentials.
- Disable the new moneyverse-telegram-market.timer to roll back. Existing base v1510 Telegram timer and Moneyverse application services are independent.
