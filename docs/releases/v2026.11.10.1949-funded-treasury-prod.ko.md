## 기능과 제한

- **관리자 보유금 국고 입금:** 신규 관리자 카드에서 실제 본인 USER_CASH를 차감해 기존 `treasury_user_donate` 정본 복식부기 기부와 영수증을 재사용한다. 개인 기부로 화폐가 새로 만들어지지 않는다.
- **조폐국 국고 신규 화폐 발행:** 국고 전용 `TREASURY_ISSUANCE` 정책을 발의·승인한 뒤, 한 번에 1~1천만 WLD를 MINT→TREASURY 정본 원장과 VAULT_MAIN 금고·감사 장부·발행증명서·영수증으로 **원자적 기록**한다. 만료·승인·잔여 한도·발행 동결·관리자 권한·멱등 UUID를 모두 DB에서 검증한다.
- **자동투자:** 종전 단순 조회를 `executed:true` 실제 투자 실행으로 오표시하던 오류 수정. 실제 시장 체결·수익 정산 근거 없는 경우 `executed:false`와 `SWF_SETTLEMENT_SOURCE_UNVERIFIED`. 장부상 SWF 평가액·가상 수익의 현금 환원과 리밸런싱 버튼 차단. **실제 증권 매수·매도/보관/정산 엔진은 구현하지 않았으며, 자동투자가 실제 수익을 내는 상태라고 보고하지 않는다.**
- **제외 범위:** 예전 국고 552건·배당 744건의 역사적 미증빙 기록은 소급 인증/삭제/현금화하지 않았다. 로그인된 실제 관리자 모바일 POST는 별도 로그인 브라우저 세션으로 독립 관측하지 못했다(백엔드·프론트 코드테스트, 정식 Test에서 실제 PG17 역할 거래/롤백, 공개 비로그인 차단은 검증).
