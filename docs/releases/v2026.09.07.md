# v2026.09.07 — Gameplay, UX and Economy Stability

This release consolidates the September 7 gameplay/UX audit into the canonical deployment.

## Highlights

### Work UX
- Career-task completion modal no longer leaves the member trapped behind an indefinite spinner.
- One modal attempt keeps one idempotency key; timeout/retry therefore replays the same receipt instead of paying twice.
- Slow requests expose a recovery state without requiring close/reopen.

### Responsive navigation
- Brand/icon/text visibility now follows CSS breakpoints and display utilities.
- Narrow viewports hide secondary brand/navigation content while retaining it in the DOM; widening the viewport restores it naturally.

### Casino
- Fixed UI/server-result drift, including the slot reel that could visually show `777` after a losing server result.
- Theme games now derive their final visual result from the server receipt.
- Removed payout multipliers hard-coded in the browser; disclosed DB terms drive the UI.
- Added a dedicated member casino-history read model.
- Standardized amount handling at the frontend boundary to avoid number/string crashes.
- Rebalanced baseline exposure to 10–200 WLD per play, 2,000 WLD daily stake and 1,000 WLD daily realized loss while retaining 95% baseline RTP.
- Personal stake/loss limits and self-exclusion remain stricter member controls.

### Banking
- Removed forced minimum 1 WLD interest payouts.
- Deposit balance changes reset the interest accrual clock.
- Manual interest claims and displayed rates now use the same server-side contract.
- Interest claims are idempotent.
- New loans use the existing credit-grade policy instead of the bypass smart-loan path.
- Direct application-role access to deposit interest trackers is closed.

### Quest truthfulness
- Removed placeholder event effects that had no backing gameplay implementation; real WLD/EXP/item rewards are unchanged.

### Documentation
- Replaced the outdated migration-host README with current production/test endpoints.
- Added localized documentation in Korean, English, Simplified Chinese, Traditional Chinese, Japanese and Spanish.
