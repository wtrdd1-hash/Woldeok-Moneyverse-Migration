# v2026.09.19.274 — 배포 연속성·캐시 최신화 표준

## 요약

모든 런타임 변경에서 프론트엔드/백엔드 무중단 전환, 회원 로그인 세션 유지, 최신 application shell 강제 적용을 필수 릴리스 게이트로 고정합니다.

## 변경 사항

- 새 Production 인스턴스가 정상 상태가 된 뒤에만 이전 인스턴스를 제거하도록 규정합니다.
- backend 재시작 전 발급된 회원 세션이 동일 PostgreSQL `auth_sessions`와 쿠키 계약을 사용해 재시작 후에도 유지되도록 검증합니다.
- 사용자가 브라우저 캐시를 직접 삭제하지 않아도 최신 HTML/bootstrap이 재검증되어 새 릴리스가 적용되도록 규정합니다.
- content-hash가 붙은 immutable Next.js asset은 장기 캐시를 유지합니다.
- 캐시 초기화를 이유로 회원 세션 삭제/revoke를 수행하는 것을 금지합니다.
- readiness, 세션 연속성, exact-SHA 최신성, smoke 검사가 모두 통과해야 재시작/rollout 완료로 인정합니다.
