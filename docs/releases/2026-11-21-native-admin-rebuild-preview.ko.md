# 네이티브 프론트엔드 재구축 — 보호된 관리자 미리보기
상태: 관리자 전용 미리보기. 독립 전체 Test·운영 프론트엔드 수용 완료가 아니다.

## 실제 반영
일반·회원·관리자 HTML은 승인된 긴급 점검503을 유지한다. 이전 DB-free 프론트엔드2개는 중지·비활성 상태이며 공유 API/로그인/DB/작업자는 유지했다.

main72714c3efd(PR3349), CI44914069245의4개 작업이 모두 성공한 실제 GitHub 아티팩트14710569805를 사용했다. JAR SHA256은 abeab840592abeef765ad93ab127840d098b69a5f2f19441920790cd25ff687f. 빌드 ID·파일·실행 PID/cwd/open JAR를 검증한 별도 loopback4830 DB-free 미리보기다. 재부팅 자동 시작은 등록하지 않았다. 기존 실제 관리자 auth_request 뒤의 HTML·전용 asset 경로만 열었으며 익명401/알 수 없는 경로404/변경 요청405, Test 도메인 접근 제한을 유지했다.

Nginx에는 미리보기 include1줄만 추가했다. 변경 후 SHA는7a80aba9dcd093d105529f4fed8370ff71e446e01f12a661c42b03e1a23dd9a7. 준비 명령의 도구 응답으로 성공을 확인하지 못했지만, 보호된 manifest/파일/JAR 해시를 별도로 검증하고 나서 apply0exit를 확인했다. 영문 정본에 전체 출처·해시를 기록했다.

## 발견 사항 / 미통과
1. 운영 상품 API가 아직 구형 임의 상품2개/camelCase 계약을 반환한다. 새 화면은 이를 거부하고 조회 실패·검색/분류 비활성을 표시한다. 실제 정상 목록·검색·상세 기능은 통과 처리하지 않았다.
2. 상품 등록/수정/삭제는 보안·멱등성·감사·실제 영수증 검증이 남아 있다. 가짜 성공을 표시하지 않는다.
3. 공통 관리자 본문 바로가기 및 탐색 접근성 명칭 일부가 비영어권에서도 영어다. 수정과 전체 문구 검사 필요.
4. 나머지 페이지는 점검 안내 상태다. 이 미리보기1개를 전체 재구축 완료로 보지 않는다.
5. 정본 조회 백엔드 PR3350 첫 실제 PostgreSQL CI 시작 실패. H2의 실제 DataSource 자동구성 검사로 jpaSharedEM_entityManagerFactory 부재를 재현했으며, Hibernate 제외 후 JPA repository 자동구성이 남은 원인을 수정·재검증 중이다. 운영 백엔드는 전환하지 않았다.
6. 독립 전체 Test·정상 데이터/browser·미리보기 정상 종료 inverse·나머지 기능 수용표·최종 운영 전환은 별도 미완료 게이트다.

익명 API stocks200/auth401/admin401 JSON과 HTML503/no-store를 전후 확인했다. 추가 JVM29개는 명시적 DB-free 모드가 아닌 기존 application/default 모드여서 이름만으로 프론트엔드라 판단해 중지하지 않았다. 실제 의존성/작업자 소유권 점검 전까지 보존한다.
