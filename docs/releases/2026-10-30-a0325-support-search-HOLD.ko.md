# 배포 판정 — A0325 회원 문의 검색: HOLD

회원 문의 검색 후보는 **main 병합 및 운영 승격 금지** 상태다. Backend·웹·Android 대상 테스트와 격리 PostgreSQL은 통과했지만 전체 Lint, Backend/Frontend 전체 테스트, 모바일 API 생성 계약, 공식 Test 정확 SHA 인증 E2E는 통과하지 않았다. 국고/Frontend 버전 P0, 독립 복원·금융 무결성 게이트도 미해결이다. 신규 마이그레이션·금융 변경·운영 배포·롤백은 수행하지 않았다. 필요 시 코드만 되돌리며 다른 예약의 브랜치는 보존한다.
