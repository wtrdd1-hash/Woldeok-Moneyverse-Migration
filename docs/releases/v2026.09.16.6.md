# v2026.09.16.6 — Filtered Trade Summary

## User benefit

The private `/stocks/history` workspace now summarizes the currently visible trade set with buy/sell counts, gross virtual trade volume, total virtual tax, and matching-trade count. Search, side filtering, and sorting continue to determine the visible set, so the summary answers “what does this filtered history add up to?” without exporting or manually calculating it.

## Integrity

This is a read-only presentation feature over the existing actor-scoped stock-history response. WLD totals use `BigInt` from canonical integer strings; no JavaScript floating-point conversion is introduced. No database schema, migration, ledger, trade mutation, authorization, idempotency, or Production data path changes.
