# v2026.10.21.1067 — AI 블로그 안전성 CI 수정 (배포 전 후보)

## 변경 내용
- 블로그 자동 게시 경로에서 관리자·스케줄러 인증만으로 미승인 금융글을 게시하지 못하게 한다. 편집 승인 및 근거 검증 전에는 HTTP 503으로 거부한다.
- 하드코딩된 스케줄러 인증 우회를 제거하고 무권한 사용자는 HTTP 403으로 거부한다.
- 관리자 페이지의 작동하지 않는 초안·즉시 발행 버튼을 제거하고 기존 게시글 조회와 편집 검증 보류 상태만 표시한다.
- 신규 AI 초안은 자동 게시하지 않는다는 기존 사실을 회귀 테스트에 반영한다. 이전 v1061 국채 오류·모바일 UI 수정도 이 브랜치에 유지된다.

## 검증 및 배포 상태
- 이전 CI #2845에서는 블로그 테스트 4건이 실패했다. 수정 후 GitHub CI 결과는 별도로 확인한다.
- 공식 운영 금융 검사에서 accounts, account_balances, system_treasury_vaults의 앱 직접 쓰기 권한 때문에 승격 차단 상태가 유지된다.
- 이번 GitHub 변경으로 운영 앱, Test, 원장, 사용자 잔액, 스키마, 세션을 수정하지 않았다.
- 정확 SHA Test 로그인·금융 검증 필요. 운영 앱 배포 미완료, main 병합 대기.
