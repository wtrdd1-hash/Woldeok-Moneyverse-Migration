# v2026.09.08 — 공개 게시판 및 검색 노출

[English](v2026.09.08-public-board-seo.md) | **한국어** | [문서 색인](../INDEX.ko.md)

이 후보 릴리스는 제한 기능의 권한 기반 구조를 유지하면서 커뮤니티 게시판을 비회원도 읽을 수 있게 합니다.

- 공개 방문자는 게시판 목록, 글, 댓글, 공개 글에 첨부된 이미지를 읽을 수 있습니다.
- 게시, 수정, 삭제, 댓글 작성, 업로드는 계속 인증·정책 동의·CSRF 보호가 필요합니다.
- 새 PostgreSQL 공개 읽기 모델은 직접 테이블 권한을 주지 않는 경계를 유지합니다.
- 게시판 글은 공개 콘텐츠에서 파생된 검색 가능한 canonical 메타데이터를 제공합니다.
- Production 프론트엔드 빌드는 공개 `SEARCH_CONSOLE_VERIFICATION` 값을 받을 수 있지만 Test 빌드는 받지 않습니다.
- robots/sitemap 동작에는 회귀 테스트가 있습니다.

이 릴리스는 스택형 배포 변경과 해당 마이그레이션이 먼저 격리된 Test 스택에서 검증되기 전에는 Production 대상이 아닙니다.
