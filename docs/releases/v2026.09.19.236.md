# v2026.09.19.236 — AI shadow health, profession-limit safety and mobile admin

This runtime release implements the v235 AI/automatic-control/mobile administrator audit findings.

## Highlights
- Adds a daily non-authoritative Economy AI shadow-health run that proves configured model reachability without making a blocked proposal eligible.
- Stores shadow evidence in a separate append-only table that the authoritative AI policy guard never consumes.
- Adds a default-disabled profession-limit tightening switch; negative assignment-limit deltas are rejected unless explicitly enabled.
- Enforces an effective minimum of 2 work-task completions per day when profession-limit tightening is enabled.
- Reworks the Economy AI administrator card to distinguish configuration, model reachability, authoritative review, shadow review, proposal eligibility and scheduler failures/staleness.
- Adds mobile card layouts for AI agent evidence, traffic series and activity logs while retaining desktop tables.
