# v2026.09.15.121 — 가상 주식 종목 탐색 검색

## 요약

로그인한 사용자가 거래나 원장 동작을 바꾸지 않고 종목 코드, 이름, 설명으로 가상 주식 시장을 빠르게 좁혀 볼 수 있는 사용자 검색 흐름을 추가합니다.

## 주요 변경

- `/stocks`에 키보드 접근 가능한 GET 검색 폼과 공유 가능한 `?q=` 상태를 추가했습니다.
- 종목 코드·표시 이름·설명을 대소문자 구분 없이 검색하며 UI 검색어는 최대 80자로 제한합니다.
- 한국어/영어 결과 개수, 초기화 동작, 검색 전용 빈 상태를 제공합니다.
- 보유 종목, 거래, 관심종목, 가격, 원장, 권한 경로는 변경하지 않습니다.
