# Private Notification Archive CSV — A0751 (DRAFT / HOLD)

Member /account/notifications provides a one-click CSV of the *entire currently retained notification set only when at most 100 rows exist*. It is not an audit ledger, not a reward receipt, and not a promise of indefinite retention. Source is the existing owner-filtered notification feed. A 101-row read rejects the export with a conflict, never silently truncates. Backend enforces SessionGuard, AuthenticatedGuard and ConsentGuard; the actor comes exclusively from requireUserId(request). Next.js gateway verifies viewer and validates each field before emitting escaped CSV with private/no-store/noindex. Android uses the existing authenticated /app-api/v1/notifications/archive-snapshot route and its private JSON contract. No new SQL grant, migration or finance mutation. All release gates remain HOLD until exact-SHA authenticated Test and required security gates pass.
