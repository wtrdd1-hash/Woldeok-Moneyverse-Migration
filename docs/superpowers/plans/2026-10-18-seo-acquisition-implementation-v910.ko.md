## 검색에서 고객까지 각 증거 구분

운영자의 2주 SEO·고객 0명 보고는 실제 Google/네이버 확정 노출수, 방문수, 가입 완료, 가상경제 첫 행동까지 모두 실측 0이라는 증거가 아니다. 원본 URL의 크롤링 허용 → IndexNow/사이트맵 제출 접수 → 외부 봇 접근 → Google URL 색인 버전 검사 → 검색 노출·클릭 → 비회원 체험 → 실제 회원가입 → 서버 확인된 첫 거래를 별도로 유지한다. 자료 미연결, 조회 오류, 오래된 수집, 누락된 날짜는 0%나 성공으로 변환 금지.
