# 검증 도움말 공개 철회 실시간 재확인 계획

**목적:** 이미 열린 도움말이 관리자의 게시 철회 후에도 검증된 정보처럼 남는 P1 위험을 완화한다.

**설계:** 미적용 280 마이그레이션에 게시 상태만 반환하는 SECURITY DEFINER 함수, NestJS 공개 조회, Next 동일 출처 no-store 경로, Android 공개 조회를 추가한다. 화면은 검증 전 본문을 숨기며 활성 탭에서 최대 30초 간격 및 포커스 복귀 시 재확인한다. 장애·철회·근거 만료는 공개 실패로 처리한다. 30초 이내 관찰은 활성 탭 기준이며 즉시 푸시 보장은 아니다.

**제약:** 기능 스위치 OFF, 운영 DB·원장 변경 금지, 이미 적용된 마이그레이션 불변, 기존 미통합 280 충돌 보존, 독립 승인·최소권한·멱등성 보호. main 및 영문 정본/국문 보조 계획 시작·중간·통합 직전 재확인. RED→GREEN→전체 테스트→Draft/HOLD PR. 공식 Test 정확 SHA·보안·백업·GitOps 미통과 시 병합·운영 배포 금지.
