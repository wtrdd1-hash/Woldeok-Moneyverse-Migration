# 검증된 도움말 재시도 응답 무결성 — 구현 계획

영어 원본: `2026-10-27-help-replay-truth.md`.

목표: 도움말 초안 생성 또는 게시가 이미 철회·상태 변경된 뒤 동일 멱등 키로 재시도할 때 과거 성공을 현재 성공처럼 반환하지 않는다.

1. 기존 280번 미적용 후보의 격리 PostgreSQL fixture에 철회 후 재시도 거부(40001) 테스트를 먼저 추가하고 실패를 재현한다.
2. SQL 멱등 재시도 분기에서 원본 도움말 행을 잠그고 현재 상태를 확인한다. 동일 상태는 기존 성공 영수증을 유지하고, 상태가 다르면 40001을 반환한다. NestJS는 409로 매핑한다.
3. 실제 격리 PostgreSQL, 계약·단위·빌드·보안·CI 및 정확한 SHA를 검증한다. 실패 시 Draft/HOLD 유지, 운영 DB·Test·Production 변경 금지.

적용된 마이그레이션과 체크섬, 타 개발 예약 작업공간, 금융 원장, 인증 권한은 변경하지 않는다.
