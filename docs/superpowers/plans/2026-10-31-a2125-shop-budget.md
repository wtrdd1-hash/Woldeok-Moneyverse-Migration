# Owner Shop Budget Filter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans and test-driven-development. Each step must be verified.

**Goal:** An authenticated member can cap the displayed shop catalogue by an exact WLD price without rounded balances or leaked owner inventory data.

**Architecture:** Reuse the existing authenticated Nest `GET /api/v1/shop/catalog` and owner-scoped PostgreSQL `shop_catalog_list_v2(actor)`. Apply a validated canonical integer-string ceiling in the Nest response, expose a labelled Next GET form, and independently validate Android requests and successful responses. No financial writes, grants, new migration or app client source required.

**Tech Stack:** NestJS, Next.js, Vitest, PostgreSQL 17, TypeScript BigInt.
