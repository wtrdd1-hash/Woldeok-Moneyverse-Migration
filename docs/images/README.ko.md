## 현재 캡처 정책
- 출처: `https://easy-scraping.com`
- 캡처 방식: 인증 쿠키가 없는 깨끗한 공개 브라우저 세션
- 용도: README/제품 문서 전용
- 비공개 회원, 관리자, 비밀정보가 포함된 화면은 커밋 금지
- 접근 토큰, 이메일 받은편지함, 개인 식별자, 브라우저 개발자 도구가 스크린샷에 포함되면 안 됨

- 데스크톱: 1440×900
- 태블릿: 768×900

주요 UI 릴리스로 탐색 구조나 소개 화면이 변경되면 해당 이미지를 다시 캡처하고 작업 로그/변경 기록에 갱신 내용을 남깁니다.
