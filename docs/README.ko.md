## 주요 문서군

| 디렉터리 | 용도 |
|---|---|
| `planning/` | 현재 기획, 상세 명세, planning delta |
| `features/` | 간결한 기능 가이드 |
| `architecture/` | 안정적 아키텍처 설명 |
| `operations/` | 운영/runtime 절차 |
| `findings/` | 감사, 연구, 근거 corpus |
| `updates/` | 버전별 짧은 업데이트 |
| `changelog/` | 변경 이력 |
| `worklog/` | 작업/증거 이력 |
| `releases/` | 실제 릴리스 증거가 있는 기록 |

과거 기록은 근거로 보존하지만 최신 명시적 기획 권위를 덮어쓰지 않습니다.
