# 대한민국 법령 준수 감사 — Moneyverse

**한국어 보조본** | [English canonical](KR_LEGAL_COMPLIANCE_AUDIT.md)

> 상태: PLANNING / 법률 검토 필요
> 시작·중간 `origin/main`: `6f025ced5239fc6bc8b365c31ad0fd59acf84dbc`
> 관측 런타임: Debian 13 운영 backend/frontend active, `production-current=prod-v453`.

이 문서는 엔지니어링 준수 감사이며 변호사·세무사·게임물 등급기관의 공식 판단을 대체하지 않는다.

## 결론
대한민국 수익화는 현재 무제한 활성화할 상태가 아니다. AdSense는 운영 공개 페이지 일부에서 실제 렌더링된다. 실결제는 `UNVERIFIED`다. 가장 큰 P0는 대한민국 카지노가 GRAC/등급·19+·법률/채널 증거 전 `BLOCK`인데 프론트/운영 번들에 `GRAC-2026-REGULAR-OPEN`, 정규 실베팅 가동·검증 통과 같은 승인성 문구가 존재한다는 점이다. 이를 뒷받침하는 실제 인증 증거는 확인되지 않았다.

## 결함 및 조치
### KR-LGL-443-01 — P0 — 대한민국 카지노 게이트 충돌
실제 등급/인증/법률 증거가 없으면 서버에서 대한민국 카지노를 fail-closed 한다. 근거 없는 GRAC 번호·승인·검증통과 문구를 제거하고 API/server action 우회도 막는다. WLD 비환전은 필요한 통제지만 등급 의무를 없애지 않는다.

### KR-LGL-443-02 — P0 — 현재 광고수익의 사업자·세무 게이트
운영 `/`, `/announcements`, `/gallery`, `/board`에서 AdSense 렌더링을 확인했다. 부가가치세법 제8조를 기준으로 실제 사업 개시일과 사업자등록·세무 상태를 세무전문가와 문서화한다. 확인 전 수익화 확대를 차단하며 발급되지 않은 사업자번호를 표시하지 않는다.

### KR-LGL-443-03 — P0(실결제 전) — 전자상거래
전자상거래법 제12·13·17조와 적용 가능한 예외를 반영한다. 유료 디지털상품/구독/광고제거 전에 사업자 신원·통신판매 신고 해당성/번호·주소/연락처·총가격/세금/갱신·주문/영수증·청약철회/환불/해지·디지털콘텐츠 예외·미성년자 계약취소 고지·고객지원을 완성한다.

### KR-LGL-443-04 — P1 — 연령확인 표현 불일치
현재는 `ageConfirmed=true` 자기확인이지 생년월일/신원 검증이 아니다. 이를 검증된 연령으로 표현하지 않는다. 만14세 미만 의심/확인 시 제한·삭제 절차와 최소 증거보존을 명시하고 더 강한 확인이 필요한 기능은 fail-closed 한다. 카지노는 별도 19+/등급 게이트다.

### KR-LGL-443-05 — P1 — AdSense/행태광고/국외이전
AdSense 기본 publisher ID와 운영 렌더링이 확인됐다. Google/Cloudflare/Discord 데이터맵, 국외이전 근거와 법정 고지항목, 쿠키/식별자, 맥락/개인화 광고 정책, CMP/거부 증거를 유지한다. 대한민국 개인화 광고는 증거 통과 전 REVIEW_REQUIRED다.

### KR-LGL-443-06 — P1 — 광고성 메시지
향후 이메일/푸시/SMS/DM 광고 전에 정보통신망법 제50조에 맞춘 채널별 사전동의, 필요한 야간 별도동의, 철회/suppression, 처리결과 통지, 발신자/광고 표시, 감사로그를 구현한다. 서비스·보안 알림과 마케팅을 분리한다.

### KR-LGL-443-07 — P1 — 게임 등급은 모바일 스토어만의 문제가 아님
게임산업법 제21조 적용성을 대한민국 웹/앱 서비스 전체 기준으로 공식 판단·증거화하고 게임/확률/수익화 중대 변경 때 재검토한다.

### KR-LGL-443-08 — P1 — 게임머니 현금화 금지 경계
게임산업법 제32조를 고려해 운영자 현금상환, 외부자산 브리지, 현금정산형 마켓, 유료 카지노 stake 등 WLD 환전가능성을 만드는 경로를 새 법률검토 없이 추가하지 않는다.

## 긍정 통제
공개 약관/개인정보처리방침, 버전 동의, ConsentGuard, 개인정보 요청·계정/데이터 삭제 화면, WLD 비환전 문구, 서버 권위 카지노 정산·멱등성·자가한도/자가제외가 존재한다. 단, 안전통제가 법적 승인 자체를 뜻하지 않는다.

## 출시 게이트
1. 광고: 사업자/세무 상태 + 개인정보/국외이전/광고사업자 증거.
2. 실결제: KR-LGL-443-03 전체 + 결제사업자/스토어 receipt·webhook·환불 테스트.
3. 카지노/확률: 실제 등급/19+/법률/채널 증거 전 BLOCK, 근거 없는 승인문구 제거.
4. 광고성 메시지: 동의/suppression 체계 전 BLOCK.
5. 모든 게이트는 서버 권위·버전·감사·증거 만료 시 fail-closed.

## 증거 상태
저장소/소스 검사와 선택 운영페이지 광고 렌더 검사를 수행했다. 인증 사용자 카지노 실제 베팅은 수행하지 않았다. GRAC 인증서/법률의견, 사업자등록/통신판매 신고/세무신고는 저장소·런타임에서 증명되지 않았다. 운영 mutation·배포·DB migration은 수행하지 않았다.
