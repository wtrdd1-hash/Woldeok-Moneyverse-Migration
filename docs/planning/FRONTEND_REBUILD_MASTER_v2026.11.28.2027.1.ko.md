사용자 승인: 과거 모든 시각 디자인 기획·시안·색상·폰트·레이아웃·토큰·시각 승인(G1/G2/v8/v10/v11 등)은 역사 자료로 전환한다. 원본과 기존 검증 기록은 보존하되 새 디자인의 기준·대체 시안·합격 기준으로 사용하지 않는다. 기존 로고/파비콘과 법정 안내는 별도 변경 승인 없이 보존한다. 통합 기능 기획, 금융·보안·데이터·접근 권한, 실제 서버/API, 기존 번역·기능 수정은 유지한다. 현재 작업 저장 후 프론트엔드 기획 및 재구축을 최고 일반 우선순위로 진행하며 긴급 확인된 보안/금융 무결성 결함은 즉시 처리한다.

## R0 기획
통합 마스터·프로젝트 계획·채택된 도메인 명세 및 전체 라우트 QA를 확인하고, 180개 현재 화면과 92개 원계약을 구분해 실제 경로를 다시 수집한다. 모든 기능·사용자 여정·권한·API·데이터·상태·언어를 매핑한다. 새 디자인 방향, 정보 구조, 내비게이션, 콘텐츠 위계, 색상/글꼴/간격/아이콘/반응형/컴포넌트/상호작용 규칙을 설계하고 근거를 기록한다. 최신 외부 디자인 조사 시 날짜·출처를 남기며 조사하지 못하면 HOLD. 기존 프로젝트 시안을 재색칠하지 않는다. 자체 디자인 와이어프레임/프로토타입을 PC·모바일용으로 작성하고, 합성 데이터는 격리된 디자인 예시임을 명시한다.

## R1–R5 구현 및 검증
R1 디자인 시스템과 공통 셸/내비게이션, 접근성·로딩·오류·빈 상태·다국어. R2 공개 홈과 회원 홈 첫 수직 구현, 실제 Spring API/동일 출처 BFF. R3 지갑·은행·주식·거래·상점·경제/퀘스트·커뮤니티·채팅·블로그·도구·관리자 및 나머지 모든 화면을 기능 단위로 재구축. R4 실제 격리 브라우저 PC/모바일, 접근 권한과 5개 언어, 상호작용·반응형·접근성·실데이터 계약 및 독립 검토. R5 잔여 백엔드와 최종 아키텍처·DB·아티팩트 검증. 영어 기본, 한국어 두 번째, 일본어/중국어/베트남어 자연스러운 번역. Unslop 9단계 및 필요한 기존 디자인 스킬 활용. 가짜 숫자·성공·기능, 금융 정밀도 손실, 권한 완화 금지.

새 디자인 자산은 아직 미생성 상태이며 기존 시안으로 합격 처리하지 않는다. 보안 격리·구독 한도·메모리 가드·독립 테스트·별도 운영 승격 승인 유지. 대규모 구조 변경이나 운영 데이터 변경을 이 지시로 승인하지 않는다. 신규 브랜치, 시작/중간/종료 기록, 영문/한글 문서와 정확한 SHA. 현재 업무 인계를 보존하고 네이티브 앱 중단 유지.
