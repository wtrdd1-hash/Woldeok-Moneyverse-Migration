# 국고 v690 — 운영자 조회 안전성 및 지급 차단

**상태: 격리 테스트 구현 후보. 운영 승격 아님.** [영문 정본](TREASURY_SAFE_ADMIN_GATES_v2026.10.15.690.md)

상위 기획 PROJECT_PLAN → 통합기획 마스터 → 경제코어 v523/v542. 기존 관리자 전체 현황은 271 보안 ACL에서 차단한 국고 금고·보조원장 테이블을 직접 조회하여 오류가 발생할 수 있다. 경제코어 국고 계정 0 WLD와 재정 보조금고 MAIN 186,138,444 WLD는 서로 다른 층이며 지급 가능한 실재원 증빙이 아니다. 금고별 장부 차이 15,139,295 WLD를 임의로 보정하지 않는다.

**수정:** 274 운영자 역할 검증 읽기 전용 SECURITY DEFINER 함수와 세션 관리자 ID 연결. 원본 테이블 권한은 확대하지 않는다. 검증 전 지급가용액은 제공하지 않고 가용액 0으로 제한한다. 관리자 자금 주입·소각·배당·지원금·그랜트·예산배분·부유세·SWF 수동 집행/설정 등 11개 위험한 변경 API는 503으로 차단한다. 271은 기존 국고 지급 SQL 함수 8개의 앱/PUBLIC 실행을 이미 거부함을 독립 테스트에서 확인했다. 새 기부도 기본 OFF.

**실증:** TDD 가드 12건/국고 현황 테스트 통과, 격리 복원 DB에서 274 적용 후 앱 역할 운영자 조회 허용·비관리자 거부·원본 테이블 읽기 차단과 ROLLBACK. 백엔드 1,217건 통과(391건 DB 의존 스킵), 프론트엔드 1,218건 통과, 타입·빌드 통과.
