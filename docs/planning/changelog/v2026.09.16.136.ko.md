# 기획 변경로그 — v2026.09.16.136

날짜: 2026-09-16
브랜치: `planning/multi-agent-economy-v2026.09.16.1`

## 기획 변경

- 단일 AI 경제 컨트롤러 개념을 독립 버전 관리되는 전문 에이전트의 적대적 위원회 구조로 확장했다.
- macro, player-welfare, commerce, stock-fundamental, stock-flow, momentum, market-integrity, business, casino-risk, abuse, causal, red-team, auditor, judge 역할을 추가했다.
- 독립 제안 -> 적대적 비판 -> 반론/수정 3단계 토론, disagreement gate, 담합 방지, 에이전트별 모델/학습 레지스트리를 추가했다.
- 제한형 가상주식 자동 가격형성을 추가했다. 에이전트는 감사 가능한 bounded component만 제공하고 실제 가격, tick bound, volatility clamp, circuit breaker, stale-market 동작은 결정론적 엔진이 계산한다.
- 가격탄력성, uncertainty, affordability, cooldown, drift, protected SKU 제약을 포함한 제한형 상점 자동 가격조절을 추가했다.
- 사전 승인 template 기반 저위험 SKU 변형의 자동 생성·게시를 추가하고 신규 경제효과, P2W, 금융/신용, chance mechanic, 신규 통화, compliance 미분류는 proposal-only로 유지했다.
- Scenario Lab에 에이전트별 추정, 토론 artifact, 불일치, counterfactual 비교 저장을 추가했다.
- correlated failure, 손상 agent, 시세조작, 잘못된 telemetry, P2W 생성 시도, rollback을 포함한 다중 에이전트 QA를 추가했다.

## 런타임/배포 상태

기획 전용 변경이다. Test 또는 Production 런타임 값은 변경하지 않았다. 구현 시 새 개발 브랜치에서 isolated Test -> backend/DB/API/UI 검증 -> Production 승격 절차를 따라야 한다.
