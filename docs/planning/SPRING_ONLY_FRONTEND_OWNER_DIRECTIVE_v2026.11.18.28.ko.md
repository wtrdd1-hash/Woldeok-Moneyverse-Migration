## 최신 사용자 지시 우선 및 기존 기획 충돌 기록
사용자는 **백엔드 API뿐 아니라 웹 프론트엔드 모든 페이지를 Java/Spring Boot로 구축하고**, 승인받은 네이비/보라 신규 UI 디자인과 전역 문의·채팅 동글을 모두 적용하며, 실제 API를 정상화하고 운영까지 승격하도록 재지시했다. 이는 기존 통합기획서·프로젝트 기획서 v2026.11.13.1 등에 있는 **“프론트엔드는 Next.js/React를 운영 런타임으로 유지”** 부분을 명시적으로 갱신한다. 기존 역사 기록을 삭제하지 않고 이 최신 사용자 지시를 최상위 변경사항으로 둔다.

- **운영 런타임:** Java Spring Boot/Spring MVC가 공개/회원/관리자/로그인 모든 URL의 HTML과 권한·API를 제공. 전환 완료 후 Node.js·Next.js의 런타임이나 RSC/Flight·React 하이드레이션 없이는 작동하지 않는 화면은 없어야 함. 단, Spring JAR/Nginx에서 제공하는 CSS/JS/이미지 자산은 사용 가능.
- **렌더링:** Spring MVC + Thymeleaf 공통 레이아웃과 실제 DB 근거 모델, 기본 영어(EN)·두 번째 한국어(KO). 네이티브 시맨틱 HTML `<form>`·GET 폼·`<details>`, CSS Grid/container queries, 키보드 포커스·스크린리더, 터치44px·모바일320/390·확대200%, JS 없이 동작하는 핵심 기능 우선. 클라이언트 신원 헤더/가짜 잔액·가짜 성공 금지.
- **제공된 영상:** `7F_TQyV-3C4`, *AI로 웹사이트 만들면 이건 필수입니다*는 Chrome 팀 등의 **Modern Web Guidance 1.0**을 권고한다. 이것은 신형 브라우저 구현 가이드이지 Spring이나 Next.js 대체 프레임워크가 아님. 공식 `developer.chrome.com/docs/modern-web-guidance`, `github.com/GoogleChrome/modern-web-guidance`. 공식 CLI **v1.0.1**로 기존 계산기 소스 국소 legacy-scan(52규칙/38가이드)에서 자동 매칭0(전문 검증 의미 아님), 그리고 forms, accessible-error-announcement, form-factor-adaptation, css-layout 실제 지침을 읽어 새 Spring HTML 구현에 적용.
