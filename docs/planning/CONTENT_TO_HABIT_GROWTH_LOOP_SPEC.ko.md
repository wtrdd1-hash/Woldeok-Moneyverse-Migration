## 1. 선택한 가장 큰 공백

현재 가장 큰 성장 공백은 콘텐츠 양이 아니다. **유용한 공개 콘텐츠를 본 사람이 오래 남을 개인적 이유를 만드는 연결고리**다.

Moneyverse에는 이미 가입 전 가치, D1~D30 복귀 이유, 공유 가능한 진전, 반복적인 브랜드/콘텐츠 cadence가 기획되어 있다. 하지만 방문자가 월드 브리프, 가상기업 스토리, 초보 가이드, 시즌 프리뷰, 공유 산출물을 읽고도 D7까지 이어지는 개인 목표를 만들지 못하고 떠날 수 있다.

이번 회차의 핵심 루프는 다음과 같다.

`유용한 콘텐츠 → 하나의 개념 이해 → 관련된 낮은 마찰 행동 → 개인 스레드 저장 → 다음 목표 가시화 → D1 이어하기 → D3 취향/정체성 형성 → D7 회고/복귀`

목표는 클릭이나 강제 일일 접속이 아니라 **호기심을 사용자가 스스로 이어가고 싶은 개인 스레드로 전환하는 것**이다.

## 2. 소비자 약속

모든 성장 화면은 순서대로 다음 세 질문에 답해야 한다.

1. **방금 무엇을 이해했나?**
2. **지금 무엇을 직접 해보거나 저장할 수 있나?**
3. **다음에 어떤 변화가 궁금해서 다시 보고 싶나?**

이 세 질문에 조작적 긴급성 없이 답하지 못하는 콘텐츠는 억지 CTA를 붙이지 않고 독립 콘텐츠로 남긴다.

## 3. 콘텐츠→행동 연결

### 3.1 한 페이지에 하나의 핵심 이어하기

고의도 공개 페이지마다 주요 이어하기 1개를 우선한다.

- 가상기업/산업 팔로우;
- 시뮬레이션 시나리오·학습 질문 저장;
- 컬렉션 챕터 시작;
- 직업/사업 경로 미리보기;
- 시즌 챕터·세계 이벤트 관심 저장;
- 공개 가능한 클럽/도시/커뮤니티 사례 탐색;
- 공유받은 산출물을 공개 안전 샘플로 이어보기.

신규 방문자에게 6개 기능을 동등한 CTA로 한 번에 제시하지 않는다.

### 3.2 가입 전 가치 먼저

안전한 경우 가입 전에 30~90초 체험을 제공한다.

- 두 개의 가상 결과 중 선택;
- 가상기업 타임라인 보기;
- 분산투자/위험 질문 하나 풀기;
- 샘플 컬렉션 한 세트 조립;
- 시즌 경로 미리보기;
- 실제 돈과 무관한 사업 선택지 비교.

이 체험은 실제 WLD/WDX 보유상태, 개인 계정 데이터, 실제 금융수익 약속, 불필요한 추적을 만들지 않는다.

### 3.3 가입은 가치 인질이 아니라 보존

가입 이유는 방금 사용자가 선택한 것을 저장하고 이어가기 위한 것으로 표현한다.

- `이 관심종목 아이디어 저장`
- `이 컬렉션 경로 이어가기`
- `이 학습 리플레이 계속하기`
- `이 시즌 루트 기억하기`
- `이 가상기업 추적하기`

안전하게 먼저 가치를 보여줄 수 있는데 `계속하려면 가입`만 제시하지 않는다.

## 4. 첫 세션 이어하기 규칙

유입 의도를 알고 있다면 가입/복귀 직후 일반 대시보드에 떨어뜨리지 않는다.

첫 인증 화면은 다음 우선순위를 가진다.

1. 유입을 만든 스레드;
2. 그 스레드를 전진시키는 의미 있는 행동 1개;
3. 눈에 보이는 진전;
4. 다음 마일스톤 1개;
5. 선택형 보조 탐색 1개.

예시:

- 분산투자 초보 글 → 가상 배분 복기 → 학습 저널 저장 → D1 복습.
- 가상기업 스토리 → 기업 팔로우 → 다음 이벤트 맥락 확인 → D3 산업 관심 신호.
- 컬렉션/lore 글 → 컬렉션 챕터 시작 → 한 칸 완성 → D7 컬렉션 회고.
- 시즌 프리뷰 → 시즌 관심사 하나 선택 → 첫 시즌 활동 → D7 진행/캐치업 회고.

## 5. D1 / D3 / D7 습관 연결

### D1 — 연속성
약속: **“내가 관심 가진 것이 그대로 있고, 몇 분 안에 이어갈 수 있다.”**

저장한 스레드를 가장 먼저 보여준다. 정확히 하루 만에 오지 않았다고 손실이나 패널티를 강조하지 않는다.

### D3 — 정체성 형성
약속: **“Moneyverse가 내가 좋아하는 방향을 조금씩 반영한다.”**

불투명한 개인화 피드로 가두는 대신 사용자가 취향을 직접 선택하게 한다. 예: 수집 테마, 직업 관심, 가상 산업 관심, 학습주제, 공간/정체성 취향.

### D7 — 회고와 다음 기대
약속: **“무엇이 바뀌었고, 내가 무엇을 배우고 만들고 수집했으며, 다음에 무엇을 할지 보인다.”**

주간 회고는 부자순위나 거래횟수가 아니라 자기 자신과의 비교가 기본이다.

- 개인 진전 요약 1개;
- 내 스레드와 관련된 세계 변화 1개;
- 미완성 aspiration 1개;
- 선택형 공유 산출물 1개;
- 짧게 끝낼 수 있는 다음 행동 1개.

## 6. 세션 모드

### 1~3분 quick check
- 의미 있는 변화 하나 확인;
- 낮은 마찰의 선택 하나;
- 개인 스레드 저장/이어가기;
- 다음 목표를 보인 채 종료.

### 5~15분 meaningful session
- 학습/직업/수집/사업/시즌/커뮤니티의 작은 마일스톤 하나 완료;
- 눈에 보이는 진전 또는 회고 산출물 생성;
- 필요하면 인접 시스템 하나 탐색.

### 30분+ deep session
- 컬렉션/공간/사업/직업 계획을 자기주도적으로 진행;
- 리플레이/저널 이력 복기;
- 클럽/도시/커뮤니티 기여;
- 아카이브·박물관·프레스티지·장기 정체성 정리.

짧은 세션 사용자가 긴 세션 사용자보다 구조적으로 불리해지지 않는다.

## 7. Acquisition·SEO 연결

콘텐츠는 트래픽이 아니라 **어떤 개인 스레드를 만들었는가**로 평가한다.

우선 검색 여정:

1. 초보 개념 검색 → 교육 답변 → 시뮬레이션 샘플 → 학습 스레드 저장;
2. 가상기업/시장 검색 → 스토리 → 팔로우/탐색 → D7 기업·세계 재방문;
3. 시즌/이벤트 검색 → 프리뷰/아카이브 → 관심 선택 → 시즌 이어하기;
4. 컬렉션/lore 검색 → 충분한 스토리 → 샘플 챕터 → 수집 aspiration;
5. 커뮤니티/프로젝트 검색 → 공개 안전 사례 → 관련 클럽/도시 경험 탐색.

색인 콘텐츠는 가입하지 않아도 독립적으로 도움이 되어야 하며, 진입점 숫자를 늘리기 위한 얇은 페이지 대량생성은 금지한다.

유기적 성장 품질 퍼널:

`노출 → 적합한 클릭 → 의미 있는 이해 → 관련 체험/행동 → 가입/복귀 → 첫 의미 행동 → D1 → D7 → D30 → contribution margin`

## 8. 소셜·바이럴 연결

소셜 증거는 의미 있는 개인 스레드를 강화해야지 대신해서는 안 된다.

좋은 공유 산출물:
- 학습 복기;
- 컬렉션 챕터;
- 시즌 진행 스토리;
- 방/오피스/박물관 쇼케이스;
- 직업/사업 마일스톤;
- 클럽/도시 프로젝트 결과;
- 시뮬레이션임이 명확한 가상기업 의견/리플레이 결과.

잔액, 부채, 비공개 포트폴리오, 카지노 결과, 계정보안 상태, 실명은 기본 공유 대상이 아니다.

Referral 성공은 회원가입 자체가 아니다. `공유 맥락 → 참여 방문 → 첫 가치 → activation → D7`로 평가하고 fraud-adjusted attribution을 적용한다.

## 9. 수익화 배치

페이지나 세션이 약속한 가치를 제공한 뒤에 수익화를 시작한다.

우선순위:
- 첫 유용 섹션 이후 contextual 광고;
- 반복 가치를 경험한 뒤 광고제거 구독;
- 비-P2W 프로필/공간/아카이브/컬렉션 표현 상품;
- 명확히 표시된 교육/lore/커뮤니티 스폰서십.

광고나 스폰서 영역이 매수/매도/대출/상환/계정보안 CTA처럼 보이면 안 된다.

단기 매출이 올라도 activation, D7/D30, 신뢰불만, 오클릭, 이탈·지원비까지 반영한 contribution margin이 악화되면 해당 수익화안은 폐기한다.

## 10. KPI

### 핵심 퍼널
- 방문→콘텐츠 참여율;
- 참여 콘텐츠→관련 체험/행동률;
- 체험/행동→가입/복귀율;
- 가입→첫 의미 행동;
- time-to-first-value;
- first-session completion;
- D1/D3/D7/D14/D30;
- 콘텐츠 유입 코호트 D7/D30;
- 저장 스레드 이어하기율;
- D7 주간회고 완료율;
- returning-user share;
- WAU/MAU;
- meaningful actions/session.

### 성장 품질
- organic signup→activation→D7;
- share/referral→activation→D7;
- 브랜드/직접 재방문 비율;
- 콘텐츠 축별 D30/LTV;
- CAC와 fraud-adjusted CAC;
- LTV/CAC;
- 유입 코호트별 ARPU/ARPDAU와 contribution margin.

### 신뢰 guardrail
- fake-signup rate;
- referral/engagement fraud rate;
- ATO signal rate;
- spam/report rate;
- privacy complaint rate;
- suspicious reward duplication rate;
- public/private exposure incident rate;
- sponsor-disclosure complaint rate;
- ad-induced churn / accidental-click rate.

## 11. 실험 backlog

### A. 유입의도 보존 화면 vs 일반 홈
가설: 가입 직후 콘텐츠 스레드로 돌아가면 첫 의미 행동과 D7이 높아진다.
대상: 고의도 공개 콘텐츠에서 가입한 신규 사용자.
대조군: 일반 인증 홈.
실험군: 스레드 우선 이어하기 화면.
Primary: 가입→첫 의미 행동, D7.
Guardrail: 혼란/뒤로가기, 지원문의, 개인정보 사고, 오류.
최소 관찰: activation 비교가 가능한 표본 + D7 성숙.
성공 시: 고의도 콘텐츠 축으로 확대. 실패 시: 유입의도를 신뢰성 있게 복원할 수 있는 경로만 유지.

### B. 저장/이어하기 CTA vs 일반 가입 CTA
대상: 익명 학습/기업/컬렉션 독자.
대조군: `가입하기`.
실험군: 맥락형 저장/이어하기 문구.
Primary: activated signup rate.
Guardrail: 기만 문구 불만, fake signup, D7.
최소 관찰: 안정적 가입 표본 + D7 성숙.
성공 시: 콘텐츠 archetype별 표준화. 실패 시: 문구 단순화·콘텐츠 독립 가치 유지.

### C. 이어하기 1개 vs 제품 선택 3개
가설: 맥락에 맞는 핵심 이어하기 1개가 첫 세션 인지부하를 낮춘다.
대상: 콘텐츠를 통해 온 신규 사용자.
Primary: time-to-first-value, first-session completion.
Guardrail: D7까지의 탐색폭, 이탈, 만족 신호.
최소 관찰: 첫 세션 표본 + D7 후속.
성공 시: 기본 1개+보조 1개. 실패 시: 유입의도가 모호한 곳만 제한적 선택 복구.

### D. D7 자기진전 회고 vs 리더보드 우선 회고
Primary: D7 의미복귀, D14.
Guardrail: 압박 불만, 위험 거래행동, 소셜 신고율.
최소 관찰: D14 성숙.
성공 시: 자기진전 기본. 실패 시: 경쟁압박 강화가 아니라 목표 설명을 개선.

### E. 가치 제공 후 스폰서 vs 초반 스폰서
대상: 공개 콘텐츠 코호트.
대조군: 핵심 답변 전 스폰서.
실험군: 첫 유용 섹션/체험 후 스폰서.
Primary: engaged visitor당 contribution margin.
Guardrail: 참여읽기, activation, D7/D30, 오클릭, 신뢰불만, ad-induced churn.
최소 관찰: 수익 비교 표본 + 가능하면 D30 방향.
초반 배치가 단기매출만 올리고 리텐션/신뢰를 악화시키면 폐기.

## 12. 보안·악용·개인정보

### High — 의도 복귀/deep-link 악용·피싱
사용자 영향: 복귀 링크를 모방한 피싱, 안전하지 않은 목적지로 유도할 위험.
최소 보호조건: growth journey는 public-safe/내부 목적지만 사용, secret/민감자산 URL 금지, 명확한 공식 도메인/브랜드 식별, 잔액·손실 협박형 복귀문구 금지.
별도 개발/QA: 실제 인증 deep-link 구현 전 필요.

### High — 공개/비공개 개인화 누출
사용자 영향: 계정 존재, 잔액, 포트폴리오 관심, 소셜그래프, 복구/보안상태, 민감 특성 추정이 노출될 수 있음.
최소 보호조건: public-safe 필드만, 공개 opt-in, 비공개 자산/보안/모더레이션 데이터 금지, 숨김/삭제 제공.
별도 개발/QA: 개인화 공개면 구현 전 필요.

### High — referral/bot 보상 파밍
사용자 영향: 가짜계정·자동화가 보상을 빼내고 acquisition 지표와 경제를 훼손하며 스팸을 유발.
최소조건: page view/share/raw signup에 의미 있는 WLD/WDX 보상 금지, retained/verified value 이후 코스메틱·명예 중심 보상, fraud-adjusted attribution.
별도 개발/QA: 경제적 referral 보상 전 필요.

### Medium — 분석/광고 과수집
credential, session identifier, 비공개 금융게임 필드, 복구/보안상태, 민감특성, 불필요한 미성년자 데이터를 분석/광고 도구에 보내지 않는다. 맞춤광고는 별도 연령/지역/개인정보 검토가 필요하다.

### Medium — UGC/커뮤니티 악용
공개 Spotlight와 공유 산출물은 신고·차단·삭제, 실명 강제 금지, 안전한 외부링크 정책이 필요하다. doxxing·사칭·괴롭힘·악성링크를 성장 비용으로 허용하지 않는다.

기존 인증/세션/RBAC/원장/경제/관리자/개인정보/Account Security Center 경계는 유지한다.

## 13. 법규·정책 주의

- WLD/WDX는 계속 virtual/simulated/game-only.
- 교육 및 가상시장 콘텐츠는 실제 투자권유, 수익보장, 예금, 현금환전, 실제 증권을 암시하지 않는다.
- 스폰서/native/creator 관계는 한국·미국 기준에 맞게 명확히 표시한다.
- 맞춤광고, 신규 추적사업자, 미성년자 타기팅, 실질 경제가치 referral, 공개 UGC 확대는 별도 privacy/legal/trust review가 필요하다.
- 공개 커뮤니티/사용자 콘텐츠는 적절한 동의와 삭제 경로가 필요하다.
