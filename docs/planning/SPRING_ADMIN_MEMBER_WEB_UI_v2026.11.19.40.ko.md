**상태: 소스 구현 후보 / 전체 운영 승격 보류.** Android·iOS 앱 개발이 아닙니다. [영문 정본](SPRING_ADMIN_MEMBER_WEB_UI_v2026.11.19.40.md). 우선순위는 통합기획서, Spring 전용 사용자 지시, 승인된 관리자·사용자 디자인 PNG입니다. 기준 `main` SHA `f488088bf50eb4659f59782dc0300a9c3bc74c69`, 회원 홈 후보 `b5e5511acd88a3136eb2673f6fadcb30530436c2` 위에 독립 작업. 보안·금융 별도 PR #3302를 덮어쓰지 않았습니다.

## 실제 코드 구현 범위

- Java Spring MVC `GET /admin` 서버 렌더링과 보호된 관리자 화면. v39.1 회원 홈(`/`)과 **공유 색상**: 배경 `#0c1020`, 카드 `#151d32`, 보라 `#9c83ff`, 블루 `#64b7ff`. PC 좌측 메뉴, 모바일 5탭·드로어, 44px 버튼, 56px 문의 바로가기. Node/Next 웹 런타임 불필요.
- 영어 기본·한국어 두 번째 언어, 일본어·중국어 간체·베트남어. 브라우저 언어 **자동 감지** + 사용자가 직접 선택하는 **수동 전환**. 112개 항목×5개 언어 검사. 로컬에는 언어 선호도만 저장하며 관리자 금융/토큰 데이터는 저장하지 않습니다.
- 관리자 인증은 Spring 세션과 DB `admin_current_roles` 검증만 사용. 기존 정적 `/admin.html`, `/admin-preview`는 권한 검사 뒤 실제 관리자 홈으로 이동. **실제 HTML 페이지에만 필터 적용**하고 `/admin/backups/status` 등 기존 JSON API는 원래 401 동작을 유지.
- 관리자 카드의 회원 수는 전체 회원 수가 아니라 **조회된 최대 50개 원천 레코드의 개수**. 시장 종목과 기능 스위치도 Spring 서비스가 실제 소스에서 가져온 결과만 표기. 금융 원장 100조나 테스트 그래프, 서버 LIVE, 가짜 활동률 표시 안 함. 일부 소스 실패 시 `조회 불가` 및 HTTP 503, 결코 성공·0으로 변환하지 않음. 회원 홈에서는 실세션 개인 지갑 및 SQL 시세만 사용.
- 관리자 메뉴는 기존 로그인 보호 라우트(회원·경제·상점·콘텐츠·시장·통계·로그·보안·문의)를 연결합니다. **다른 관리자 상세 기능 전체를 이번 작업에서 새로 구현한 것은 아닙니다.** 예전 페이지의 가짜 숫자/미구현 동작과 나머지 회원 180개 경로는 전수 실기능 검증이 남았습니다.
