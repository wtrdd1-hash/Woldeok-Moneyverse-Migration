# v1946.2 — 사용자 변경 지시: 미검증 AI 글 공개

**근거:** 2026-11-09 사용자 명시 지시. 기존 v1405의 공개 여부·광고 지면 규칙에만 우선. 원본 출처, 영수증, 금융 수치 및 금융 거래를 조작하라는 뜻은 아님.

1. 사람의 사전 승인은 불필요. `PUBLISHED`와 `WITHDRAWN`을 검증과 분리. 명시적 공개 글만 노출, 초안·비공개·삭제는 제외.
2. 검증 통과 글은 기존 DB 및 SECURITY DEFINER 유지. 검증 실패 글은 `quality: PASS` 조작 없이 별도 블로그 전용 멱등 JSON에 `UNVERIFIED`로 저장·공개.
3. 공개 미검증 글에 AI 생성·미검증 경고 표시, HTML·스크립트 안전 렌더링. 공개 쓰기 API나 전역 경제 스케줄러 재활성화 금지.
4. 사용자 지시에 따라 블로그 광고 지면 허용. **AdSense 위험:** Google은 사람이 검수/큐레이션하지 않은 자동생성 콘텐츠에 Google 광고 제공을 금지함. 사용자 승인은 광고 적합성 보증이 아니며 계정 제한 위험, 수익·광고 미표시 가능성이 있음.
5. 정확 SHA 테스트, Test 실제 발행, SSR·사이트맵 카나리, Nginx 롤백 및 기존 금융 서비스 점검 전 운영 완료 주장 금지.
