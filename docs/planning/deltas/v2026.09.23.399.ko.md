# v2026.09.23.399 — 시간 기반 직업 보상 경제 기획 델타

## 결론
즉시 완료형 WLD faucet은 폐기 방향으로 기획한다. 일반 직업 참여 자체는 무제한으로 유지하되, **WLD 발행은 실제 서버 경과시간에 묶고 계정당 시스템 지급 작업 슬롯을 기본 1개로 제한**한다.

경제제어는 단일 일일 cap보다 `시간당 발행량 × 반복감소 × sink × 전체 화폐공급 피드백` 조합을 사용한다. 이는 계속 플레이할 자유는 유지하면서 버튼 연타로 화폐가 무한 발행되는 문제를 제거한다.

Test 초기값은 일반 300–600 WLD/실시간 1시간, 고급 최대 1.5배, 반복 저난도 25–40% WLD율이다. 운영 고정값이 아니며 7/30/90일 경제 시뮬레이션을 통과한 값만 Production에 사용한다.

## 외부 레퍼런스 요지
- EVE Online은 월간 경제보고에서 money supply, faucets/sinks 및 가격지수 변화를 지속 관찰한다.
- Unity의 최신 game economy 가이드는 inflation rate, currency velocity, sink-to-faucet ratio, days-of-currency-on-hand를 결합해 진단할 것을 권한다.
- 대규모 OSRS 경제 연구는 transaction tax/item sink 같은 개입의 실제 시장 효과를 인과추론으로 측정해 단순 직감형 조정의 위험을 보여준다.
- GameDeveloper 경제 설계 자료는 시간을 핵심 비용자원으로 보고, 무제한 반복보다 time control/cost rhythm을 경제설계에 사용한다.

## 구현 게이트
서버 권위 minimum duration, one paid slot, 즉시완료 거절, 멱등/동시정산, 재시작 타이머 유지, 반복계수 연속성, ledger reconciliation, 경제지표 telemetry와 exact-SHA Test가 없으면 운영승격 금지.
