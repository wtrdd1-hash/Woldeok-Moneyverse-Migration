## 채택 보안 변경

- 공개 저장소는 비공개 보안 경계가 아니라 이미 공개된 표면으로 취급한다.
- 내부 업데이트 기록과 민감한 상세 보안 증거는 승인된 비공개 저장소에 둔다.
- 공개 트리의 secret 통제는 Git 이력 인지형 검사를 요구하며 현재 파일 삭제를 과거 이력 소거로 간주하지 않는다.
- 저장소 정리는 테스트, DB bootstrap, 재현 가능한 빌드에 필요한 소스를 보존해야 한다.
- 모바일 release signing은 공개 credential fallback을 금지하고 debug 빌드는 release signing을 사용하지 않는다.
- 일반 Android PR CI는 unsigned/debug 전용이며 signed release bundle은 secret-backed 전용 release workflow에서만 만든다.
