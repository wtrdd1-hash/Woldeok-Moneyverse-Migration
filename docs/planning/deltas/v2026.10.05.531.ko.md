## 구현된 소스 변경

- `/admin/seo`: 좁은 화면에서 관제 액션 전체를 stack/wrap하고 긴 라벨을 재배치하며 주요 액션 높이를 최소 44 CSS px로 유지.
- 관리자 인터랙션 바닥값: mobile/coarse-pointer 관리자 button/button-role에 44×44 CSS px 최소 target 계약 적용.
- 소비자 플로팅 위젯: 온보딩/고객지원을 하나의 pathname-aware floating layer로 통합하고 모든 `/admin/**`에서 숨김.
- 전역 주요 헤더 제어: 모바일 메뉴, 언어, 로그인/세션, 계정 메뉴 제어를 44px 터치 바닥값으로 상향.
- 루트 홈 시맨틱: 랜딩 hero에 실제 보이는 localized `h1` 추가.
- 계정 identity read model: 연결된 로그인 수단으로 `local_email`을 허용하되 OAuth 연결은 Google/Discord로 계속 제한. identities 500의 소스/데이터 불일치를 해결.
