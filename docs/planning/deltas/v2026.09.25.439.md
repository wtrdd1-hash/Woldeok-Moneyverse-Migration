# Planning Delta v2026.09.25.439 — Login/Session Persistence Hard Gate

**Status:** PLANNING  
**Date:** 2026-09-25  
**Start/mid origin/main:** `118a58ddc289839957caacd14650863e614f8fad`

## Decision
- P0: valid authenticated sessions survive deploys, service/host restarts, proxy reloads, cutovers, rollbacks, and non-revoking key rotations.
- Runtime replacement is not a logout reason.
- Allowed logout causes are limited to user logout, explicit admin/security revocation, compromise response, account disable/delete, or normal authoritative expiry.
- Shared durable session authority and overlap-safe key validation are mandatory.
- Silent fallback of a valid pre-release session to guest is a release failure.
- Test and Production promotion require continuity checks using the same pre-existing authenticated sessions.
- Any deployment-caused logout or release-attributable auth error spike blocks promotion or requires rollback.

## Evidence gate
Exact candidate SHA, runtime identities, shared-session health, privacy-safe continuity identifiers, authenticated read plus safe CSRF mutation, and auth-error deltas are required. Session-count equality alone is insufficient.

## Scope
Planning/documentation only. No runtime, Test, or Production deployment is claimed.
