## 최신 결정

- 제품/공개 fallback은 영어가 아니라 한국어다.
- GeoIP는 공개 색인 페이지에서 게시 언어 추천/selector 기본값에 사용하고 crawler/명시 locale URL을 강제 전환하지 않는다. 비색인 앱 온보딩은 첫 세션 기본값으로 사용할 수 있다.
- 해외 출시는 EN/JA 이후 DE/FR/ES/pt-BR을 한 locale씩 품질 우선으로 진행한다.
- 실제 사이트 검색성과와 시장 키워드 검색량 추정을 분리하며 synthetic GSC fallback을 운영 판단에 금지한다.
- pSEO는 독립 사용자 가치 게이트를 사용하고 고정 페이지수 목표를 성공지표로 두지 않는다.
- 해외 공개 utility·가상경제 도구·현지화 onboarding·시간대/이벤트·UGC 번역/탐색·리텐션 기능을 확장한다.
- 일반검색·Images·video·보조 Discover를 canonical/hreflang/CWV/internal link 품질 게이트로 운영한다.
- 현금수익은 광고 전용이며 실제 Page RPM/자격 자연검색 세션당 수익과 증분 운영비로 시장 수익성을 판단한다.

문서/기획 전용이며 런타임/Test/Production/수익 달성을 주장하지 않는다.
