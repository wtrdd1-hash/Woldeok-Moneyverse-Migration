## 확인사항
현재 Work quota 화면은 유한 일일/주간 WLD 카운터와 자정/UTC 00:00 문구를 함께 사용할 수 있다. 런타임 증거상 대시보드는 이미 서버 권위 Moneyverse 게임 시계의 `day_ends_at`, `week_ends_at`을 받으며 가속 게임시계도 사용한다. 따라서 하드코딩된 초기화 문구가 실제 표시 타임스탬프와 모순될 수 있다.

또한 제품 정책은 일반 직업 참여를 기본 무제한으로 규정한다. 따라서 유한 일일/주간 WLD cap은 일반 작업/플레이 하드캡이 아니라 한시적·버전 관리형 보상 발행 보호 윈도우로 취급해야 한다.

## 기획 수정
- canonical 초기화 경계는 서버 `day_ends_at` / `week_ends_at`.
- 일일/주간 설명문은 서로 분리하고 활성 게임시계 정책과 정합시킨다.
- 실제 정책이 그렇지 않다면 UTC/현지 자정을 하드코딩하지 않는다.
- 무제한은 `null`; 임의 거대숫자나 모호한 0을 사용하지 않는다.
- 유한 cap에는 정책버전, 사유 분류, 재평가/만료 metadata, 무제한 복귀 경로가 필요하다.
- 별도 보호상태가 막지 않는 한 WLD 발행 여유 소진 뒤에도 작업/숙련도는 계속될 수 있다.
- 웹/모바일은 동일 summary/API 계약을 사용한다.
- 정산/read-model/UI 경계 정합은 exact-SHA Test 게이트다.
