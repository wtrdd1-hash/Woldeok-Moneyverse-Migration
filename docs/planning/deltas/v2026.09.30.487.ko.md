## 상위 대체 결정
- 사용자 사업자등록 제약: 현재 안내 기준에서 직접 상품판매는 허용되지 않는다.
- 따라서 향후 등록 사업범위/세무/법률 검토가 명시적으로 허용 범위를 넓히기 전까지 현금 수익화는 **광고수익 전용**이다.
- 유료 구독/광고제거, 코스메틱·디지털 상품, 유료 WLD/WDX, 유료 확률형, 사용자 유료 마켓 수수료, 후원/멤버십, 유료 API/B2B, 제휴/직접판매 수익은 BLOCKED로 유지한다.
- 기존 광고 민감 route 차단은 유지한다.
- 월 광고수익 100만 원 목표는 실측 Page RPM을 사용해 `PV = 1,000,000 / PageRPM × 1,000`으로 계산한다.
- 시나리오상 Page RPM 2,000원에서는 50만 PV, 20,000원에서는 5만 PV가 필요하지만 어떤 RPM도 보장하지 않는다.
- 광고 성장은 정상 인간 트래픽, audience-first 콘텐츠, Search Console/색인 진실성, 실측 AdSense 실험으로 수행한다. 자가/유도/보상/traffic-exchange 트래픽은 금지한다.
