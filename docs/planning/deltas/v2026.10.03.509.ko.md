## 권위 델타

v507에서 글로벌 성장의 실질 설계를 이미 정의했다. v509는 같은 조사를 새 버전처럼 다시 포장하지 않고, 사용자가 승인한 v507 설계를 최신 main의 현재 기획 권위 체계에 통합한다.

현재 기획 권위로 채택한 계약:
- 제품/공개 fallback locale은 한국어(`ko`)다.
- GeoIP/Accept-Language는 언어 선택 보조 신호이며 공개 색인 URL 강제 redirect 근거가 아니다.
- 명시 locale URL과 저장된 사용자 언어가 추정 locale보다 우선한다.
- locale과 법적 관할/결제국가/연령/기능자격은 독립 정책축이다.
- 해외 서비스 가치는 URL 개수 목표보다 현지화 utility, 지식/검색, 온보딩, 번역, 시간대/이벤트, 해외 탐색·리텐션 기능을 우선한다.
- 국제 SEO는 locale별 self-canonical, 상호 hreflang, 정확한 sitemap/lastmod, crawlable 내부링크, 화면내용 일치, 품질/색인 게이트를 요구한다.
- 시장 검색수요 추정과 실제 Search Console/Search Advisor 성과는 서로 다른 증거 유형으로 유지한다.
- 현재 사업 권위에서 현금수익은 광고 전용이며 해외 경제성은 실제 광고수익과 번역/콘텐츠/컴플라이언스/운영 귀속비용으로 평가한다.

## 버전 결정

- `PROJECT_PLAN`, `INTEGRATED_PLANNING_MASTER`: 현재 권위를 v2026.10.03.509로 갱신한다.
- v507 상세명세와 조사기록은 provenance를 위해 v507 식별자를 유지하고 v509 권위 채택 표시만 추가한다.
- v508 런타임/보안 증거는 보존하며 글로벌 성장 구현 증거로 잘못 재분류하지 않는다.

## 구현/릴리스 상태

v509는 런타임 코드, DB, Test, Production을 변경하지 않는다. 이후 구현은 당시 최신 main에서 별도 브랜치를 만들고 exact-SHA Test에서 백엔드 health까지 검증한 뒤 프로젝트의 무중단 Production 승격 게이트를 따라야 한다.
