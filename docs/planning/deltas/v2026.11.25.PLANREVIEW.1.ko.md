## PLANREV-DEC-01 — 가상 예금보호
한도는 **회원별·부보 기관별**로 적용합니다. 전체 기관 합산 한도가 아닙니다. 양쪽 상세 명세의 기존 설계 금액500,000 WLD를 유지하고, 색인의50,000,000 WLD는 전사 오류로 정정합니다. 같은 기관 안의 원금·적격 이자 합산, 지급 재원·우선순위·적격성·재원 부족 처리는 구현·검증이 필요합니다.
게임 내 WLD 보상 설계이며 실제 예금보험·정부 보증·원화 환급·법정 보장을 뜻하지 않습니다. 공식 예금보호 배지 사용을 허용하지 않습니다. 기존 은행 안전·원장·원천 검증 차단은 유지합니다. 잔액·보험료·지급·금융 함수를 변경하지 않습니다.

## PLANREV-DEC-02 — 모든 게시 언어의 화면 URL 접두사
영어·한국어를 포함해 /en/, /ko/, /ja/, /zh/, /vi/를 사용합니다. 영어 기본·fallback은 유지합니다. 과거 한국어 prefix 없는 canonical과 /ko redirect alias, 한국어 기본언어 지시는 현재 기획에서 이 결정이 우선합니다. 과거 릴리스 증거는 변경하지 않습니다.

- 명시 언어 URL이 우선합니다. 언어가 없는 진입은 기존 승인 순서인 지속된 수동 선택→허용된 계정 선호→지원 브라우저 언어→영어를 유지합니다. GeoIP가 명시 선택을 덮어쓰지 않습니다.
- 실제 번역·게시된 공개 페이지는 해당 접두사 URL로 self-canonical과 상호 hreflang을 제공합니다. 동등한 영어 페이지가 있으면 x-default는 그 페이지를 사용합니다. 번역이 검증되지 않은 URL을 접두사만 만들어 hreflang·sitemap에 넣지 않습니다.
- 회원·관리자 화면은 권한 검사·noindex·비캐시 계약을 유지합니다. 언어로 관할·연령·금융 권한·기능 허용 여부를 바꾸지 않습니다.
- API·Socket.IO·OAuth 콜백·외부 연동·정적 자산·세션/CSRF 프로토콜 경로는 유지합니다. 이번 결정은 현지화된 HTML 화면 URL에 적용합니다.
- 실제 이전 전 구→신 경로와 redirect 계약을 고정하고 동적 ID·쿼리·딥링크·초안·세션을 보존해야 합니다. 독립 exact-SHA Test에서 SEO·5개 언어·권한을 검증합니다. 기존 URL을 조용히 삭제하지 않습니다. 이번 PR에서 실제 URL·라우터·리디렉션은 바꾸지 않습니다.

[Google 공식 다국어 안내](https://developers.google.com/search/docs/specialty/international/localized-versions)는 언어별 대응 링크·x-default 기술 참고이며, 접두사 선택은 사용자 결정입니다.
