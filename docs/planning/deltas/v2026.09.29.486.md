- **DB486-02 / P0:** every nullable business-key uniqueness invariant explicitly chooses NULL-distinct semantics and tests it.
- **DB486-03 / P1:** create extended statistics only for measured correlated-column estimation errors and verify the resulting plan.
- **DB486-04 / P0 when enabled:** replication/CDC slots require owner, consumer, lag/retained-WAL telemetry, capacity budget, and bounded retention policy or documented exception.
- **DB486-05 / P0:** physical/base-backup verification includes `pg_verifybackup` plus a real disposable restore drill; neither substitutes for the other.
- **DB486-06 / P0:** large-table constraint changes use low-impact staged validation where supported and retain lock/scan classification.
- **DB486-07 / P1:** RLS, if introduced, is defense-in-depth with explicit owner/BYPASSRLS/FORCE-RLS tests; it does not replace the current restricted-role mutation boundary.
