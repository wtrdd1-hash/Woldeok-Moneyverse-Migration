## 0. 목적

Moneyverse는 기본적으로 플레이 횟수나 성장에 임의 하드캡을 두지 않는 방향을 사용한다. 따라서 장기 플레이로 생성되는 WLD를 자연스럽게 흡수할 수 있도록, 단순 세금이 아니라 사용자가 자발적으로 돈을 쓰고 싶어지는 다양한 소비처가 필요하다.

경제 흐름은 다음을 구분한다.

- **하드 싱크:** 재화가 경제에서 실제로 제거된다.
- **이전(transfer):** 유저 사이에서 돈만 이동한다. 총량은 줄지 않는다.
- **변환(converter):** 재화를 다른 자원으로 바꾼다. 실제로 제거된 부분만 싱크로 계산한다.

유저 간 거래액 전체를 소비처로 계산해서는 안 된다. 거래 수수료처럼 실제 제거되는 부분만 하드 싱크다.

## 1. 기본 원칙

1. 소비는 주로 정체성, 꾸미기, 수집, 선택지, 편의, 명예, 유지비, 새로운 목표를 제공해야 한다.
2. 저자산/중간자산/고자산 유저 모두에게 살 것이 있어야 한다.
3. 고자산 유저용 소비처는 선택형 명예 소비처로 만들고 일반 유저를 압박하는 강제세로 만들지 않는다.
4. 유저의 야망이 커질수록 자연스럽게 소비가 늘어야 한다. 사업체, 집, 클럽, 수집, 도시 프로젝트 등이 그 역할을 한다.
5. 돈을 쓰게 하려고 영구 성장을 강제로 삭제하지 않는다.
6. 기본 한도 정책은 unlimited를 유지한다.
7. 모든 가격은 서버 정책/config로 관리한다.

## 2. 소비처 포트폴리오 목표

30일 기준 전체 WLD 제거량이 하나의 시스템에 지나치게 몰리지 않게 한다.

| 소비처 계열 | 전체 제거량 목표 비중 |
|---|---:|
| 꾸미기/수집/프로필 | 15~25% |
| 사업 확장/유지 | 15~25% |
| 제작/복원/커스터마이징 | 10~20% |
| 시장 수수료 | 8~15% |
| 주거/공간/인테리어 | 8~15% |
| 클럽/소셜/도시 프로젝트 | 8~15% |
| 이동/서비스/편의 | 5~10% |
| 시즌/이벤트 | 5~12% |
| 기타 동적 소비처 | 0~10% |

수치는 튜닝 범위일 뿐 하드캡이 아니다.

## 3. 상점·꾸미기·수집

항상 판매 가능한 항목:

- 프로필 프레임
- 아바타 테두리
- 프로필 카드 배경
- 대시보드 테마
- 주식 터미널 스킨
- 거래내역 테마
- 채팅 말풍선
- 칭호 효과
- 닉네임 플레이트
- 포트폴리오 카드 스킨
- 사업체 간판
- 사무실 가구
- 클럽 배너
- 수집품 진열장
- 시즌 기록 앨범 표지
- 업적 전시장 슬롯

이 항목들은 소득 배율을 올리지 않는다.

### 수집품 가격대 예시

- 일반: 300~1,500 WLD
- 중급 테마: 2,000~10,000 WLD
- 명예 수집품: 25,000~250,000+ WLD
- 박물관급 고자산 명예 수집품: 500,000 WLD+

세트 완성 보상은 배지, 스토리, 프로필 연출, 전시 레이아웃, 칭호 중심으로 한다.

### 복원·전시 서비스

이미 산 수집품에도 반복 소비처를 만든다.

- 액자 변경
- 외형 복원
- 획득일 각인
- 전시장 조명
- 앨범 묶기
- 비양도형 출처 인증서
- 전시 이름 변경

## 4. 집·방·개인 공간

장기 고자산 소비처의 핵심으로 개인 공간을 둔다.

소비 요소:

- 공간 해금/건축
- 바닥/벽 테마
- 가구
- 조명
- 트로피 벽
- 수집품 전시장
- 식물/수족관/분위기 오브젝트
- 도시 배경
- 음악/환경음
- 방명록 꾸미기
- 시즌 장식
- 리모델링

예시 가격:

| 공간 | 예시 가격 |
|---|---:|
| 스타터 룸 | 무료 또는 저가 |
| 스튜디오 사무실 | 15,000 WLD |
| 로프트 작업실 | 75,000 WLD |
| 비즈니스 펜트하우스 | 350,000 WLD |
| 스카이라인 본사 | 1,500,000+ WLD |

고정 상한 대신 더 큰 공간과 명예형 인테리어로 소비를 확장한다.

## 5. 사업 소비처

### 시작/확장

- 사업 등록비
- 위치 임대/허가비
- 장비 구매
- 인테리어
- 진열장
- 간판
- 운영 모듈
- 분석 도구
- 창고 확장
- 지점 추가
- 이전/리모델링

### 반복 운영비

- 유지보수
- 재고 폐기
- 공공요금
- 청소/서비스 계약
- 장비 정비
- 품질 검사
- 광고 캠페인
- 시즌 매장 리뉴얼
- NPC 채용/구인 서비스비

### 고자산 명예 소비

- 플래그십 지점
- 랜드마크 간판
- 프리미엄 로비
- 기업 박물관
- 배송차량 스킨
- 광장 후원
- 도시 이벤트 후원
- 사업 역사관

명예 소비는 외형과 평판 표시를 강화하고 패시브 수익을 폭발적으로 키우지 않는다.

## 6. 제작·변형 소비처

- 제작 서비스비
- 재료 소모
- 레시피 해금
- 색상 변경
- 각인
- 중복 수집품 합성
- 외형 리롤
- 복원
- 장식 주문 제작

확률형 요소가 있으면 확률을 공개하고, 실제 돈과 결합되는 확률형 판매는 별도 검토 전까지 넣지 않는다.

## 7. 시장·거래 소비처

### 주식시장

- 체결 수수료
- 고급 주문유형 사용료(필요한 경우)
- 과거 시뮬레이션 시나리오 구매
- 포트폴리오 리포트 템플릿
- 분석 화면 커스터마이징

플레이 횟수 제한 대신 거래 금액에 연동되는 수수료 구조를 우선한다.

### 유저 거래소가 생길 경우

- 등록 수수료
- 판매 성공 수수료
- 추천 노출 수수료
- 장기간 미판매 재등록비
- 고가 수집품 감정비

유저가 받는 판매대금은 여전히 경제에 남으므로 수수료만 실제 소비처다.

## 8. 은행/금융 시스템 소비처

- 대출 실행 서비스비
- 재조정 행정비
- 계좌 테마
- 재무 리포트 생성
- 고급 명세서 디자인
- 보관함/전시 슬롯 임대
- 자동 예산규칙 부가 기능

연체비용이 회복 불가능한 부채 악순환을 만들어서는 안 된다.

## 9. 이동·물류·서비스

자주 쓰는 소액 소비처:

- 빠른 이동
- 특급 배송
- 사업 물류
- 구역 간 운송
- 보관 장소 간 아이템 배송
- 임시 보관
- 리모델링 서비스
- 기록 보관소 조회
- 이벤트 장소 이동

기본 콘텐츠 접근이 지나친 비용 때문에 막히지 않게 한다.

## 10. 클럽·소셜 소비처

- 클럽 창설/브랜딩
- 클럽하우스 방
- 배너/엠블럼
- 역사관
- 클럽 이벤트 개최
- 멤버 축하 연출
- 공동 트로피장
- 도시 프로젝트 기부
- 게시판 꾸미기
- 시즌 클럽 장식
- 대회장 외형

클럽 기부는 유저 간 단순 이전이 아니라 시스템으로 소각되도록 설계할 수 있다.

## 11. 도시·커뮤니티 프로젝트

고자산 유저까지 흡수할 수 있는 대형 공동 소비처:

- 도시 광장 재건
- 가상 교통 기념물
- 시즌 축제 후원
- 박물관 복원
- 커뮤니티 정원
- 스카이라인 랜드마크
- 연구 관측소
- 서버 전체 장식 이벤트

유저가 WLD를 기부하면 프로젝트 원장으로 들어가고 실제 경제에서는 제거한다. 목표 달성 시 명예표시, 칭호, 기념패, 프로필 마크, 장식 공간 등을 제공한다.

이 시스템은 기부금액에 상한을 두지 않아도 되므로 unlimited-by-default 정책과 잘 맞는다.

## 12. 시즌·이벤트 소비처

매 시즌 새 소비처를 만든다.

- 시즌 테마 꾸미기
- 기념 수집품
- 시즌 집 장식
- 과거 시즌 아카이브 상점
- 시즌 사업 장식
- 축제 기부
- 시즌 박물관 전시
- 다음 시즌 티저 수집품
- 시즌 리플레이 시나리오
- 시즌 프로필 레이아웃

시즌 WLD 소비처는 랭킹 우위를 직접 사는 방식으로 만들지 않는다.

## 13. 성장·숙련 소비처

플레이를 제한하지 않고 장기 진행에 비용을 연결한다.

- 직업 자격 시험
- 전문분야 해금
- 숙련 배지 외형
- 훈련 시뮬레이션
- 고급 튜토리얼
- 전문분야 재설정 서비스
- 명예 프레스티지 재도전
- 상위 사업 라이선스
- 투자 연구 노트 업그레이드

새 선택지와 명예를 제공하되 수익 배율 폭증은 피한다.

## 14. 유지비 정책

허용:

- 사업체 합리적 운영비
- 수집품 외형 복원
- 대형 선택형 공간 유지비
- 편의 장비 정비

금지:

- 접속하지 않았다고 영구 구매품 삭제
- 오프라인 유저의 재산을 0까지 소모
- 획득한 프로필 보상 회수
- 일반 유저가 회복할 수 없는 수준의 유지비

## 15. 인플레이션 대응용 동적 소비처

인플레이션이 높아질 때 플레이 하드캡을 추가하기 전에 다음을 우선한다.

- 초고가 명예 꾸미기 추가
- 고급 주택 모듈
- 도시 프로젝트 캠페인
- 새로운 사업 지점 유형
- 시스템 명예 경매
- 각인/이름변경 이벤트
- 한정 장식 제작
- 공개 범위 내 거래 수수료 조정
- 세계관 내 기부/후원 이벤트

필수 비용을 몰래 올려 재산을 회수하는 방식은 사용하지 않는다.

## 16. 자산 구간별 소비 설계

내부 분석용 예시:

| 자산 구간 | 일반 구매 단가 |
|---|---:|
| 신규/저자산 | 100~2,000 WLD |
| 초기 성장 | 2,000~20,000 WLD |
| 중자산 | 20,000~200,000 WLD |
| 고자산 | 200,000~2,000,000 WLD |
| 명예 자산 | 2,000,000+ WLD |

이 구분명은 내부 분석용이며 사용자에게 모욕적인 등급명으로 노출하지 않는다.

## 17. 가격 정책

- 기본 상품: 고정가
- 명예 아이템: 단계형 가격
- 추가 공간/지점: 점진적 건설비
- 도시 프로젝트: 자유 기부액
- 시스템 경매: 시장형 가격
- 시즌 카탈로그: 시즌 가격표
- 번들: 할인 여부를 명확히 공개

불투명한 개인별 차등가격은 피한다.

## 18. 경제 모니터링 지표

반드시 추적:

- 시간/일/주 WLD 발행량
- 시간/일/주 WLD 소각량
- 순발행량
- 하드싱크율 = 소각 / 발행
- 유저 간 이전 거래량
- 평균/중앙값/P90/P95/P99 잔액
- 상위 1%/10% WLD 점유율
- 소비처별 사용량
- 코호트별 사용 소비처 수
- 상위 3개 소비처 의존도
- 대표 상품 구매에 필요한 평균 플레이 일수
- 신규 유저 D7/D30 잔액
- 고자산 유저 잔액 증가율
- 사업 유지비 부담률
- 시즌 소비처 사용률
- 도시 프로젝트 기여 분포

## 19. 초기 튜닝 목표

- 성숙한 활성 유저에게 항상 의미 있는 WLD 소비 선택지 최소 5개 이상 제공
- 고자산 유저에게 유동자산의 5~25%를 자발적으로 쓸 수 있는 명예 소비처 최소 3개 이상 제공
- 특정 한 소비처가 전체 소각의 약 40% 이상을 지속적으로 독점하지 않도록 조정
- 필수 성장 비용은 중앙값 활성 유저가 감당 가능해야 함
- 성장기에는 순발행이 양수여도 되지만 증가속도를 대시보드로 감시
- 상위 1% 자산점유율이 빠르게 상승하면 전체 세금보다 고자산 명예 소비처를 먼저 추가

## 20. 개발 우선순위

P0:

1. 영구 꾸미기 상점 확대
2. 사업 등록/유지/업그레이드

## 21. 기술 요구사항

모든 WLD 소비 mutation은:

1. 사용자 인증
2. 대상 권한 검증
3. 서버에서 가격/config 조회
4. 잔액/조건 검증
5. 원장 차감과 구매/상태 변경을 하나의 트랜잭션으로 처리
6. 재시도 가능한 요청은 멱등성 적용
7. 분석/감사 이벤트 기록
8. 클라이언트 가격 신뢰 금지
9. `hard_sink`, `transfer`, `converter` 분류
10. 소비처 계열별 대사 가능

권장 메타데이터:

- `sink_family`
- `sink_code`
- `season_id`
- `business_id`/`club_id`/`project_id`
- `pricing_policy_version`
- `idempotency_key`
- `burn_amount`
- `transfer_amount`
- `source_context`

- 차감/상태변경 원자성

- 접근성/오류/잔액부족 상태
- 영문/한국어 문서
- 경제 대시보드 측정 가능
- 테스트 서버에서 차감 및 원장 대사 검증
