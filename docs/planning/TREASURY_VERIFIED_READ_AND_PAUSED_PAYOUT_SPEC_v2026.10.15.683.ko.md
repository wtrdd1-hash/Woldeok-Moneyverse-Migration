## 이번 v683 수정
1. 새 272 전진 마이그레이션에 `treasury_admin_reconciliation(p_actor uuid)` SECURITY DEFINER 읽기 전용 함수 추가. 세션 UUID 전달, DB 내부 operator 역할 확인, 안전한 search_path, PUBLIC EXECUTE 회수, 앱에는 **좁은 함수 EXECUTE만** 허용. 금고별 보조원장 순흐름·행 연속성·금액 불일치·절대 차이 합계를 계산하되 Economy Core 전체 실재원이 증명되었다고 간주하지 않는다.
2. 백엔드 관리자 원장대사는 세션 사용자 ID를 재사용하고 파라미터화 함수만 조회한다. `UNVERIFIED` 및 `DISCREPANCY`는 정상 지급 승인 판정이 아니다.
