## 1. 이번 회차에서 선택한 성장 공백

현재 가장 큰 유입·활성화 공백은 **계정을 만들기 전 단계**다. 기존 기획은 가입 이후 첫 3분은 비교적 구체적이지만 검색, 공유 카드, 시즌 페이지, 가상기업 페이지, 커뮤니티 링크로 들어온 비회원에게는 다음 질문에 즉시 답해야 한다.

1. Moneyverse가 무엇인가?
2. 지금 바로 무엇을 해볼 수 있는가?
3. 무엇을 본 뒤 왜 계정을 만들어야 하는가?

따라서 모든 공개 방문자를 곧바로 로그인으로 보내기보다 **가입 전 활성화**를 독립 퍼널로 관리한다.

## 2. 방문자 가치 제안

첫 화면에서는 복잡한 시스템 설명보다 한 문장의 가치를 먼저 전달한다.

**실제 투자 위험 없이, 가상시장·수집·직업·사업·시즌이 연결된 지속형 가상경제를 배우고 성장하고 경쟁한다.**

증거는 기능 수 나열이 아니라 구체적 예시로 보여준다.

- 가상기업 하나를 보고 왜 가격이 움직였는지 이해하기
- 수집품 또는 시즌 기록 미리보기
- 짧은 직업→수집→사업 성장 경로 확인
- 주간 결산 또는 업적 카드 샘플 보기
- WLD/WDX가 현금환전 불가한 가상·시뮬레이션 자산임을 이해하기

첫 화면부터 은행 전문용어, 복잡한 경제 대시보드, 관리자용 숫자, 전체 기능 목록을 한꺼번에 보여주지 않는다.

## 3. 첫 30초

비회원 첫 방문자는 첫 화면에서 다음을 확인할 수 있어야 한다.

- 핵심 약속 1개
- 실제 가치를 증명하는 인터랙션 또는 콘텐츠 1개
- 1차 CTA: **샘플 체험** 또는 **Moneyverse 둘러보기**
- 2차 CTA: **계정 만들기**
- 시장/경제 내용을 보여줄 때 간단한 `virtual / simulated / game-only` 안내

공개 화면에는 비공개 잔액, 포트폴리오, 회원 식별정보, 보안 상태, 신고/제재 상태, 인증 전용 API 데이터가 노출되면 안 된다.

## 4. 첫 3분 — 계정 없는 샘플 여정

익명 방문자에게 가짜 계정을 만드는 대신 제한된 미리보기를 제공한다.

### 0~1분: 관심 경로 선택
세 가지 선택지만 제시한다.

- **시장:** 가상기업/이벤트 하나를 보고 비구속형 예측하기
- **성장:** 직업 → 수집 → 사업 성장 경로 미리보기
- **수집:** 테마 수집품/시즌 세트와 기록 살펴보기

### 1~2분: 되돌릴 수 있는 샘플 행동 1개
예시:

- 어떤 가상 이벤트가 기업에 영향을 줄지 고르고 해설 확인
- 샘플 아이템 3개로 수집 세트 완성
- 초보 목표 3개 중 하나를 골라 다음 두 성장단계 미리보기

비회원 샘플은 WLD를 발행하지 않고, 실제 보유자산·주문·추천보상을 만들지 않으며 민감 상태를 저장하지 않는다.

### 2~3분: 방금 한 행동과 연결된 가입 이유 제시
CTA는 직전 행동을 그대로 이어가야 한다.

- `이 관심종목을 저장하고 시장 학습 계속하기`
- `이 수집 세트를 시작하고 진행도 저장하기`
- `이 성장 경로를 선택하고 첫 실제 작업 열기`

인증 후 일반 홈으로 던지지 말고 같은 의도로 복귀시킨다.

## 5. 검색→플레이 콘텐츠 구조

SEO 콘텐츠는 검색의도와 실제 다음 행동을 연결한다.

| 검색의도 | 공개 콘텐츠 | 자연스러운 다음 행동 |
|---|---|---|
| 모의투자/가상투자란? | 초보 학습 가이드 | 가상시장 시나리오 1회 체험 |
| 분산의 의미 | 교육 가이드 | 가상기업 3개 샘플 관심목록 만들기 |
| 가상기업/티커 | 기업 세계관+이벤트 기록 | 가입 후 저장/팔로우 |
| 경제게임 초보 | 제품 설명 | 성장 경로 선택 |
| 시즌/이벤트 기록 | 아카이브+수집 기록 | 현재 시즌 목표 미리보기 |
| WLD/WDX 뜻 | 용어집 | 안전한 샘플 루프 시작 |

콘텐츠 자체로도 질문에 답해야 하며, 가입을 해야만 답을 볼 수 있는 구조로 만들지 않는다. 대량 자동생성 티커·용어·이벤트 페이지나 얇은 키워드용 페이지는 금지한다.

## 6. 공유→플레이 루프

공유 카드는 비회원도 이해할 수 있어야 하고 안전한 공개 랜딩으로 이어져야 한다.

좋은 공유 대상:

- 수집 완성
- 시즌 기록
- 교육용 리플레이 결과
- 공개 범위의 클럽/도시 프로젝트 성과
- 비공개 보유량이 없는 가상시장 학습 기록
- 코스메틱 방/프로필 쇼케이스

공유 URL에는 세션토큰, 비공개 포트폴리오, 잔액, 이메일, 기기 식별자, 신고/제재 정보, 계정복구 정보, 숨겨진 추천인 식별값을 포함하지 않는다.

추천 보상은 원시 가입 건수가 아니라 검증된 활성화 마일스톤을 기준으로 하며 WLD 우위보다 외형·칭호·수집·편의 보상을 우선한다.

## 7. 활성화 정의

성장 분석에서 다음 단계를 분리한다.

- **방문:** 공개 랜딩 또는 콘텐츠 세션
- **참여 방문:** 의미 있는 공개 상호작용 또는 충분한 가이드/샘플 소비
- **가입 시작:** 인증/회원가입 흐름 진입
- **가입 완료:** 계정 생성/인증 성공
- **첫 가치:** 가입 후 첫 검증된 의미 있는 제품 행동
- **활성 사용자:** 첫 세션 핵심 마일스톤과 다음 목표를 모두 확보한 사용자

첫 가치는 가이드 작업 완료, 가상 관심종목 저장, 수집 시작, 안전한 학습 단계 완료 등을 사용한다. 대시보드 진입만으로 활성화로 간주하지 않는다.

## 8. 코호트 KPI 체인

모든 유입경로는 다음 체인으로 평가한다.

`노출/추천 → 공개 방문 → 참여 방문 → 가입 시작 → 가입 완료 → 첫 가치 → D1 → D3 → D7 → D14 → D30 → 수익/마진`

핵심 지표:

- 공개 방문→참여 방문
- 참여 방문→가입 시작
- 가입 시작→가입 완료
- 첫 가치까지 중앙시간
- 첫 세션 완료율
- 유입경로별 D1/D3/D7/D14/D30
- organic 가입 활성화율
- 공유링크 방문→활성화
- 추천→활성 사용자
- 재방문자 비중
- 광고 이탈률·구독 전환
- 리텐션과 연결된 CAC/LTV

노출수, 클릭수, 가입수, 세션수만으로 성공을 판정하지 않는다.

## 9. 실험 백로그

### 실험 A — 공개 샘플 vs 즉시 가입벽
- 가설: 인증 전 유용한 샘플을 보여주면 활성화된 가입자가 늘어난다.
- 대상: 첫 공개 방문자
- 대조군: 즉시 가입 중심
- 실험군: 관심경로 선택 + 샘플 1회 + 의도연결 가입 CTA
- 주요지표: 방문→활성 사용자 전환
- 가드레일: 가입 완료율, D1, 오류율, 개인정보 불만, 가짜가입률
- 최소관찰: 최소 1회 전체 주간 트래픽 주기

### 실험 B — 단일 약속 vs 기능 그리드
- 가설: 한 문장의 약속+증거가 첫 30초 혼란을 줄인다.
- 주요지표: 참여 방문율, 가입 시작률
- 가드레일: 이탈, 접근성, 페이지 성능, 금융 오인 신고

### 실험 C — 인증 후 의도 보존
- 가설: 인증 후 원래 보던 콘텐츠/샘플로 복귀시키면 첫 가치 도달이 빨라진다.
- 주요지표: 첫 가치까지 시간, 첫 세션 완료율
- 가드레일: 인증 오류, redirect 악용, 계정 보안 사고

### 실험 D — 교육 CTA vs 일반 가입 CTA
- 가설: 학습 검색 유입에서는 `이 개념 체험하기`가 `지금 가입하기`보다 활성화를 높인다.
- 주요지표: organic 방문→첫 가치
- 가드레일: 검색 랜딩 참여, D7, 오인 콘텐츠 신고

## 10. 첫 가치 이후 리텐션 연결

첫 가치 직후에는 다음 목표 하나만 보여준다.

- D1: 첫 행동 이후 무엇이 바뀌었는지 확인
- D3: 여러 세션에 걸친 작은 목표 완성
- D7: 주간 결산과 다음 성장 경로 선택
- D14: 정체성/수집/사업의 눈에 보이는 성장
- D30: 아카이브·수집·시즌·소셜 기록 유지

하루를 놓쳤다고 진행도가 사라지면 안 된다. 복귀 메시지는 손실 위협보다 변경 요약과 따라잡기 경로를 제공한다.

## 11. 수익화 배치

수익화는 사용자가 가치를 확인한 뒤에 최적화한다.

첫 가치 전:
- 핵심 설명·샘플을 paywall로 막지 않음
- 매수/매도/대출처럼 보이는 CTA 옆에 혼동되는 광고 배치 금지
- 첫 샘플을 끊는 강제 전면광고 지양

반복가치 이후:
- 광고제거 구독은 편의로 제공
- 코스메틱·프로필·공간·시즌 표현 상품은 경제우위 없이 판매 가능
- 스폰서 콘텐츠는 명확히 표시하고 가상시장 결과와 분리

평가는 광고 노출수보다 D1/D7/D30, 광고 후 이탈, 구독 전환, ARPU/ARPDAU, LTV/CAC, 마진을 함께 본다.

## 12. 보안·개인정보·악용 검토

### High — 공개/비공개 경계 노출
위험: SEO·공유·샘플 페이지에서 계정·포트폴리오 정보가 노출됨.
최소 조건: 명시적으로 공개된 데이터만 사용하고 계정/포트폴리오/보안/복구/신고 상태는 인증+검색 제외.
별도 QA: 신규 공개/공유 표면 출시 전 필수.

### High — open redirect / 인증 이어가기 악용
위험: 인증 후 원래 위치 복귀 기능이 피싱 redirect로 악용됨.
최소 조건: 허용된 내부 목적지만 사용하고 서버 검증된 continuation 상태를 사용.
별도 QA: 런타임 구현 시 필수.

### Medium — 추천/가짜가입 악용
위험: 봇 가입, 스팸 초대, 다계정 보상.
최소 조건: 단순 가입에는 보상하지 않고 활성화 마일스톤 검증, 악용 모니터링, 비경제 보상 우선.

### Medium — 공개 UGC 괴롭힘·사칭·악성링크
위험: 공유 가능한 소셜/클럽/시장 콘텐츠가 악용 채널이 됨.
최소 조건: 공개범위, 신고/차단, 안전한 링크 처리, 모더레이션, 비공개 회원정보 제외.

### Medium — 분석/개인정보 과수집
위험: 유입 attribution 때문에 과도한 추적이 발생.
최소 조건: 목적 제한 분석, 필요한 경우 동의/선택권, 토큰·비공개잔액·보안속성 수집 금지, 연령/지역 보호.

## 13. 법규·정책 주의점

- WLD/WDX는 계속 `virtual / simulated / game-only`이며 실제 투자수익·예금보호·현금환전·수익보장을 암시하지 않는다.
- 보상성 리뷰/추천은 긍정평가를 조건으로 하지 않으며 이해관계·인센티브는 필요한 경우 공개한다.
- 맞춤광고, 미성년자, 국외이전, 신규 추적 사업자 도입은 필요 시 개인정보/법률 검토 후 진행한다.
- 금융학습 콘텐츠는 신뢰성·출처를 강화하고 실제 금융자문으로 오인될 표현을 피한다.

## 14. 외부 근거 검토 — 2026-09-13

유형: 공식 검색 문서. 직접 채택.
핵심: 실제 방문자 문제를 해결하고 Moneyverse만의 원본 가치를 제공하며 검색엔진용 대량 콘텐츠를 만들지 않는다. 금융 안정성에 영향을 줄 수 있는 주제에서는 신뢰가 특히 중요하다.

유형: 공식 검색 업데이트. 참고.
핵심: 선정적 클릭베이트보다 독창적·깊이 있는·시의성 있는 콘텐츠와 주제별 전문성이 지속 가능한 유입 자산이다.

유형: 현행 제품 사례. 참고만.
핵심: 시뮬레이션 체험을 교육·커뮤니티·성장과 연결해 깊은 참여 전에 서비스 가치를 이해하게 할 수 있다. TradingView의 실제 현금상금 모델은 Moneyverse에 채택하지 않는다.

### 미국 FTC 리뷰/추천 가이드 및 2026 집행
유형: 정부 가이드/집행. 추천·리뷰 보호에 직접 채택.
핵심: 보상을 긍정적인 평가 조건으로 걸 수 없으며 중요한 이해관계·인센티브는 공개가 필요하다.
