# v2026.10.28.1405 — 2시간 국가·언어·경제/코딩/컴퓨터 AI 블로그 자동 발행 정책

**상태: 사용자 최신 정책 채택 / 2시간 슬롯 및 검증 순수 정책 코드 후보 구현 / 원어 AI 작성·DB 원자 발행·운영 적용 미완료.**

## 1. 사용자 승인 이력과 최종 변경

- 2026-10-22 **v1107**: 사용자는 각국 원어글 작성 직후 자동 공개, 나중에 본인이 삭제·수정하는 방식 승인. 개발 기획자가 GREEN 즉시발행, AMBER 사전 인간 승인, RED 차단과 24시간 사후검토를 추가했다. [v1107](AI_BLOG_COUNTRY_AUTO_PUBLISH_SPEC_v2026.10.22.1107.ko.md).
- 2026-10-22 **v1108**: 사용자는 24시간·48시간·30일 검토 지연으로 자동 비공개·검색제외·삭제를 **완전히 금지**했다. 관리자 직접 조치만 유효. [v1108](AI_BLOG_NO_AUTO_UNPUBLISH_ADDENDUM_v2026.10.22.1108.ko.md).
- 2026-10-27 **코드 v1102 (7827122c)**: 출처·승인영수증이 없는 구형 JSON 발행을 막기 위해 `/api/blog/generate`에서 503. 이것은 신규 자동발행 정책 취소가 아니라 안전한 발행기 미구현에 대한 구형 API 차단이다.
- 2026-10-28 **v1405 최신 사용자 지시**: 사람의 사전 승인도 사후 필수 검토도 제거. **독립 자동 품질 검사를 통과한 글은 바로 공개**, 이미 공개된 글은 무기한 유지. 관리자 본인이 필요할 때만 수동 수정·비공개·삭제. 2시간마다 4개국·4개 언어와 경제·코딩·컴퓨터 소재 순환. 광고 수익도 운영 목표.

**우선순위:** 최신 v1405 지시는 v975·v1107의 필수 사람 사전승인 및 v1108의 24시간 필수 사후검토 부분을 대체한다. 대신 무검증 금융·법률·투자 정보나 복제 콘텐츠는 공개하지 않고 해당 슬롯을 실패로 기록한다. 사용자에게 검토를 강요하지 않으며, 차단된 글은 자동으로 사람이 심사할 대기열로 보내지도 않는다. 공식 출처/수치/언어/독창성/코드 재현·권리·중복 자동검증과 DB/금융/보안 릴리스 게이트는 유지한다.

## 2. 정확한 2시간 국가·주제 순환

- 한국시간 04:00를 편집일 시작으로, `04,06,08,10,12,14,16,18,20,22,00,02`시 총 12회 **작성 시도**. 실제 게시수는 품질·출처 검사 성공건수만 계산한다.
- 국가/원어: 한국 `KR/ko-KR`, 미국 `US/en-US`, 일본 `JP/ja-JP`, 중국 `CN/zh-CN`. 일자별 시작 오프셋을 바꿔 특정 국가는 항상 같은 시각에만 글이 올라가지 않게 한다.
- 주제: `ECONOMY` = 보편 경제·화폐·물가 원리(근거 없는 최신 금리·예측 제외), `CODING` = 실행 가능한 프로그래밍 예제, `COMPUTER` = OS·네트워크·DB·서버/하드웨어·컴퓨터 구조.
- 4국가×3주제 = **하루 12개 고유 조합**. 슬롯은 시간·편집일에서 결정론적으로 생성. 실패·재기동·두 워커 충돌 때 같은 언어·주제·본문이 중복 공개되지 않도록 DB 멱등 영수증·단일리더·Outbox를 추가해야 함.
- 순수 슬롯 구현 `backend/src/blog-editorial/blog-two-hour-rotation.ts` / `selectTwoHourBlogSlot`. 백엔드 `blog.rotation_2h`는 매시간 선점하되 짝수시간에만 슬롯을 배정하고 홀수시간 건너뜀. 구형 `blog.daily_publish` 호출 제거는 **새 브랜치 코드 후보에만** 적용. 별도 운영 Cron 04:00는 정식 승격 때 비밀키 회수 및 중복 작업 해제.

## 3. 발행/관리자 권한 계약

`주제선정 → 현지 공식원문 수집 → 독립 원어 AI 작성 → 출처·숫자·권리·중복·기술예제 자동검증 → 적합 시 DB 원자 공개/영수증 → 이후 선택적인 관리자 수동 정정/비공개/삭제`.

- 사람의 사전·사후 승인 모두 **필수 아님**. 24시간 편집 검토 큐/리뷰 마감으로 공개상태 변경 불가; 자동 비공개·검색 제외·자동 삭제·제한시간 만료에 의한 공개 철회는 **절대 금지**.
- 오류·출처 부족·불확실한 현행법/세금/개인화 투자 조언·유사도 높은 복붙·미검증 컴퓨터 성능 수치는 출판 불허 및 사유 기록. 좋은 후보를 재작성할 수 있지만 품질 미달인데도 12개를 채우기 위해 강제로 공개하지 않는다.
- 관리자만 유효 세션, CSRF/권한, 정정/철회 사유, 원본·리비전·감사 영수증으로 명시적 상태 변경. 스케줄러·AI·자동 모니터는 게시된 콘텐츠 비공개 권한 없음. 킬스위치는 **미래 글 작성만 중지**.
- 한국어 원고를 영어/일본어/중국어로 단순 번역해서 4개 국가별 독립 기사로 가장하면 안 된다. 기술 주제는 주제 관련 1차 기술 출처, 경제 주제는 해당 국가 적용 범위·기간이 검증된 공식 원문.
- 코딩·컴퓨터 글에는 금융 계산기·무관한 금융 연구소·수익 보장·허위 실측이 표시되지 않아야 한다(v1380/v1403).

## 4. 광고 수익 정책 충돌에 대한 명확한 처리

Google [게시자 정책](https://support.google.com/publisherpolicies/answer/11112688?hl=en)은 **사람 검토·큐레이션 없이 자동 생성된 글에 Google 광고를 붙이는 것을 금지**한다. 사용자의 사람 검토 없는 자동 **공개** 요구는 유지하되 Google 광고 자격은 별도로 다룬다. 새 AI 글은 기본적으로 Google 광고 제외이며, 나중에 진짜 수동 큐레이션 및 콘텐츠 품질·광고 정책 확인이 있는 글만 광고를 허용한다. 사람 검토를 광고 목적으로 강제하여 글 공개를 지연시키지 않는다.

Google [검색 스팸 정책](https://developers.google.com/search/docs/essentials/spam-policies)은 순위 조작을 목적으로 독창성이 없는 AI 글을 대량 게시하는 행위를 scaled-content-abuse로 분류한다. [도움되는 콘텐츠 정책](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)에 따라 실제 근거·독창성·언어 적합성·AI 작성 공개를 갖춘 글만 게시. 수익 예상은 실제 GSC 유입·승인 광고 인벤토리·RPM 기반이며 검증되지 않은 예상 수익 숫자는 제공하지 않는다.
