# 국가별 독립 AI 글 작성·즉시 발행·사후 검토·삭제 시스템 — v2026.10.22.1107

**한국어 상세판** | [영문 정본](AI_BLOG_COUNTRY_AUTO_PUBLISH_SPEC_v2026.10.22.1107.md)
**상태:** `PLANNING` — 통합기획서가 채택하는 신규 제품 요구사항이며 **기능 개발·Test·운영 발행은 아직 미실시**. 기존 [v975 출처 검증 편집 설계](AI_BLOG_EDITORIAL_PUBLICATION_ENGINE_SPEC_v2026.10.20.975.ko.md)의 일부 사전 인간승인 조건만 아래 GREEN에 한해 최신 지시로 변경한다. 출처검증·원자 발행·감사·권한·스케줄러 및 금융 안전 조건은 계속 적용한다. 구형 `/api/blog/generate` 403/503은 해제하지 않는다.

## 1. 사용자 결정: 국가마다 따로 글 작성하고, 작성 뒤 가능한 즉시 발행해 나중에 삭제

1. **독립 원어 기사:** 한국 `ko-KR`, 미국 `en-US`, 일본 `ja-JP`, 중국 본토 `zh-CN` 각각의 독자·현지 검색의도·고유 제목·정부 제도·통화·예시·원문 출처로 별도 작성. 한국 기사를 일괄 번역하거나 키워드만 바꿔 4페이지를 양산하지 않는다. 국가와 언어, 세법상 거주지는 구분하고 방문자 IP로 국가를 강제하지 않는다.
2. **GREEN 즉시 자동발행:** 내부 AI가 초안을 만들면 안전성·공식출처·내용 독창성·계산식·본문/SEO 자동 검사를 먼저 수행한다. 안전한 상식·기초 금융교육 GREEN은 **사람의 사전 발행 승인을 기다리지 않고** 새로운 원자적 DB 발행기로 바로 공개한다. 글 생성 즉시 무검증 공개가 아닌, **필수 자동검사 직후 지체 없는 공개**다.
3. **사후 검토:** 자동 공개 글은 전부 `PUBLISHED_UNREVIEWED` 대기열에 들어간다. 편집자는 **24시간 이내** 유지·수정·철회 판단한다. 24시간 내 검수가 끝나지 않으면 **자동으로 공개에서 내리고 검색 제외**하며 검토 후 재공개한다. 24시간은 초기 설계 SLA로, 테스트/운영능력 점검 후 변경 가능하다.
4. **나중에 삭제:** 관리자 화면에서 즉시 단건 철회·수정·검토 보류 및 증빙 있는 일괄 철회가 가능하다. 홈페이지·관련글·RSS·사이트맵·검색구조화데이터에서 제거하고 캐시를 무효화한다. 삭제는 원본 증거를 몰래 지우는 것이 아니라 공개 중단과 `410 Gone` 또는 정정 안내 `noindex`의 상태 변경으로 처리하고, 게시/철회 시각·사유·관리자를 불변 감사기록으로 보존한다. 검색엔진에서 사라지는 데는 시간이 걸릴 수 있다.
5. **위험한 금융 글은 예외:** 국가별 세금·연금 혜택·시행연도·투자상품 조건·시장 금리 등 틀리면 독자에게 피해가 되는 내용은 ‘일단 내고 나중에 삭제’하지 않고 사전 승인 필요. 근거 없는 수익률·실시간 수치·허위 법규는 항상 차단한다.

## 3. 공개 전 자동 안전등급

| 등급 | 발행 조건 | 시스템 행동 |
|---|---|---|
| **GREEN — 즉시 발행** | 수학적 복리 원리·기초 금융상식·비개인화 교육 등 검증 가능한 저위험 원문. 핵심 주장에 공인 출처, 만료되지 않은 증빙, 일관된 계산식, 국가별 원어 글·차별화된 사례, 이미지 권리·SEO·중복 검사를 모두 통과 | **자동 발행 → 사후 검수 대기 → 24시간 내 미검토 시 자동 비공개** |
| **AMBER — 사전 승인** | 해당 국가의 세법·연금/상품 자격·제도 개정, 현행 시장 지표·금리, 채무·투자 판단에 영향을 주는 권고, 상충하는 출처 | 출처와 법령에 정통한 사람의 **정확한 원고 리비전 사전 승인** 후 발행 가능 |
| **RED — 발행 금지** | 출처 없는 최신 수치, 투자수익 보장, 허위 통계·법규, 개인정보, 무단 이미지·링크, 악성 명령 삽입, 유사 글 복제/대량 SEO 도배 | 격리/폐기·관리자 경고. 공개 금지 |

AI가 직접 자기 글의 안전등급을 승인할 수 없으며 서버의 독립 규칙·저장된 출처 증거·DB 권한으로 강제한다. 분류가 불확실하면 AMBER 이상으로 보류한다. 전체 또는 국가별 자동발행 중지 스위치를 제공한다.

## 4. 실제 발행·삭제 처리 과정

`국가별 주제 발굴 → 현지 공인 원문 수집(시각·기관·원본해시 보관) → 해당 국가 언어로 AI 초안 → 수치·법규·중복·국가별 계산기 검증 → GREEN 즉시발행 / AMBER 검토대기 / RED 차단 → 출판영수증 → 사후 검토·24시간 제한 → 유지/새 리비전 정정/즉시 철회 → SEO 반영 및 성과 확인`.

- **기록:** `country`, `locale`, `intent_cluster`, `native_title`, `currency`, `policy_year`, `claim_source_ids`, `retrieved_at`, `effective_at`, `risk_tier`, `gate_policy_version`, `evidence_hash`, `draft_revision_hash`, `publication_receipt`, `published_at`, `review_due_at`, `review_actor`, `withdrawn_at`, `withdraw_reason`, `seo_visibility`, `calculator_contract`를 저장한다.
- **중복 방지:** 기존 181개 구형 기록 및 4개 국가 글 전체를 제목·문단·의미유사도로 검사한다. 검증된 국가별 실질 차이만 예외 허용. 새 글은 `(국가, 언어, slug, 리비전)` 멱등성으로 단 한 번만 발행한다. 워커 재시작/중복 POST/철회와 발행 경합 때 유령글을 재공개하지 않는다.
- **권한:** 별도 검증된 GREEN 발행 DB 함수와 수정·철회 관리자 함수. `SECURITY DEFINER`, PUBLIC 권한 회수, 사람·AI·스케줄러 권한 분리. 블로그 때문에 금융 원장 직접 쓰기 권한을 열지 않는다. 기존 JSON에 `chmod 644` 후 재발행하는 방식 금지.
- **관리자 UI:** 한국/미국/일본/중국 탭, 초안·자동검사·공개 후 미검토·24시간 임박/초과·차단·철회 이유, 작성·검토·출처·적용연도·검색수집/색인 상태, '즉시 철회'·'정정'·'전체 자동발행 중지' 버튼. 모바일 320/375/768/1024 이상에서도 작동.
- **SEO:** 기존 국가별 URL을 활용하고 독립적인 현지 제목/H1/메타·자기 자신을 canonical로 지정. 실제 문맥·내용이 편집상 동등한 게시판끼리만 `hreflang` 상호 연결. 미국 IRA 글과 일본 NISA 글처럼 다른 의도의 콘텐츠는 억지로 hreflang 연결하지 않는다. 공개글만 사이트맵·BlogPosting에 반영; 철회 시 `410` 또는 정정 `noindex` 및 내부링크 정리. Google/Naver 제출과 검색색인은 구분한다.

## 5. 발행 속도, 분석 및 개발 승인 기준

**초기 운영 목표는 전체 국가 합산 주 2편의 검증된 독립 원고**다. GREEN은 그 주간 일정까지 인위적으로 대기하지 않고 검증 완료되면 **바로 자동 발행**한다. 주 2편은 초기 편집역량 계획치이지 하루 2편 자동발행 강제가 아니다. 4개 국가 각각의 주제 후보·완료/지연 사유를 관리하고, 출처와 담당자 여건이 허락하면 4주 내 국가마다 고유 글이 나오는 흐름을 목표로 한다. 가짜 포스트로 채우지 않는다.

**수용 테스트 필수:** 4개 언어의 본문·국가·출처가 실제로 다름; GREEN 사전 사람 승인 없이 자동 공개; AMBER/RED 공개 차단; 미검토 24시간 초과 자동 철회; 관리자 1회 즉시 삭제와 사이트맵/캐시/검색상태 정합; 배포 실패·중복 스케줄러·재시도에도 출판영수증 1개; 철회 후 재출현 없음; 현지 통화·세금·공식 자료·계산식 검증; canonical/hreflang/안전한 `noindex`; 관리자·회원 구분·모바일/전체 앱 QA; 금융·로그인·Test SHA·백업·무중단 운영 검증. 이 조건의 실행은 **아직 미검증**이다.

**성공 지표:** 국가별 검증된 신규 글수, 실제 검색노출/CTR/유입, 계산기 이용, 중복 차단, 게시 후 24시간 검토 준수, 철회 건수/위험도, 품질 개선. Search Console·네이버 실측 전 숫자 추측 금지. 광고 수익이나 페이지 수를 위해 저품질 자동 문서를 찍어내지 않는다.

**버전별 작업 순서:** v1107.1 구형 작성자·데이터 조사 및 4국가 자료형, v1107.2 독립 국가 원어 AI 초안·근거·안전등급 검사, v1107.3 GREEN 즉시 발행·AMBER 보류·멱등 DB 영수증, v1107.4 24시간 사후심사·삭제/정정/긴급중지, v1107.5 국가별 SEO·계산기·관리자 UI, v1107.6 CI·정식 Test·전수 모바일·금융 검증, v1107.7 승인·백업 후 무중단 운영 승격. 각 단계 별도 브랜치/중간 main 재확인/영문 정본·한국어 문서·변경이력 필수.
