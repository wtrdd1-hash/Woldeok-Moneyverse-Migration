## 1. 원인 구분과 확인된 코드 문제

사용자는 'SEO 2주 이상 고객 0명'이라고 보고했지만 공식 Google/네이버 확정 노출수·클릭수·실제 가입 성공수·실제 원장 기록 수는 이번 세션 직접 조회하지 못했다. SEO 제출 성공, 검색봇 방문, 실제 색인, 검색 노출, 클릭, 홈페이지 이용, 서버 계정 생성, 원장 확인 첫 행동은 단계가 다르다. Google 검색 수집은 며칠~몇 주가 걸릴 수 있으며 색인 보장이 없다. 네이버 노출/클릭 리포트는 지연과 90일 범위가 있어 '2주 동안 관측값 없음'과 실제 0을 구분한다.

GitHub 소스 재검사 결과 첫 화면이 P2P 송금·은행·주식 메뉴와 금융 계기판 중심으로 구성되어 외부 검색 방문자에게 로그인 없이 얻는 가치가 약했다. `+4.8% 24h`, `179,460,000원 실시간 환산`, 정적 자산비중 62/28/10, '100% 무손실 원장' 등은 실측 계정 근거 없이 보여지는 시연 문구이며 금융 정합성이 아직 검증되지 않은 상황에서 실제 보장으로 오해될 수 있다. 계산기 하단 고정 배너는 10,000 WLD 무료 지급과 영구 저장을 증빙 없이 안내한다. 이 문제를 고객 신뢰·가입 전환·브랜드 검색 평판 P0로 분류한다.

## 2. S0 — 이번 버전 실제 구현

1. 홈 최상단에 '가입 없이 하나를 직접 체험해 보세요' 네 언어 문구와 **3개의 공개 링크**를 제공. 한국어 복리 계산기는 `/tools/compound-calculator`, EN/JA/ZH는 각 언어의 실제 `/{언어}/tools/compound-interest-calculator`를 사용. 경제 용어사전도 실제 물리적 언어 페이지로 연결. 세 번째는 서비스 공개 기능 설명 `/features`. 어떤 단계에서도 WLD·회원가입 성공·예금 가입 성공으로 가장하지 않는다.
2. 사용자가 클릭하기 전에 **WLD는 실제 현금 또는 금융상품이 아닌 게임 재화**임을 공개. 키보드 포커스·적절한 터치 영역·모바일 320px 및 스크린리더 라벨 보장. CTA 이동을 가입 완료로 계상하지 않는다.
3. 홈에서 고정된 투자 성과/자산비중을 실제 라이브 회원 수치라고 주장하지 않고 시연 예시로 표시, 확증 없는 '100% 무손실' 약속 및 고정 현금 환산 문구 정정. 서버 기반 실제 지갑 표시 자체는 분리 유지.
4. 도구 하단 배너의 '신규 10,000 WLD 무료'와 '영구 저장' 보장은 삭제하고 로그인 후 **실제 계정 저장 가능 여부 확인**만 안내. 저장의 실제 성공은 서버 영수증 없이는 주장하지 않는다.
5. 라우트 헬퍼·게스트 진입·오표기 재발 방지 테스트 작성. 구현 후보는 금융 DB, 로그인, 지급, IndexNow, GSC 제출, 실제 분석 이벤트 수집을 바꾸지 않는다.

## 3. S1 — 계측 및 진짜 유입 퍼널 설계 (다음 독립 브랜치)

`landing_view → guest_entry_selected → calculator_result_rendered 또는 glossary_topic_read → signup_start → sign_up(서버 성공) → first_economy_action_verified(원장 기장) → D1/D7`. 단계별로 `NOT_CONFIGURED / NO_ROWS / OBSERVED_ZERO / OBSERVED_NONZERO / STALE / AUTH_ERROR / PARTIAL`을 저장하여 미설정·오류·자료 없음과 실측 0을 구분한다. 수집자, 기준일, 조회 범위, 국가, 언어, 기기, 배포 SHA 및 동의 여부를 표시한다. 개인정보·이메일·잔액·원문 IP를 광고 분석 도구로 보내지 않는다. GA4 `sign_up`, `tutorial_begin/complete` 등은 공식 추천 이벤트와 서버 영수증을 구분해서 사용하고, 봇·직원·중복 이벤트는 분리한다.

관리자 SEO는 GSC API의 색인 페이지 버전, 노출·클릭, 네이버 수집/색인/검색 클릭, IndexNow 접수와 실제 사이트 URL의 200/canonical/robots 상태를 각각 분리. 401/403/429/비밀키 누락·부분 통계·태평양 시간 보고·크롤러 방문과 색인 지표 혼동을 테스트한다. 수집권한 없으면 '증거 미확인' 표기.
