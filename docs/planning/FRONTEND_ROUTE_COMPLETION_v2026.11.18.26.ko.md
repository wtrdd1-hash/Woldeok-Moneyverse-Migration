## 구현·QA 필수 순서
1. **전체 경로 목록**: 180개 Next 페이지 소스를 URL/다국어 경로로 매핑, 공개·로그인 회원·관리자/MFA 권한, Spring MVC 핸들러, 실제 API/DB 소유자 함수, UI 위치·디자인, SEO/캐시/오류 코드를 문서화. 기본 언어 영어(EN), 두 번째 언어 한국어(KO), 다른 언어는 계약 순서로. 단순 파일 개수는 실제 URL 개수 아님.
2. **페이지 누락/잘못된 200 차단**: 메뉴에 노출된 회원/관리자 전 경로가 전용 Spring SSR/템플릿 또는 진실한 401·403·404·503을 반환. SPA 기본 홈페이지를 누락 화면으로 표시 금지. 인증은 DB 실세션/동의/권한, 변경은 CSRF·멱등키·실제 영수증 필수. 로그인·회원가입·로그아웃 및 Android 연동 정합성 확인.
3. **동적 공개 페이지**: `/blog`, `/gallery`, `/announcements`, `/newspaper`, `/search`를 실제 자료·검색어·페이지네이션 기반 Spring 렌더링으로 전환. 시점 캡처 정적 HTML로 가짜 최신성·다른 계정의 검색 결과를 만들지 않기. 이미 정상 제공되는 13개 공개 스냅샷 유지.
4. **관리자 새 디자인**: v17 새 네이비/보라 UI·하위메뉴·사용자/주식/경제/SEO/로그 등 모두 실제 인증 Spring 템플릿으로 연결. 비로그인302만으로 새 UI 완료 주장 금지, 관리자 정상 세션 양성 및 MFA·CSRF·역할 음성 QA 필수.
5. **모든 페이지 문의/채팅**: 관리자 문의 도크 vs 일반 회원 떠 있는 문의 동글을 중복 없이 표시. 모바일320/390, 키보드/스크린리더, 44px 터치, 진짜 회원 세션/채팅 작성 영수증·실패 상태 검증. 현재 운영 지원·채팅은 GET 조회만 검증된 상태이므로 메시지 전송을 성공처럼 표시 금지.
6. **화면 전환/버전**: Next RSC/Flight 정상 구현 또는 Spring 문서 전체 이동으로 검증된 경로. 200 HTML을 RSC 데이터처럼 전달하면 안 됨. 실제 페이지별 빌드 ID 정합성, 이전 탭·캐시·계정 전환 테스트. v26의 Referer 분기 버전 JSON은 과도기 대응.
7. **승격 게이트**: Gemini 공동 작업 충돌 방지 작업트리/소유권, 시작/중간/종료 EN/KO 로그, 불변 Test SHA·운영 동등 API/DB, 모든 CSS/JS, 1440/390/320 그래픽·200% 확대·접근성·반응형/스크롤/입력 검증, 실제 로그인 회원·관리자·금융 원장/정산 양성, 공식 외부 Test, nginx 문법·무중단 승격·독립 복원. 아직 남은 API 503 28건 해결 전 전체 정상 판정 금지.
