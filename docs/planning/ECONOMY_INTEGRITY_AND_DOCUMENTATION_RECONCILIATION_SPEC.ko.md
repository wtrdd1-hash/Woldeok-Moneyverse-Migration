## 3. 통합 경제 수학·회계 기준

1. **통화량:** `M_total 변화 = 인증 발행 - 인증 영구폐기`. 국고 금고 이동·세금·지급은 총량 0 변화다. `VAULT_MAIN` 입금이나 소각 풀 적립만으로 영구폐기가 아니다.
2. **국고 가용액:** `가용 현금 = 유동현금 - 보호준비 - 확정 의무`(0 이상). 25M은 증거를 요구하는 목표이며, 30%는 정의된 기준액의 재정 유동성 규칙이다. 채권 원금, 쿠폰, 장애 환급, 복지 우선순위를 함께 정의해야 한다.
3. **예산:** 동일한 확정 잉여금 기준 `복지40 + 인프라30 + 비상20 + 소각10 = 100%`. 시민배당·복지는 복지 재원에서, 사업비는 인프라 재원에서 집행. 소각은 실제 폐기증서와 분개가 있어야 한다.
4. **금리:** `단리 쿠폰 = 원금 × 연이율 × 경과 현실초 / 게임연도 대응 현실초`. 게임 시간 가정·복리 여부·정산 반올림·이벤트 스냅샷이 승인되기 전 이자율 확정·원리금 보장 금지.
5. **테일러 준칙:** 현재 화면은 고정된 예시 인플레이션·산출갭으로 클라이언트 계산만 수행. 실제 저장에는 재인증/권한·승인·정책 버전·최댓값·영향 분석·감사·롤백이 필수다.
