## 새 필수 편집·화면 불변 조건

1. `articleType: TECH|FINANCE|PRODUCT_GUIDE` 및 독자 목표·관할 국가·언어·검색의도·최신성 상태를 본문/SEO/도구 배치의 원천으로 사용한다. 템플릿의 공통 금융/거시경제 서론을 TECH에 섞지 않는다.
2. TECH: 해결하려는 시스템 문제 → 설계/자료구조 → 재현 가능한 최소 코드/SQL/명령 → 벤치마크의 하드웨어·런타임·데이터셋·실행횟수·원본 출력 → 정확한 제한조건·트레이드오프 → 관련 내부 구현/실습/일차 문헌. 숫자 영수증 없는 TPS/오차/성능 비교는 게시 금지. 고품질은 글자 수가 아니라 문제 해결·검증 가능성으로 판단한다.
3. FINANCE: 현지 관할·제도 시행일, 실제 원문 링크와 문장별 주장/수치 연결, 계산식 버전·단위·반올림, 적용 대상/예외, 고위험 AMBER 사전승인을 요구한다. 현행 시장 수치를 '실시간 실측'이라 부르려면 출처·관측시각·신선도 검증 영수증이 필수다.
4. 각 콘텐츠의 관련글·계산기·CTA는 `content_id → context-approved relation → enabled target`으로 명시적으로 매핑한다. TECH에 복리·세금·가상주식 CTA 기본 삽입 금지; 일치하는 도구가 없으면 **도구 블록 자체를 생략**한다. 세제·상품 정확성 100%, 지급보장, '300+ 도구'와 같은 근거 없는 홍보문구는 숨기거나 검증한다.
5. 모든 공개글은 정확한 작성/갱신/검토 일시·AI 도움 여부, 근거·정정 이력·정확한 게시 상태를 표시한다. 가짜 조회수/읽기시간 고정/조작된 실험치 금지. 조회 실측이 없으면 숫자를 표시하지 않는다.
6. 국가별 원고는 같은 주제라도 실질적 독자 문제와 근거를 각각 수집한다. `hreflang`은 동일 검색의도의 검증된 언어 대응 글만 연결하며 독립 문서는 별도 canonical 사용. 자동 IP 국가 강제 금지. 기본 콘텐츠 언어 영어, 한국어 두 번째 지원 언어라는 제품 지침을 지키되 국가별 글의 실제 원어는 별도 보존한다.

- 신규 기능 테스트는 카테고리 부적합 위젯/근거 허위/국가 불일치/중복·재시작·시각오류/48h 경과/자동철회 금지/수동 정정/SEO/320–1024px/자연 번역/웹·앱 관리자·DB ACL을 포함한다. 독립 Test 백엔드 및 정확 SHA E2E/CI, 백업, 롤백 검증까지 완료 후 운영 무중단 승격한다.
