2026-11-21 제공된 /wallet 스크린샷에는 총자산 394,728 WLD, 현금 394,728 WLD, 은행 0 WLD, 최근 거래 내역, 송금 입력란이 보인다. 해당 숫자는 **화면 관찰값일 뿐 실제 원장 검증 결과나 기본값이 아니다**. 두 번째 화면의 청록색 사이드바·배경은 승인된 11월 18일 네이비·보라색 통합 디자인과 다르다. “2838 x 1321” 오버레이와 확대 아이콘은 출처 확인이 필요하다. 기존 API 문서에는 송금, 예금/출금, 이자, 저축 포켓, 대출, 채권이 이미 기재돼 있다. **API 문서가 존재한다는 사실만으로 현재 Spring 운영 작동이 검증된 것은 아니다.** 카드 발급 API는 검토한 은행 API 목록에서 확인되지 않아 신규 설계 대상으로 구분한다.

## 화면 구성 — Spring Boot MVC + Thymeleaf 반응형 웹
- 공통 탐색: 홈 / 지갑 / **은행** / 송금 / 카드 / 투자 / 퀘스트 / 상점 / 커뮤니티 / 고객센터 / 내 계정. 신규 경로는 기존 라우트 충돌을 먼저 확인한다.
- **지갑 /wallet**: 실제 서버 자산·현금·예금 잔액, 원장 기준 최근 내역과 갱신 시각, 빠른 실행 'WLD 송금 / 예금 / 출금 / 내 카드'. 인증 실패 시 타인 내역을 노출하지 않는다.
- **은행 /banking (제안 경로)**: 은행 자산 요약, 예금 상품·이자·만기·해지조건, 목표 저축 포켓, 대출 및 채권, 거래 명세·필터·영수증. 서버 미지원 항목은 숨기거나 '준비 중'으로 명확히 표시한다.
- **송금 /banking/transfers (제안)**: 수취인 ID 검색 → 수취인 확인 → WLD 금액/수수료/한도 → 최종 확인 → CSRF 및 필요 시 재인증 → 멱등 전송 → 실제 원장 거래 ID가 있는 영수증. 잔액 부족, 잘못된 상대방, 중복 요청, 네트워크 시간초과 등에서 가짜 성공 금지.
- **예금 /banking/deposits (제안)**: 현금↔은행 이동, 예금 상품 상세, 이율 계산 기준 및 만기·중도해지, 이자 지급·수령, 목표 포켓 생성·설정·입금·출금·보관 종료. 금리·수익률은 실제 상품 계약에서만 표시.
- **카드 /banking/cards (제안)**: **머니버스 내부 WLD 가상 결제카드**의 발급 자격, 카드 디자인, 발급 신청, 승인 대기/활성/일시정지/만료/폐기, 결제 한도, 내부 결제 내역. 카드번호·CVV·실제 금융기관 제휴·실물 배송·현실 카드망 결제는 별도 검증/승인 전 구현·약속 금지. 카드 상태 전환은 서버 권한·감사 기록 기반이어야 한다.
- **모든 화면**: 금융 문의/관리자 문의/회원 DM을 구분하는 전역 단일 56px 도움 버튼과 다국어 선택. 입력 중 송금·문의 내용은 언어 전환으로 손실되지 않도록 한다.

## 보안·원장·API 검증
기존 문서 확인 API: `GET /api/v1/wallet`, `POST /api/v1/wallet/transfers`, `POST /api/v1/bank/movements`, `GET /api/v1/banking/standing`, `POST /api/v1/banking/deposit`, `POST /api/v1/banking/withdraw`, `POST /api/v1/banking/claim-interest`, `/api/v1/banking/pockets`, 기존 대출·채권. Spring 실제 매핑과 운영·Test 기능은 별도로 확인해야 한다. 옛 문서에서 게스트 허용으로 표기된 금융 쓰기 경로를 그대로 수용하지 말고 **인증 세션·사용자 소유권·CSRF·멱등성·이중 원장·DB SECURITY DEFINER 및 실제 영수증**을 검증한다. 가상카드의 신규 발급/결제 API 및 DB 스키마는 별도 명세·보안 검토 전 확정하지 않는다.
