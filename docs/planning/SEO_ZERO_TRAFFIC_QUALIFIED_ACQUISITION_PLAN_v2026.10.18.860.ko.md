## 1. 판단 요약과 증거 구분

사용자는 SEO 시행 2주가 넘었으나 실제 고객이 없다고 보고했다. 다만 **검색 노출수, 클릭수, 실제 방문자, 회원가입 성공, 검증된 첫 경제 활동의 수치는 아직 확인되지 않았다.** 운영자 진술의 '고객 0명'을 모든 분석 단계의 '실측 0'과 동일하게 취급하지 않는다. Google 공식 문서에 따르면 URL 크롤링에 수일~수주가 걸릴 수 있고 색인은 보장되지 않는다 [R01]. 따라서 'SEO 2주 = 알고리즘 실패'라고 단정하지 않는다.

**현재 우선순위:** ① 실제 운영 배포본과 GitHub 소스 일치 여부 확인 ② 검색엔진 페이지 노출·다국어·색인 증거 분리 ③ 검색 유입 사용자가 회원가입 전에 가치를 경험하도록 개선 ④ 가입 후 첫 금융/게임 행동의 서버 증빙 ⑤ 소규모 외부 유입 실험을 통해 구체적 이탈 원인 발견.

**문서 권한:** `docs/DOCUMENTATION_POLICY.md` → `docs/planning/PROJECT_PLAN.md` → `docs/planning/INTEGRATED_PLANNING_MASTER.md` → 명시적으로 채택된 v527 검색 수요, v507 검색 운영, v675 제품 검토, v688 GSC 증거, v681 계산기→학습, v686 첫 세션 설계. 본 문서는 **추가 제안**이며 기존 v530 전체 로그인 UI 다섯 차례 검증, v523/542/543 금융·복식부기, v487 광고 전용 현금 수익, 법률·동의·무중단 운영 승격 규칙을 변경하지 않는다.

## 2. 검색에서 실제 고객까지: 원인 진단 체계

기존 **`/admin/seo` 화면(v688)**을 하나의 소유권 있는 검색 진실 대시보드로 유지하고, 개인정보를 최소화한 전환 지표를 연결한다.

| 단계 | 확인해야 할 실제 데이터 | 원인별 조치 |
| --- | --- | --- |
| 검색 발견 | 사이트맵, 정상 HTML, 내부 링크, robots/noindex, 정규 URL, 언어별 실제 본문 | 잘못된 URL·메타 정보·미번역 중복을 정리 |
| 수집과 색인 | Google Search Console 페이지 색인 및 URL 검사; 네이버 수집·색인 보고서 | 제출/수집/색인/클릭은 전부 별도 상태로 표시 |
| 검색 노출 | 기간·검색어·페이지·국가·기기별 GSC 확정 노출수 | 0건인지 자료 미연결·미보고인지 분리하고 검색 의도 재검토 |
| 검색 클릭 | 실측 클릭수, CTR, 평균 게재순위와 집계 범위 | 노출은 있으나 클릭이 없으면 유용한 제목·설명·도구 적합성 개선 |
| 방문자 효용 | 도구 실행과 결과 확인, 실제 모의 시나리오 완료 | 방문 후 무반응이면 가입 강제·UI 오류·신뢰 부족 진단 |
| 회원가입 | 가입 시작, 오류 유형, **서버에서 확인된 가입 완료** | 결과 저장 등 가치가 생긴 뒤 가입 유도, 원래 작업으로 복귀 |
| 최초 활성화 | 실제 서버/원장 영수증을 갖춘 작업·은행·가상 주식 행동 | 모의 결과·로컬 상태·보상 표시를 거래 성공과 구별 |
| 재방문 | D1/D7/D30의 유의미한 활동, 유입 채널 및 언어별 집단 | 선택형 다음 목표, 주간 뉴스, 자발적 알림 제공 |

상태 표시는 `ZERO_OBSERVED / NO_ROWS / NOT_CONFIGURED / STALE / ERROR / INCOMPLETE`를 분리한다. Search Console 날짜 기준(Pacific Time), 구간 확정 여부, 익명화된 검색어와 표본 제한, 클릭·노출 집계 차이를 표시한다. 로그의 봇 방문을 색인 완료로 처리하지 않는다. 관리자는 **출처·사이트 속성·기간·마지막 수집 시각·배포 SHA**를 확인할 수 있어야 한다.

## 4. SEO 외 신규 고객 확보 전략

목표 고객군은 **가설**이다. 실제 타깃 수요가 확인됐다고 표현하지 않는다.

- **A 한국의 금융 계산 도구 사용자:** 연봉 실수령액, 저축·복리·예산 도구 결과를 바로 제공하고 원하는 경우 가상경제 학습으로 연결.
- **B 경제 시뮬레이션·게임 이용자:** 3분 동안 회사/주식/직업의 실험 결과를 보고 친구와 가상 선택지를 비교.
- **C 소규모 커뮤니티·교육 그룹:** 공개 가능한 가상 시뮬레이션과 모임 단위 체험. 가상 WLD를 실제 경제적 이익으로 광고하지 않음.

**1~7일:** 관련 커뮤니티 운영 규정을 지키고 소수의 자발적 체험 참가자를 모집. 10~20명 인터뷰/테스트 및 핵심 고객군별 5개 실제 사용자 과업 관찰을 *연구 목표*로 제시한다. 구매 트래픽·검색 클릭 조작·스팸 메시지·가짜 후기 금지.

**8~21일:** 측정한 검색 수요에 대응하는 3개의 실제 유용한 도구/자료를 엄선해 출시 후보로 검증. 설명 영상·짧은 실습 사례·질의응답을 허용된 채널에 게시하고 올바른 UTM 출처를 기록. 교육·모임 운영자에게 **회원 정보가 없는 데모**를 제안.

**22~30일:** 실제 첫 가치 완료·가입 완료 데이터가 있는 경우에 한하여 소개 카드와 7일 학습 챌린지 실험. 무분별한 광고 집행이나 신규 기능 수십 개 추가보다 유입 채널별 재방문·불만·오류를 살핀다. 유료 광고 실험은 별도의 법률·예산 승인 후 검토.

| D 가상경제 첫 동작 | 독립 체험 vs 조건에 맞는 최대 3개 추천 행동 | 서버 검증된 최초 활동, D1/D7, 이탈 이유 | 허위 돈 지급, 권한 우회, 중복 거래 |

**목표치와 실측치 구분:** 100% 주요 이벤트의 출처 및 확인 시각 기록, 허위 색인 주장 0건, 허위 거래 성공 0건, 관리자·개인정보 페이지 색인 0건, 새로운 치명적 오류 0건을 품질 *합격 조건*으로 제안한다. 2주 안에 구글 상위권·방문자 수·가입률 향상을 보장하지 않는다. 작은 표본으로 통계적 승리를 선언하지 않는다.

분석 이벤트는 실사용자 행동 시에만 발생하며 `search_landing_view`, `guest_scenario_completed`, `auth_return_complete`, `economy_activation_verified` 같은 맞춤 이벤트는 서버 증빙 ID와 연결한다. 분석·광고로 원장 잔고, 회원 이메일 원문, 신원 식별자, IP 지문, 개인 거래내역을 전송하지 않는다.

## 7. 공식 가이드·서비스 벤치마킹 레퍼런스

- **R01** [Google 재수집 안내](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl): 색인 요청 후 수일~수주, 포함 보장 없음.
- **R02** [Google Search Console 실적 보고서](https://support.google.com/webmasters/answer/7576553): 노출/클릭/CTR/순위·집계 기준.
- **R03** [Google 페이지 색인 보고서](https://support.google.com/webmasters/answer/7440203): URL별 미색인 원인.
- **R04** [Google 다국어 SEO](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites)와 [적응형 언어 크롤링](https://developers.google.com/search/docs/specialty/international/locale-adaptive-pages): 개별 URL과 올바른 hreflang.
- **R05** [Google canonical 가이드](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls): 리디렉션·정규 URL·사이트맵 일치.
- **R06** [Google 사람 중심 콘텐츠](https://developers.google.com/search/docs/fundamentals/creating-helpful-content): AI 대량 복제보다 실제 쓸모.
- **R07** [네이버 서치어드바이저](https://searchadvisor.naver.com/)와 [수집/색인](https://searchadvisor.naver.com/guide/report-crawl-refine): 한국 시장 독립 진단.
- **R08** [IndexNow 공식 안내](https://www.indexnow.org/ko_kr/faq): 통보·접수와 색인 성공 분리.
- **R09** [GA4 권장 이벤트](https://support.google.com/analytics/answer/9267735?hl=ko): 회원가입·튜토리얼·공유 계측.
- **R10** [Sim Companies](https://www.simcompanies.com/): 느긋한 기업 경영·다자간 거래 게임 사례.
- **R11** [Virtonomics](https://virtonomics.com/): 다산업 기업 경제 시뮬레이션 사례.
- **R12** [Wall Street Survivor](https://www.wallstreetsurvivor.com/): 금융 교육과 모의 거래의 결합 사례.
- **R13** [Habitica](https://habitica.com/static/front): 작은 과업·레벨·협업·보상 경험 사례.
- **R14** [Duolingo streak 안내](https://www.duolingo.com/help/what-is-a-streak): 선택형 재방문 동기, 강압적 습관 유도 금지.

외부 자료는 **설계 방향의 참고 근거**이지 월덕 머니버스의 실측 수요, 전환율, 운영 안정성 또는 규제 준수를 입증하지 않는다.
