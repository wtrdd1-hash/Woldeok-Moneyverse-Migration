## 상위 기획과 회계 불변식
PROJECT_PLAN → INTEGRATED_PLANNING_MASTER → v523 중앙은행/조폐국/국고/Economy Core → v542 재정 무결성을 따른다. 이미 병합된 전체기획 v675와 독립 그랜트 PR #857, 전수감사 PR #859 참조.
국고 세금·배당·기부·연금·국채·지원금은 기존 WLD 이전만 수행한다. 중앙은행은 정책 승인, 조폐국만 공식 발행·폐기, 국고는 실제 자금의 징수·예약·집행, Economy Core는 복식원장/영수증/멱등키/감사 책임이다.
국고 표시잔액과 검증된 실제 현금, 확정채무 차감 뒤 지급 가능한 현금을 구분한다. 가용재원 = max(0, 입증된 결제자금 − 보호준비금 − 국채원금·쿠폰·연금·환급부채 − 기승인지출). 빠진 자료가 있으면 미검증으로 결제를 차단한다. 30% 비축, 2,500만 목표, 85% 현금 규칙과 운영 설정 8,500만 보호액은 분모·우선순위·부채·정책버전을 명시해야 한다.

## 금융 실행 상태 및 DB 계약
신청 사용자 ID는 요청 본문이 아니라 서버 세션에서 획득한다. 금액은 큰 정수 문자열로, 정책버전·원천거래·멱등키·감사사유를 기록한다. PENDING_REVIEW → APPROVED → RESERVED → SETTLED이며, 승인과 지급 완료는 다르다. 트랜잭션 1개 안에 재원·정책·부채·예산·수령자 계정잠금→잔액/권한→차변·대변 분개→국고보조원장→감사·Outbox·불변영수증까지 함께 처리한다. 동일 멱등키 다른 금액은 거부. 실패는 전부 원자적 롤백.
기존 VAULT_MAIN과 Economy Core TREASURY를 단순 같은 숫자로 복제하지 않는다. 초기 시드, 2,500만 보정, 모의 SWF 평가자산, 연금·국채 채무 등 기존 데이터를 입증/레거시/모의/미확정으로 분류한 후 정정근거가 있을 때만 승인된 역분개로 조정한다.
