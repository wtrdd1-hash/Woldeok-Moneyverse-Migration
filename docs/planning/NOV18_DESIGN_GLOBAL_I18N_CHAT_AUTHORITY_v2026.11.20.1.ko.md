## 2. 자동·수동 다국어 — 모든 화면
- 기본 영어(EN), 필수 한국어(KO), 기존 일본어(JA)·중국어 간체(ZH)·베트남어(VI) **총 5개 언어**를 모두 유지. 비회원·회원·관리자·로그인·오류·로딩·빈 화면·FAQ·전역 채팅에도 적용한다.
- 최초 언어 결정 순서: 사용자의 저장된 **수동 선택** > 허용된 계정 언어 설정 > 브라우저 `Accept-Language` 중 지원 언어 > 영어. IP 위치로 사용자의 수동 언어 선택을 덮어쓰지 않는다.
- 헤더와 모바일 메뉴/설정에 항상 눈에 띄는 언어 선택기. 로그인 여부와 무관하게 5개 언어 중 수동 선택 가능. 변경해도 로그인, 작성 중 폼 및 채팅 초안을 잃지 않도록 한다. 로그아웃·계정 변경에서는 민감 정보 초기화.
- 날짜·숫자·단위·복수형을 언어에 맞게 표시하되 WLD 원장 정수값과 API 필드·금융 의미는 변경하지 않는다. 번역 누락은 영어로 대체하고 기록한다. 번역 키 그대로 출력 또는 검증되지 않은 금융/보안 설명의 자동 번역을 운영 정답처럼 노출 금지.
- 320/360/390/430/768/1024/1440/1920px 및 200% 확대, 5개 언어 긴 문구, 키보드/스크린리더, Spring 서버 오류 다국어, 자동 감지와 수동 선택을 각각 테스트한다.

## 3. 모든 페이지에서 관리자 문의 및 회원 채팅 쉽게 접근
- **모든 공용·로그인·관리자·오류 화면**에 하나만 존재하는 **56×56px 원형 플로팅 문의/채팅 버튼**. PC 오른쪽 아래, 모바일 하단 내비·안전영역 위. 다른 도우미/툴팁·CTA·배너와 겹치지 않도록 한다. 중복 위젯 제거.
- 누르면 **관리자에게 문의**와 **회원 1:1 채팅**을 명확히 분리한 패널. FAQ, 문의 등록/조회·답변 상태, 받은 메시지, 계정·WLD 원장·주식·아이템/퀘스트·오류 등 분류 제공. 관리자 화면은 권한 있는 문의 배정/답변/종료와 감사 기록을 제공하고, 일반 회원 간 대화를 무제한 열람하지 못한다.
- 내부 화면 이동과 언어 전환 후에도 열린 상태/임시 글 유지. 임시 내용·계정·토큰을 디스크/localStorage에 저장하지 않고 로그아웃·계정 변경 때 삭제. 이전 화면 정보는 상위 메뉴 카테고리만 보내며 URL 쿼리·회원번호·결제번호 자동 전송 금지.
- 빈 입력 금지, 1,000자 제한, 중복 제출 방지, 실제 서버 성공 영수증 전에는 '전송 완료' 표시 금지. 401/403/429/5xx/오프라인은 원인과 안전한 재시도 상태 분리.
- 기존 `/app-api/v1/support`와 `/app-api/v1/chat` 계약을 검증 후 재사용하여 중복 저장소/API를 만들지 않는다. **P0 선결:** Spring 문의/채팅의 조작 가능한 신원 헤더(`X-User-Id`/`x-actor-user-id`) 및 고정 UUID 대체 제거, 실제 서버 세션 신원/대화 소유권/RBAC·관리자 재인증/CSRF/감사/오류 시 실패 응답 검증. 해결 전에는 실제 메시지 전송 활성화 및 운영 승격 금지.
- 접근성: 44px 이상 터치 대상, 열 때 초점 이동·닫은 뒤 복귀, Escape 닫기, 모바일 키보드/세이프에어리어 대응, 스크린리더 레이블, reduced-motion.
