## 구현 경계·아키텍처
- Spring 라우팅 브랜치의 SpaWebMvcConfig는 Next 빌드가 만든 정적 화면을 Spring Boot에서 서빙하는 구조다. 실제 사용자 화면 전환에는 이 브랜치 코드의 빌드, 격리 Test 서버 Spring 연결, 로그인/권한/정확한 API 등 확인 필요. 기존 운영 프론트엔드를 즉시 교체하지 않는다.
- 사이트 루트에 이미 FloatingSupportChatWidget이 존재해 비관리자 화면에서는 고객문의·1:1 대화를 제공하고 있으나 /admin 경로에서는 숨겨져 있다.
- 이 개발은 **관리자 전체 경로에 56px 원형 안전한 문의 안내 버튼**을 추가한다. 여기서 관리자 지원, 서비스 고객센터, 도움말로 바로 이동하며 실제 채팅/문의 메시지를 전송하지 않는다. 다른 일반 회원 페이지는 기존 단일 고객지원·쪽지 위젯을 유지하면서 원형 버튼·모바일 세이프에어리어·접근성만 개선한다.
- 관리자 공통 레이아웃에 다크 네이비·보라/블루 테마 적용. 기존 관리자 화면의 API·실제 수치·UNKNOWN/오류 상태·권한 검증은 유지한다. 40개 관리자 화면의 개별 데이터를 가짜로 대체하지 않는다.
- 기존 frontend/의 제한된 부분만 새 브랜치에서 수정. Spring Controller/DB/Nginx/금융 원장·운영 프로세스 변경 금지.

## 보안 게이트
Spring SupportController/ChatController의 사용자 헤더 기반 신원·고정 UUID 대체, SupportService의 DB 실패 뒤 허위 성공형 응답이 소스상 확인됐다. 따라서 서버의 유효 세션 기준 신원/CSRF/스레드 소유권/실제 영수증 검증 전 **새 관리자 팝오버에서 실제 문의·쪽지 전송 API 연결 금지**. Spring 담당자의 보안·재현 QA가 필요하다.

## UI·기능/접근성 기준
- 관리자 화면: 심플한 네이비 배경/보라 강조, 실제 정보 근거, 작은 화면 세로 구성, 표는 내부 스크롤. 개별 메뉴 및 접근 권한 유지.
- 관리자 동그라미: 56×56px, 데스크톱 우측 24px/하단 24px, 모바일 우측 14px/바텀 내비(80px+safe-area) 위. 열기/닫기, Escape, 포커스 이동 및 복귀, 명시적인 “현재 문의 전송은 비활성” 문구, 관리자 지원·일반 도움말 링크 제공.
- 일반 화면: 기존 고객지원/1:1 위젯 유지, 56px 터치 버튼·세이프 에어리어/ARIA 제어 개선. 실제 서버 응답과 상관없는 성공 상태를 만들지 않는다.
- 관리자가 아닌 /administrator는 /admin으로 취급하지 않는다. 관리자 전용 실제 개인 대화 조회는 허용하지 않는다.
- 영어는 기본 계획 언어, 한국어는 2차 필수 언어. 기존 locale 표시 체계 준수.
