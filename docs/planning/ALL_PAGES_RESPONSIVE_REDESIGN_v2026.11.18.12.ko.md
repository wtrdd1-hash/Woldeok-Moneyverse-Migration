## 3. 페이지 배치와 사이트 정보구조

기능이 많다는 이유로 기존 메뉴를 제거하지 않는다. PC 마스트헤드는 기존 공식 디자인 기준의 홈, 거래소, 금융 도구, 커뮤니티, MY 다섯 영역으로 묶고, 하위 30+ 메뉴는 검색·명령 팔레트·왼쪽 내비·상황별 링크로 접근한다. 모바일은 홈·자산·게임·커뮤니티·MY 하단 내비를 사용하되 금융 도구는 전체 메뉴와 검색에 명시한다.

- 홈: 게임형 판타지 히어로, 퀘스트, 지갑 요약, 경제 지표, 알림, 공지. 비로그인 상태에 민감 데이터 미노출.
- MY: 내 정보, 프로필, 로그인 보안, 계정 설정, 알림 및 로그아웃.
- 금융·경제: 지갑, 은행, 주식 및 상세·포트폴리오, 국채, 국고, 중앙은행, 조폐국, 예금보험, 연금, 외환, 국영기업, 사업, 창업, 가이드, 예측.
- 게임: 직업, 퀘스트, 명성, 시즌, 아케이드, 카지노, 상점, 인벤토리, 도감, 경매, 부동산, 캘린더.
- 커뮤니티: 게시판, 블로그, 뉴스, 채팅, 클럽, 사진, 로비, 공지, 도움말, 고객지원.
- 계산기: 각 계산 항목에 서로 다른 입력·결과·방법론·가정 안내.
- 관리자: 별도 운영 UI 패밀리, 실제 서버 권한·재인증·감사 기록이 전제.
- 인증·정책: 소셜 로그인·동의·비밀번호 복구·이메일 확인·개인정보·약관·삭제 등.

기본 언어는 영어, 필수 두 번째 언어는 한국어다. 기존 지원 언어·라우트는 제거하지 않는다. 시안의 한국어 문구는 검토용이며 구현 때 화면 텍스트를 하드코딩해서는 안 된다.

- 브랜드 보라 #9C83FF, 보조 블루 #64B7FF. 녹색·하늘색은 금융 긍정/중립 상태에서 사실에 맞게 제한적으로 사용.
- 게임은 보라/골드 경험치·보상·캐릭터 등 장식을 허용하되 핵심 기능을 방해하지 않는다.

- 커뮤니티는 글 중심 레이아웃, 계산기는 가정·입력·결과 분리, 약관은 독서 중심 조판.
- 시각적 강조는 제한적으로 사용하고 150ms 호버, reduced-motion, 포커스 표시와 키보드 탐색을 지원한다.

## 5. 화면 깨짐·반응형·접근성 기준

실제 구현 시 320, 360, 390, 430, 768, 1024, 1280, 1440, 1920px에서 각각 QA한다. 모바일을 PC 비율대로 축소하는 것은 금지한다.

- 휴대폰은 세로 카드, 바텀 내비, 세이프 에어리어 대응, 모달 바텀시트 적용.
- 태블릿은 필요한 경우 2열 구성, 데스크톱은 정보 유형에 맞춘 분할 화면.
- 문서 자체의 예상치 못한 가로 스크롤 0건, 겹침·텍스트 잘림·버튼 가림·z-index 충돌 0건.
- 터치 영역 44×44px 이상, 200% 확대, 키보드·스크린리더, WCAG 2.2 AA 기준.
- 한국어·영어·일본어·중국어·베트남어 및 긴 수치·식별자가 레이아웃을 파괴하지 않도록 구현.
- 화면 상태를 반드시 분리: 게스트, 로딩, 검증된 빈 목록, 인증 만료, 권한 없음, 입력 오류, API 장애·데이터 오래됨, 거래 대기, 실제 영수증 수신 후 성공, 안전한 재시도.
- 개인정보·관리자 화면 캐시 금지 및 비공개 검색 인덱스 정책 준수.

## 6. 기능·보안 명세

**관리자:** Spring 서버의 세션·권한·필요 시 OTP 재인증과 CSRF를 실제 검증하고, 감사로그에 작업자·시간·대상·근거를 남긴다. 공개 HTTP 200 또는 예시 UI만으로 접근을 허용하지 않는다.

**금융:** 실제 원장/서버 API 기반으로 표시, WLD 정수 정확성 보장(BigInt/정확한 문자열), 조회와 쓰기 구분, 거래·송금 전 명확한 확인, 결제 중복 방지. 장애나 알 수 없는 값은 성공 또는 0으로 대체 금지.

**게임:** 실제 퀘스트 달성 근거·서버 보상·보관함 만료·유지비·아이템 정지 상태 구분. WLD는 서비스 안의 가상 재화임을 명시하고 실제 투자·보상 수익 보장 문구 금지.

**커뮤니티:** 접근권한, 안전한 글 게시·미디어 처리·신고·관리·날짜·콘텐츠 출처 필수.

**계산기:** 이름 있는 단위, 계산 근거·기준일, 숫자 경계 및 소수점 검증, 예시·추정 결과의 불확실성 표시.

**인증/약관:** 소셜 OAuth, 계정 동의·복구·삭제 절차를 보안과 접근성 기준에 맞춰 설계하고 미검증 완료 안내를 금지한다.
