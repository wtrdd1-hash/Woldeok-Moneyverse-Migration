# v2026.09.19.261 — 랜덤 초기 가격 주식 3종 추가

## 범위

게임 전용 가상주식 3종을 추가한다.
- WDT — Woldeok Tech / 월덕테크
- WDM — Woldeok Mobility / 월덕모빌리티
- WDB — Woldeok Bio / 월덕바이오

각 주식은 상장 시점에 정해진 안전 범위 안에서 초기 가격을 랜덤 생성한다. 생성 직후 `initial_price`, `current_price`, `day_open_price`는 같은 값으로 시작한다. 이후 가격 변동은 기존 주식 시장 dynamics 엔진이 담당하며 별도의 가격 엔진은 추가하지 않는다.

## 안전성 / 호환성

- 종목 코드 기준 `ON CONFLICT (symbol) DO NOTHING`으로 재실행 안전성 확보.
- 신규 종목은 `virtual_stock_dynamics`에도 즉시 초기화.
- 기존 시장 기본 변동성 파라미터를 그대로 사용.
- 사용자 잔액, 보유주식, 원장, 과거 거래 데이터는 변경하지 않음.
- DB migration 변경이며 Test에서 exact-SHA migration 및 백엔드 확인 전에는 운영 승격 완료로 간주하지 않음.
