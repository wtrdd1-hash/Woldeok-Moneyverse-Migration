# v2026.09.19.261 — Randomized three-stock seed

## Scope

Adds three game-only virtual stocks:
- WDT — Woldeok Tech
- WDM — Woldeok Mobility
- WDB — Woldeok Bio

Each stock receives a randomized listing-time initial price inside a bounded range. Initial, current, and day-open prices are identical at creation. After creation, the existing stock market dynamics engine owns price movement; this change does not introduce a second price engine.

## Safety / compatibility

- Idempotent by stock symbol with `ON CONFLICT (symbol) DO NOTHING`.
- Initializes `virtual_stock_dynamics` immediately for newly inserted stocks.
- Uses the existing market base volatility parameter.
- No user balance, position, ledger, or historical trade data is rewritten.
- Database migration only; no production promotion claim until Test exact-SHA migration and backend checks pass.
