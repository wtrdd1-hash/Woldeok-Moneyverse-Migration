## Retention / viral / brand
- D1 원칙을 `새것보다 인식 먼저`로 정의했습니다.
- D7 성공을 새 획득/claim이 아니라 자기주도 큐레이션 행동으로 정의했습니다.
- favorite piece, 배열, exhibit, 완성 chapter, archive milestone을 향후 우선 공유 아티팩트로 정의했습니다.
- WLD wealth, WDX return, debt, casino result, private/security state는 기본 공유에서 제외했습니다.
- 브랜드 방향을 `사용자가 고른 것을 기억하고 역사로 만들게 돕는다`로 명확히 했습니다.

## SEO / 수익화
- private collection dashboard, first-piece state, personal recap, draft, 민감 경제/보안 페이지를 검색 inventory에서 제외했습니다.
- 충분한 lore, editorial exhibit, archive, 맥락이 충분한 opt-in public project/showcase만 색인 후보로 둡니다.
- value-first 실험에서 first-piece → D1 → D7 경로를 interruptive monetization으로부터 보호합니다.
- 애착 이후 non-P2W presentation 중심 수익화를 유지하고 collection preservation 자체는 유료잠금하지 않습니다.

## 보안·개인정보·악용
- private-state leakage, collection-progress phishing/ATO, prestige/farming manipulation, public-annotation UGC abuse를 High로 기록했습니다.
- public-safe allowlist, personalized state 기본 비공개, 명시적 공개선택, 공식 도메인 일관성, raw share/open에 경제보상 금지, 첫 public-UGC pilot의 bounded/preset text를 최소조건으로 기록했습니다.
- personalized public continuity, 외부 push/deep-link, public prestige, open-ended annotation 전 별도 개발/보안/fraud/privacy QA를 요구합니다.
