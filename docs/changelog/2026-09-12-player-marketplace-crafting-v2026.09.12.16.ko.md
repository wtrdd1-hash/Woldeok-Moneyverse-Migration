- 결정형 우선 제작, 분해, 색상변경, 복원, 각인, 중복합성, 가구제작, 아카이브 복원을 추가했다.

- 시즌 아이템 거래정책과 D-14/D-7/D-3/D-1 제작·거래 연속성 요구사항을 정의했다.
- 개인공간·도시프로젝트 연계를 추가했다.
- 자기거래, 원형거래, wash volume, 에스크로 우회, 중복정산, 봇 등록폭주 방지 요구사항을 추가했다.
- 권장 PostgreSQL 엔터티, API, 관리자 콘솔, 경제대시보드, 분석이벤트를 정의했다.

## 배포 영향

이번 변경은 문서-only이며 런타임 코드, API, DB 스키마/마이그레이션, 배포 동작은 변경하지 않는다. 따라서 이 문서 변경 자체에는 테스트 서버 배포가 필요하지 않다.

실제 구현은 별도 개발 브랜치, forward-only migration, 서버 권위 원장/인벤토리, 정확한 후보 SHA Test 배포, 백엔드/API/PostgreSQL/멱등성/동시성 검증 후에만 Production으로 승격한다.
