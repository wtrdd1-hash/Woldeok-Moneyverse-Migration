# 내부/외부 업데이트 내역 — v2026.11.17.5 — 디스코드 로그인 세션 정합성

- **장애:** Spring의 `mv_session`과 Nest의 `__Host-mv_session`이 동시에 존재할 때, 로그인 시작 및 콜백에서 서로 다른 세션을 읽어 `oauth_state`(400) 오류 발생.
- **수정:** OAuth 시작 시 새 Spring 익명 세션이 만들어진 경우 과거 호스트 쿠키를 만료하고, 인증 성공 후 Nest 새 호스트 쿠키가 발급된 경우 이전 Spring 쿠키를 만료. 계정 연결, 추가 인증, 로컬 로그인, 가입, 자금 기능은 변경하지 않음.
- **보안:** 세션/상태 검증 우회 없음. 쿠키 삭제는 Secure, HttpOnly, SameSite=Lax, 호스트 전용으로 처리. 인증값과 개인 식별 정보 출력 없음.
- **검증:** 실운영 익명 OAuth 취소 기반 재현, 단위 4개·라우트 통합 4개 테스트, 타입 검사 및 프론트 빌드 통과. Test/운영 승격 결과는 작업 로그에 별도 기록.
- **제한:** 디스코드 실제 사용자 동의 후 최종 로그인 성공은 별도 확인 필요.
