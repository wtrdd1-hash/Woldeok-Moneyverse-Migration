# 디스코드 길드 명령어 초기화 — v2026.09.17.194

## 요약
디스코드 음악 명령어 초기화 시 기존 항목을 단순 수정/생성하는 대신 길드 명령어 집합을 지원하는 음악 명령어 7개로 원자적으로 교체하도록 수정합니다. 애플리케이션 글로벌 명령어는 변경하지 않습니다.

## 변경 사항
- 길드 명령어를 `/play`, `/skip`, `/stop`, `/pause`, `/resume`, `/queue`, `/nowplaying` 7개로 `guild.commands.set(...)` 한 번에 교체합니다.
- 교체 과정에서 남아 있던 오래된 길드 범위 명령어를 제거합니다.
- 기본 명령어명은 영어를 유지하고 한국어를 두 번째 언어 현지화로 유지합니다.
- 정확히 7개 명령어 정의가 전달되는지 확인하는 회귀 테스트를 추가합니다.
- 봇 테스트 스크립트가 두 봇 모듈 문법 검사와 명령어 동기화 회귀 테스트를 함께 수행하도록 확장합니다.

## 검증
- `npm ci`: 통과, 취약점 0건.
- `npm test`: 통과, 문법 검사 및 회귀 테스트 1/1 통과.
- 변경 전 운영 확인: 봇 서비스 실행, 로그인 성공, 음악 명령어 7개 등록 로그, 목표 음성 채널 연결 정상.

## 배포 순서
기능 브랜치 -> 격리 검증/Test 후보 -> Test 백엔드 상태 확인 -> `main` 병합 -> 운영 봇 재시작 -> 명령어/음성 스모크 검증.
