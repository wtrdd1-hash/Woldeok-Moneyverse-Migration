# 프론트엔드 전면 재디자인 v2026.09.19.260

## 요약

기존 라우트, API, 인증, 경제 동작을 유지하면서 머니버스 공통 시각 계층을 전면 재구축했다.

## 사용자 화면 변경

- 기존 종이·테라코타 계열을 절제된 미드나이트 인터페이스와 문라이트 골드 포인트로 교체
- 공통 내비게이션, 브랜드, 페이지 셸, 푸터, 모바일 내비게이션, 버튼, 입력창, 카드, 페이지 헤더 재설계
- 동일 크기 카드 반복 대신 비대칭 정보 위계를 사용하는 반응형 홈 대시보드 재구축
- 공지 영역을 반복 카드에서 편집형 활동 목록으로 변경
- 44px 지향 모바일 터치 타깃과 reduced-motion 동작 유지
## 디자인 근거

사람이 직접 설계한 금융·커뮤니티·게임 제품 인터페이스를 중심으로 레퍼런스를 종합했다. 동일 카드 그리드, 장식적 글래스모피즘, 반복 글로우, 기계적으로 동일한 여백을 줄였다. 금융 정보는 숫자 위계를 강화하고, 내비게이션과 운영 기록은 밀도 높은 리스트 구조를 사용하며, 포인트 색상은 상태와 행동에 제한적으로 사용한다.

## 검증

- 프론트엔드 테스트 650/650 통과
- 프론트엔드 TypeScript 타입체크 통과
- 필수 contract 선행 빌드 후 Next.js 프로덕션 빌드 통과
- 구현 중간에 제품/접근성 기획 문서를 재확인했고 내용 변경 없음
- 테스트 서버 배포와 백엔드/DB 스모크 검증은 저장소 Test Candidate 통합 절차 이후 진행
