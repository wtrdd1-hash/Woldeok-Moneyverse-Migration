# 마켓플레이스 최근 획득 필터 v2026.09.14.94

## 추가

- 로그인 회원용 `/marketplace` 보유 아이템 작업대에 최근 획득 기간 필터를 추가했습니다.
- 최근 7일 또는 30일 안에 획득한 authoritative holdings만 좁혀 볼 수 있습니다.
- 기존 검색, 카테고리, 희귀도, 효과 유형, 최소 수량, 아이템 상태, 정렬 필터와 함께 사용할 수 있습니다.

## 안전 범위

- 기존 authoritative `GET /api/v1/shop/holdings` 읽기 모델만 사용합니다.
- 판매 등록, 구매, 이전, 에스크로, 제작 정산, 가격 쓰기, DB migration은 추가하지 않았습니다.
- 잘못된 날짜나 미래 시각의 획득 기록은 최근 기간 결과에서 제외해 신뢰 가능한 보유 이력으로 취급하지 않습니다.
