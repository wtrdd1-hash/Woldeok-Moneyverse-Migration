# v2026.09.12.29 — 인증 보안 및 구현 우선순위

## 요약

- 미구현 기능 중 자체 계정 보안을 P0로 지정했습니다.
- 이메일/비밀번호 회원가입, 이메일 인증, 로그인, 복구, 세션 보안, 사용자 보안센터를 구현 수준으로 기획했습니다.
- SQL Injection 방지, Argon2id 비밀번호 저장, CSRF/XSS/session fixation 방어, 계정열거 방지, credential stuffing 대응, MFA/passkey 로드맵, 최소권한 DB, 개인정보 보존/삭제/내보내기, 관리자 masking, append-only 보안감사를 추가했습니다.
- 기존 OAuth/OIDC, 서버 세션, 재인증, TOTP/관리자 보안 구조를 폐기하지 않고 기반으로 재사용합니다.

## 배포

문서-only 변경입니다. 이 문서 변경 자체는 테스트서버/운영 배포가 필요하지 않습니다. 실제 구현은 별도 개발 브랜치에서 진행하고 격리된 테스트서버에서 exact-SHA 백엔드/DB/API/보안 검증을 통과한 뒤 운영에 반영합니다.
