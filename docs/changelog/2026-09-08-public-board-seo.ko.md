# 2026-09-08 공개 게시판 / SEO 후보

[English](2026-09-08-public-board-seo.md) | **한국어** | [문서 색인](../INDEX.ko.md)

- 참여 권한은 그대로 유지하면서 게시판 읽기를 공개합니다.
- 공개 게시판 글은 글별 canonical 메타데이터를 통해 검색 색인이 가능해집니다.
- Production Search Console 확인값을 프론트엔드 빌드에 전달합니다.
- Production/Test robots 및 sitemap 경계에 회귀 검증을 추가합니다.
- 기존 경제 쓰기 함수나 직접 테이블 권한을 완화하지 않습니다.

상태: 후보 전용. `main` 또는 Production 반영 전 CI 및 격리 Test 서버 검증이 필요합니다.
