# 브랜치 정리 자동화 v2026.09.12.15

날짜: 2026-09-12

## 요약

- 같은 저장소의 작업 브랜치 PR이 `main`에 병합되면 해당 소스 브랜치를 자동 삭제합니다.
- 예약/수동 정리 작업에서는 커밋이 이미 `main`에 모두 포함된 브랜치만 삭제합니다.
- `main`, `production`, `staging`, `develop`, `release/*` 브랜치는 보존합니다.
- 배포 순서는 유지합니다: `main` 병합 → exact-SHA 테스트 후보 빌드 → `wdmv-test` GitOps 승격 → exact-SHA 백엔드/API 스모크 검증 → 운영 이미지 빌드 → GitOps 운영 반영.

## 안전 조건

검토되지 않은 작업을 자동 병합하지 않으며, `main`에 아직 없는 커밋을 가진 브랜치는 삭제하지 않습니다. 보호되었거나 삭제할 수 없는 브랜치는 그대로 유지합니다.
