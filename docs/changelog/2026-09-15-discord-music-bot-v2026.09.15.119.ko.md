# 디스코드 음악 봇 — v2026.09.15.119

## 요약
기존 월덕 디스코드 봇의 24/7 음성 채널 감시 기능을 유지하면서 길드 전용 YouTube 음악 재생 기능을 추가합니다.

## 변경 사항
- `/재생`, `/스킵`, `/정지`, `/일시정지`, `/계속재생`, `/대기열`, `/현재곡` 한국어 현지화 명령을 추가했습니다. 기본 명령어 표기는 영어입니다.
- 최대 50곡 대기열과 곡 최대 길이 설정(`DISCORD_MUSIC_MAX_TRACK_SECONDS`, 기본 3시간)을 추가했습니다.
- HTTPS YouTube 주소만 허용하고 실시간 방송은 차단합니다.
- `yt-dlp` 기반 검색/오디오 스트리밍과 Discord 음성 플레이어를 연동했습니다.
- 명령 처리 오류 대응과 프로세스 종료 시 오디오 스트림 정리를 추가했습니다.

## 검증
- `node --check bot/index.js`
- `node --check bot/music.js`
- `bot/`에서 `npm test`

## 배포 순서
기능 브랜치 -> 테스트 런타임 -> 백엔드/봇 상태 확인 -> 운영 승격.
