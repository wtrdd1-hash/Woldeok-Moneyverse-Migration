# 마켓플레이스 최소 보유 수량 필터 — v2026.09.14.93

## 추가

- 마켓플레이스 작업대에 최소 보유 수량 필터를 추가했습니다.
- 기존 검색, 카테고리, 희귀도, 효과 유형, 상태, 정렬 조건과 함께 사용할 수 있습니다.

- 기존 `/api/v1/shop/holdings`의 authoritative 보유 데이터만 읽는 기능입니다.
