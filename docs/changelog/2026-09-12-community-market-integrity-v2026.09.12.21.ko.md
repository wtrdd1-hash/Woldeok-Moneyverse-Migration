# 변경내역 — 커뮤니티·시장 무결성 v2026.09.12.21

기준일: 2026-09-12

## 추가

- 구현 지향형 `COMMUNITY_MARKET_INTEGRITY_SPEC.ko.md` 추가.
- WDX 종목 태그 토론의 가상시장 표시·포지션 공개 원칙 정의.
- 신고 유형, 멱등 신고 계약, 집단 신고 악용 방지 규칙 추가.
- 커뮤니티 제재와 시장 무결성 기능 제한을 별도 상태머신으로 분리.
- 정상 게시활동은 기본 unlimited로 유지하고 일일 게시한도 대신 스팸·보안 스로틀 사용.
- 자기/순환거래, 펌프 공모, 가짜 유동성, 악의적 집단 신고 조사 신호 정의.
- 신고·반응·감성·팔로워 수가 WDX 가격에 직접 반영되지 않도록 명시.
- 이의제기, 사유코드 제재, 근거 최소화, 모더레이터/관리자 콘솔 요구사항 추가.
- DB/API/분석/시즌/클럽/소비처/출시 단계 계약 추가.

## 안전·경제

- 커뮤니티 인기도는 WLD 발행, WDX 가격, 대출·작업·사업 조건, 시즌점수를 직접 바꾸지 않는다.
- WLD로 경고 삭제, 이의제기 우선권, 시장보류 해제를 구매할 수 없다.
- 커뮤니티 꾸미기 상품은 실제 WLD가 시스템에서 제거될 때만 hard sink로 집계한다.

## 검증

문서-only 변경이다. 런타임/API/DB/migration/ledger/deployment 동작 변경은 없으므로 이번 문서 갱신 자체에는 Test 배포가 필요하지 않다. 실제 구현은 별도 개발 브랜치에서 진행하고 정확한 후보 SHA를 Test 환경에서 검증한 뒤 Production으로 승격해야 한다.
