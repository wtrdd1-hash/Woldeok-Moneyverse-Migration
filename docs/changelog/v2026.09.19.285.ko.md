# v2026.09.19.285 — 실제 등록 주식 AI 시나리오

- AI 주식 자동 시나리오 대상을 현재 `active=true`인 실제 등록 `virtual_stocks`로 제한했다.
- 자동 생성에서는 전체시장/null, 미등록·비활성 심볼, 강도 3 effect를 저장/게시 후보에서 제거한다.
- 활성 등록 종목이 없으면 모델 호출 전에 fail-closed로 종료한다.
- 자동 시나리오는 최대 24시간, 실제 변동 등록 종목 최대 2개 제한을 유지한다.
- 등록 종목 필터링과 빈 종목 카탈로그 차단 회귀 테스트를 추가했다.
- Test 검증 후 Production 활성화와 실제 실행 증거를 확인해야 승격 완료로 기록한다.
