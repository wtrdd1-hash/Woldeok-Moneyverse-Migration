# 변경 이력 — v2026.10.17.749

**영문 정본:** [English](2026-10-17-dual-disk-safety-v749.md)
**구분:** 실제 과거 캐시 안전 정리·읽기 전용 운영 점검 개발·승격 조건 기록. 애플리케이션 운영 배포 아님.

### 실제 변경 사항
- 운영본·Test·DB·백업·회원 잔액을 제외한 옛 테스트 `.next` 빌드 캐시 15개만 삭제.
- 100GB 시스템 디스크에서 **7,176,216,576바이트** 확보, 사용률 **92% → 85%**. 200GB 데이터 디스크는 그대로 보호하면서 이번 격리 개발 작업공간부터 데이터 디스크 활용.
- `ops/storage/dual-disk-check.mjs` 읽기 전용 두 파일시스템 점유율 점검 도구·`--json`·`--strict` 작성, 테스트 5건 통과.
- `package.json` 표준 테스트 대상에 신규 테스트 편입.
- EN/KO 운영 표준, 작업 기록, 내부용·GitHub용 업데이트 작성.
- 재정 사전검사는 5개 핵심 테이블 앱 계정 직접 쓰기 권한과 19개 초기잔액 대조 미확정으로 차단. 현 v717 운영과 v735.2 테스트의 자기 버전 확인은 통과. **운영 앱 전환 없음**.

**복구:** 과거 캐시는 필요시 해당 소스에서 다시 빌드할 수 있음. 활성 서비스 또는 DB를 건드리지 않았으므로 임의 데이터 복구나 데이터베이스 재작성은 불필요하며 금지.
