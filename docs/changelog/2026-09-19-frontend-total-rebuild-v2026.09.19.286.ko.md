## 요약
다음 개발 단계를 웹 프론트엔드 전면 재구축으로 정의한다. 각 라우트는 실제 백엔드/API 계약을 먼저 확인한 다음 사람 중심의 제품 UI 기준과 명시적인 반응형 완료 조건에 따라 다시 설계한다.

## 추가 요구사항
- 현재 화면을 부분적으로 꾸미는 방식이 아니라 프론트엔드 구조와 페이지 구성을 처음부터 다시 구축한다.
- 프론트 구현 전에 라우트별 백엔드/API 동작을 전수조사한다.
- 백엔드에는 있지만 사용 가능한 UI가 없는 기능을 재구축 백로그에 연결한다.
- AI 생성물처럼 보이는 반복적 시각 패턴과 범용 대시보드 구성을 피한다.
- 새로운 디자인 시스템과 공통 상호작용 프리미티브를 확립한다.
- 320/360/390/768/1024/1280/1440 CSS px 및 필요한 확대/리플로우 동작을 검증한다.
- 로딩, 빈 상태, 오류, 권한 부족, 세션 만료를 필수 라우트 상태로 취급한다.
- 병합 전에 exact-SHA 테스트 서버 검증을 요구하고 병합된 동일 SHA만 무중단 운영 승격한다.

## 개발 순서
1. 백엔드/API 전수조사 및 라우트 매트릭스.
2. 디자인 시스템 기반.
3. 전역 셸/내비게이션.
4. 인증/계정.
5. 경제/직업/주식/지갑.
6. 상점/마켓/커뮤니티/콘텐츠.
7. 관리자/운영.
8. 반응형/접근성/성능/회귀 QA.
9. 테스트 exact-SHA 검증 후 무중단 운영 승격.
