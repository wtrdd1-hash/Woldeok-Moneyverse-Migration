# 경제 소비처 카탈로그 — v2026.09.12.7

기준일: 2026-09-12
범위: 제품 기획/문서 변경만 수행

## 추가 사항

- 구현 가능한 수준의 `ECONOMY_SINK_CATALOG.md`와 한국어 대응 문서를 추가했다.
- 보호 목적이 아닌 숫자 제한은 `null`/unlimited를 기본값으로 사용하는 소비처 공통 설정 계약을 정의했다.
- `HARD_SINK`, `TRANSFER`, `CONVERTER`를 명확히 분리해 유저간 이전액을 소각으로 계산하지 않도록 했다.
- 프로필, 수집, 주거, 사업, 제작, 시장, 은행, 물류, 클럽, 도시 프로젝트, 직업, 명예, 시즌 영역의 P0/P1/P2 소비처를 구체화했다.
- 플레이 횟수 하드캡 대신 가격곡선과 점진적 확장비용으로 경제를 조절하도록 초기 가격안을 작성했다.
- 소비처별 원장 transaction type을 정의해 실제 소각량 대사가 가능하도록 했다.
- 개인정보 최소화형 소비 분석 이벤트와 경제 대시보드 지표를 정의했다.
- 순발행, 소비처 집중도, 고자산층 잔액 증가율의 운영 검토 기준을 추가했다. 이 기준은 플레이를 자동 제한하지 않는다.
- 시즌 종료 `Legacy Museum` 무제한 자발 기부 등 시즌 WLD 소비처를 추가했다.
- 원자적 원장 차감, 멱등성, 설정 버전, 실제 PostgreSQL 통합검증, 테스트 서버 검증, 운영 대사를 포함한 런타임 완료조건을 정의했다.

## 설계 근거

- 현재 PlayFab 상점 문서는 아이템 카탈로그와 상점별 가격·판매 구성을 분리하는 구조를 제공한다. Moneyverse도 소비처의 정체성은 안정적으로 유지하고 가격·판매기간·활성상태는 버전 관리된 서버 설정에서 조정하는 방향으로 설계했다.
- TradingView Paper Trading/Bar Replay 및 대회 구조는 연습·경쟁용 상태를 실제 자산과 분리하는 사례를 제공한다. Moneyverse에서도 위험·안전교육은 무료로 두고 시즌/리그 경제를 메인 WLD와 분리하며, 주변 소비는 외형·기록·아카이브 중심으로 구성한다.

## 검증

문서만 변경했다. 런타임, API, DB 스키마, 배포 동작에는 변화가 없으므로 이 버전은 테스트 서버 배포가 필요하지 않다. 실제 기능 구현 시에는 별도 개발 브랜치에서 구현하고 정확한 후보 버전을 테스트 서버에서 검증한 뒤 운영으로 승격해야 한다.
