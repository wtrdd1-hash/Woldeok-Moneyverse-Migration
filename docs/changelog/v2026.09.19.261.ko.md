# v2026.09.19.261 — AI 주식 시나리오 자동화

- 가상 주식 AI 뉴스룸에 opt-in 시간별 자동 실행을 추가했다.
- AI는 시나리오만 생성하고 결정론적 market-event 코드가 유일한 주가 기록 권위로 유지된다.
- 자동 게시는 전체시장 효과와 강도 3 충격을 제외하고 변동 종목 최대 2개, 기간 최대 24시간으로 제한한다.
- 기존 서킷브레이커, 일중 가격 밴드, 이벤트 점프, drift, 감사, 멱등성을 그대로 적용한다.
- 활성화와 감사 actor identity는 fail-closed 환경설정으로 추가했다.
