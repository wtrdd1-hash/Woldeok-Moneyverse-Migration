# v2026.09.14.91 — 웹 자체 계정 로그인

## 요약

- 공개 웹 로그인 화면에 월덕 머니버스 자체 이메일/비밀번호 로그인 폼을 추가했다.
- 기존 `auth/local/login` 백엔드 흐름과 기존 서버 관리 세션 모델을 그대로 재사용하며 별도의 인증/세션 체계를 만들지 않았다.
- 자격 증명 전송 전에 Next.js 서버 액션에서 로그인 전 세션 생성/재사용과 CSRF 처리를 수행한다.
- API가 발급한 세션 쿠키는 기존 보안 쿠키 릴레이 도우미를 통해 브라우저로 전달한다.
- 필수 입력 누락, 잘못된 자격 증명, 자체 인증 서비스 이용 불가, 일반 자체 로그인 실패에 대한 한국어 사용자 오류 메시지를 추가했다.
- Discord/Google 로그인은 기존 방식 그대로 유지한다.

## 보안 메모

- 브라우저에는 계속 `INTERNAL_API_TOKEN`을 노출하지 않는다.
- 비밀번호는 서버 액션/API 인증 흐름에만 전달되며 브라우저 저장소에 기록하지 않는다.
- 존재하지 않는 이메일과 잘못된 비밀번호는 UI에서 동일한 일반 자격 증명 오류로 처리한다.
- 기존 서버측 세션 회전, HttpOnly/Secure 쿠키 정책, Argon2id 검증, rate limit, 계정 열거 방어가 계속 최종 기준이다.
