## 포트 4550의 정체
4550은 과거 문서상 Spring Boot HTTP/API 서비스이며 **테스트 서버 전용 포트가 아니다**. 과거 공식 테스트 백엔드/프론트엔드는 3100/3101, 실시간 Netty-SocketIO는 9092로 기록되어 있다. 현재 활성 프로세스/환경은 원격 미니PC 오프라인으로 확인 불가. 포트 이름만으로 환경 구분 금지. PID, systemd 유닛, 실행 파일, 실제 바인딩 IP, Nginx, EnvironmentFile, 배포 SHA가 일치하기 전까지 4550 재할당·종료·외부 개방·운영 라우팅 변경 금지.

## 승격 불가를 기본값으로 하는 필수 게이트
1. **T0 기준·담당자:** 작업 전/중 최신 main 및 통합문서 재확인, 독립 브랜치·작업폴더, Gemini와 파일 소유권 분리, 시작/중간/종료 기록. 운영/main 직접 수정 금지.
2. **T1 물리·논리 격리:** 테스트 전용 도메인, Nginx, 서비스, DB, 세션, 캐시, 저장소, 큐, WebSocket 채널, 비밀키, 스케줄러. 테스트 외부 접근은 인증·권한·가능하면 MFA를 거친 HTTPS 443으로만 허용. 4550·3100·3101 등 내부 포트를 인터넷에 직접 개방 금지. 백엔드 루프백/사설망 바인딩, 최소 권한, 관리자·테스터 접근통제, 검색엔진 비색인, 디버그·액추에이터 공개 차단.
3. **T2 데이터 격리:** 운영 원장·사용자·세션·잔고·금융 스케줄러에 테스트 쓰기·실행권한 0. 별도 DB/계정/스토리지 및 합성·비식별 데이터 사용. 운영 데이터 복제는 별도 개인정보 승인·암호화·비식별화 없이는 금지. 테스트 송금·예금·주식·배당 실행은 샌드박스에서만.
4. **T3 코드·CI:** 정확한 40자리 SHA와 불변 빌드, 비밀정보/의존성 검사, Java/프론트 빌드, 단위·통합·계약·DB 마이그레이션·권한 부정검사, 로그인 세션 유지, 금융 멱등성·동시성, 11월18일 UI 시각 비교, 모바일·PC, 영어 기본/한국어·일본어·중국어·베트남어 전환을 모두 필수. 스킵/모킹만으로 통과 처리 금지.
5. **T4 실제 테스트:** 포트별 PID·서비스·SHA 및 HTTPS 검증, 실제 DB 연결 데이터 송수신, 고정 가짜 성공 응답 금지, 구글/디스코드·자체 로그인, 관리자 RBAC, 문의/채팅, 은행/송금/예금/주식, 계획된 180개 화면/이미지/파비콘, 콘솔 오류·로그·재기동·복구·부하 점검. 요청 ID·시간·스크린샷·검증자·실패 건수 증거 보관.
6. **T5 운영 승격:** 독립 검토자, 보호 규칙·필수 체크·승인. 관리자 우회/강제 푸시/자가승인/자동 운영승격 금지. 운영 백업 및 복원 리허설, 원장 대사, 실제 테스트 서버 승인, 정확한 아티팩트, 카나리/블루그린 무중단 전환, 관측 및 자동 롤백 준비. health 200만으로 승인 금지.
7. **T6 즉시 중단:** 운영 DB 접근·내부포트 외부 노출·SHA 불일치·인증/관리자 권한 오류·원장 불일치·비밀정보 노출·검증 누락·불명확한 소유권·백업/복원 실패 중 하나라도 있으면 운영승격 **BLOCKED**.

## 실제 환경 확인 지침
권한 있는 미니PC에서 읽기 전용으로 `ss -ltnp`, `systemctl list-units --type=service --state=running`, `nginx -T`, `systemctl show`를 실행하여 4550/3100/3101 담당 PID, 포트, 프록시 경로, 유닛, 빌드 SHA를 교차 검증한다. 결과에서 계정/비밀/호스트 정보 제거 후 기록. 서비스 조정이나 방화벽 변경은 별도 롤백 계획 및 검증 후에만.

**현 상태:** 미니PC 원격 장치 오프라인. 본 문서는 정책 제안이며 실제 서버 적용·테스트 성공·운영 승격을 의미하지 않는다.
