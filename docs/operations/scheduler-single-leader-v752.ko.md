# 스케줄러 단일 리더·격리 실행 지침 — v2026.10.17.752

**상태:** 소스 구현 및 로컬 테스트, **실제 운영 승격 미실시**. [영문 정본](scheduler-single-leader-v752.md).

## 실제 발견한 문제
v751 정확한 main 소스의 개인용 섀도 테스트 백엔드를 `NODE_ENV=test`, **271개 마이그레이션을 적용한 합성 전용 격리 DB**로 구동했으나, 개별 SWF·ticker·AI·Discord 작업 플래그가 꺼져 있음에도 전체 스케줄러가 실행됐다. DB 작업 2건이 오류를 기록해 해당 격리 프로세스를 즉시 중단했다. 공개 Test·운영 및 실제 회원 DB는 변경하지 않았다.

## 개선 규칙
- `MONEYVERSE_SCHEDULER_ENABLED=true`이고 `NODE_ENV != test`인 경우에만 범용 스케줄러 실행. 설정 누락·false·다른 값은 기본 중단. Test는 flag가 true여도 실행하지 않는다.
- 실제 운영에서 검증된 **단일 작업 리더**만 명시적으로 실행 허용. Test·섀도·카나리·신규 교체 세대·기존 중복 운영 세대에서는 중단 상태 유지. 작업 리더의 DB 역할·현재 버전·권한을 독립 확인 후 지정한다.
- 이 변경은 일반 SchedulerModule 범위이며 별도 cron, SWF, ticker 등 모든 작업기를 자동으로 제한하는 것은 아니다. 각각 리더 소유권을 확인해야 한다.
- 미확인 초기 원장 19건·금융 5개 테이블 권한·v530 전체 인증 UI·정확 SHA 테스트·세션·무중단 롤백은 별도 필수 조건. 소스 통과를 운영 승인이라고 표시하지 않는다.

## 검증
TDD 수정 전 신규 3건 실패, 수정 후 5/5 통과, 관련 15/15, 전체 백엔드 1,235건 통과(금융 DB 의존 396건 건너뜀), Nest 빌드 성공. 운영·Test 환경파일, 기능 플래그, 데이터베이스, 릴리스·Nginx는 수정하지 않았다.
