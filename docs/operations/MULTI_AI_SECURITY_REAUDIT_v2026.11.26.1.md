# Multi-AI repeated security review — v2026.11.26.MULTIAUDIT.1

**English canonical** | [한국어](MULTI_AI_SECURITY_REAUDIT_v2026.11.26.1.ko.md)

Owner direction: repeated independent security testing by multiple AI families. Supplement TESTGATE.1 and the Security Assurance Master Plan; applies to both Moneyverse repositories, all agents and scheduled QA. This policy candidate does not itself enforce runtime gates or authorize deployment.

1. Freeze exact candidate SHA, artifact digests, dependency versions, scope and threat/coverage ledger. Use Cloudflare security-audit deep profile for release-wide/high-risk reviews; explicitly mark bounded quick reviews partial. Budget for reconnaissance, critics and independent verifiers before starting.
2. Require at least three independent initial review passes across GPT/Codex, Claude and Gemini (or owner-approved equivalent independent reviewers if unavailable). Use separate contexts and read-only source views, no prior reviewer conclusions during initial discovery. Author review is supplementary, never independent approval. Scope all trust boundaries including auth/session, OAuth, admin, WebSocket lifecycle, BFF, finance/ledger, database grants, injection, privacy, dependencies and infrastructure.
3. After initial reports, deduplicate root causes, exchange sanitized evidence and independently challenge every candidate; a fresh non-author verifier establishes scope and outcome. Preserve unresolved/needs-validation and rejected evidence with reasons. Use isolated dummy principals and local fixtures; no live production discovery or credentials in prompts. Keep sensitive details private.
4. Fix in an owned branch; rerun negative/regression cases on the exact new SHA. Run at least two independent post-fix review passes (different model families, at least one non-author), including affected and adjacent trust boundaries; repeat if a new confirmed finding, material source change or coverage gap appears. Run final coverage-critic pass, and continue discovery for gaps within approved budget. Budget exhaustion = incomplete/HOLD, never automatic PASS.
5. Combine with SAST/SCA, secret scanning, dependency/SBOM, isolated real DB, authorization matrix, safe Test integration QA, and applicable browser/device tests under TESTGATE.1. No AI consensus substitutes for evidence. Critical/high unresolved, required missing evidence, unavailable independent reviewer, mismatched SHA or unverified isolation/lease = HOLD. Never infer whole-system security from zero findings.
6. Only the designated QA publisher with shared exclusive lock can publish official Test. Preserve independent review, exact artifact, rollback and separate owner Production approval. Record run ID, model/family, timestamps, scope, SHA, findings dispositions, test counts, skips, coverage gaps, and status. Public EN/KO records sanitized; no secrets or exploitation details. No automatic Production promotion.

Current blockers: Gemini skill discovery works but review timed out; Claude-triggered Codex review is ongoing at inspection; shared QA publisher/lease not certified. Do not claim three-model or full repeated audit completion until evidence exists.
