# 데이터베이스 마이그레이션

[English](database-migrations.md) | **한국어** | [문서 색인](../INDEX.ko.md)

데이터베이스 마이그레이션은 `packages/database/migrations/` 아래의 순서가 있는 SQL 파일입니다.

## 규칙
1. Test 또는 Production에 이미 적용된 마이그레이션은 절대 수정하지 않습니다.
2. 새로운 동작은 새 순번 마이그레이션으로 추가합니다.
3. 작업 의미상 정말 허용되는 경우에만 멱등성을 적용하며 드리프트를 숨기지 않습니다.
4. 새 `SECURITY DEFINER` 함수를 추가할 때 함수 권한 revoke/grant를 명시적으로 설정합니다.
5. 업그레이드뿐 아니라 새 데이터베이스 설치 동작도 검증합니다.

## 체크섬 강제
배포 실행기는 마이그레이션 파일명과 SHA-256 체크섬을 기록합니다. 과거 마이그레이션의 체크섬이 달라지면 배포를 중단합니다. 이는 스키마 이력을 결정적으로 재구성할 수 없다는 안전 경고입니다.

## 새 데이터베이스 테스트

```text
빈 PostgreSQL 17.11
  ↓
모든 마이그레이션을 순서대로 실행
  ↓
백엔드 DB 테스트 실행
  ↓
권한 / 불변조건 / 정책 값 검증
```

이미 업그레이드된 운영 데이터베이스에서는 보이지 않는 드리프트를 찾는 데 유용합니다.

## SECURITY DEFINER 체크리스트
- 필요한 경우 안전한 `search_path` 설정
- 함수 내부에서 행위자/역할 검증
- 기본 PUBLIC 실행 권한 제거
- 의도된 런타임 역할에만 권한 부여
- 금액을 기준 텍스트/문자열 타입으로 반환
- 권한 있는 호출자와 없는 호출자를 모두 테스트
