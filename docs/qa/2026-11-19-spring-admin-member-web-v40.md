## Verified risks and tradeoffs

1. Live mini-PC Spring 4550 (BEFORE our candidate) returns anonymous HTTP200 on `/admin`, `/admin.html`, `/admin/analytics`, `/admin-preview`, but non-admin API `/api/v1/admin/users` returns HTTP401. New gate covers **Spring** HTML alias paths, not installed on live runtime. Public `https://easy-scraping.com/admin` already redirects to login. Full public edge paths and port exposure are not independently certified.
2. The historical `AdminGovernanceService` uses a fallback actor if its argument is null; the new controller **never passes null**: verified DB admin actor required first. API security must still undergo independent audit; not claimed fixed by this UI.
3. Old `admin.html` includes fictional user count/treasury data and runtime information. New canonical `/admin` never embeds that file; `/admin.html` and preview aliases redirect after verifying admin session. Other old admin pages may still contain sample displays, so each remains its own source-truth gate.
4. Admin `listUsers(50)` is a **capped source subset**, never a total user count. An empty valid list can show `0` as **records returned only**; source outage is `Unavailable` and HTTP 503, not zero. No chart points or WLD asset totals are manufactured.
5. Visual desktop/mobile screenshots are marked fixture-only. XSS escapes verified in Java unit test; no real PII or real money values are in screenshots or GitHub docs. Locale preference may persist; auth credentials, personal/financial data never cached in JavaScript.
6. PR #3302 separately fixes wallet/fail-open errors and reports 243/243 Spring pass, but is draft/unmerged and needs signed integration. v40 is intentionally independent of this teammate's Java/security/Nginx changes.

**Release decision: HOLD** until complete admin/member authenticated Test/DB/roles/source matching, all mandatory API + visual regression tests pass, official Test 403 resolved legitimately, exact merged candidate source attested, independent backup/rollback exercised, and main/Gemini ownership coordinated.
