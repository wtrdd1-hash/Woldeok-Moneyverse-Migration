# v2026.11.20.42.3.1 — 사용자 신고 프론트엔드 UI 깨짐: 긴급 롤백·시각 재검증·운영 재승격

**핵심: 모바일·PC 반응형 회원 웹 홈만 운영 적용 완료. 전체 관리자·금융 Java/API와 약 180개 전체 경로 승격은 아님.** Android/iOS 앱 작업 아님.

## 발생·원인·즉시 복구

- 사용자가 v42.2 운영 배포 직후 **UI 화면 깨짐** 스크린샷 신고. 기존 브라우저 테스트는 HTTP200·가로 넘침·JS 오류·언어 메뉴를 확인했으나 **승인 디자인과의 시각적 배치 차이**는 검증하지 않았음. 모바일 로그인 전 카드 3개가 거대하게 세로 반복, 바로가기 6개가 단일열, 760px 표는 가로 스크롤, 우하단 플로팅 문의 버튼이 다른 버튼을 덮음.
- 초기 Nginx 배포 시 기존 운영 `location = /` 중복으로 `nginx -t` 거절 → 자동 이전 설정 복구. 두 번째 시도는 잘못된 `alias`로 index.html 이름이 두 번 추가되어 실제 HTTP500 발생 → 헬스체크 감지 자동 복구. 이후 최초 v42.2 배포는 기술검사를 통과했지만 사용자 시각검증에는 실패.
- **2026-11-20 08:47 KST** 사용자가 UI 깨짐 신고한 후 새 홈 즉시 운영 롤백. Nginx SHA `1181941...` → 직전 정상 설정 `161cbce538be78d4ed666e6b2c62141caf3694a18923644c388e8b1dda70d5b9`. `nginx -t`·무중단 reload·실제 HTTPS 홈200/관리자302/API401 확인. 기존 홈에 있던 **가짜 100조 WLD·+2.41%·회원 12,840명·활성 1,420회**도 재확인했기에 임시 복구일 뿐 최종해결로 판정하지 않음.

## 수정 및 운영 적용

- 별도 브랜치 `fix/member-mobile-visual-v2026.11.20.42.3`에서 승인 UI 참조 재확인 후 회원 홈 카드 1+2 배열, 빠른 작업 2열, 작은 화면 줄바꿈/44px 터치, 로그인 링크 중복 최소화.
- 주식 표는 **실제 운영 `/api/v1/stocks` 데이터 기반** 모바일 카드 8개(종목/이름/정확한 가격/등락)로 표시하고 PC에는 상세 표 유지. 국고·자산 변화 가짜 그래프 생성 금지. 운영 구형 게시판 가짜 `post-wld-*`는 UI에서 차단해 조회 불가로 표시.
- 가려지는 플로팅 문의 버튼은 모바일/태블릿에서 숨기고, 같은 기능의 문의·채팅 빠른실행 버튼은 그대로 유지. CSS·JS 주소에 `v2026.11.20.42.3.1`을 붙여 이전 캐시와 충돌 방지.
- 실제 외부 HTTPS 사용자 홈 재승격. v42.3 적용 후 추가 겹침 발견해 v42.3.1 수정. v42.3.1 최초 배포 스크립트에서 경로 버전이 `.1.1`로 중복 생성된 오류를 **공개 파일 해시 검사로 감지하고 자동 이전 버전 복구**. 스크립트 수정/정확한 경로 검증 후 v42.3.1 정상 배포.
