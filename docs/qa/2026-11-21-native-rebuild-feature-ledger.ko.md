# 현재 네이티브 프론트엔드 전체 경로 점검표

현재 상태는 **진행 중**입니다. 소스 경로180개(정적147/동적33/관리자40)는 기능 성공180개가 아닙니다. 모든 경로의 전체 기능 수용은 OPEN입니다.

공개 화면은 승인된 긴급 점검 안내를 유지합니다. 별도 보호 경로의 관리자 상점 미리보기만72714c3efd로 실행 중입니다. 실제40개 화면 크기·언어 조합과 메뉴·도움말·새로고침을 확인했지만, 기존 API가 정식 카탈로그 규격과 맞지 않아 정상 목록·검색·상세 성공은 BLOCKED이며 저장 작업도 미수용입니다. [실제 배포·브라우저 기록](../releases/2026-11-21-native-admin-rebuild-preview.ko.md).

[180개 전체 경로 표](2026-11-21-native-rebuild-feature-ledger.md)와 [기계 판독 원장](2026-11-21-native-rebuild-feature-ledger.json)에 경로별 코드 파일, API 문자열, HTML 컨트롤러 후보를 기록했습니다. 후보만으로 선택된 실행 구성이나 권한·실데이터·저장 성공을 증명하지 않습니다. 문자열이 동일한 경로만 대응하며 Next의 [id]를 MVC의 {id}로 정규화하지 않습니다. 후보가 비어 있다는 이유만으로 구현이 없다고 단정하지 않습니다. 동적33개는 실제 테스트 fixture가 지정되기 전까지 미검사입니다. 비공개 사용자·금액·쿠키·응답 본문은 포함하지 않습니다.

이번91f753bf8b 소스에서 기존 도구를 재실행했습니다. 이전166개 inventory 및 v30의180개 VERIFIED_PASS/HTTP200 표는 현재 기능 수용 근거로 사용하지 않습니다. 공개 공지·갤러리 통합 소스 Spring659/Node539개 검증은 통과했지만 PostgreSQL24개는 로컬 대상에서 제외되어 실제 CI를 기다립니다. 앞선 카탈로그 소스의 PostgreSQL18개는 별도 main CI44920156614에서 성공한 기록입니다. 문서 작성으로 신규 배포가 이뤄지지 않았습니다.

경로마다 남은 검사: 역할·fixture, 실제 실행 컨트롤러/API/DB 함수, 모든 버튼·입력·검색·탭, 로딩·빈 목록·오류·권한 상태, 금액 문자열 대조, 저장 영수증·재시도·다른 사용자 거부,5개 언어·8개 너비·200%확대·키보드, 동일 산출물의 독립 Test와 복구 절차입니다. 화면별 기능을 추적하기 전 저장 작업을 임의로 해당 없음 처리하지 않습니다.


PR3351은925f725d28로 병합됐습니다.91f753bf8b의 CI44923868917 네 검사와 후보 빌드44923833095가 성공했고 실제 PostgreSQL 작업과 카탈로그4·공개 게시물6개의 XML 누락/실패/제외 차단 게이트가 통과했습니다. 로그에 직접 인쇄된 문의9개 결과는 실패0/오류0/제외0입니다. 나머지 클래스별 개수는 출력되지 않아 로컬 검사를 실제 DB 결과로 바꿔 세지 않습니다. 동일 main의 새 CI/산출물과 실제 브라우저 수용은 별도입니다.
