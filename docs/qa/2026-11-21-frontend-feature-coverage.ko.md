# 프론트엔드 기능 지원 행렬 — 조사 착수

현재 신규 운영 공통 셸은 관리자 조회9개·공개5개이며 전체 기능 지원이 아니다. [정적 소스 참조 원장](2026-11-21-frontend-feature-coverage.json)은 Next page 후보 180개와 Spring HTML mapping 후보 79개를 수집했다. 동적 fixture·import·서버 action·API 문자열은 실제 동작 증거가 아니므로 기본 NOT_RUN/UNVERIFIED다. route 개수나 export/form 수를 지원 기능 수로 계산하지 않는다.

| 영역 | 확인된 현재 지원 | 미완료/추가 확인 |
|---|---|---|
| 관리자 신규9 | 실제 조회·회원 검색·로그 필터·공통 셸 | 변경 작업/다른 관리자 기능은 별도 검증 |
| 공개 신규5 | 홈/도구 허브/두 계산기·실제 favicon | 도구 로그인 헤더 연결 |
| 미활성 신규 stocks/shop/board | 코드상 시세·카탈로그·게시물 조회 후보 | 매매·구매·작성 전체 대체로 승격 불가 |
| wallet | 소유자·잔액·이체 증거를 검사하는 전용 소스 | 실제 API 계약/세션/운영 연결 |
| support/chat | owner header·세션 변경·중복키 방어와 입력 UI 소스 | 현재 edge403; 실제 연결 및 Test DB/브라우저 검증 |
| account/security | 기존 Next 설정·연결·재인증·개인정보 action 소스 | 현재403; 축소 프로필로 대체하지 않음 |
| API 관제 | 기존 API에 고정 정상 수치/실패 무시 결함 확인 | 실제 원천 조회 점검으로 교체 필요 |

기능별 실제 버튼·탭·입력·조회·서버 응답·변경 수용은 후속 브라우저/계약 기록으로 구분한다.
