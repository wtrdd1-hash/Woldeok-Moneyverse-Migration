# 광고 표시 및 경로 QA — v2026.11.23.11

## 기준
AD_ONLY_ADVERTISING_REVENUE_SPEC.ko.md 및 RETENTION_SAFE_MONETIZATION_GROWTH_SPEC.ko.md 기준: 광고는 충분한 자체 가치가 있는 공개 콘텐츠에만 표시한다. 은행·지갑·주문·카지노·로그인·관리자·비공개 채팅·동의 화면은 광고 차단. 실제 광고 공급 실패 시 가짜 광고를 만들지 않는다.

## 변경 내용
- 기존 Google AdSense를 사용. EN/KO/JA/ZH/VI 각 언어에 맞는 명확한 광고 라벨을 표시.
- 광고 영역에 눈에 띄되 과하지 않은 테두리·배경·여백을 사용하여 게임/금융 버튼과 구분.
- 한국어·베트남어 공개 URL에서도 승인된 블로그·가이드·계산기 광고 정책이 적용되도록 누락된 locale 처리 수정.
- 기존 관리자의 광고·광고 스크립트 제외, 거래·보안·계정 페이지 광고 제외 및 미충전 슬롯 숨김 유지.
- 유료 광고 소재/노출·수익을 합성하거나 확정했다고 주장하지 않음.

## 테스트
- 선택 단위 테스트 55개 전부 통과, 계약 패키지 빌드 후 TypeScript 타입 검사 통과.
- 실제 Google fill/브라우저/동의/CLS, 운영 중 Spring 네이티브 화면과 광고 컴포넌트 연결, Test·Production 승격은 미검증.
- 게임형 이미지 시안에는 공개 허용 콘텐츠의 핵심 정보 뒤에만 광고임을 밝힌 별도 슬롯을 표현할 것. 실제 광고주 소재를 발명하거나 은행/관리자/주문 화면에 광고를 넣지 말 것.
