# 개발 C v1130 — IndexNow 변경 알림 접수 증빙 검증

## 확인된 문제
최신 main의 관리자 SEO 수동 제출 화면은 `success: true`만으로 검색엔진 접수 성공을 표시했습니다. Next.js 게이트웨이도 응답 증빙을 확인하지 않고 HTTP 200을 전달했습니다. 실제 색인 성공을 뜻하지 않습니다.

## 변경
기존 인증·CSRF가 적용된 NestJS API를 그대로 사용하면서 검색엔진 3곳의 고유 응답, 200/202 접수, 제출 URL, 응답 시각, 중복·위조 결과를 검증합니다. 증빙 불일치는 HTTP 503, 전부 미접수는 HTTP 502로 표시합니다. 브라우저에는 확인된 접수 건수만 안내하며 검색 색인을 보장하지 않습니다. 금융·DB·외부 크롤러·운영 환경은 변경하지 않습니다.

## 배포
독립 브랜치에서 검증하며 필수 CI·보안·공식 exact-SHA Test E2E와 GitOps 승인 전 병합·운영배포를 금지합니다. P0 백업 사고 #1718은 미해결입니다.
