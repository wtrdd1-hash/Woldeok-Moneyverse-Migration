## 2. 영상이 소개하는 기능

AgentMemory는 개발 작업 세션의 기록(Capture), 이전 결정 검색(Recall), 다른 도구·세션에서 이어 하기(Continue), 내용 검토/수정(Inspect)을 목표로 하는 외부 오픈소스 기억 저장 시스템이다. 릴스는 MCP/HTTP 기반 여러 CLI 도구의 공유를 소개하며, README는 API 키 없이 키워드 검색하는 경로를 설명한다.

**중요:** 개발 기억이지 실제 금융 원장·회원 프로필 DB·권한 확인 데이터·Git 저장소·승인된 통합 기획서를 대체하지 않는다. 영상의 GitHub 별 수·벤치마크는 외부 게시자의 수치이며 독립적으로 검증하지 않음.

## 3. 지금부터 적용할 공통 작업 기록 프로토콜

설치 여부와 무관하게 모든 후속 머니버스 작업에 적용한다.

1. **착수 전:** `origin/main` 최신화, `docs/planning/PROJECT_PLAN.md` 및 `docs/planning/INTEGRATED_PLANNING_MASTER.md` 우선 열람, 관련 보안 규칙·최근 작업기록 검색. 다른 AI와 공유하는 원본 브랜치를 건드리지 않고 별도 브랜치/워크트리를 만들며 **실제 수정 전에** 영·한 작업로그 작성.
2. **기억 기록:** 요구·승인 조건, 현재 SHA, 파일 담당자/브랜치, 결정 사유, 수행 조치, 민감정보를 제외한 검증 명령, PASS/FAIL과 미해결 사항을 날짜·버전별로 안전하게 기록.
3. **중간 점검:** 최신 main과 통합 문서를 재확인. 다른 작업자의 수정과 비교, 기록·브랜치 업데이트를 푸시. 기억 속 옛 결정으로 최신 소스를 덮어쓰지 않음.
4. **다음 세션 재조회:** 이어받을 작업의 요약을 다시 읽고 **실제** main SHA·코드·CI·Test/운영 증거와 대조. 기억은 검색 보조정보이지 최신 운영 증거가 아님.
5. **종료:** 최종 SHA·PR, 테스트 결과, 실패와 보류, 배포 여부, 다음 단계까지 기록. 유지 문서는 영어 우선·한국어 두 번째로 함께 작성.

AgentMemory의 독립된 보안 검토·설치·연동 검증 전까지는 **GitHub 작업로그 + 통합 기획서가 영구 공유 기억의 실제 수단**이다. 아직 자동 수집이나 MCP 기억 서버가 동작한다고 표현하지 않는다.

## 4. 개인정보·보안·충돌 방지

- **절대 기록 금지:** 비밀번호, API 키, 각종 토큰·쿠키·세션 ID, 비밀 주소·DB 접속 정보·SSH 개인키, 터미널의 비밀값, 회원/관리자 개인정보, 실제 금융 원장 상세, 개인 메시지·문의 원문.
- 기록 허용 항목을 제한하고 **저장 전에** 가림 처리. 모든 새 기억 및 내보내기에 비밀검사 적용. 외부 프로그램 자체의 비밀값 제거 기능만 믿지 않음.
- `~/.agentmemory`, 기억 DB·인덱스·임베딩·원본 대화/HTTP 덤프를 Git과 공개 웹 폴더에 저장 금지. 추후 저장소는 별도 보호 폴더, 최소 접근권한.
- 미검증 원격 HTTP 공개·외부 AI 공급자 전송·자동 수집 훅·원격 모델 다운로드는 기본 비활성. 외부 접근 보호, 삭제·보존, 백업·복원 기능부터 검증.
- 프로젝트별·테스트/운영별 기억을 분리하고 실사용자의 금융 정보는 개발 기억에 넣지 않음.
- 공동 기억은 동시수정 잠금이 아니다. 파일 담당권, 분리 워크트리, SHA 확인, CI와 PR 직렬 통합으로 충돌 차단.
- 운영 미니PC에서 검증되지 않은 `npx ... @latest` 자동 실행 금지. 정확한 버전과 설치 스크립트/의존성/라이선스를 검토한 뒤 격리된 테스트에서 시험.

## 5. 단계별 도입 승인 기준

| 단계 | 통과 조건 | 현재 |
| --- | --- | --- |
| R0 원본 | 게시자·원본 링크·출처가 검증됨 | PASS: 설명 메타데이터와 공식 README |
| R1 보관 | EN/KO 규칙·통합 문서·에이전트 규칙 링크 | 별도 문서 브랜치 후보 |
| R2 격리 설치 | 버전 고정, 미니PC 비운영 계정, 로컬 전용 서버 | 미시작 |
| R3 보안 | 비밀값 차단 시험·저장 권한·외부 통신 거부 | 미시작 |
| R4 공유 | 개인정보 없는 합성 결정으로 다른 AI 2개에서 기록·검색 | 미시작 |
| R5 복원 | 재시작·백업·복원·삭제·만료·충돌 시험 | 미시작 |
| R6 정식 채택 | 검토·문서 병합·실제 각 에이전트 연동과 동작 증거 | 미검증 |

**실제 변경 범위:** 이번 작업은 문서만 수정한다. 기억 서버 설치, 앱 소스 수정, Test/운영 배포, 금융 DB 접근은 하지 않는다. 실제 자동화는 별도 검증이 필요한 후속 단계다.
