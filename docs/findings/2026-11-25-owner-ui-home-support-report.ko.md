# 사용자 제보 UI 결함: 홈 명칭과 고객센터 시간

## 확인 범위

사용자 제공 화면을 관찰하고 프론트엔드 브랜치 `origin/fe/next-spring-test-connect-20261124`의 `c154bfc27a2627bd303dbde3e080fe36a087b677`와 대조했다. 화면이 어느 서버나 배포 SHA에서 제공됐는지는 확인되지 않았다. 스크린샷의 계정 잔액, 문의 내용 및 개인정보는 기록하지 않는다.

## UI-01: 홈 화면의 길드 명칭

- 관찰: 사이트 홈 제목과 상단 경로에 “길드 홀”, 공지 영역에 “길드 공지”가 나타난다. 사용자가 해당 명칭에 이의를 제기했다.
- 코드 근거: `frontend/src/app/page.tsx:159`, `:256`, `frontend/src/components/v10-nav.ts:144`에서 홈과 공지 명칭을 고정 문자열로 지정한다.
- 영향: 홈과 별도 길드 기능의 구분이 불명확하다. 고정 문자열의 언어별 표시도 점검해야 한다.
- 상태: OPEN. 올바른 제품 명칭과 전체 언어 계약은 기획 기준으로 확정 필요. 코드 수정 및 배포는 수행하지 않았다.

## UI-02: 고객센터 문의 목록에 NaN일 전 표시

- 관찰: 고객센터 1:1 문의 목록의 상대 시간에 “NaN일 전”이 표시된다.
- 코드 근거: `frontend/src/components/floating-support-chat-widget.tsx:207`의 `formatTimeAgo`는 날짜 변환 결과의 유효성을 확인하지 않고 일수를 계산한다. 유효하지 않은 날짜는 JavaScript에서 예외 없이 NaN이 되므로 catch에 도달하지 않고 해당 텍스트를 만들 수 있다. 문의 목록의 호출 위치는 같은 파일 `:1340`이다.
- 미확인: 실제 응답의 날짜 필드 값과 배포 버전은 확인하지 않았으므로, 이 코드가 제보 화면의 정확한 실행 코드인지와 입력 데이터가 왜 유효하지 않았는지는 확정하지 않는다.
- 상태: OPEN. 재현 시 시간 값의 누락·형식·시간대 및 API 필드 매핑을 확인하고, 정상·빈 값·잘못된 날짜를 각 언어에서 검증할 것. 문의 내용이나 계정 정보는 증거에 저장하지 말 것.
