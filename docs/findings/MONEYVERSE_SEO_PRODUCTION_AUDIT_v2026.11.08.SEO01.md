## Findings, severity and source evidence
1. **P0 — Repeated blog article titles:** Of 53 live article URLs, **50 occur in 11 multi-URL exact-title clusters**; examples: KR computer title x7, US coding x7, US economy x6, JP coding x6, JP computer x6. The source directly defines one title for each country x topic combination (12 fixed titles): `backend/src/blog-editorial/blog-original-author.ts`, `countryTitles[slot.country][slot.topic]`. Existing `blog-duplicate-review.ts` contains exact-title screening, but the observed publishing pipeline accepted duplicate titles; integration/coverage must be fixed, not merely rename old pages. Use per-article verified facts, topic and unique title and H1, suppress publication on title collision; regenerate and re-evaluate existing live posts for near-duplicate intent, content and original-source adequacy.
2. **P0 — Test-labelled article publicly discoverable:** `/blog/2026-10-29-kr-compound-97a4ea4f` is HTTP 200, `index,follow`, self canonical, and listed in /sitemap-blog.xml; title includes “테스트 복리 전략”. Review editorial legitimacy, withdraw if it is a test, remove from sitemaps, and return appropriate noindex/410 once content policy decides. Do not delete financial/other data by inference.
3. **P1 — Robots/sitemap contradiction:** `/account-deletion` and `/businesses/ventures` are listed in /sitemap.xml and /sitemap-static.xml, HTTP 200 and `index,follow`, while `robots.txt` disallows paths starting `/account` and `/businesses`. Fix source route-policy invariant: either make publicly intended URLs crawlable or remove/noindex their private-only equivalents. Verify every sitemap against effective robots.txt and HTTP metadata.
4. **P1 — Static lastmod metadata stale/inconsistent:** All 1,017 `sitemap.xml` entries report **2026-10-24**, all 62 `sitemap-static.xml` entries **2026-10-11**, while the sitemap index's non-blog lastmod refreshes to current request time, even without a verified page change. `frontend/src/app/sitemap.ts` has a release date fallback; `frontend/src/app/sitemap-index.xml/route.ts` emits `new Date()` for five sitemaps. Use actual per-resource change or authoritative release manifest timestamps, not request time. Blog per-post dates vary appropriately in sample.
5. **P1 — Multiple sitemap listings:** 59 URLs overlap between primary and static sitemaps. Not an automatic penalty; eliminate redundant sitemap declarations where appropriate and maintain one auditable index topology.
6. **P1 — Search-result presentation:** 51 of 53 articles have meta descriptions longer than 160 characters, usually model prose excerpts up to ~290; Google may use its own snippets, so this is not a numeric ranking penalty. Produce concise, unique summaries that accurately describe each page. The /en/blog rendered title repeats “Woldeok Moneyverse” twice.
7. **P1 — Content quality and pSEO:** The 53 article bodies sampled have a median ~3,943 rendered article characters; length alone is not a quality score. Prioritize specific problem statements, runnable code examples when applicable, primary citations in context and usefulness over fixed educational headings. Audit the 738 /tools programmatic URLs for unique user intent, truthful examples and meaningful differentiation; no thin-page verdict from sitemap count alone.
8. **P2 — Publication reliability:** systemd `moneyverse-verified-blog-v1419.timer` includes an even-hour publishing attempt and retries. A 22:07 KST attempt failed with `ARTICLE_QUALITY_HOLD:NUMERICAL_CLAIMS_NEED_INDEPENDENT_PROOF`; a 22:46 retry recorded `PUBLISHED` for the 22:00 JP coding slot. Retain fail-closed source/quality policy; do not bypass rejection merely to increase volume.

## Recommended acceptance gates
- **P0:** no new duplicate title; no public test content; review historical duplicates before IndexNow/sitemap publication, retain evidence-backed article verification; no fake financial claims.
- **P1:** robots vs each sitemap URL vs final HTTP robots/canonical 100% agreement; truthful lastmod; EN/KO/JA/ZH metadata and hreflang; Search Console owner-authorized 30-day baseline by country, query and page; real Core Web Vitals, indexing errors and CWV p75.
- **P1:** per-country/topic editorial keyword map derived from actual query demand; unique articles, context links, citations, useful calculator/blog interlink, source-aware FAQ/schema only when visible and eligible.
- **Safety:** engineering fixes require separate feature branch, TDD and CI, independently verified exact-SHA Test/backend/edge and zero-downtime production promotion only after authorized gates; no rollout or DB write was performed by this audit.
