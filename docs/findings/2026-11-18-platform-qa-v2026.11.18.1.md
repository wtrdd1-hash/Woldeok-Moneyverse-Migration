## Root-cause directions (evidence, not speculative fixes)
1. Authentication: Spring's global fail-open web rule and controller-level weak gate require verified session, role, CSRF and owner-scoped DB check. Do not publish reproduction values.
2. Rendering: auth-dependent Next server components were exported as static HTML containing error placeholders; serving static snapshots does not recreate authenticated SSR semantics.
3. Contract: reconcile Java SQL to canonical DB function arguments and return columns. On DB error, fail closed and never synthesize financial/catalog data as if authoritative.
4. Delivery: restore fully isolated exact-SHA official Test app endpoints, rather than interpreting green health on a different upstream as passing Test.
5. Integrations: Discord voice join and reconnect must be tested against authorized guild channels before declaring restored.
