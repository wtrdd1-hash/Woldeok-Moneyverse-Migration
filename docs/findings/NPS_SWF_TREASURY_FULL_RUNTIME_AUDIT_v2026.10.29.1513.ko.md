## 실제 실행 테스트
- 국민연금 백엔드 **47/47 통과**, 프런트엔드 **21/21 통과**. 이는 중단 상태와 UI/계약 테스트 결과이지 실제 지급 성공이 아님.

## 조치 순서
1. **최우선 P0**: 리밸런싱과 수동 회수의 Nest/Next/서비스를 원장 인증 전 503으로 차단하고, 성공 시각·이벤트·알림을 만들지 않게 수정. 펀드 설정상 활성 상태와 실제 운용 상태 분리. 기존 다른 개발자의 미병합 PR과 충돌 방지.
2. **P0 금융 증빙**: 국민연금 과거 238 지급과 98 무원장 내역의 재원 확인, 국고 현금 0과 과거 금고 기록 출처 확인. 임의 조정분개·가상 지급·권한만 추가하는 우회는 하지 않음.
3. **P1 연금 수리 재설계**: 연간 7~10.5% 표기와 시간당 8~12bp 공식 중 경제 계약을 하나로 확정하고 1 WLD 최저지급·95/5 환급·평생부채·안전자금 적용.
4. **P1 UI/API**: 공개 데이터 장애 시 가짜 값 제거, 허위 확정 지급 문구 제거, 회원 조회 GET의 계좌 생성 부작용 분리, 연금/펀드 조회 증빙을 본인/관리자별 검증.
5. 최신 정확 SHA 격리 PG·회원/관리자 로그인 인증 테스트, 원장 균형, 백업·복원, 전체 CI 및 무중단 테스트 서버 절차를 완료한 다음에만 배포.
