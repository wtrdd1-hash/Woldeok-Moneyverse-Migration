## 4. Heuristic hits explicitly NOT confirmed as vulnerabilities

- 695 SECURITY DEFINER pattern occurrences are raw syntax hits, **not** 695 unsafe functions. Owner/search_path/ACL and live DB role grants still need server-side privileged negative tests.
- Static GRANT EXECUTE to PUBLIC in historical migration 114 for profile_get_cosmetics is **superseded by migration 125**, which revokes PUBLIC. Do not register this old line as a current exploit without measuring actual ACL.
- 26 apparent SQL interpolation candidates are in backend *.db.test.ts test utilities, not established runtime SQL injection. Four eval hits are inside theme tests. 116 dangerouslySetInnerHTML hits need input-provenance review, not an automatic XSS count.
- 32+ method-route authorization heuristic candidates include endpoints delegating to backend-enforced authorization; a pattern absence does not prove a security bypass.
