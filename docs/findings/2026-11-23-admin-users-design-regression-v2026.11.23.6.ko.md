## 근거 및 보안 처리
2026-11-23 사용자가 **추가 제공한 스크린샷**의 주소창에는 `https://easy-scraping.com/admin/users`가 표시됨. 서버 상태, 인증 권한 및 백엔드 API를 실제 접속해 검증한 기록은 아님. 화면에는 회원 표시명·UUID가 보여 **원본 스크린샷 및 개인정보를 GitHub에 공개 업로드하지 않음**. 아래는 비식별화된 화면 구조 기록만 남긴다.

## 관찰된 디자인 불일치
- 상단 `WOLDEOK / ADMIN` 텍스트와 기본 링크형 메뉴가 보이고, 승인한 공식 W 로고·네이비/보라 관리자 공통 헤더·사이드바 구조와 다름.
- `Member directory` 목록이 단일 기본 표 중심이며 역할별 관리자 메뉴·일관된 컴포넌트·통합 지원/채팅 진입 UI가 스크린샷에서 확인되지 않음. 보라 버튼과 네이비 배경만 유사하다고 통일 UI 적용 합격 금지.
- 가입일이 원본 ISO-8601 시각 문자열로 보임. 현지 시간/언어 맞춤 표시, 모바일 표 및 긴 이름·ID 표기 검증 필요.
- 검색 안내에 **첫 제한 수의 원천 레코드만 검색**한다고 명시. 전체 회원 검색인 것처럼 안내하지 말고 검색 범위·페이지네이션·정렬·전체 수/결과 수·보안에 대해 별도 API/화면 QA 필수.
- 이번 증거는 PC 캡처 한 장임. 모바일 320/360/390/430px, 태블릿, 200% 확대, 키보드/스크린리더, EN/KO/JA/ZH/VI, 로딩·빈 결과·오류·403 등은 **아직 미검증**.

## 시정 및 정밀 QA 필수
1. **공식 선택 v2026.11.23.3 디자인**의 공통 W 헤더·관리자 사이드바·검색·언어 선택·단일 문의/채팅 런처 및 역할별 메뉴를 적용할 것.
2. 회원 목록의 실데이터 출처·검색 범위/정렬/페이지네이션, 이름·ID 노출권한, 안전한 필터·상태 표시, 원본 시간의 현지 변환을 검증할 것.
3. PC/모바일 8개 뷰포트, 긴 5언어 문장, 접근성, 화면 확대, 가로 스크롤, 빈 목록·서버오류·권한거부까지 시각 회귀 테스트할 것. QA 캡처는 이름·UUID·세션 값을 마스킹하고 안전한 더미/테스트 회원으로 시행할 것.
4. Spring MVC+Thymeleaf 격리 테스트 환경에서 실제 기능/권한/API QA 후 정확 SHA·복원 계획을 검증해야만 무중단 운영 반영 가능.

## 판정
**디자인 불일치(스크린샷 근거) / 기능 정밀 QA 미실시 / 수정 코드 미적용 / 운영 검증 미실시.** 이 기록은 실제 적용 완료 선언이 아닌 시정 및 QA 지시이다.
