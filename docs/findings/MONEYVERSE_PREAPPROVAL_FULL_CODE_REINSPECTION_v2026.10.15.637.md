## 3. Reconfirmed financial authority defects

- Read-only DB query: `public` 241 tables; `moneyverse_app` can INSERT, UPDATE and DELETE **237** each, SELECT 238; zero RLS-enabled ordinary/partition tables. Direct privileges include `account_balances` writes, `ledger_postings` insert, `users` update, `audit_logs` delete. **P0: violates least-privilege, immutable audit and function-only financial authority.** Never hot-`REVOKE` without a Test-safe dependency map.
- Of 549 public functions, 485 SECURITY DEFINER and **11 executable by PUBLIC**, including financial treasury grant/dividend/distribution operations. Several use `admin_role_holder(p_actor)` inside the function, so PUBLIC privilege alone is **not proof of unauthorized success**; however `p_actor` is a caller-supplied UUID and the DB exposure must be reviewed and tested with appropriate identity and role binding. Do not invoke sensitive procedures on live data.
- Development DB's actual ledger aggregates: 831 `ledger_transactions`, 1,692 postings, **0** posting debit/credit imbalance, **0** transactions without postings, **0** disallowed negative balances, **0** currently observed balances exceeding JS safe integer. This snapshot **cannot detect unlogged direct balance mutations** or establish runtime atomicity.
- DB `schema_migrations`: 266 rows, highest applied prefix 268; 269–271 and historical 237 absent in applied history. Current migration 271 proposes default ACL + PUBLIC EXECUTE withdrawal and a *selected* set of direct-DML revocations, but does not close all 237 broad table grants by itself. Existing migration checksums and Test application must be reviewed, not overwritten.
- Existing v636 findings remain applicable: live `claim` and grant success divergence, duplicate DAO voting in `frontend/src/app/api/treasury/proposals/route.ts:239-254`, `admin-backup.controller.ts:33` lacks explicit admin-role/step-up guard, `/api/indexnow` accepts unauthenticated external submissions, planning/SEO rating claims and `DOCS_INDEX.md:3` unresolved `<<<<<<< HEAD` marker. Many controllers without explicit local guards are intentionally public or protected by global `InternalTokenGuard`, so a bare scanner result must not be misrepresented as a security flaw.
- Critical source scanner leads: 64 money-related JS number casts in 22 non-test backend files, including marketplace, stock league, FX, alerts and pension-adjacent monetary flows. These are candidates for numeric-overflow/precision review, not 64 confirmed exploits.
