# 은행 UI·다국어 불일치 및 정밀 QA 요구 — v2026.11.23.7
상태: P0 번역 / P1 UI / OPEN / 사용자 화면 관찰 근거. [English](2026-11-23-bank-ui-i18n-regression-v2026.11.23.7.md) · [이슈 #3380](https://github.com/wtrdd1-hash/Woldeok-Moneyverse-Migration/issues/3380).

## 화면에서 확인한 불일치
사용자가 보내준 `https://easy-scraping.com/bank`의 **스크롤 중간 위치** 캡처에서 왼쪽 은행 메뉴가 문자 그대로 **Translation unavailable**로 표시됨. 다른 메뉴·화면은 대부분 한국어인 혼합 번역 오류이며, 브라우저 제목에도 같은 실패 문구가 보인다. 선택한 [공식 통일 디자인](https://github.com/wtrdd1-hash/Woldeok-Moneyverse-Migration/blob/design/nov18-unified-all-180-20261123/docs/design/OWNER_SELECTED_UNIFIED_DESIGN_v2026.11.23.3.ko.md)의 W 브랜드·PC/모바일 공통 메뉴와 비교할 때 직업/커리어 진입 메뉴가 보이지 않고 구버전 메뉴 구성이 혼재한다. 예금 입금·출금 WLD 입력창은 배경이 회색으로 튀고 라벨·금액 단축 버튼·실행 버튼의 폭·간격·정렬이 불균형하다. 금리/복리/이자 수령 CTA가 존재하지만 **표시 수치가 정확한지 또는 틀렸는지는** 실제 서버·원장·정책 출처 없이는 판단하지 않는다. 화면 상단이 잘려 있으므로 헤더 미존재를 단정하지 않는다.

## 시정 및 정밀 QA 지시
1. 새 통일 디자인의 네이비·보라 컴포넌트, 직업·은행·지갑 이동 및 전역 문의/채팅을 PC/모바일 일관된 공통 셸로 구성한다.
2. EN 기본, KO 두 번째, JA/ZH/VI 및 자동 감지·수동 선택 유지. 누락 번역은 의도된 영문 안전 대체로 처리하고 메뉴명/문서 제목에 `Translation unavailable`이 노출되지 않도록 QA한다.
3. 입금·출금·예금·이자 지급 화면의 입력 정렬, 검증·에러, 잔액 부족, 금액 최솟값/최댓값/빈값·음수, 실제 승인·확인·영수증·중복 제출 차단, CSRF·소유권·WLD 원장 정수 정확도 검증.
4. 이율·복리·지급 이력은 권한 있는 API 및 원장·정책값과 대조하며, 샘플·미확인 데이터를 실제 성공처럼 표시하지 않는다.
5. 320/360/390/430/768/1024/1440/1920px, 200% 확대, 5언어, 키보드·스크린리더와 로딩/권한 거부/실패/성공 화면의 PC·모바일 회귀검증을 한다. 테스트용 데이터만 사용하고 개인정보·계좌값은 공개 GitHub에 넣지 않는다.

**판정:** 시각/번역 결함 관찰. API/원장 QA와 실제 수정은 미실시, 운영 변경 없음. 이 문서는 시정 지시이지 수정 완료 영수증이 아니다.
