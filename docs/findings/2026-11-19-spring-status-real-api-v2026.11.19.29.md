- `StatusTruthService` queries only public+active configured sources, left joins each source's **indexed newest snapshot**, safely caps output to 200 rows. No private source, free-form detail, connection address, raw DB error, owner information or invented state is exposed. Database-source failure returns **503**, not fabricated success.
