# 국민연금 P0 무원장 정산 긴급 차단 — v2026.10.17.762

**영문 정본:** [English](NPS_CORE_LEDGER_P0_v2026.10.17.762.md)
**상태:** 소스 수정 후보, 실제 운영 앱 반영은 별도 검증.

## 실제 운영 데이터 원인
10월 11일 실제 운영 DB 백업을 Test 클러스터에 따로 복원하고 17일 현재 운영 DB와 READ ONLY 대조. 현금 계정 1개에서만 원장 없는 **4,410 WLD 증가**. 실제 지급 로그가 **45 WLD × 98회 = 4,410 WLD**로 정확히 일치하며 마지막 지급과 계정 수정 시점도 일치. 회원 ID는 비공개. 10월 11일 이전부터 존재하던 **4,774,778 WLD** 불일치는 별도 증명 필요.

## 개발·권한 수정
- 국민연금 납입, 중도해지, 자동 지급, 수령 상태 전환은 SQL 호출 전에 HTTP 503과 PENSION_LEDGER_SETTLEMENT_UNCERTIFIED로 거부. 환경변수 우회 불가. 기존 연금·지급 내역 조회 유지.
- 자동 국부펀드 SWF 내부의 **또 다른 직접 국민연금 지급 블록** 제거. 다른 SWF·채권 등 직접 정산을 모두 해결했다는 뜻 아님.
- 프론트 포털 중단 문구, 거래 버튼 비활성화, 요청 핸들러 차단. 실제 지급 없는 확정 보장 주장 수정.
- 순방향 마이그레이션 **275번**은 앱 계정의 연금 지급/기여 로그 직접 쓰기 및 연금계좌 UPDATE·DELETE 권한 회수. 회원 잔액/원장 변경 없이 기존 기록 SELECT 보존.

## 검증과 남은 조건
새 백엔드 TDD 5개 실패→5개 성공, SWF 별도 TDD 1개 실패→성공, UI 1개 실패→성공. 백엔드 전체 **1,243 통과·DB 의존 396 건너뜀**, Nest 빌드 통과. 프론트 전체 **1,256 통과**, 타입검사 통과. 실 운영 DB 백업 복제본에 269–275 적용해 계정 40건·분개 1,692건 불변, 앱 역할 직접 연금 수정 SQL 권한 거부 확인.

실제 운영 v717에 이번 소스·DB 권한은 아직 적용되지 않았다. 검증된 자금 조달·멱등·양면 원장 정산으로 교체 전 재활성화 금지. 기존 19개 원장 차이, 핵심 5개 직접쓰기, v530 인증 전면 UI ×5 및 동일 SHA 운영 무중단 절차는 별도 해결.
