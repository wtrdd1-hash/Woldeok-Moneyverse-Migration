## 운영·Test 전체 고정 화면 GET 실측

- 최신 파일 인벤토리: Next 페이지 **166**, 관리자 **34**, 동적 **31**, 정적 **135**.
- 서버별 정적 135개 + 잘못된 이동 경로 4개를 읽기 전용 GET으로 검증, **양쪽 합계 278건**.
- 운영: **2xx 124, 3xx 11, 기존 죽은 경로 404 네 건, 5xx 0, 타임아웃 0**.
- Test: **2xx 124, 3xx 11, 기존 죽은 경로 404 네 건, 5xx 0, 타임아웃 0**.
- **API 익명 GET 추가 28건**(각 14): 금융/보상/관리자/채팅 보호 URL은 대부분 401, 주식·사진·헬스 등 200, 공지 구 주소 404. 일부 `/banking/loans` 등 GET 404는 공식 GET 계약 미확인으로 무작정 오류 간주하지 않음. [실측 JSON](../qa/v901-public-http-sweep.json).
- 동적 31개·로그인 회원 실제 거래·관리자 권한·Discord DM·AI 블로그 발행·모바일 기기 UI 등은 **합격 검증 대상에 포함되지 않음**. HTTP 200을 기능 성공과 혼동하지 말 것.
