# 사용자 제공 3개 화면 디자인 불일치 통합 보고서 및 정밀 QA 시정 지시
버전: **v2026.11.23.8** | 판정: **P0 OPEN / 첨부 화면 증거 / 통일 UI 시정 및 정밀 QA 필요** | [English](2026-11-23-consolidated-ui-regression-and-qa-v2026.11.23.8.md)

## 1. 검사 대상, 기준, 사실 범위
2026-11-23 사용자가 순서대로 제공한 **서로 다른 3개 페이지**의 실제 브라우저 캡처를 묶었다.

1. `https://easy-scraping.com/admin/users` — 관리자 **회원 목록**.
2. `https://easy-scraping.com/admin/logs` — 관리자 **감사 로그**. 회원 목록과 **별개 페이지**이며 기존 회원 목록 기록에 섞지 않는다.
3. `https://easy-scraping.com/bank` — **은행 예금 입출금·이자 수령**.

비교 기준은 사용자가 선택한 [네이비·보라색 공식 통일 UI v2026.11.23.3](https://github.com/wtrdd1-hash/Woldeok-Moneyverse-Migration/blob/design/nov18-unified-all-180-20261123/docs/design/OWNER_SELECTED_UNIFIED_DESIGN_v2026.11.23.3.ko.md), `PROJECT_PLAN`, `INTEGRATED_PLANNING_MASTER`, `DOCUMENTATION_POLICY`이다. 디자인 기준은 아직 **Draft PR #3376**에 있어 main 병합이나 운영 적용이 완료된 상태가 아니다. 시작·중간 main SHA: `9876c09888ec84034eec183cf1309c85df3d7447`.

**증거의 한계:** 사용자 캡처에서 보이는 상태만 관찰했다. 운영 서버의 DOM/CSS, 인증된 관리자 세션, API/DB, 거래나 감사 로그 데이터를 실제 검증하지 않았다. 일부 화면은 스크롤된 위치라 화면 바깥 영역이 없다고 단정하지 않는다. 회원 표시명·UUID 등 개인정보가 포함된 원본 스크린샷은 공개 GitHub에 업로드하지 않고 이 문서에도 전사하지 않는다.

### 감사 로그 화면에 대한 별도 주의
**이번 두 번째 캡처는 `/admin/logs`이며 `/admin/users`가 아니다.** 이전에 회원 목록으로 잘못 묶였을 가능성을 정정하고 이번 보고서에 **관리자 감사 로그의 독립 결함**으로 명확히 기록한다. 보라색의 큰 그래픽이 보인다는 점만으로 감사 로그 데이터가 삭제되었거나 API가 작동하지 않는다고 단정해서는 안 된다. `본문으로 건너뛰기` 링크 자체는 접근성 기능일 수 있으며, **그래픽 크기와 실제 업무 UI 가시성**이 점검 대상이다.

## 3. 공통 디자인 수정·정밀 QA 완료 기준
1. **공통 UI:** 배경 `#0C1020`, 카드 `#151D32`, 보라 `#9C83FF`, 파랑 `#64B7FF`, 본문 `#E9F1FF`, W 로고·PC 좌측 메뉴·모바일 하단 메뉴·직업 진입·전역 단일 문의/채팅·언어 변경으로 통일.
2. **관리자 회원 목록:** 실데이터 출처, 안전한 회원 검색·정렬·상태·페이지네이션, 개인정보 권한, 읽기/관리 행위별 확인 UI, 403·로딩·빈 상태·오류.
3. **관리자 감사 로그:** 정상 레이아웃 복구, 감사 로그의 실제 검색·기간 필터·상세 보기·내보내기 권한, 행위자·시간·작업·결과의 안전한 표시와 마스킹, 대량 로그·오류 시나리오.
4. **은행:** 입금·출금·예금·적금·이자 수령 폼, WLD 금액 검증(잔액부족·0·음수·중복 요청), 이율/원장 계산, 본인·권한 확인, CSRF/멱등성, 처리 중·성공·실패·영수증.
5. **반응형/다국어:** PC/모바일 `320/360/390/430/768/1024/1440/1920px` 및 200% 확대, 수평 오버플로, 긴 텍스트, 키보드·스크린리더, EN/KO/JA/ZH/VI 전수 확인. 번역 오류 문구는 사용자에게 노출 금지.
6. **검증/배포:** 개인정보를 가린 테스트용 PC·모바일 전후 비교 캡처, 실행 SHA/역할/언어/브라우저/화면 크기/정확한 API 결과 영수증 기록. Gemini와 파일 작업 분리. Spring MVC + Thymeleaf 독립 Test 서버·API·보안 회귀 검증과 롤백 기준을 통과하기 전 운영 승격 금지.
