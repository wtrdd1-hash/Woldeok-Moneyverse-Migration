# v2026.11.19.41 — 운영 API 무로그인 읽기 전용 QA 결과

2026-11-19 KST 실제 Spring OpenAPI는 경로 **973개**, GET **644개**입니다. 중복 별칭 포함이며 **973개 기능이 정상이라는 뜻은 아닙니다.** 위험한 변경성 GET/동적 ID/미디어 등을 제외하고 안전한 GET 581개(중복 제거 312 계열) 중 **208개를 실제 운영 HTTPS에서 읽기 전용으로 검사**했습니다. 토큰·쿠키·금융 쓰기/사용자 정보 본문은 수집·공개하지 않았습니다. 익명 요청의 302 로그인 이동 후 200을 성공 처리하던 QA 도구의 오진은 수정해 리다이렉트를 따라가지 않고 재검사했습니다.

**최종 208개 HTTP 응답:** 200=96, 401=71, 302=29, 403=8, 301=1, 406=1, 502=1, 503=1. **200은 실제 동작·금융 정합성 인증이 아닙니다.** `/api/v1/board` 및 관련 두 경로는 운영에서 `post-wld-*` 허위 게시글을 아직 반환합니다. 새 후보 Spring 코드는 실제 DB 공개 함수·세션·CSRF·멱등성·실제 영수증 사용으로 수정했지만 **운영 JAR 미승격**입니다. Discord 길드 상태 502는 Nginx가 REST 경로를 Socket.IO 9092로 보내고, 기존 Java 4550은 가짜 `connected:true`·길드/지연 수치 응답이므로 임의 프록시 변경으로 가짜 정상 200을 만들지 않았습니다. KDIC 조회 503은 미검증 원장으로 인한 차단입니다.

**운영 적용 완료:** 구형 `/admin.html`·`/admin-preview*` 4경로 200→302 로그인 경로 전환; `/admin/blog`, `/admin/blog/`, `/admin/blog-verified`, `/admin/blog/articles` 추가로 비로그인 302. `/admin/blog-verified`는 기존 무로그인 JSON 약 471KB, `/admin/blog/articles`도 200으로 나왔습니다. 기존 관리자 세션 검증을 Nginx 해당 경로에 적용하고 `nginx -t`·백업·무중단 reload·실제 HTTPS 8경로 및 사용자 홈/블로그/API 회귀 확인. 208개 매트릭스에서는 200 98→96, 302 27→29 두 API 경로만 바뀜. 별도 금융 긴급 Nginx 설정도 보존했습니다.

**검증 한계:** 독립 Spring Test가 기본 JDBC localhost5432(기동 안 됨)를 사용해 실패, 운영 실제 DB 환경과 다른 주소임을 확인했으나 비밀 접속정보 복사·우회는 하지 않았습니다. 실제 PostgreSQL DEV 조회 함수의 1건 원천 기록과 app 역할 함수 실행 권한, 테스트용 JUnit/Chromium만 확인했습니다. 공식 HTTPS Test `/api/version`은 403, 실계정 금융 영수증·관리자 역할·180개 웹페이지 5회 전체 QA·독립 롤백 미검증. **전체 운영 승격 보류**.
