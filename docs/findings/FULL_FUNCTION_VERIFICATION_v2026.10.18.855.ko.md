## 중요 발견사항

### F855-P0-01 — 금융 운영 승격 불가

실제 운영 DB의 `moneyverse_app`에 `account_balances`, `accounts`, `system_treasury_vaults` 직접 변경 권한이 남아 있습니다. 잔액 기록 40개 중 **19개 원장 증빙 불일치(+4,779,188 WLD)**, 그중 분개가 전혀 없는 계좌 5개(+2,627,807 WLD 차이)가 관측됩니다. 이는 분실액으로 확정된 것이 아니라 **검증되지 않은 차이**입니다. 거래별 복식부기 합계 불일치 0건이더라도 계좌 잔액 증빙 문제는 그대로입니다. 근거 없는 맞춤 분개·잔액 조정·권한 무력화 금지.

### F855-P1-02 — 모의 예금 계정 간 기록 노출(수정 후보 완료)

이전 v806 이후 브라우저의 7/30/90일 모의 저축 기록이 모든 계정에서 `wdmv_savings_pots_guest` 하나를 사용했습니다. 같은 브라우저에서 계정을 바꾸면 다른 계정의 모의 기록을 볼 위험이 있었으며, 소유자가 불명인 과거 기록의 자동 복사도 위험했습니다. 인증된 지갑 API의 `userId`를 사용하도록 개선하고 신원 조회 실패 시 기록을 숨기도록 했습니다. RED 실패를 먼저 확인한 후 신규 테스트가 통과했습니다. 기존 모의 기록을 자의로 다른 계정에 귀속하지 않습니다.

### F855-P1-03 — ‘5회 전체 QA 100%’ 허위 양성 구조(수정 후보 완료)

기존 검사 스크립트는 HTML 내 큰 너비 문자열이 없다는 이유로 모바일 레이아웃 검증 완료, HTTP 200만으로 100조 WLD 견딤 검증, 인증 없는 관리자 URL 접근만으로 관리자·거래 검증을 완료한 것처럼 분류했습니다. 이에 HTTP/정적 검사임을 명시하고, 로그인 UI/실제 브라우저 폭/번역 콘텐츠/원장 거래 영수증/관리자 권한/세션 연속성 증빙이 없으면 **전체 기능 정상 판정을 차단**하도록 수정했습니다.

### F855-P1-04 — 최신 코드 운영 미반영 및 미검증

실제 공개 운영·테스트 서버는 v805이며 GitHub 메인은 더 최신입니다. 166개 전체 화면을 5회씩 실제 브라우저에서 회원·관리자 권한으로 점검하지 못했습니다. 클릭, 입출금, 관리자 승인, 주식 거래, 카지노, 채권, 블로그 발행, 회원 상태, 320px 화면 넘침 등을 모두 정상이라고 인정할 수 없습니다. 실제 브라우저 실행 도구가 설치되지 않은 상태입니다.

### F855-P2-05 — 추가 보완

전체 Lint 경고 1,060개는 치명적 오류는 아니어도 개선해야 합니다. 7/30/90일 정기예금은 여전히 **브라우저 모의 체험**이며, 실제 WLD 입금은 별도 DB 원장 기반 복리예금입니다.
