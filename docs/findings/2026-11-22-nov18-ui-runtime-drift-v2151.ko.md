## 기준·조사 범위

`PROJECT_PLAN`, `INTEGRATED_PLANNING_MASTER`, 문서 거버넌스, 11월18일 디자인 승인 명세, 180개 이미지 색인, 11월21일 전체 QA/경로 원장, 최신 UI PR와 FE-A/B/C·QA-1/2 작업로그를 대조했다. 통합 기획이 최상위 기준이며 이 감사 결과가 기획의 권위를 대체하지 않는다. 착수·중간 원격 `main` SHA: `86393ad8bc1c66ba5c8593aa3770e2310173fd29`. Android 별도 저장소도 확인했으나 수정하지 않았다. 180개 이미지는 실제 작동 승인 결과가 아닌 디자인 시안이다.

이번 감사는 11월18~22일 UI 전달 및 관련 기록과 현재 Nginx/Java/정적 소스를 중심으로 했다. 수천 개의 역사 문서를 한 줄씩 전수 판독했다고 주장하지 않는다. 로그인된 실제 계정 전체 E2E, 브라우저 180개 화면 비교 및 실제 자금 거래는 수행하지 않았다.

## 확인된 사실

1. **새 디자인과 기존 소스가 섞여 있음(P0).** `spring-backend/src/main/resources/static/`의 최상위 HTML **59개**, Spring HTML 템플릿 **22개**. 정적59개 가운데 새 `mv-shell-nov18.css` 참조는 **19개**, `/_next/static` 참조는 **50개**, 구형 `bg-[#090A0F]` body 클래스는 **48개**. `mv-theme-nov18.css`는 59개 모두 참조하지만 공통 셸·마크업까지 같지는 않다. 이 수치는 파일 검사이고 모든 페이지를 눈으로 승인한 결과가 아니다. `account`·`support`는 새 CSS+기존 Next 자산/클래스가 함께 남고 `bank`·`shop`·`index`는 새 셸 CSS를 참조하지 않는다.
2. **운영 프론트엔드 단일화 미증명(P0).** 현재 Nginx에는 구형 정적 alias, 11월18일 v24 경로 include, `4550/4632/4646` 포트 프록시가 공존한다. 실제 세 포트 모두 Java LISTEN. `4632`·`4646`는 11월18일 기동, `4550`는 **11월22일 20:32** 기동. 4550의 JAR 파일 시각은 20:30이며 이후 20:43/21:21 UI 병합이 이 시각보다 늦다. 단, 일부 HTTP 응답은 더 최신 소스와 같아 외부 파일시스템 동적 정적 제공이 가능하다. 각 URL의 실제 자산 출처는 아직 **미검증**이다.
3. **익명 HTTP 점검 결과 차이.** 로컬 Nginx에 `Host: easy-scraping.com`으로 `/`, `/bank`, `/shop`, `/stocks`, `/quests`, `/board`, `/work`, `/account`는 200; `/wallet`, `/chat`, `/support`, `/admin`은 로그인 리다이렉트; `/api/version`은 **503**. 자격증명을 사용하거나 리다이렉트를 따라가지 않았다. `/`은 영문 “My assets dashboard · W Moneyverse” 응답으로 현재 `main` 한국어 홈 HTML과 불일치한다. HTTP200은 기능 통과 증명이 아니다.
4. **패키지와 제공 소스의 해시 차이.** `account.html`의 20:30 JAR 내 HTML SHA256과 최신 소스 SHA256은 다르지만 실제 `4550/account` 응답은 최신 소스와 일치했다. JAR 파일명·시작 시각·URL200 각각 하나만으로 배포 정합성을 주장할 수 없다.
5. **미해결 과거 QA.** 11월21일 180개 분류: 공통 셸26, 시안 부분5, 기타 화면37, 오류/차단79, 동적 미실행33. 관리자 테마·언어/문의·주요 업무 버튼·403 문제 기록. **11월22일 새 PR을 반영하여 재측정한 숫자가 아니므로** 최신 운영의 확정 장애 수와 혼동하지 않는다.
6. **작업자·협업 추적 한계.** FE-A/FE-B/FE-C 및 QA-1/QA-2의 오늘 작업로그는 전체 E2E 및 정확한 SHA Test 인증이 미완료라고 명시한다. FE-C 작업트리에는 미커밋33경로가 기록되어 있으며 FE-A가 공통 셸 소유라고 남겼다. 최신 GitHub 커밋이 동일 계정으로 기록돼 있다는 사실만으로 Gemini/ChatGPT/다른 자동화 중 누가 실제 개별 줄을 작성했는지는 특정할 수 없다. 추측으로 책임을 귀속하지 않는다.

## 전체 관련 작업 인덱스 추가 점검 — 숫자 해석 주의

- 11월18~22일 Git 이력에서 **총 293개 커밋** 제목을 조회했고, `ui|frontend|design|visual|thym|nov18` 키워드가 들어간 제목 **153개**를 확인했다. 이는 UI 승인·배포 153건이 아닌 **제목 검색 건수**다. Git 작성자 표시명 `wtrdd1-hash` 229개, `Hong Jong-hwan` 64개이며 표시명만으로 어떤 AI가 작업했는지는 판정 불가.
- 11월21~22일 미니PC FE-A/B/C 및 QA-1/QA-2 작업 디렉터리 **218개**, 읽기 가능한 `AUDIT.md` **217개**, 누락 **1개**를 조사했다. 텍스트 키워드 `hold` 포함 **216개**, `blocked` 포함 **213개**다. 이는 **키워드 포함 파일 수**이지 테스트 실패 216건/213건이 아니다. 가장 최근의 5개 담당 기록은 직접 내용 검토했고, 그 이전 전체 파일은 텍스트 인덱스 기반으로 분류했다.

## 결론

근본 원인은 **소스 디자인 분산 + 운영 화면 제공 경로 다중화 + GitHub/실행물 버전 불일치 + 전체 기능·시각 검증 게이트 누락**의 복합 문제다. 이번 회차는 **문서 감사만** 수행했고 코드·DB·테스트·운영·Android 배포는 변경하지 않았다.
