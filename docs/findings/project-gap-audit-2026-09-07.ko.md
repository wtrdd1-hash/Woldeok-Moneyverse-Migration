# 프로젝트 부족 사항 감사 — 2026-09-07

범위: 현재 `main`, 병합되지 않은 신원/운영 브랜치 2개, Test 및 Production 스택, PostgreSQL 불변조건, CI/CD, 백업, 모바일 탐색, 콘텐츠 공개, 공개 경제 화면.

## 이번 변경에서 해결된 사항

1. **OAuth 키 회전으로 한 사람이 다른 사용자 행으로 분리될 수 있음 — 긴급.** 신원 조회가 변경 가능한 암호화 키로 생성된 결정적 암호문에 의존했습니다. 마이그레이션 162는 암호화 저장을 유지하면서 공급자 범위의 키 독립 조회 해시를 추가하고 회원이 선택한 이름을 보존합니다.
2. **제안된 계정 복구가 참조 데이터를 삭제함 — 긴급.** 기존 호스트 스크립트는 현금만 확인하고 신원, 잔액, 계정, 세션, 사용자를 삭제했습니다. 사진, 동의, 성장, 활동, 작업 기록을 무시했고 선택된 이름도 덮어쓸 수 있었습니다. 마이그레이션 163은 사용 가능한 잔액을 복식부기 원장을 통해 이동하고, 지원되는 현재 상태를 병합하며, 불변 행위자 이력을 유지하고, append-only 병합 이벤트를 기록하며 안전한 일반 정책이 없는 소유 유형은 거부합니다.
3. **백업이 배포 주변에만 존재함 — 높음.** 각 스택은 중첩 방지 잠금, 타임스탬프, 결과 코드, 제한된 고빈도 보존 정책을 갖춘 10분 간격 암호화 전체 DB/사진 저장소 백업을 엇갈리게 설치합니다. Production과 Test는 두 번째 물리 디스크의 서로 다른 디렉터리를 사용합니다.
4. **배포 SSH가 단계마다 재연결되어 연결 손실을 키움 — 높음.** 워크플로는 인증 및 호스트 키가 고정된 SSH 제어 연결 하나를 재시도하고 파일 전송, 롤아웃, 보고에 재사용합니다. 불필요한 재연결은 줄지만 GitHub 호스팅 러너 연결을 모두 거부하는 호스트/방화벽 정책 자체를 해결하지는 못합니다.
5. **새 원장 유형에 회원용 라벨이 없음 — 중간.** 계정 통합 전송이 일반 활동 라벨 대신 `계정 통합`으로 표시됩니다.
6. **Lint에 설정성 경고 2개가 남음 — 낮음.** 워크스페이스 React 버전을 명시하고 App Router 프로젝트에 불필요한 Pages Router 규칙을 비활성화했으며 PostCSS는 이름 있는 설정 객체를 내보냅니다.

## 정상으로 검증된 항목

- Production 갤러리는 승인된 사진 객체와 미디어 경로를 렌더링 HTML에 반환합니다.
- 상점과 지갑은 같은 기준 지갑 개요를 읽습니다. 최근 정합성 검사에서 미균형 거래, 누락 잔액, 잔액 불일치, 원장/잔액 차이가 모두 0입니다.
- 마이그레이션 157과 159에는 작업 배정/보상 횟수 제한이 없습니다. 반복 감액은 일일 사용 제한이 아니라 경제 정책입니다.
- Production/Test 데이터베이스, 이미지 태그, Secret, 포트, 백업 경로가 분리되어 있습니다. Test 마이그레이션은 `moneyverse_migration`에만 적용되었습니다.
- Production 의존성 감사에서 알려진 취약점이 보고되지 않았습니다.

## 남은 작업 — 위험 순서

1. **GitHub 호스팅 배포 ingress 사용 불가 — 높음.** 릴리스 중 새 SSH 시도 6회가 파일 전송 전에 타임아웃됐습니다. CI와 이미지 게시에는 문제가 없었고 동일 게이트 후 호스트에서 로컬 배포를 완료했습니다. 범위가 좁은 방화벽 규칙, VPN/오버레이 경로 또는 잠긴 셀프호스팅 러너로 접근을 복구하고 자동 운영 배포를 신뢰하기 전에 Test 배포를 증명해야 합니다.
2. **호스트 외부 백업 사본 없음 — 높음.** DB 볼륨과 암호화 백업은 다른 물리 디스크에 있지만 장비 전체 손실 시 둘 다 사라집니다. `BACKUP_COPY_TO`를 다른 장비의 마운트 저장소나 오브젝트 스토리지 게이트웨이에 지정하고 복구 훈련을 해야 합니다. 같은 PostgreSQL 호스트의 두 번째 라이브 DB는 재해 복구가 아닙니다.
3. **복구 리허설이 수동 — 높음.** 모든 백업은 복호화, CRC 검사, 매니페스트 수치 비교를 거치지만 격리 PostgreSQL 인스턴스로 정기 복구하면 역할/스키마 재생성까지 검증할 수 있습니다.
4. **모바일 브라우저 검증이 컴포넌트/반응형 테스트에서 끝남 — 중간.** 관리자 표시, 로그인/로그아웃, 토큰 전달은 코드로 검증되지만 CI에는 배포된 Test 주소를 대상으로 하는 Android Chrome/iOS WebKit E2E가 없습니다. Playwright 디바이스 프로젝트와 스크린샷/아티팩트에 자격 증명이 노출되지 않는 운영자 테스트 계정을 추가해야 합니다.
5. **의도적으로 남은 raw-image 경로 9개가 성능 경고를 생성 — 중간.** Blob 미리보기와 크기 제한이 없는 승인 외부 URL은 기본 Next 이미지 로더를 안전하게 쓸 수 없습니다. 동일 출처 미디어는 크기를 아는 이미지 컴포넌트로 옮기고 외부 출처는 검토된 allowlist를 사용해야 합니다.
6. **백업 실패가 로그에만 남고 경보가 없음 — 중간.** 최신 검증 매니페스트가 1시간을 넘거나 cron 결과가 0이 아닐 때만 비공개 운영 채널에 알리는 watchdog을 추가해야 합니다.
7. **GitHub 호스팅 Action 런타임 지원 종료 경고 — 낮음.** 러너가 해당 Action을 Node 24로 강제하여 CI는 성공하고 있습니다. 릴리스 노트와 고정 동작을 검토한 뒤 Action 메이저 버전을 올려야 합니다.

## 릴리스 게이트
계정 연속성 스택은 CI가 PostgreSQL에서 두 새 마이그레이션과 실제 DB 계정 병합 테스트를 수행하기 전에는 병합/배포하지 않습니다. Production 적용 전 새 암호화 DB/사진 백업을 생성·검증하고, 각 병합을 롤백되는 dry-run으로 실행한 뒤 고유 멱등성 키로 실제 적용하고, 정합성 검사와 신원/세션 검사를 통과해야 합니다.
