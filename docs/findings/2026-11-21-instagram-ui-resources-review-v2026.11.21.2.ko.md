## 우리 화면과 비교
사용자가 제공한 /wallet 스크린샷에는 총자산·현금·은행 예치금 카드, 송금 폼 및 거래 원장이 보인다. 특히 청록색 사이드바/배경 버전은 승인된 11월 18일 일관된 네이비/보라 디자인과 맞지 않는다. 화면에 보이는 `394,728 WLD` 등은 **실제 원장 확인값이 아닌 스크린샷 관찰값**이다. `2838 x 1321` 문구와 확대 아이콘은 브라우저/화면 보조 도구 가능성도 있으므로 실제 DOM·CSS 원인을 확인할 때까지 웹 오류로 단정하지 않는다.

## 적용 우선순위
1. **P0 공통 디자인:** 배경 `#0C1020`, 표면 `#151D32`, 포인트 `#9C83FF`, 보조 `#64B7FF`, 본문 `#E9F1FF`, 보조글 `#A8BCD8`. 모든 사용자/관리자 화면의 헤더·사이드바·카드·버튼·폼 규격 공유, 청록색 전체 배경 제거. 실제 데이터·실패/빈 상태·조회 시점 표시.
2. **P1 금융 사용성:** 지갑→자산 요약→4대 빠른 동작(송금·예금·출금·카드)→거래 원장→은행 상품. 모바일은 카드 재배치·2열 바로가기·거래내역 카드 변환, 가로 스크롤 금지. 금융 영수증과 송금 오류는 서버 정본을 따른다.
3. **P1 미세 애니메이션:** 아이콘·탭·모달 등 장식보다 **상태 피드백**에 사용, 보통 120~200ms 정도를 설계 가이드로 제안(영상의 주장 아님). 움직임 줄이기 환경설정 존중. 잔액이나 송금 완료를 허위로 애니메이션 표시하지 않는다.
4. **P1 은행/카드:** 앞서 제안한 송금·예금·저축·가상 카드 화면에 실제 API 연동 및 인증/CSRF/멱등성/원장/영수증 검증. 카드 발급은 아직 신규 설계이며 실물 은행 카드 아님.
5. **P2 완성도:** SHIUI의 선/간격 계층과 Minimal Gallery의 여백·타이포그래피에서 학습하되 사이트 테마·코드 무단 복사 금지. 동일 채팅 버튼은 모든 화면에 1개.

## 변경·QA·배포 조건
웹은 **Spring Boot MVC + Thymeleaf** 기준, 기본 영어·두 번째 한국어·일본어·중국어 간체·베트남어 및 수동 선택 유지. 320~1920px/200% 확대/5개 언어, 탭·키보드·스크린리더·애니메이션 감소, 실제 두 회원 데이터·원장·보안·영수증을 테스트한다. Gemini 수정 파일과 충돌 피하고 main 시작/중간에 재확인, 변경 기록 영문/국문, 격리 브랜치·Draft PR·공식 Test·무중단 롤백 게이트 준수. **이번에는 실제 코드를 수정하거나 배포하지 않는다.**
