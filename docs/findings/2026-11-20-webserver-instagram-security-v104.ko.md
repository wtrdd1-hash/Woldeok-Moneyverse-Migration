**성격:** 공개 보안정보 검토 및 미니PC 읽기 전용 점검. **보안 패치 완료·운영 승격 증빙이 아님.**

## 1. 제보 원문과 확인 범위

- 사용자 제보 인스타그램: https://www.instagram.com/reel/Df7MYiaKeXL/
- 게시일: 2026-11-19. 11월 20일 공개 **게시물 캡션**을 직접 수집하여 요지를 확인함. 영상 전체 화면·음성에 대한 완전한 검수는 수행하지 않음.
- 릴스 요지: Apache와 NGINX의 보안 결함, 조건부 원격 코드 실행(RCE), 설치 버전 확인, 패치 적용, HTTP/2 임시 완화.
- 캡션의 **10월 14일 NGINX 보안 릴리스 1.30.6·1.31.7**과 **11월 18일 새 NGINX2Root 5건의 수정 릴리스 1.30.7·1.31.9**는 **서로 다른 보안 패치 회차**임. 옛 버전으로 패치 완료 판정을 내리지 말 것.

## 3. 월덕 머니버스 서버 영향 확인

미니PC에 **읽기 전용**으로 접근하여 실행 서버·설치 패키지와 운영체제 보안 저장소를 비교함. **긴급 보안 패치 검토가 필요한 상태**를 확인했음. 다만 공개 GitHub 저장소에는 정확한 운영 버전, 패키지 차이, 네트워크 설정, IP, 로그, 비밀값 등 공격에 활용될 수 있는 **운영 세부정보를 기재하지 않음**. 상세 증거는 미니PC의 별도 접근제한 파일에 안전하게 기록함.

취약한 버전이라는 사실만으로 외부 공격 가능 경로나 침해 사실이 증명되는 것은 아님. 실제 HTTP/2·HTTP/3 노출, NGINX 모듈·설정, TLS 종료 지점, 프로세스 상태, 이상 로그를 추가 검증해야 함. 반대로 정상 HTTP 200 응답만으로 안전하다고 판단할 수도 없음.

[현재 프로젝트 기획](../planning/PROJECT_PLAN.md), [통합 마스터](../planning/INTEGRATED_PLANNING_MASTER.md), [문서 정책](../DOCUMENTATION_POLICY.ko.md)을 우선하고 이 보고서는 신규 기획 권위가 아닌 조사 증거로 취급함.

## 4. 긴급 조치 절차 — 이 문서 작업에서는 실행하지 않음

1. **민감 증거 보존:** 실제 실행 바이너리, 패키지 출처·보안 백포트, 사용 모듈·리스너·설정, 오류·접근 로그를 비공개로 수집. 개인정보·토큰·DB 접속정보는 공개하지 않음.
2. **패치 후보 분리:** 현재 OS의 공식 수정 패키지를 확인하고, Gemini 등 동시 작업과 충돌하지 않도록 담당자를 고정. 설정과 롤백 수단을 먼저 확보.
3. **Test 정밀 QA:** 관리자 권한의 `nginx -t`, HTTPS/TLS·HTTP/2/3, Spring 역방향 프록시, 관리자 익명 401/302, 실제 로그인 회원/관리자 API, 5개 언어, 모바일/PC, 원장 비변경 및 복구 확인.
4. **운영 변경 게이트:** 설치·실행 바이너리 정확한 버전 일치, 실제 트래픽·헬스 확인, 무중단 또는 승인된 유지보수 전환, 롤백 증거 후 승격. **설정 reload 성공만으로 새 보안 바이너리 적용을 확정하지 말 것.**
5. 즉시 패치할 수 없으면 HTTP/2·3 비활성화 등 해당 조건별 임시 완화 가능성을 영향 분석 후 검토. 이것만으로 resolver·메일 관련 취약점까지 해결되지는 않음.
6. 적용 후 NGINX 워커 비정상 종료·새 프로세스·로그 이상 등 침해 징후를 추가 조사하고 발견 시 별도 보안 사고 절차로 확대.
