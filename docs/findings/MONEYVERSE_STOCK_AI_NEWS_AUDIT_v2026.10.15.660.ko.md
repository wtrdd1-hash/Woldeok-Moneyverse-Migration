## 최종 진단

**P0 / 현재 자동 주식 뉴스 발행 장애.** 백엔드와 Ollama 서비스 활성 상태만으로 자동 생성·게시 정상 동작을 인정할 수 없다. 다루는 뉴스는 실제 증권시장 기사 수집이 아니라 **머니버스 게임 내 가상기업/가상시장 AI 시나리오**다.

## 실측 근거

1. 백엔드, 내부 Ollama, PostgreSQL 가동 확인. Ollama `http://127.0.0.1:11434/v1/models`는 HTTP 200이며 `llama3.2:3b` 존재.
2. 실행 백엔드 설정상 `AI_NEWS_AUTO_ENABLED=true`, actor UUID, 모델 `llama3.2:3b`, 로컬 루프백 AI 주소가 지정됐다. AI API 키 부재는 로컬 Ollama의 필수 실패 원인이라고 단정할 수 없다. 비밀 값은 노출하지 않았다.
3. 시간별 스케줄러 `stock.ai_scenario_auto`의 2026-10-15 10:27 KST 작업이 `the model API could not be reached`로 실패. 서버 로그와 DB `scheduled_job_runs` 상세가 일치한다. DB 누적 실패 131회, 성공 상태 469회(스킵도 성공 처리될 수 있어 뉴스 게시 성공 건수와 구분). 마지막 스케줄러 성공 상태는 10월 11일 17:25.
4. AI 배치 4건, 게시된 시나리오 4건, source=`ai` 주식 시장 이벤트 5건 확인. 마지막 AI 생성·시장 이벤트 기록은 10월 11일 17:26 KST. **현재 활성 AI 시장 이벤트 0건.**
5. 운영 `dist/security/ssrf-defense.js`로 실행한 읽기 전용 재현에서 AI 주소 `127.0.0.1:11434`가 `SsrffSecurityError`로 차단됨을 확인했다. 이는 Ollama 자체가 꺼졌다는 증거가 아니라 보안 필터와 로컬 모델 설정의 충돌이다.

## 원인과 추가 결함

- **NEWS-660-01 / P0:** `backend/src/admin/ai-news.service.ts`의 AI 요청이 공통 `safeFetch()`를 사용한다. `backend/src/security/ssrf-defense.ts`가 의도적으로 모든 로컬/사설 IP를 거부하므로 서버가 자기 자신의 Ollama에 접근할 수 없다. 예외가 `ai_news_model_unreachable`로 변환되어 운영 로그에는 접속 불가로만 기록된다.
- **NEWS-660-02 / P1:** `backend/src/stock/newspaper.controller.ts`의 `getMarketPulse()`는 시장 심리 68, 활성 이벤트 4개, 제목/요약을 고정값으로 제공하면서 `updatedAt`만 현재 시각으로 표시한다. `weekly-brief`에도 DB 수치와 하드코딩된 거래 수치가 섞여 있다.
- **NEWS-660-03 / P1:** 신문·주식 화면은 진행 중 시장 이벤트를 읽는 연결은 있지만, v325가 요구하는 기사 아카이브·출처/AI 생성 표시·정정 등 전체 소비자 기사 체계의 구현/운영 수용까지 이 점검으로 확인한 것은 아니다.

## 시정 제안 (아직 미실행)

1. 공통 SSRF 보호는 유지하고, 운영 환경이 소유한 명시적 로컬 모델 API에만 접근하는 **전용 내부 모델 호출 경로**를 추가한다. 외부 요청·임의 host·리다이렉트·비밀 헤더 우회를 금지한다.
2. 사설 IP/메타데이터 SSRF 차단 회귀 시험, 전용 허용 경로와 모델 응답 검증, 중복/충격 상한 테스트를 추가한다.
3. 격리 Test DB·테스트 actor에서만 AI 생성 → 안전 후보 → 시장 이벤트 → `/newspaper` 및 `/stocks` 표시를 검증한다. 운영 서버에서 실제 가격에 영향을 미치는 수동 게시 시험은 수행하지 않는다.
4. 고정값 시장 심리·주간 뉴스 숫자는 실제 집계에 연결하거나 샘플임을 명시한다. 기사 아카이브/AI·게임 정보 표시의 수용 기준을 마련한다.
5. 최신 main을 중간/종료 재확인하고 병행 작업을 보호하면서 별도 수정 브랜치, CI/보안/DB/Test 백엔드 검증 후 무중단 운영 승격을 진행한다.

## 미확인 범위

AI 텍스트 추론 성공, 인증된 운영 화면 전체 E2E, 최신 main의 격리 Test, 자동 뉴스 운영 게시 정상화는 **검증하지 않았으며 수정·배포도 진행하지 않았다.**
