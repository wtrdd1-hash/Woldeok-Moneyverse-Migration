## 원인 분리 및 복구 순서
1. 세션·권한·CSRF를 중앙에서 검증하고 모든 관리자 접근을 거부 우선으로 구성합니다. 민감한 재현 정보를 공개하지 않습니다.
2. 인증 기반 서버 렌더링 화면을 오류 상태의 정적 HTML로 대체하지 않고, 실제 사용자별 데이터 조회를 구현합니다.
3. Java와 PostgreSQL 함수 계약을 일치시키고 SQL 오류 때 가짜 정상 데이터가 나오지 않도록 합니다.
4. 독립 테스트 서버에서 정확한 SHA 기반으로 백엔드·프론트엔드·DB 계약을 확인합니다.
5. 디스코드 음성 입장/재연결, 320/390px 모바일 화면 및 로그인 관리자 기능을 E2E 검증합니다.
6. 금융 원장·수익·국고 변경은 격리 환경의 ROLLBACK 검증 후 승인받은 무중단 운영 승격 게이트를 통과합니다.
