# Woldeok 공식 브랜드 아이콘 규격서 (Official Brand Icon Specification)

## 📌 기본 정보
- **문서 식별자**: `DOC-SPEC-BRAND-ICON-001`
- **적용 대상**: Woldeok Moneyverse 웹 포털, 모바일 PWA, 관리자 콘솔, 공식 문서
- **마스터 파일 위치**: [woldeok-official-icon.png](../frontend/public/images/woldeok-official-icon.png)

---

## 🎨 디자인 정체성
1. **황금/실버 왕관 (Crown)**: 경제 생태계 내 자산의 최고 주권
2. **크롬 메탈릭 'W'**: 견고한 블록체인/금융 트랜잭션 원장의 신뢰성
3. **월계수 엠블럼 (Laurel)**: 이용자 커뮤니티의 번영과 승리
4. **다이아몬드 (Jewel)**: 타협 없는 보안과 금융 자산의 무결성
5. **네온 퍼플 궤도 (Orbital Ring)**: 국경 없는 글로벌 금융 네트워크

---

## 📂 파일 시스템 배치 현황

```
frontend/public/
├── favicon.ico                         # 멀티 사이즈 브라우저 탭 아이콘 (16/32/48)
├── favicon.png                         # 512x512 고해상도 파비콘
├── apple-touch-icon.png                # iOS 홈 스크린 바로가기 아이콘 (180x180)
├── manifest.json                       # PWA 메타데이터 정의 파일
└── images/
    └── woldeok-official-icon.png       # 1024x1024 마스터 원본 공식 아이콘
```

상세 디자인 토큰 및 컴포넌트 구현 가이드는 [OFFICIAL_BRAND_ICON_GUIDELINES.ko.md](design/OFFICIAL_BRAND_ICON_GUIDELINES.ko.md)를 참조하십시오.
