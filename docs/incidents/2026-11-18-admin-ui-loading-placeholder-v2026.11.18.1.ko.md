# INC-2026-11-18-P0 — 관리자 UI가 무한 로딩 임시 페이지로 대체된 장애

**관측:** 2026-11-18 07:07 KST. **심각도:** P0 운영 관리자 진입 화면. **상태:** 운영 엣지에서 부분 완화. 로그인·전체 사이트 미해결.

### 실제 증거와 원인 경로
1. Android Chrome 화면 `easy-scraping.com/admin/`에 `페이지를 불러오는 중입니다...`만 출력.
2. 운영 재현 `/admin/`·`/login`·`/` HTTP200이지만 내용은 475바이트 임시 HTML. Spring health와 PostgreSQL 정상. 200 헬스만으로 실제 화면 정상 여부 판정 불가.
3. Nginx `prod_frontend`, `prod_spring`이 모두 Spring :4550. 옛 Next 프론트 포트 리스너 부재. 디스크 내 정적 파일·프론트 빌드는 남아 있음.
4. 최신 standalone Next는 `next` 의존성 심볼릭 링크가 이전 작업트리로 연결돼 부팅 실패. 임시 우회 후에도 핵심 경로 HTTP 500. 과거 릴리스 번들은 포함된 모듈과 정식 환경 설정으로 정상 실행.
5. Next를 전체 업스트림으로 바로 되돌리면 익명 `/api/v1/admin/users` 200과 SSR 식별자 노출 위험. 따라서 모든 공개 관리자 UI를 Spring의 본인 세션·권한 검사로 선차단, 외부 API는 Spring 유지.

### 이번 복구
:4524 루프백 전용 재부팅 지속 Next 서비스, 관리자 Nginx 인증 가드, 제한된 화면 경로, 최근 정적 에셋/기존 SEO fallback 유지. 원본 설정 백업. 분리 8/8 및 운영 익명 인증·자산 검증 통과. Spring/DB/금융 미중단. 로그인한 운영자 긍정 E2E는 미검증.

### 남은 위험·재발 방지
1. OAuth 인증 시작·콜백 실제 배포 계약 불일치. 현 Spring 소스의 Google OAuth 또한 placeholder 상태. 로그인 정상이라고 표시 금지.
2. 일반 홈·회원 화면도 Spring 임시 페이지. 다른 작업자의 Spring 웹 작업이 진행 중이므로 배포 SHA·충돌 조율 후 전체 전환.
3. UI/API 업스트림 분리, 엣지 관리자 권한 검사, pnpm 심볼릭 링크를 외부 작업트리에 의존하지 않는 독립 실행 빌드 규정, 200 상태뿐 아니라 HTML/JS/CSS/실제 로그인 E2E 검증.
4. 화면 대체 HTML·정적 자산 404·익명 관리자 데이터 노출이 발생하면 배포 자동 차단. 원자적 교체·롤백 및 빌드 출처 보존.
