# 문서 한국어 현지화 작업 로그 — v2026.09.12.28

[English](2026-09-12-documentation-localization-v2026.09.12.28.md) | **한국어** | [한국어 문서 색인](../INDEX.ko.md)

날짜: 2026-09-12  
범위: 문서 전용

## 요청

영어 문서를 읽기 어려운 한국어 사용자가 저장소 문서를 실제로 사용할 수 있도록 하되 저장소 표준인 **1. 영어 기준 원문 / 2. 한국어 유지 번역본** 순서는 그대로 유지합니다.

## 수행한 작업

1. 문서 색인과 현재 아키텍처, 기능, 운영, 현지화, 연동, 감사, 릴리스, 작업 로그 문서를 다시 확인했습니다.
2. 영어로만 있던 현재 사용 문서에 한국어 대응 문서를 만들었습니다.
3. 중요 과거 릴리스/작업 로그/감사 문서의 영어 전용 항목에도 한국어 대응 문서를 추가했습니다.
4. 원문 자체가 이미 한국어이거나 영어/한국어 병기인 과거 문서는 같은 내용을 불필요하게 복제하지 않고 색인에서 한국어 문서로 표시했습니다.
5. `docs/INDEX.ko.md`를 한국어 문서 이동 허브로 정리했습니다.
6. `docs/INDEX.md`에서 영어 원문과 한국어 문서를 한 줄에서 함께 이동할 수 있게 정리했습니다.
7. 새 한국어 문서 상단에 영어 원문과 한국어 색인으로 이동하는 링크를 넣었습니다.
8. 초기 영어 전용 기반/백엔드 구현 계획에도 한국어 대응 문서를 만들고, 현재 런타임/배포 문서가 우선한다는 역사 문서 표시를 넣었습니다.
9. 이 문서 전용 작업을 `v2026.09.12.28`로 기록했습니다.

## 검증 방식

- 저장소의 문서 전용 정책에 따라 파일을 `main`에 직접 반영했습니다.
- 가능한 경우 영어 `NAME.md` → 한국어 `NAME.ko.md` 규칙을 사용했습니다.
- 이미 한국어 또는 병기 문서인 과거 기록은 번역 가치가 없는 중복 파일을 만들지 않았습니다.
- 기획서는 상시 변경되는 문서이므로 작업 중간에 다시 확인했고, 동시에 추가된 새로운 기획 문서들도 영어/한국어 쌍이 있는지 확인했습니다.
- 이번 문서 작업으로 실제 런타임 배포 상태를 변경하거나 배포 완료라고 표시하지 않았습니다.

## 과거 문서 주의사항

오래된 문서는 폐기된 배포 구조를 설명할 수 있습니다. 한국어 대응 문서는 당시 기록을 보존하며 조용히 최신 사실로 다시 쓰지 않습니다. 실제 작업 전에는 최신 `docs/architecture/deployment-flow.*`, `docs/operations/production-deployment.*`, `docs/INFRASTRUCTURE.*` 및 GitOps 저장소를 다시 확인해야 합니다.

## 런타임 / 배포 상태

문서 전용입니다. Test 배포와 Production 배포가 필요하지 않았습니다. 코드, 마이그레이션, 데이터베이스 데이터, 컨테이너 이미지, Kubernetes/Flux 리소스는 변경하지 않았습니다.
