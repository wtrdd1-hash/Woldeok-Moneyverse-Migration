# 내부 작업 기록 — 브랜치 정리 자동화 v2026.09.12.15

날짜: 2026-09-12
브랜치: `ops/auto-branch-cleanup-v2026.09.12.15`

## 확인한 항목

- 현재 애플리케이션 CI/테스트 후보/운영 릴리스 워크플로.
- 현재 GitOps 배포 흐름과 `wdmv-auto-reconcile.yml` 동작.
- 런타임 기능 개발과 겹치지 않도록 열린 PR 및 활성 작업 브랜치.

## 변경 사항

`.github/workflows/cleanup-merged-branches.yml`에 두 가지 보호된 정리 경로를 추가했습니다.

1. PR이 `main`에 병합되면 같은 저장소의 소스 브랜치만 삭제합니다.
2. 일일/수동 정리에서는 예약 브랜치를 제외하고 `main`과 비교해 브랜치 전용 커밋이 남아 있지 않은 경우에만 삭제합니다.

## 릴리스 흐름 확인

기존 GitOps 자동 조정기가 성공한 `main` 테스트 후보를 주기적으로 확인하고, 격리 테스트 환경에 반영한 뒤 exact-SHA 검증과 production-ready 신호를 거쳐 운영 매니페스트를 갱신합니다. 이번 변경은 이 게이트를 우회하지 않습니다.

## 구현 시 제한

설정된 미니PC 개발 장비가 오프라인이어서 이번 저장소 자동화 변경은 GitHub 연결을 통해 수행했습니다. 런타임 애플리케이션 코드는 변경하지 않았습니다.
