# 내부 작업 로그 — v2026.09.15.102

## 작업 계기

Android 앱에서 관리자 제한이 과도하게 적용되고, 백엔드 작업 목록이 `daily_limit = 0`을 반환해 사용자가 의도된 당일 작업량을 확인하거나 채울 수 없는 문제가 확인되었습니다.

## 확인 결과

- `work_task_catalog.daily_limit`에는 이미 작업별 authoritative 일일 제한값이 저장되어 있습니다.
- 마이그레이션 166에서 `work_task_board()`가 `daily_limit`을 `0`으로 반환하도록 바뀌었고 직접 완료 경로도 사실상 무제한 반복으로 변했습니다.
- 모바일 API 스키마는 여전히 `daily_limit`, `taken_today`를 요구하므로 실제 구현이 API 계약에서 이탈해 있었습니다.
- `taken_today`가 배정 생성 건수를 세고 있어 완료되지 않은 작업도 사용량처럼 보이는 문제가 있었습니다.
- 관리자 기능 스위치와 회원의 일일 quota는 서로 다른 정책입니다.
