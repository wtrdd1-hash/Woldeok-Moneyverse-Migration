# 오프호스트 immutable 백업 전달 — v2026.09.21.323

- 이미 암호화된 Moneyverse 백업을 rclone 원격지로 전달하는 단계를 추가했습니다.
- 기존 원격 객체는 `--immutable`로 덮어쓰지 않으며 수정본은 새 타임스탬프 백업으로 생성해야 합니다.
- 전송 전 로컬 checksum을 확인하고 전송 뒤 원격 객체를 다시 읽어 SHA-256을 검증합니다.
- `OFFSITE_REMOTE`는 rclone 원격지여야 하며 로컬 경로는 거부합니다.
- 설정된 경우 오프호스트 복사/검증 실패 시 예약 백업도 실패 처리됩니다. 실제 원격지 설정과 그 복사본 기반 restore drill 전까지 DR 완료로 간주하지 않습니다.
