# v2026.09.16.1 — 주식 탐색 통합

## 사용자 이점
회원은 가상 주식 종목을 검색한 뒤 그 결과만 등락률, 가격, 거래 가능 수량, 이름순으로 정렬할 수 있으며 어느 조건도 사라지지 않습니다. `q` + `sort` 조합 URL을 그대로 공유하거나 북마크할 수 있습니다.

## 참고 자료
- Next.js App Router 검색/페이지네이션 지침: URL 검색 파라미터로 공유 가능한 서버 렌더링 화면 상태를 유지하고 관련 없는 기존 파라미터를 버리지 않습니다.
- W3C WAI-ARIA `aria-current`: 관련 탐색 항목 집합에서 현재 항목을 보조기술에 명시합니다.

## 구현 및 안전성
주식 탐색 UI/도우미/테스트와 문서만 변경했습니다. 정렬은 `BigInt`를 사용하며 API, PostgreSQL 스키마, 원장, 권한, 멱등성, 마이그레이션, 운영 데이터 경로는 변경하지 않았습니다.

## 검증
contract build 후 검색/정렬 집중 테스트와 frontend typecheck가 통과했습니다. GitHub CI와 exact-SHA Test 런타임은 계속 필수 승격 게이트입니다.
