# Backend B v668 — 개인 대화 조회 최소 권한 복구

**상태:** DRAFT / RELEASE HOLD. **관련:** #2053. **기준 main:** bf8d0d48f810932b43783d8605dce53954c60cff.

기존 대화 목록·메시지 이력·동기화·미확인 수·보관 경로의 테이블 직접 접근은 마이그레이션 220의 권한 회수와 충돌했다. 신규 전진형 마이그레이션 313에 회원 참여 검증이 포함된 SECURITY DEFINER 함수 4개를 추가하고, 앱 계정에는 함수 실행 권한만 부여했다. 기존 테이블 권한은 복구하지 않았다.

Backend는 함수 호출로 전환하고 PostgreSQL 권한 거부(42501)를 HTTP 403으로 변환한다. 미검증 미확인 건수를 0으로 표시하지 않는다. 응답 필드와 정확한 bigint 문자열 커서는 유지한다. 금융 원장·WLD·운영 DB는 변경하지 않았다.

수정 전 테스트 3+1건 실패를 확인했고, 집중 테스트 10/10 및 채팅 회귀 144 PASS/8 SKIP을 확인했다. 격리 PostgreSQL 17.11에서 전체 002~313 마이그레이션과 회원별 접근·제3자 차단·보관을 검증한 후 컨테이너를 제거했다. 전체 Backend 126건·Frontend 55건 실패와 전체 lint 1건 오류, 공식 Test exact-SHA 미검증으로 병합·배포는 금지한다. Frontend C v1203과 통합 검증이 필요하다.
