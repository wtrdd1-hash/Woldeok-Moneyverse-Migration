# v2026.10.29.1205 — 원장 불일치 해결 구조 구축 기록

**상태: 격리 PostgreSQL 증거 수집 기능 테스트 통과 / 역사적 잔액 불일치 미해결 / 운영 미반영.** 작업 시작 main `bd590720237020c2ad329d6f62c3b0db5a95a6c1`. 기존 금융 쓰기 권한은 사용자 지시대로 유지, Gemini 등 다른 작업트리 불변.

## 기존 진단 정정 — 매우 중요
이전 v1202/v1203 보고의 24계좌·20,261,240 WLD는 분개 부호를 잘못 반대로 계산한 수치였으므로 철회한다. `economy_post_transaction`과 공식 018 대사 함수의 실제 규칙은 **debit=잔액 증가, credit=잔액 감소**다. 동일 격리 복원 DB를 재계산한 결과 **USER_CASH 18계좌 각각 +1,000 WLD, 총 18,000 WLD**의 저장 잔액-원장 차이가 확인됐다. MINT/SINK/은행/국고 계좌는 일치. 거래별 대차불균형 0건. 이전 수치는 잘못된 검사 이력으로만 남기며 현재 진단으로 인용하지 않는다.

18개의 1,000 WLD 차이가 가입 시 지급된 합법적 기초 자금인지 원장 외 직접 변경인지는 아직 증명되지 않았다. 국고 별도 기록 552건의 원장 ID NULL도 당시 정책·거래 발생 시기 조사 전에는 오류로 확정할 수 없다.

## 실제 구현
신규 순방향 마이그레이션 `294-ledger-discrepancy-case-registry.sql`: PK/FK/CHECK가 있는 `ledger_reconciliation_runs`, `ledger_reconciliation_cases` 생성. `ledger_capture_reconciliation(source_tag)`로 정확한 차변/대변 부호에 따라 계좌별 증거·차이·분개 수·원장 불균형 합계를 수집하고 스캔 경합 검증. 쓰기 가능 DB에서는 `BEGIN ISOLATION LEVEL REPEATABLE READ` 사용. 새 증거 테이블의 앱 직접 쓰기는 차단하지만 **기존 금융 테이블 GRANT는 변경하지 않음**. 기존 `moneyverse_reconciler` 역할에 실행 권한 부여. 금액·원장·국고 자동 변경이나 임의 지급 없음.

격리 PostgreSQL 17.11에 적용하고 `verify/294-ledger-discrepancy-registry.sql` 시험 통과: 18계좌 × 1,000 WLD = 18,000 WLD, 대차 불균형 0건. 시험 데이터는 `ROLLBACK`으로 삭제. 원본/운영 DB에는 적용하지 않았다.

## 해결 결정 기준
- **합법적인 과거 초기 지급이 입증된 경우:** 해당 지급 원본·정책·반대계정·이중 지급 방지 기록을 검증한 다음 사용자 잔액을 재지급하지 않는 복식부기 *과거 기초 잔액 인식 분개*를 별도 개발·검증해야 한다. 단순 1,000 WLD 차이만으로 자동 발행 금지.
- **승인되지 않은 직접 잔액 조정이 입증된 경우:** 개별 증거·승인·감사 영수증에 따른 정정 정책 필요. 캐시 잔액을 원장 합계로 무단 덮어쓰지 않는다.
- **원인 불명:** UNEXPLAINED 상태 유지, 자동 보정·소각·신규 발행 없이 경보 및 후속 비교.

추가 완료해야 할 사항은 18계좌 초기 지급 증거, 국고 552건 분리 정책, 메모리/캐시와 병행 거래 처리, 인증 공식 Test, 전체 마이그레이션, 운영 DB 최종 동기화다. 실제 차이 해소를 완료한 것으로 보고하지 않는다.

## 2026-10-29 운영자 확인: 과거 1,000 WLD는 국고 지급
사용자가 **USER_CASH 18개 계좌의 각 +1,000 WLD 차이(합계 18,000 WLD)는 국고에서 지급한 돈**이라고 명시적으로 확인했다. 과거 자금 출처를 **`TREASURY_FUNDED_PAYMENT`(국고 지급금)**, 확인 근거를 **`OPERATOR_ATTESTED`(운영자 진술 확인)**, 실제 원장 연결 상태를 **`NOT_YET_CORROBORATED`(국고 출금·지급 영수증 대조 미완료)**로 기록한다. 이로써 지급 주체에 관한 운영자 설명은 확보됐지만, 특정 `system_treasury_ledger` 행 및 실제 지급 거래 ID를 찾았다고 주장하지 않는다.

**회계 처리:** 수령자 잔액에 이미 반영된 **과거 국고 지급금**으로 분류한다. 사용자에게 1,000 WLD를 재지급하거나 임의 조폐·소각·상계하지 않는다. 수정 분개 전 국고 잔액, 지급 일시·영수증, 국고 보관함 기록, 정확한 차변·대변 방향을 대조하여 **국고 중복 차감 및 사용자 중복 지급을 금지**한다. 기존 국고 지출 기록이 이미 존재하면 그 지출을 중복 인식하지 않는다. 과거 날짜·거래 ID를 만들어내지 않는다.

상태: **사용자 자금 출처 확인 완료 / 실제 국고 지급 영수증 및 원장 연결 검증 대기 / 잔액·전표 변경 없음**. 이번 추가 기록 시 격리 DB 컨테이너가 없어 신규 DB 검증은 수행하지 못했다.
