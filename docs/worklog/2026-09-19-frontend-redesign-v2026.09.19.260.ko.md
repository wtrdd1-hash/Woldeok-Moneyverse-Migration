## 제약사항

- 모든 라우트와 API 동작 유지
- 브라우저에서 백엔드 API 직접 노출 금지
- 저장소 기본 언어는 영어, 두 번째 문서 언어는 한국어 유지
- WCAG 2.2 AA 지향 상호작용 유지 또는 개선
- 모바일 주요 액션은 가능한 한 44 CSS px 이상
- reduced-motion 사용자 설정 존중
- 작은 화면이라는 이유로 재무·운영 핵심 정보 숨김 금지

## 레퍼런스 분석 요약

사람이 직접 설계한 대규모 제품 디자인 생태계와 최신 금융·커뮤니티·게임 대시보드 사례를 폭넓게 표본화했다. 동일 크기 카드 반복, 과도한 글로우, 장식적 글래스 효과, 모든 영역의 동일 밀도를 피하고 비대칭 위계, 리스트·테이블 표면, 편집형 여백, 절제된 포인트 색상, 기능 영역별 정보 밀도를 적용했다.
