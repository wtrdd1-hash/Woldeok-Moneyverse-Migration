## 프론트엔드 구현 필수 규정
1. 승인된 업무 기능을 유지한다. 하단 5탭 또는 사용자 승인 대체 구성과 별도 상시 전체 메뉴를 제공한다. PC·모바일·검색은 공통 역할별 경로 모델을 사용한다. 금융·투자, 직업·사업, 게임, 상점, 커뮤니티, 계산기·가이드, 계정, 지원·약관을 분류하고 인가된 관리자만 관리자 항목을 표시한다. 백엔드 RBAC 별도 강제. 검색만으로 전체 메뉴를 대신하거나 화면 단순화를 이유로 기능을 제거하지 않는다.
2. 의미 기반 번역 키와 언어별 검수 사전을 사용한다. 직역·어색한 기계번역을 피하고 문맥에 맞는 자연스러운 문장, 금융·게임 용어 일관성을 검수한다. 메뉴, 제목, 버튼, 설명, 입력·placeholder, tooltip/ARIA, 표·차트, 모달, 토스트, 오류·빈·로딩 상태, 영수증, 시스템 알림까지 적용한다. 서버 오류 코드는 안전한 현지어 UI 메시지로 매핑한다. 사용자 작성 콘텐츠/출처 원문은 명시 번역 요청 없이는 보존한다. 금액·식별자·실제 원장 및 서버시간을 번역이나 숫자 포맷 과정에서 임의 변경하지 않는다.
3. 서버·클라이언트·BFF·기존 화면의 언어 해석을 일치시킨다. 수동 선택은 페이지 이동·새로고침·로그인/로그아웃 시 계정 경계를 지키며 보존하고 GeoIP/브라우저 감지가 이를 덮어쓰지 않게 한다. 번역 키 노출, `Translation unavailable`, 의도하지 않은 언어 혼용, 영어 선택 시 첫 화면 한국어 깜빡임, 부분 번역 완료 판정을 금지한다. 예외 fallback은 안전하고 관측 가능해야 하며 QA PASS로 인정하지 않는다. 영어 첫 번째/기본, 한국어 두 번째 고정. 디자인 시안 문구를 전체 번역 사전으로 오인하지 않는다.
4. 승인된 180 디자인/QA 목록 및 해당 경로 계약(서로 다른 집합)을 대상으로 역할×경로×언어×화면 크기 검사를 필수화한다. 비회원·회원·인가 관리자, EN/KO/JA/ZH/VI, 모바일 320/390px·PC, SSR/hydration·언어 변경·딥링크·뒤로가기·새로고침·인증 전환·오류·비동기 갱신을 검증한다. 44px 터치·포커스·긴 번역·줄바꿈·잘림·가로 넘침·검색 없이 메뉴 접근도 확인한다. 번역 키/변수 정적 검사, 브라우저 캡처, 실 API 연계 E2E 필수. 누락 번역 및 인가 기능 메뉴 누락은 운영 승격 차단 사유다. 경로·언어·역할·상태·스크린샷·정확 SHA·결과 기록 후 독립 Test와 기존 보안/롤백 규정을 적용하며 별도 승인된 무중단 운영 승격만 허용한다.

## 작업 범위 / 인수인계
미니PC 착수·중간 기록, 기존 메뉴 감사 및 영어 오류 제보 보존, 운영 공개 SSR 재현 완료. 앱 코드·서버·DB·배포 변경 없음. 전체 문서 수동 전수·번역 감수 및 인증 E2E는 미완료. 구현 착수 전 최신 main을 재확인하고 Claude/Gemini와 격리 브랜치로 충돌 방지, 현재 시각 권위는 변경하지 않는다.
