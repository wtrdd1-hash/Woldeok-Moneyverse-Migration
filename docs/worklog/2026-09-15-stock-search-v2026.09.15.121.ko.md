# 작업 기록 — v2026.09.15.121 주식 검색

## 사용자 이점

사용자는 모든 시장 카드를 훑지 않고 종목 코드, 이름, 설명 키워드로 가상 종목을 바로 찾을 수 있습니다. GET 검색 상태는 북마크·공유할 수 있고 클라이언트 JavaScript 없이도 동작합니다.

## 참고 자료

- Next.js 검색 가이드: URL 검색 파라미터는 검색 상태를 북마크·공유 가능하게 하고 서버 렌더링에 활용할 수 있습니다.
- W3C WAI Forms Tutorial: 네이티브 컨트롤, 연결된 레이블, 명확한 피드백은 접근 가능한 폼 사용성을 높입니다.
- Nielsen Norman Group: 비교·탐색 작업에서는 선택지와 비교 정보를 쉽게 훑을 수 있어야 합니다.
