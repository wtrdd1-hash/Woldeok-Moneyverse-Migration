# Worklog — v2026.09.15.121 stock search

## User benefit

Members can find a virtual stock directly by ticker, name, or descriptive keyword instead of scanning every market card. GET query state is bookmarkable and works without client-side JavaScript.

- W3C WAI Forms Tutorial: native controls, associated labels, and clear feedback improve accessible form use.
- Nielsen Norman Group: comparison/discovery tasks benefit when choices and comparable information remain easy to scan.
