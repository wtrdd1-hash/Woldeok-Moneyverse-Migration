# 한국어 문서 이동 정비 작업 기록 — v2026.09.13.16

날짜: 2026-09-13
범위: 한국어 문서 탐색 및 링크 정비
적용: `main` 직접 반영

## 확인한 문제

1. `README/README.ko.md`는 이전 작업에서 한국어 전용 문서 지도로 정리되었습니다.
2. 별도로 남아 있던 `README/README.auto.ko.md`에는 영문 상세 문서 링크가 다수 남아 있었습니다.
3. `docs/operations/production-deployment.ko.md`에서 실제 인프라 설명 링크가 영문 `INFRASTRUCTURE.md`를 가리키고 있었습니다.
4. 운영자 체크리스트 안내도 영문 `RELEASING.md`를 먼저 제시하고 있었습니다.

## 적용

- 한국어 보조 README를 한국어 전용 탐색 페이지로 교체했습니다.
- 한국어 문서에서 대응 한국어 파일이 존재하는 일반 링크는 `*.ko.md`로 연결했습니다.
- 기획 관련 사용자 표시를 `기획서`로 유지했습니다.
- 명시적인 언어 전환 링크(`English`, `영문 원문`)는 영어 문서 접근 수단으로 별도 유지합니다.

## 추가 확인

대표 경로인 한국어 문서 홈, 전체 가이드, 문서 색인, 시스템 개요, 직업 및 성장, 모바일 API, 보안 모델, 운영 배포를 다시 확인했습니다. 이들 문서의 일반 연관 문서 링크는 한국어 문서로 연결되도록 구성되어 있습니다.
