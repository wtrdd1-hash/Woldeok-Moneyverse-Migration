## 중간
- 공용 KDIC API가 프론트에 필요한 기관 ID·예금 수탁액·예보료율을 누락하던 계약 수정. 비공개 지급 기록이나 개인정보는 새로 노출하지 않음.
- 화면에 존재하던 1000만 WLD 기본값, 가짜 2개 기관, 가짜 평균 BIS 수치 제거. 실제 0이면 0, 원본 정보 없으면 '자료 없음', 정상 기관이 0개이면 0개로 표시.
- 숫자 안전 정수 범위·원본 기관 합계·요율·날짜 검증. 보호한도 계산기에 음수·소수·오버플로우 방어 및 총 예금 0일 때 NaN 방지. 실제 지급·법정 보증이라는 허위 문구를 가상경제 정책 시뮬레이션으로 명확히 구분. KDIC 지급 자체는 정식 재원 검증 전 503 보호 유지.
- 프론트 집중 테스트 7/7, 백엔드 집중 테스트 7/7, 양측 타입 검사 통과. DB·원장·운영 회원금액 무변경. Test KDIC 500은 운영과 다른 기존 SELECT 권한 차이이며 이번 UI 수정만으로 해결됐다고 주장하지 않음.
