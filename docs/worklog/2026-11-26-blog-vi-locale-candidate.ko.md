# 블로그 베트남어(vi) 로캘 — 후보 명세 v2026.11.26.1625.1
[English](2026-11-26-blog-vi-locale-candidate.md) | **한국어**

상태: PLANNING(코드·콘텐츠 없음). 소유자 결정 v1517.1: 기사 번역을 생성·게시하지 않고 웹 5개 언어 계약에 맞는 후보 준비.

## 관찰
- 사이트는 ko/en/ja/zh/vi를 지원하지만 블로그는 별도 `BlogLocale`(ko/en/ja/zh)을 사용 → 운영 `/vi/blog` 404, 나머지 4개 언어 200.
- `blog_verified_articles.locale` CHECK 제약은 ko-KR/en-US/ja-JP/zh-CN만 허용, 국가별 편집 기사는 4개 언어 본문만 보유.

## 후보(웹 단계)
1. `BlogLocale`에 `vi` 추가, 허브/상세 화면 문구·안내·hreflang `vi-VN`·날짜 형식은 검수된 번역 사용(런타임 생성 금지).
2. 기사 본문: 베트남어 본문이 없으므로 `vi` 방문자에게 영어판과 "영어 기사" 안내를 명시, hreflang/canonical은 영어 URL. 기계 번역 본문을 베트남어로 표시하지 않음.
3. DB: 베트남어 편집 원천이 생기기 전까지 마이그레이션 없음. 이후 새 마이그레이션으로 CHECK에 `vi-VN` 추가(기존 마이그레이션 수정 금지).
4. 테스트: `/vi/blog` 200·베트남어 화면, 상세의 영어판 안내, 사이트맵/hreflang은 본문 있는 언어만, 기존 4개 언어 불변.

## 차단
검수된 베트남어 UI 문구(제품 문구는 소유자 관할), 베트남어 편집 원천 계획 여부 결정.
