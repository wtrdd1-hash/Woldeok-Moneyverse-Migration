## 작업 종료 및 제약
구형 JSON 파일의 일반 계정 직접 수정·교체·삭제를 막는 **긴급 임시 차단**으로, 상위 root 권한이나 다른 파일에 대한 전역 차단을 의미하지 않음. 이 설정으로 기존 JSON 관리자 수정·비공개·삭제 기능도 제한됨. 추후 DB 영수증 발행기/인증된 관리자 수정 경로가 정상 운영되면 0600 백업과 체크섬 확인 후 승인된 유지보수 상황에서만 sudo chattr -i를 사용하고, 구형 발행기가 남아있다면 보호를 재적용할 것. 지금은 글 13건 자동 철회하지 않음.
