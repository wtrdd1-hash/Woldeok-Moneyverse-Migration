## 실제 main의 문제와 분리 작업

현재 main의 Next.js `/api/admin/treasury/swf/liquidate`는 수동 청산 POST를 NestJS로 전달하며, 관리자 화면은 원장 정산 영수증 검증 없이 `success` 값만으로 국고 회수 성공을 알릴 수 있다. 이는 **코드상의 잠재 위험**이며 운영에서 실제 자금이 이동했다는 증거는 아니다. Backend 개발 B의 Draft PR #1751이 NestJS 차단을 담당하므로 해당 서비스와 DB를 수정하지 않았다. 기존 C SWF 조회 PR #1691도 보존한다.
