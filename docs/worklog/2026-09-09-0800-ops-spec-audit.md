The CI workflow already has one comprehensive `check` job covering secrets, lint, typecheck, build, PostgreSQL migrations, database-backed tests, Prisma migration guards, and production dependency audit.

### P2 — workflow action pins and image attestations are weak

The current workflows use movable major action tags rather than reviewed full commit SHAs. The production image build also sets both `provenance: false` and `sbom: false`. GitHub's secure-use guidance identifies full-length commit SHA pinning as the immutable action reference, while GitHub and Docker support signed provenance/SBOM evidence for container images.

Action this run: opened issue #129. The implementation should be coordinated with #126 so the authoritative Kubernetes/Flux deployment path consumes exact image digests and can verify the evidence instead of hardening a deployment path that is being retired.
