## 종료 범위 / 미완료
- 전체 180개 PNG **재디자인·교체는 미완료**. 신규 CSS가 실제 적용되는 범위는 **Spring Thymeleaf 공통 셸을 사용하는 화면만**이며, legacy 정적 HTML/별도 화면에는 자동 적용되지 않음.
- 인증 없는 화면의 관리자 링크·검색 결과 노출 여부를 실서비스에서 검증하지 못함. 기존 공통 셸에는 일반 관리자 메뉴가 없으나 전체 화면 관리자 전용성은 실서버 역할별 QA가 필요.
- 은행 입출금 폼과 서버 금리 정산 기능, 전 사이트 기능 QA, 독립 Test·운영 브라우저 스크린샷 및 운영 승격 **미실시**.
- GitHub 독립 승인·필수 체크가 없으면 main 병합 불가. 이 회차에서는 PR만 생성하여 검토를 요청하고, 기존 보호 규칙은 해제하지 않는다.
