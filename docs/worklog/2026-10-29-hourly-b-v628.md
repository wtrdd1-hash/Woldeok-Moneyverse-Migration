# Backend B v628 — Treasury overview evidence integrity (RELEASE HOLD)

Date: 2026-10-29 09:35–09:53 KST. Baseline main: `2ac90063d45cfab879d4fb36863484d8a423deba`. Isolated branch `auto/hourly-b-treasury-overview-evidence-v628-20261029-0935`.

## Source-backed defect
`TreasuryRepository.getOverview()` swallowed circulation and 30-day outflow SQL failures, replacing missing circulation with zero, reporting a fabricated 100% reserve ratio, and substituting 10,000 WLD/day for absent or zero expenses. `calculateLiveBudgets()` silently returned zero settled amounts when ledger evidence failed. The new public `GET /api/v1/treasury/public-overview` and the admin overview both consume this repository. No actual loss or abuse was observed.

## Implementation
- Missing, invalid or failed circulation evidence now raises HTTP 503 `TREASURY_CIRCULATION_UNVERIFIED` instead of a synthetic ratio. Zero denominator cannot produce a meaningful percentage.
- Missing, negative or failed 30-day outflow evidence raises HTTP 503 `TREASURY_OUTFLOW_UNVERIFIED`; SQL COALESCE uses real zero instead of 10,000 WLD. A verified zero expense omits `coverage_days` from JSON, and the existing admin UI displays `-` (no fabricated number).
- Budget ledger query failure raises HTTP 503 `TREASURY_BUDGET_EVIDENCE_UNVERIFIED`, not an empty/zero spend claim.
- Preserved real bigint WLD strings, existing public/admin authorization, read-only behavior and the reconciliation `UNVERIFIED` contract. No DB migration, grant, WLD, ledger, Production or Test mutation.
