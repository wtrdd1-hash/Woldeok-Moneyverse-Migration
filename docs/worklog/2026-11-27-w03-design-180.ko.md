## 작업 전
- 권위: 권위 PR #3469(미병합) 기준으로 G2 "Guild Ledger Terminal"이 유일한 활성 시각 기준. main에는 G1/G2/v11 드리프트가 남아 있어 미해결 모호성으로 기록. 180개 경로 이미지는 원형 예시일 뿐 승인 증거가 아님. 관리자 접근은 기본 거부.
- 기준: fe/mobile-nav-i18n-20261126 @ 2a13ab5d78.
- 읽은 스킬과 사용 방식:
  - frontend-design: G2 브리프의 하위 도구, 새 시각 방향 없음.
  - design-taste-frontend(Taste Skill): 마케팅 사이트용 규칙이 G2와 충돌해 템플릿 패턴 점검에만 사용.
  - ui-ux-pro-max: 짧은 라벨 넘침, 터치 대상 크기, 포커스 가림을 로컬 검색.
  - browser-qa: 읽기 전용 격리 샌드박스, 두 폭, 역할 부정 검사 포함.
  - Impeccable·Unslop·Huashu Design: 소유자 v0925.1 요청, 결함 순위가 높은 경로에 사용.
- Gemini 시안은 비권위 참고. 호환되는 라벨 처리 조언만 채택하고, 밝은 테마·FAB 내비·고정폭 데이터 글꼴·시뮬레이션 배너·통화 표기 변경은 G2와 충돌해 기각.
