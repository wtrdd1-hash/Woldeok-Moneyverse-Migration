- 최신 `main` 시작 커밋 `c9462af98074306d67030a40037c00ac42e65493`. 새로운 격리 브랜치 `fix/seo-locale-canonical-v2026.10.19.920`.
- 우선 열람: AGENTS, 문서 정책, 통합 계획, PROJECT_PLAN, v860 SEO·사용자 유입안, sitemap, proxy, 기존 테스트, 실제 번역 복리 계산기 코드. 다른 작업자 파일·원장은 수정하지 않는다.
- MiniPC Desktop Commander 장치는 모두 오프라인이고 전용 PC RPC 시간초과. 지침에 따라 GitHub에서 작업. 이번 세션의 실제 Test/운영 SHA, 금융 준비 검사 및 공식 검색 제공자 성과 수치는 미검증.
- 코드 결함: 모든 비로캘 공개 경로에 en/ja/zh 대체 주소를 기계적으로 생성. 일부 대체 주소가 한국어 본문·제목·정규 URL을 그대로 반환한다. 특히 `/en/tools/compound-calculator`, `/ja/tools/compound-calculator` 등에서 관찰. 실제 외국어 복리 계산기는 별도의 `/{locale}/tools/compound-interest-calculator` 경로에 구현됨.
- 수정 범위: 확인된 실제 번역 페이지만 다국어 대체 링크 제공; 잘못된 복리 계산기 별칭을 해당 언어 실제 계산기로 영구 리디렉션; 쿼리 보존 및 대체 언어 왕복 테스트. 회원·금융 데이터, 지급, 캐시, 운영/Test 배포 포인터 및 색인 전송은 변경하지 않는다.
- 이전 사용자 초기화 승인만으로 운영 회원 원장·계좌·감사 데이터 근거를 제거하지 않는다. 운영 승격에는 정확한 SHA CI, 격리 Test, 금융 원장과 인증 전체 기능 테스트, 백업·무중단·롤백 증거가 필요하다.

## 중간 기록 — 2026년 10월 19일
- 검증된 언어 경로 매핑·오래된 복리 계산기 주소 리디렉션·사이트맵 검증 테스트를 먼저 작성. PC 접속 불능으로 로컬 테스트를 실행했다고 주장하지 않음.
- `seo-locale-alternates.ts`, 사이트맵, 프록시, 번역된 글로벌 복리 계산기 한국어 역방향 hreflang 수정. 한국어 페이지 URL 및 원장/개인정보 유지.
- Google 공식 규정에 맞춰 한국어/영어/일본어/중국어 사이트맵에 동일한 왕복 hreflang 그룹을 제공하도록 추가 보완.
- 첫 GitHub CI의 정적 검사에서 새로운 사이트맵 테스트 정규식 파싱 오류가 발견돼 바로 수정. 최신 커밋으로 CI 재실행 중, 이전 실패를 통과로 오인하지 않음.
