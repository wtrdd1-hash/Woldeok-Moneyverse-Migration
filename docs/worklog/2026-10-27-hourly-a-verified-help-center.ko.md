## 시작
Debian 13.6 미니PC·서비스·DB 연결을 직접 확인했다. 최신 main `5888176454648f51d5f986be60a22847bd234777`, 저장소 정책, 국영문 기획, QA v1312, 계획 v1352를 읽었다. 다른 개발자의 Worktree와 미통합 변경을 보호하고 tmpfs에 독립 브랜치를 만들었다.

## 진행
승인된 자료만 공개하는 PostgreSQL 함수, 운영자 초안·별도 승인자 게시/철회, 관리자 세션·권한 검사, 멱등 영수증과 변경 버전 검사, 감사 기록 불변 트리거, NestJS 공개·관리자 API, Next.js 공개 검색/상세·관리자 화면, Android 공개 조회 허용 경계를 작성했다. 기본 기능 스위치는 OFF다. 실서비스 연결 DB는 변경하지 않았다.

격리 PostgreSQL 17에서 100개 동시 게시·100개 동시 철회·100개 재시도·100개 위조 관리자 요청, 합성 자료 10,001건, 만료·미승인 비공개, 앱 역할 직접 DML 및 PUBLIC 실행 거부를 검사했다. 모든 동시 요청에서 중복 게시·철회 영수증이 생성되지 않았다. 백엔드 빌드와 Typecheck, Webpack 기반 프론트 빌드, 전체 린트는 통과했지만 보안 감사와 마이그레이션 연속성 검사는 실패했다.
