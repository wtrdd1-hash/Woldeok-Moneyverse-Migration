## Mandatory implementation contract
1. Preserve all approved business features. Keep the five quick tabs or an owner-approved equivalent and add a persistent, accessible full-menu entry; use one role-filtered navigation model across desktop, mobile and search. Group financial/investment, careers/business, games, shop, community, calculators/guides, account, support/policies; expose administrator entries only to verified authorized administrators and enforce backend RBAC independently. Search is not a substitute for browsing. Do not remove features solely to simplify layout.
2. Use stable semantic message keys and reviewed locale catalogs, with consistent terminology, natural idiomatic wording and context-specific financial/game language. Translate menus, headers, buttons, descriptions, form labels/placeholders, tooltips/ARIA, tables, charts, modals, toast/error/empty/loading states, receipts and system-generated notifications. Localize backend error codes via safe UI messages; preserve user-generated content and original source text unless an explicit translation is requested. Never fabricate financial values or translate identifiers/amounts. Format dates, numbers and units by locale without changing canonical game time, currency amounts or ledger semantics.
3. Resolve language consistently between server, client, BFF and legacy surfaces; persist explicit selection through navigation/reload/login/logout subject to account boundaries. Do not allow GeoIP/browser detection to override manual choice. No visible translation keys, `Translation unavailable`, unintended language mixing, initial Korean flash in EN, or silent partial success. An exceptional runtime fallback must be safe, observable and not count as a QA pass. Keep English first and Korean second. Never use design-preview strings as a complete translation catalog.
4. Gate future frontend work on a role × route × locale × viewport matrix covering the authoritative 180 design/QA inventory and applicable route contract (not equivalent counts), 320/390px and desktop, guest/member/authorized administrator, all five languages, first SSR, hydration, switches EN↔KO and other locales, deep links, back/reload, auth transitions, errors and async updates. Verify 44px touch targets, focus, long translations, line wrapping, no clipped labels or horizontal page overflow. Check role-safe menu reachability without requiring search. Static key-parity and placeholder tests plus browser screenshots and real API-backed E2E evidence are mandatory. A missing translation or authorized menu entry is a release blocker. Track route, locale, role, state, screenshot, exact SHA and test result; independent Test and existing security/rollback gates before separately authorized zero-downtime Production promotion.
