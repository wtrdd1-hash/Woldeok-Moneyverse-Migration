# 라이선스 공개 준비 작업기록

업데이트 버전: `2026.09.12-02`

## 작업 범위

- 애플리케이션 저장소를 공개 상태로 전환하기 위한 코드/문서 준비.
- 인프라 저장소와 동일한 Apache License 2.0을 루트 `LICENSE`에 추가.
- 루트 `package.json`에 `Apache-2.0` 라이선스 메타데이터 명시.
- 기존 테스트/운영 배포 게이트 유지. 이번 변경은 런타임 동작, DB 스키마, 배포 매니페스트를 변경하지 않음.

## 확인 사항

- 작업 시작 시 애플리케이션 저장소는 private 상태였음.
- 변경 전 GitHub 저장소 메타데이터에는 감지된 라이선스가 없었음.
- 인프라 저장소가 이미 Apache License 2.0을 사용하므로 애플리케이션 저장소도 동일 기준으로 맞춤.

## 검증 / 배포 상태

- 변경은 `license/public-reopen-20260912` 브랜치에 격리함.
- 활성 통합/릴리스 브랜치에 병합하기 전에 CI 통과가 필요함.
- 저장소 공개 여부는 GitHub 관리자 설정이므로 이 커밋 자체로 공개 상태가 변경되지는 않음.
- 런타임 테스트 및 운영 승격은 기존 사전운영 검증 절차를 그대로 따름.

## 남은 위험

저장소를 실제 공개하기 전에 현재 트리와 Git 이력에 비밀키, 자격증명, 개인정보, 내부 전용 산출물이 없는지 다시 확인해야 함.
