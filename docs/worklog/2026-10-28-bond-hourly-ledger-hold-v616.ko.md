# 개발 B v616 — 국채 시간당 쿠폰·만기 정산 안전 차단

기존 Repository의 시간당 쿠폰·만기 정산은 회원 `account_balances`를 직접 증가시키고 국채 쿠폰 로그만 남겼다. 복식원장 거래, 정산 기간별 멱등 영수증, 국고 재원 검증이 없으며 반복 실행 시 중복 이자가 발생할 수 있었다. SWF 자동 세금 처리에도 동일한 위험을 가진 별도 SQL `DO` 블록이 존재했다. **실제 운영 손실이 확인되었다는 뜻은 아니다.**

이번 소스 변경은 Repository와 Service에서 정산을 DB 접근 전 HTTP 503으로 차단하고 SWF의 별도 쿠폰·원금 입금 블록을 제거했다. 조회 기능, 다른 SWF 처리, 적용 마이그레이션, 실제 DB·원장·잔액은 변경하지 않았다. 이는 정산 기능의 완성이 아닌 안전 차단이다.

수정 전 회귀 테스트 3건 실패를 확인한 뒤 집중 테스트 17건, Backend 1,942건(440건 건너뜀), DB 패키지 46건(4건 건너뜀), Backend 타입검사·빌드, API 계약 180개, 보안 정책 9건, 전체 lint 오류 0건을 확인했다. 다만 `qs@6.16.0` Moderate 취약점이 남고 전체 Frontend/Next 빌드, 운영 스키마 격리 PostgreSQL, 인증 E2E, 공식 Test 정확 SHA는 검증되지 않았다. 디스크 98%로 자원 소모가 큰 검증은 실행하지 않았다.
