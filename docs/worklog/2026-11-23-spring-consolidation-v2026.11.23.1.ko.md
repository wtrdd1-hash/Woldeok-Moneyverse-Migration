# Spring 전체 전환 통합 감사 — v2026.11.23.1

**상태:** 문서·저장소 조사 단계 완료. 실제 전체 코드 전환 및 운영 승격은 **미완료**. 영문 정본: [Spring migration consolidation audit](./2026-11-23-spring-consolidation-v2026.11.23.1.md).

## 작업 전
사용자 지시: 기존 전체 분석을 통합해 웹 프론트엔드·백엔드 변경을 Spring 중심으로 정리하고 실제 전환할 것. 통합기획 `docs/planning/INTEGRATED_PLANNING_MASTER.md`, `PROJECT_PLAN.md`, 11월18일 디자인 권위문서, 11월21일 Spring 전체 재구축 계획, `AGENTS.md`, `GEMINI.md`, 11월22일 배포 기록을 우선 조사함. 시작 기준 main `9876c09888ec84034eec183cf1309c85df3d7447`. 원격 접속 대상 minipc/debian13/weoldog 모두 오프라인이어서 실제 Nginx·systemd·DB·Test 서버 접근 불가.

## 현재 확인 사항
- 웹 저장소 `Woldeok-Moneyverse-Migration`에는 Spring `spring-backend/` 외에 구형 NestJS `backend/`, Next.js `frontend/`, `bot/`, PostgreSQL 패키지와 운영 코드가 공존. 소스 존재만으로 실제 구동 중이라고 판단하지 않음.
- 별도 `woldeok-moneyverse-app`은 Kotlin/Gradle **안드로이드 앱**. 사용자가 지시한 웹의 Spring 전환과 구별하고 앱은 Spring 서버 API 연동 대상으로 유지.
- 통합기획의 최신 상단 기록 기준 공개/회원/관리자 웹은 긴급 503 유지보수 상태. 11월22일 Spring 관리자 상품 조회는 보호된 미리보기 연결이지 전체 운영 전환이 아님.
- 11월22일 문서의 662개 Spring 테스트 통과 및 PostgreSQL 대상 24개 제외는 **과거 기록**. 이번 작업의 신규 테스트 결과가 아님.
- 현재 main 최종 커밋은 Google·Discord OAuth 복구 관련. 임의로 로그인 수단을 삭제하지 말고 현재 실제 인증 흐름 검증 필수.
- 11월18일 디자인 180화면 대비 기존 시안·구형 HTML·Spring 템플릿 혼재, 샘플 잔액/그래프, 은행·지갑·관리자 쓰기, 글로벌 채팅·문의, 5개 언어, 동적 화면 검증은 미해결 또는 일부 완료 상태.

## 적용할 확정 원칙
1. **웹**의 모든 사용자·관리자 화면과 API 제공 계층은 Spring Boot MVC/Thymeleaf로 단계적 통합. 독립 Node 웹서비스를 목표 구성에서 제거하되 실제 의존성을 확인한 뒤 중단. 클라이언트 JavaScript 자체를 금지하는 뜻은 아님.
2. 기존 PostgreSQL `SECURITY DEFINER` 이중원장·최소권한 유지. Spring으로 옮긴다는 이유로 DB 직접쓰기·원장 우회 금지.
3. 11월18일 승인 디자인, 네이비·보라 색 체계, 현재 파비콘, PC/모바일 반응형, 언어 자동 감지와 수동 선택(기본 영어·한국어 2순위, 기존 승인한 총 5개 언어), 전역 채팅/관리자 문의 접근성 유지.
4. Google/Discord 로그인, 회원·관리자 권한, 지갑 잔액·예금·입출금·송금·카드, 실제 상점·주식·커뮤니티 기능의 응답 출처와 영수증 검증. 존재하지 않는 기능은 허위 성공 대신 명시적 미지원.
5. 보안 및 원장 관련 CSRF·세션·소유자 검증·금액 정밀도·중복처리·감사·영수증 필수. 운영 전 정밀 QA와 무중단 롤백 증거 필수.
