# v2026.09.16.137 — 적체 브랜치 자동 재시도 및 재조정

- GITHUB_TOKEN으로 push한 브랜치는 후속 워크플로가 자동 실행되지 않을 수 있으므로, 재조정된 브랜치마다 `Build Test Candidate`를 명시적으로 실행하도록 수정했다.
- 같은 exact HEAD SHA에서 후보 테스트가 2회 이상 실패한 관리 대상 브랜치는 동일한 실패 테스트를 반복하지 않고 최신 `main` 기준으로 자동 재조정한다.
- 재조정된 새 HEAD는 반드시 fresh exact-SHA 후보 테스트를 다시 통과해야만 병합된다.
- 재조정 결과가 `main`과 동일하면 PR을 닫고 브랜치를 삭제하며, 검증된 정상 브랜치는 병합 후 원본 브랜치를 삭제한다.
- 실패한 브랜치나 재조정된 브랜치가 무기한 남아 브랜치 정리 목적을 방해하던 마지막 적체 경로를 제거한다.
