## 2. Key Implementations

### 1) SEO Single Source of Truth (SSOT)
- Created `frontend/src/config/routes.config.ts`:
  - Declaratively manages `isPublic`, `indexable`, `sitemapPriority`, and `changeFrequency` for all application routes.
- Updated `frontend/src/app/robots.ts`:
  - Dynamically disallows private member routes (`/bank`, `/wallet`, `/casino`, `/quests`, `/seasons`, `/work`, `/businesses`, `/spaces`, `/newspaper`, `/marketplace`, `/chat`, `/account`, `/admin`, `/stocks/*`).
  - Standardized the canonical `Sitemap` directive.

### 2) Sitemap Timestamp Standardization & 307 Redirect Prevention
- Eliminated fake `new Date()` request timestamps, switching to fixed release timestamps (`2026-09-26T21:00:00.000Z`) and genuine DB post timestamps.
- Removed protected routes (`/stocks/[symbol]`, `/casino`) from sitemaps to prevent crawling 307 redirects.
- Aligned `sitemap-static.xml`, `sitemap-stocks.xml`, `sitemap-announcements.xml`, and `sitemap-board.xml`.

### 3) Default Locale Harmonization & Metadata Overhaul
- Standardized default locale to English (`DEFAULT_LOCALE = 'en'`) with Korean fallback.
- Removed redundant same-URL hreflang declarations.
- Implemented dynamic 4-locale (ko/en/ja/zh) metadata via `generateMetadata` and Schema.org JSON-LD.

### 4) 150,000 Multilingual Corpus (69.22MB)
- Deterministic generator `scripts/generate-i18n-corpus-150k.mjs` creating 150,000 unique 4-locale vocabulary entries.
- Resident core dictionary and O(1) lookup helper `corpus-lookup.ts`.
- Vitest integrity test `corpus.test.ts` passing 100%.
