- personalized state private by default;
- explicit publication choice;
- no secret/session/recovery values in URLs/analytics/share payloads;
- no meaningful WLD/WDX reward for raw view/share/open;
- official-domain consistency;
- bounded/preset text for first public-UGC pilots;
- reporting/removal and external-link policy.

Separate development/security/fraud/privacy QA is required before personalized public continuity, push/deep-link messaging, public prestige or open-ended public annotation. No security code was changed in this run.
