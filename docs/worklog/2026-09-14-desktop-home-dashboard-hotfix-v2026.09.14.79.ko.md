# 내부 작업기록 — 데스크톱 홈 대시보드 긴급 수정 v2026.09.14.79

## 발생
운영 데스크톱 화면에서 홈이 소개형 히어로부터 시작하고 지갑/빠른 바로가기 대시보드가 보이지 않는 현상을 확인했습니다.

## 원인
`MobileHomeView`에 `lg:hidden`이 적용되어 데스크톱 구간에서 핵심 기능 대시보드가 의도치 않게 완전히 숨겨지고 `page.tsx`의 소개형 데스크톱 영역만 노출되었습니다.

## 수정
대시보드 컨테이너의 데스크톱 숨김 breakpoint를 제거했습니다. 이제 대시보드가 화면 크기와 관계없이 홈 최상단에 유지되고 기존 데스크톱 소개/소식/로비 영역은 아래에 이어집니다. 데스크톱 숨김이 재발하지 않도록 회귀 테스트를 추가했습니다.
