## 중간 MID
- v754 최신 코드 백엔드를 실제 Test DB 복제본에서 비공개 기동하니 health/version은 통과했고 리그 익명 참가 요청은 401이었다. 그러나 `/api/v1/stocks/league/current` GET은 HTTP 500이며 공개 Test v752에서도 동일하다. 원인은 리그 조회가 비공개 관리자 역할 테이블 `user_roles`를 직접 조회하는데 앱 계정에 읽기 권한이 없기 때문이다. 참가 과정에서도 사유 보유 주식 원본 두 테이블 직접 조회 때문에 오류가 난다.
- 새 불변 전진 마이그레이션 274는 PUBLIC 실행 권한을 철회한 `SECURITY DEFINER` 최소 결과 판정 함수 `stock_league_is_admin(uuid)`와 `stock_league_portfolio_value(uuid)`를 추가하며 앱에는 함수 EXECUTE만 허용한다. 앱에 민감 원본 테이블 SELECT를 부여하지 않았다. 리더보드, 상위 이용자 조회, 참가 과정의 관리자 제외 및 가치 계산을 전부 제한 함수로 바꿨다. 기존 273 참가비 복식부기 경로·회원 잔액을 수정하지 않았다.
- RED→GREEN TDD 2/2. 실제 Test DB 복제본에서 앱 역할로 읽기 전용 테스트/ROLLBACK을 실행, 비공개 원본 테이블 차단, PUBLIC 실행 권한 차단, 허용된 결과 함수 실행·쿼리 정상 확인. 전체 타입검사, 빌드, 테스트(백엔드 1,237/프론트 1,255), 보안 검사 통과. 린트 오류 0, 기존 경고는 존재한다.
- 이전 격리 백엔드가 스케줄러·외부 통신 차단 상태에서도 SEO 크롤러 감사 경로를 실행하며 Discord DNS 오류를 기록해, 외부로 나가지 않도록 차단하고 비공개 유닛을 정지·환경 파일 삭제했다. 공개 Test·운영 서버는 유지했다.
