## 2. 영상 본편에서 직접 확인한 UI/UX 명칭

아래 명칭은 영상 약 4초·7초·10초·13초·16초에 보이는 화면을 판독한 것이다. `vs`는 비교 대상이며 서로 같은 컴포넌트를 뜻하지 않는다.

| 분류 | 영상 표시 용어 (한국어 / 영어) | 기획·구현 시 의미 |
| --- | --- | --- |
| 선택 입력 | 토글 vs 체크박스 / Toggle vs Checkbox; 라디오 vs 체크박스 / Radio vs Checkbox; 빠른 선택 칩 / Quick chips | 즉시 설정과 복수 선택 구분, 단일 선택과 다중 선택 구분, 권장 빠른 선택 |
| 레이아웃·이동 | 히어로 / Hero section; 벤토 그리드 / Bento grid; 카드 그리드 / Card grid; 스플릿 / Split screen; 페이지네이션 / Pagination | 첫 화면 정보 우선순위, 대시보드 카드 묶음, 반응형 콘텐츠 배열, 두 영역 분할, 목록 페이지 이동 |
| 날짜 입력 | 캘린더 / Calendar; 기간 선택 / Date range; 휠 피커 / Wheel picker | 날짜 입력·시작/종료기간 선택·터치 조작형 선택기 |
| 알림·레이어 | 토스트 vs 스낵바 / Toast vs Snackbar; 모달 등장 / Modal present; 모달 vs 바텀시트 / Modal vs Bottom sheet; 바텀시트 vs 드로어 / Bottom sheet vs Drawer; 푸시 / Push | 알림의 유지시간·행동, 대화상자/모바일 레이어 사용 맥락, 시스템 알림과 페이지 내 알림 구분 |
| 버튼·위치 | 플로팅 vs 하단 고정 / Floating vs Sticky; 액션 버튼 / Action button; 베지 버거 / Veggie burger | 떠 있는 버튼과 하단 고정 버튼, 중요 동작 CTA, 영상에서 명명한 메뉴 아이콘 형태 |
| 모션 | 페이드 업 / Fade up; 이즈 인 / Ease-in; 스프링 / Spring; 공유 요소 / Shared element; 확대 전환 / Zoom transition | 화면 전환·애니메이션 움직임을 정의할 때 사용하는 용어. 모션 감소 설정 존중 |
| UX 심리 | 앵커링 / Anchoring; 기본값 효과 / Default effect; 피크엔드 법칙 / Peak-end rule | 사용자 인지·결정에 관한 개념. 공통 UI 코드 컴포넌트가 아님 |
| 입력·콘텐츠 | 약관 동의 / Terms agreement; 플레이스홀더 / Placeholder | 동의 입력 및 명확한 입력 예시 |

작은 화면이나 잘린 카드에서 **일부만 확인한 항목**(100개 전수 검증에 포함하지 않음): 상단 탭(Top tabs), 스플래시 화면(Splash screen), 마스크 리빌(Mask reveal), 햄버거(Hamburger), 노브(Knob), 손실 회피(Loss aversion), 계단(Stairs). 확인되지 않은 나머지 명칭을 추측으로 채우지 않는다.

## 4. 코드 수정·승격 전 검증 기준

1. 적용하려는 패턴을 최신 `PROJECT_PLAN.md`, 통합 기획서 및 11월 18일 승인 디자인과 비교한다. 릴스 자체가 디자인 교체 승인이나 운영 변경 지시가 될 수는 없다.
2. 해당 Spring 웹 경로, 인증, 실제 API 및 DB 근거를 확인한다. 회원 정보·잔고·송금·알림 성공을 지어내지 않는다.
3. Gemini 등 다른 작업자의 수정과 충돌하지 않는 전용 브랜치·워크트리를 사용하고 시작/중간/종료 작업 기록을 남긴다.
4. PC·모바일·키보드·접근성·오류/로딩/빈 상태·EN/KO/JA/ZH/VI 언어 일치·전역 문의 버튼 중복 여부를 검증한다.
5. 구글/디스코드 로그인과 실제 API 정상·오류 데이터 송수신을 포함한 Test E2E, 보안·롤백 확인 이후에만 별도 무중단 운영 승격을 고려한다.
6. 제작자의 전체 사전을 실제 확보할 수 있게 되면 출처·사용 라이선스를 확인하고 **실제 100개를 독립 대조한 후 새 버전**을 발행한다. 지금은 전수 확보로 표기하지 않는다.
