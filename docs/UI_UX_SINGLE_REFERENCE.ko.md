## 4. UI 정밀 QA·종결 규칙

문제별로 **경로, 화면 폭, 언어, 로그인/권한, 기대 화면, 실제 화면, 비교 이미지, 프론트 SHA, API/백엔드 출처, 재현 방법, 담당자, 중요도, 관찰 일시, Test와 운영 검증 결과**를 남긴다. `OPEN`, `BLOCKED`, `TEST_VERIFIED`, `PRODUCTION_VERIFIED`를 명확히 구별한다.

겉모양 동일 = 기능 정상 아님. 실제 API 요청·응답과 저장 상태까지 확인하고 금융은 안전한 Test 데이터로 원장 대조. 401/403/404/429/5xx, 세션 만료, API 장애, 오프라인, 재연결, 큰 정수, 5언어 및 모바일 경계값을 포함한다. 소스 수정 시 별도 브랜치·PR, 검토, 정확 SHA 테스트, 독립 Test 검증, 무중단 운영승격/롤백 규정 준수. 금융·보안·관리자 권한 보호 규칙은 UI 변경을 이유로 해제하지 않는다.
