# DESIGN.md — 월덕 머니버스 웹 (한국어 보조본)

**상태:** 로컬 소스에서 추출·대조한 디자인 계약. Stitch 클라우드 프로젝트 구성이나 전체 화면 구현 완료를 뜻하지 않음.
**기준:** 2026년 11월 18일 승인 디자인. 최신 통합기획·Spring MVC/Thymeleaf 소스가 이전 초안보다 우선.
**근거:** `docs/planning/NOV18_DESIGN_GLOBAL_I18N_CHAT_AUTHORITY_v2026.11.20.1.ko.md`, `docs/FRONTEND_AND_UI_MASTER_GUIDELINES_20261119.md`, `spring-backend/src/main/resources/static/css/mv-theme-nov18.css`, `docs/design/all-pages-v2026.11.18.12/previews/`.

## 1. 시각 원칙
프리미엄 게임 경제·은행 웹 UI. 심해 네이비 배경, 짙은 카드, 단일 브랜드 보라 강조, 명확한 수치 위계. 비회원·회원·관리자 화면에서 동일한 공통 셸 사용. 장식보다 금융 수치와 실제 출처의 명확성이 우선.

## 3. 타이포그래피·컴포넌트
- 본문 Pretendard 및 시스템 폴백(`--mv-font-sans`), 금융 수치 JetBrains Mono(`--mv-font-mono`). 정확한 정수·단위·천 단위 구분 유지.
- 카드 기본 `#151D32`, 모서리 반경 8/12/16px, 버튼 44px 이상. 로딩·빈 상태·실패·성공을 명확히 구분.
- 공식 로고/파비콘·공통 헤더·PC 사이드바·모바일 내비게이션 일관성 유지. 관리자/회원/문의의 권한을 UI 텍스트로만 판단하지 않음.
- 전 페이지 문의/채팅 플로팅 56×56px 버튼 1개; 모바일 안전영역 준수, 클릭 가능한 요소 가림 금지.

## 4. 반응형·접근성·언어
- 320/360/390/430/768/1024/1440/1920px, 200% 확대에서 화면 깨짐·가로 넘침·중첩 없이 동작 검증.
- 키보드 초점, 명도 대비, 스크린리더 의미, 움직임 감소, 오류 상태 및 터치 영역 확인.
- 영어 기본(en), 한국어 두 번째(ko), 일본어(ja), 중국어 간체(zh), 베트남어(vi); 사용자의 저장된 수동 선택을 자동감지보다 우선.

## 5. 기술·실데이터·보안
- 실제 서비스는 Java Spring Boot MVC + Thymeleaf 웹 유지. Stitch 디자인 산출물이 런타임 대체물이 되어서는 안 됨.
- 계좌/지갑/시세/거래/관리자 정보는 인가된 API·DB에서만 조회. 목업 수치·가짜 차트·가짜 전송 성공 금지.
- 관리자 RBAC, 인증 세션, CSRF, 원장 무결성 보호. 외부 디자인 서비스에 시크릿·실사용자 데이터·운영 화면 원본 업로드 금지.

## 6. Stitch 사용 절차
1. 최신 통합기획·11월 18일 시안·이 문서 확인. 격리 작업 브랜치에서 Spring CSS/HTML 기준으로 `stitch-extract-design-md` 스킬 사용.
2. 추출 결과를 승인 색상·컴포넌트·언어·로고와 대조하고 차이를 기록.
3. Stitch MCP를 별도로 연결하고 외부 업로드 승인을 받은 뒤에만 **비식별/비밀정보 제거 시안**을 Stitch에서 생성·수정.
4. 승인된 시안을 Spring/Thymeleaf에 반영하고 독립 Test에서 실제 API·권한·5개 언어·반응형·롤백 QA.
5. QA 미통과 또는 Test 불가 시 운영 승격 금지.

**미완료:** Stitch MCP 연결·원격 시안 생성·180개 실제 화면 검증·실제 계정 E2E·Test/운영 배포.
